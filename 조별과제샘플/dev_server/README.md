# 개발용 주차 서버 — 이 폴더 **하나만** 있으면 돈다

```
빌드   c++ -std=c++11 -O2 -o srv server.cpp
실행   ./srv
화면   http://127.0.0.1:9900/
```

🔴 **`../server/` 를 참조하지 않는다.** 하나라도 밖을 가리키면 "단독"이 깨진다.
확인: `grep -rn '#include "\.\.' .` → **아무것도 안 나와야 한다.**

---

## 고칠 파일은 **`lot.cpp` 하나다**

```cpp
lot.spot("A1").sensor("P1","A1").actuator("P1","LD");   // 조립
lot.label("P1","LD","안내등");                           // 표시 이름
lot.control("P1","LD").toggle();                         // 화면 조작 UI
```
설명은 `docs/net/GUIDE-sample.md` 에 있다. **이 파일은 따라 치는 것이고 그 문서는 읽는 것이다.**

### 다 만들면 운영으로 옮긴다
`lot.cpp` **하나만** `조별과제샘플/server/` 로 복사하면 된다 — **그것이 유일한 이음매다.**
```
sh net/sync_check.sh   → 두 트리 모두에서 lot.cpp 가 컴파일되는가
```
🔑 공개 API(`parking.h`)가 갈리면 **여기서 빨강**이 난다. 사람이 안 세도 된다.

## 포트 — 운영과 **일부러** 다르다

```
dev  : 웹 9900 · 아두이노 9991 · 카메라 5500     ← 기본값. 손잡이 없이 그냥 뜬다
운영 : 웹 9990 · 아두이노 8888 · 카메라 8911
```
🔴 **근거는 실패 방향의 비대칭이다:**
```
dev 값으로 운영에 쓰면  → **안 붙는다.** 즉시 드러난다
운영 값으로 dev 에 쓰면 → 🔴 **운영에 붙는다.** devid 가 겹치면 남의 노드를 쫓아내고,
                          **로컬에서는 멀쩡해 보인다**
```
> **틀렸을 때 조용한 쪽을 기본값으로 두지 마라.**

바꾸려면: `./srv --port-web=9901 --port-ardu=9992 --port-cam=5501`
⚠ 셋이 서로 겹치면 **어느 둘인지 이름으로 말하고 안 뜬다.**

### 아두이노도 같이 맞춰야 한다
`조별과제샘플/ardu/Config.h` 의 **`SERVER_IP` 와 `SERVER_PORT` 를 한 벌로** 본다 —
포트만 고치고 IP 를 안 고쳐서 헤매는 일이 실제로 있었다.

## 🔴 운영판에서 **뺀 것** (있었는데 없앤 것)

| 뺀 것 | 왜 |
|---|---|
| 자가검증 5파일 **2,300줄** | 배포 관문이지 디버그 도구가 아니다 |
| 소크 요약 (60초마다 **1,329자** + 종료 총평) | 운영 관측. **콘솔에서 못 읽고** 프레임 로그를 밀어낸다 |
| 기계용 `=== INSTANCE logfmt=…` 경계 줄 | monitor 가 한 파일에 쌓인 인스턴스를 자르려고 읽는 줄. **여기선 자를 것이 없다** |
| 계약값 덤프 2줄 (**289자·188자**) | arduino·monitor 가 계산에 쓴다. 개발자는 안 쓴다 |
| 로그 **파일** (`--log=` · `open_log`) | 출력은 stdout 하나다. 남기려면 `./srv > dev.log` |
| rid 커서 · 노드 대장 영속 | 🔴 `~/parking-logs` 를 **아예 안 건드린다.** 재기동하면 잊는다 — **개발엔 그게 낫다** |
| `exe_path` · `iso8601` · `open_log` · `default_log_path` · `lock_log_exclusive` | 위 것들에 **딸려 죽었다.** 🔑 컴파일러가 `-Wunused-function` 으로 알려 줬다 |

**10,158줄 → 7,681줄 (−24%)**

### ⚠ 그런데 `data_log.json` 은 **아직 쓴다** — 처음에 "영속 전부 뺐다"고 적었다가 고쳤다
```
실행 폴더에 `data_log.json` 이 생긴다 (주차 기록 · 명세 §9)
🔑 그건 **관측이 아니라 제품 기능**이다. `~/parking-logs`(운영 관측)와 다른 것이다
```
> **"전부"라고 쓰기 전에 세라.** 기동 로그가 `data_log.json 이 없어 빈 배열로 만들었다` 라고
> 말하고 있었는데 나는 "영속 전부 뺐다"고 적었다. **한 줄 위에 반증이 떠 있었다.**

## ⚠ **못 뺀 것** (빼려고 봤지만 남긴 것)

```
metrics.h · ledger.h  →  `nodes.h`·`uplink.h` 와 얽혀 있다
```
🔴 빼려면 **전선 코드(상행 파서)를 고쳐야 하고, 그러면 두 트리의 전선이 갈린다.**
**그게 가장 위험한 갈림이다.** → **호출만 끊어 출력을 없앴다.** 코드는 남고 콘솔은 조용하다.

## ⚠ 아직 **안 넣은 것** ("뺐다"가 아니다)

```
index.html — 🔴 web-engineer 가 넣는다. 이 폴더에서 그 파일만 web 소유다
             🔑 **갱신 주체와 소유자를 갈라 놓으면 반드시 낡는다**
             그때까지 `GET /` 는 404 다. 기동 로그가 그렇게 말해 준다
```
