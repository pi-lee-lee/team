# 개발용 주차 서버 — 이 폴더 **하나만** 있으면 돈다

```
macOS/Linux   c++ -std=c++11 -O2 -o srv server.cpp   →  ./srv
Windows(VS)   dev_server.sln 을 열고 F5              →  콘솔 창이 뜬다
화면          http://127.0.0.1:9900/
```

## 🔴 Visual Studio 에서 "빌드 오류" 가 나면 — 원인이 코드가 아닐 수 있다

```
이 서버는 **유니티 빌드**다 — `server.cpp` 가 나머지를 `#include` 로 끌어온다.
`lot.cpp` 도 그중 하나다.
🔴 VS 가 폴더의 `.cpp` 를 **자동으로 추가하면 `lot.cpp` 가 따로 컴파일된다**
   → `buildLot`·`onTick`·`onCmdResult` 가 **두 번 정의되고 링크가 깨진다**
🔑 하필 `lot.cpp` 는 **혼자서도 문법이 통과하도록 일부러 만들어져 있다**
   (편집기가 타입을 알아야 빨간 줄이 안 뜬다) → **VS 가 진짜 소스로 오해한다**
```
✅ **동봉한 `dev_server.vcxproj` 가 그것을 막는다** — 컴파일 항목은 `server.cpp` **하나뿐**이고
`lot.cpp` 는 `<None>` 이라 **보이지만 컴파일되지 않는다.**
🔑 그래서 **이 프로젝트 파일은 낡지 않는다** — 컴파일 항목이 영원히 하나다.
헤더를 몇 개 더 만들어도 `server.cpp` 가 `#include` 하면 그만이다.

### ⚠ `/utf-8` 을 빼지 마라 — **조용히 틀린다**
이 소스는 BOM 없는 UTF-8 이고 안내 문구가 한글이다.
빼면 MSVC 가 시스템 코드페이지(CP949)로 읽어 문자열이 깨지는데 **컴파일은 그대로 통과한다.**
🔴 **빌드 로그로는 절대 못 잡고 브라우저 화면에서 처음 보인다.**

### ⚠ 우리는 Windows 기계가 없다 — **빌드를 실측하지 못했다**
```
✅ 잰 것 : POSIX 전용 헤더가 **전부 `#ifdef _WIN32` 밖으로 안 샌다**(0건)
          MSVC 에 없는 이름(`ssize_t`·`strcasecmp`·`__attribute__`…) **0건**
          시각 함수는 `GetTickCount64`·`GetSystemTimeAsFileTime` 로 갈라져 있다
🔴 못 잰 것 : **실제 `cl.exe` 빌드.** 그래서 "된다"고 쓰지 않는다
```
**빌드가 여전히 안 되면 오류 메시지의 `파일:줄`을 알려 달라.** 추측 대신 그것으로 고친다.

🔴 **`../server/` 를 참조하지 않는다.** 하나라도 밖을 가리키면 "단독"이 깨진다.
확인: `grep -rn '#include "\.\.' .` → **아무것도 안 나와야 한다.**

## 고칠 파일은 **`lot.cpp` 하나다**

```cpp
lot.spot("A1").sensor("P1","A1").actuator("P1","LD");   // 조립
lot.label("P1","LD","안내등");                           // 표시 이름
lot.control("P1","LD").toggle();                         // 화면 조작 UI
```
설명은 `docs/net/GUIDE-sample.md` 에 있다. **이 파일은 따라 치는 것이고 그 문서는 읽는 것이다.**

### 다 만들면 운영으로 옮긴다
`lot.cpp` **하나만** `조별과제샘플/server/` 로 복사하면 된다 — **그것이 유일한 이음매다.**
```
sh net/sync_check.sh   → 두 트리 모두에서 lot.cpp 가 컴파일되는가
```
🔑 공개 API(`parking.h`)가 갈리면 **여기서 빨강**이 난다. 사람이 안 세도 된다.

## 포트 — 운영과 **일부러** 다르다

```
dev  : 웹 9900 · 아두이노 9991 · 카메라 5500     ← 기본값. 손잡이 없이 그냥 뜬다
운영 : 웹 9990 · 아두이노 8888 · 카메라 8911
```
🔴 **근거는 실패 방향의 비대칭이다:**
```
dev 값으로 운영에 쓰면  → **안 붙는다.** 즉시 드러난다
운영 값으로 dev 에 쓰면 → 🔴 **운영에 붙는다.** devid 가 겹치면 남의 노드를 쫓아내고,
                          **로컬에서는 멀쩡해 보인다**
```
> **틀렸을 때 조용한 쪽을 기본값으로 두지 마라.**

바꾸려면: `./srv --port-web=9901 --port-ardu=9992 --port-cam=5501`
⚠ 셋이 서로 겹치면 **어느 둘인지 이름으로 말하고 안 뜬다.**

### 아두이노도 같이 맞춰야 한다
`조별과제샘플/ardu/Config.h` 의 **`SERVER_IP` 와 `SERVER_PORT` 를 한 벌로** 본다 —
포트만 고치고 IP 를 안 고쳐서 헤매는 일이 실제로 있었다.
