## 🔑 사용자는 센서를 물리적으로만 달았다 — 코드에 없었다

포트를 잡지 않고 값으로 갈랐다:


## 무엇을 고쳤나 — 등록 줄은 한 글자도 안 바뀐다

```
readB1 : digitalRead(9) == LOW   →   초음파(Trig 11 · Echo 10)
setup  : pinMode(9, INPUT_PULLUP) → pinMode(11, OUTPUT); pinMode(10, INPUT);
등록   : node.sensor("B1").on(readB1)   ← 불변
```
🔑 그것이 이 설계의 값이다 — 함수 내용만 갈면 그 자리의 센서 종류가 바뀐다.
이름이 계약이고 함수가 구현이다. 그 문장을 코드 주석에 적었다.

⚠ 복사를 골랐다(공통 함수로 뽑지 않았다). 근거: 둘까지는 핀이 함수 안에 그대로 보여서
더 읽기 쉽고, 축을 늘리지 않는다. 셋 이상이면 아파진다는 것을 주석에 적었다.
