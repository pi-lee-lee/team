## 2. 🔴 오늘 확정된 것

### ① 두 축은 독립이다 — **한 창 안에서 다르게 움직인 직접 증거**
```
창 AB : 70.0분 · esprst **0.86/시간** · 손상 0.29%
창 AD : 86.6분 · esprst **5.54/시간** · 손상 0.31%
→ 손상은 그대로, 결합만 **6.4배**
```
⚠ **날값(1→8, 10→13)으로 보면 "둘 다 늘었다"로 보인다. 시간당·분모당으로 정규화해야 갈린다.**
⚠ `n` 이 1 대 8 이다. **6.4배는 표본 하나에 크게 흔들린다.** 귀속은 안 했다(축이 넷 이상 실렸다).

### ② 🔴 UART 손상은 **ESP 링크 층** 이다 (00:2x · 전수)
```
`[TX]`(장치가 만든 프레임 · USB) : 125,754 중 손상 **0**
`[AT]`(ESP 가 되돌려준 것)       : 125,205 중 손상 **593** (0.474%)
```
**같은 USB · 같은 리더 · 같은 파일.** 다른 것은 바이트가 지나온 경로뿐이다.
🔑 **12만 표본 손상 0 이 이 결론의 힘이다.** ESP 링크 개선으로 없앨 수 있는 층이다.

### ③ `occ` 비트 배치 (n=6) — **실측 검증됨**
```
A1 **0x20** · B1 **0x10** · LD **0x08** · LC **0x04** · DR **0x02** · L2 **0x01**
(모듈 idx i → 비트 n-1-i · `n` 이 바뀌면 전부 바뀐다)
```

### ④ 🔴 교차 불변식 — **다음 세션의 주 판정자다**
```
`(occ & 0x10) != 0`  ==  `(occ & 0x08) != 0`      (B1 = digitalRead(13) · LD = 명령 에코)
🔑 경로가 다른데 같은 물리량이다 → 갈리면 둘 중 하나가 거짓말이다
✅ 교정됨 : 창 AD(옛 판 · 훅 없음) **어긋남 4,137 / 4,203**(손상 21 제외) ← **발화 확인**
🔮 새 판 예측 : **0**
```
**도구**: `python3 monitor/occ_period.py <로그>` — 주기 검정 + 불변식 + 비트 해독.
⚠ **적용 범위: LED 되읽기 훅이 있는 판(창 AE~)만.** 옛 로그에 돌리면 4,137 이 나오는데 **정상이다.**
