**발행 00:1x — 굽기·배포 *전* 에 쓴다.** ⚠ **결과를 보고 해석을 고치면 사전 등록이 무의미해진다.**

## 0. 🔴 t0 와 순서
```
굽기 → (대기) → **배포** → 그때 연다
t0 = **배포 완료 시각** (굽기 리셋 아님 — 서버가 자극원이다)
⚠ 내 탭 개방도 DTR 리셋이다 → **개입 중 가장 나중 것 뒤** 가 실질 t0. 둘 다 값으로 적는다
⚠ 첫 `[CNT]` 줄은 부팅 60초 기여분(§7.174)
```


> ### **판정 : 🔴 장치가 **8888** 에 실제로 붙는가. `CIPSTART` 성공 → 등록 완료.**
> ### **나머지 표지는 다 *같아야* 한다 — 달라지면 그게 신호다.**

### 🔴 새 표지 하나 · ❌목록에 하나 추가
```
🔴 ✅ **`[NET] 대상 192.168.35.21:8888`**        ← **새 줄. 부팅 맨 앞쪽**
🔴 ✅ `AT+CIPSTART="TCP","192.168.35.21",**8888**`  ← **따옴표 없이 8888**
🔴 ❌ **`9991`** — **어디에도 0건**
```

### ⚠ **소스를 읽어 포트를 짐작하지 마라**
```
소스(샘플 진실) : `SERVER_PORT = "9991"` (dev · 기여자 기본값)
구운 것         : **빌드 플래그로 8888 덮어씀**
🔑 **`[NET]` 줄이 칩의 진실이다**
```
**사유(arduino)**: 기본이 dev 인 것은 **안전** 때문이다 — 8888 이 기본이면 **dev 보드가 조용히 운영에 붙어** 남의 노드를 쫓아낸다. **로컬에선 멀쩡해서 안 보인다**(§*"결함이 드러나는 단계가 멀면 그 사이가 낭비"*).

### 🔴 그리고 **그 플래그가 한 번 틀렸다 — 내가 볼 자리를 알려 왔다**
```
🔴 첫 시도 : `…,**"8888"**`  ← **따옴표가 들어가 AT 가 깨진다**
✅ 고친 뒤 : `…,**8888**` · `9991` 문자열 0건
```
> ### **빌드 성공은 플래그가 먹었다는 뜻이 아니다. 그대로 구웠으면 접속 실패를 *서버 쪽* 에서 쫓았을 것이다.**
🔑 **그래서 `[AT]` 에코에서 *따옴표 유무* 를 본다** — arduino 가 또 틀렸으면 거기서 보인다.
**남이 자기 실패 모드를 알려 주면 그것을 검사 항목으로 만든다.**

## 3. 🔴 **거동 변화 둘 — 결함으로 읽지 않는다** (미리 박는다)
```
① 실물 칸에는 `M`(시뮬 한 걸음)이 **안 먹는다** → **`result=5`**
   ⚠ **설계다.** `result=5` 를 보고 "거절이 늘었다"로 쓰지 않는다
🔴🔴 ② **자리 값이 *스스로 움직인다*** — A1 훅이 시뮬이다
   **주기 24초 · `slotNo` 기반이라 재현 가능** → `S` 의 occ 칸이 24초 주기로 오간다
   ⚠ **이건 정상이다. 고장으로 읽지 마라**
🔴 ③ **B1 은 LED 를 되읽는다** → `srv.send("P1","LD",1)` 하면 **자리가 "찼다"로 바뀐다**
④ 명령 LED 는 **핀 13(내장 LED)** — **보드에서 눈으로 보인다**
```
### 🔴🔴 **②가 루트 예고와 *정반대* 였다**
```
❌ 루트 : "자리 A1 이 **명령 없이는 안 움직인다.** 시뮬의 자율 움직임이 **없다**"
✅ 정본 : **자리 값이 스스로 움직인다.** A1 훅이 시뮬이고 **주기 24초**다
```
> ### **그대로 박았으면 24초 주기로 움직이는 것을 보고 *"결함"* 으로 냈다.**
> ### **예고를 반대로 받으면 정상이 이상으로 보이고, 그 방향의 오판은 조사를 부른다.**
🔑 **`주기 24초 · slotNo 기반이라 재현 가능` 이 좋은 표지다** — **셀 수 있고 예측할 수 있다.**
**주기가 24초가 아니면 그때가 물음이다.**

### 🔴 그리고 arduino 가 **셀 수 있는 값**을 줬다 (00:1x · 굽기 보고)
```
A1 훅 = `(slotNo % 20) < 10`  ·  슬롯 **1.2초** × 20 = **24.0초 주기** (12초 찼다 / 12초 비었다)
🔑 `slotNo` 는 **부팅부터** 세므로 재현 가능하다. **무작위가 아니다**
```
```
`occ` 비트 (n=6) :  A1 = **0x20**(비트5)  ·  B1 = **0x10**(비트4)
🔮 예측 : **`0x20` 비트(A1)** 가 **24초 주기**로 섰다 내린다
🔴 `srv.send("P1","LD",1)` → B1 이 LED 를 되읽어 **`0x10` 비트가 선다**
   🔑 **그 전이가 "명령 왕복이 *자리 값까지* 닿았다"의 증거다**
```

#### 🔴🔴 **내 첫 예측이 틀렸다 — 창 AD 자료로 굽기 전에 잡았다**
```
❌ 첫 예측 : "`occ` 가 **`20` ↔ `00`** 을 오간다"
🔴 실제    : **액추에이터를 켜면 하위 비트가 같이 선다** → `2F ↔ 0F` 가 된다
✅ 고침    : **`0x20` 비트만 마스크해서** 잰다. **필드 전체를 비교하지 않는다**
```
**근거 — 창 AD 실측(내 로그):**
```
부팅~22:42:32  occ `00`
🔴 22:42:34~00:07  occ **`0F`** 로 86분 내내 고정  (표본 4,146)
   `0F` = LD+LC+DR+L2 = **묶음이 켠 액추에이터 넷**. 아무도 안 껐으니 계속 서 있다
```
> ### **필드 전체로 비교했으면 전이가 하나도 안 잡히고 "주기가 없다 → ❌" 를 냈다.**
🔑 **비트 배치를 알아낸 것이 이것을 막았다** — arduino 의 `A1=0x20 · B1=0x10` 에서 역산했다:
```
n=6 · 모듈 idx i → 비트 (5-i)
A1 **0x20** · B1 **0x10** · LD **0x08** · LC **0x04** · DR **0x02** · L2 **0x01**
```
> ### **판정선 : 주기가 **24.0±2초** 면 ✅ · 벗어나면 물음(슬롯 길이나 훅이 바뀐 것)**

### 🔴🔴 **교차 불변식 — 이 창의 가장 강한 판정자다** (arduino 가 소스에서 냈다)
```
`0x10` B1 = **센서 훅이 `digitalRead(13)` 으로 읽은** 값
`0x08` LD = **라우터가 명령 인자에서 만든** 에코
🔑 **경로가 완전히 다른데 같은 물리량(핀 13)이다**
```
> ### **불변식 : `(occ & 0x10) != 0` 과 `(occ & 0x08) != 0` 은 **항상 같아야 한다.****
> ### **갈리면 둘 중 하나가 거짓말하는 것이다 — 그게 진짜 신호다.**
⚠ **한 프레임 안에서 어긋날 수 없다** — `espRead`(명령) → `readSensors`(B1) → `statusTick`(S) 순서가 보장된다.

### 🔴 정당한 예외 하나 — **주입(`T`)이 훅을 이긴다** (arduino · 소스)
```c
readSlotSensor(i):
  ① if (testArmed && (ovrActive & bit)) return 주입값;   // 🔴 **주입이 먼저다**
  ② if (srcReal & bit)                  return 훅;        //    훅은 그 다음
```
**→ B1 에 주입이 걸리면 B1 비트는 LED 가 아니라 주입값이다. `B1 != LD` 가 *정당* 하다.**

**✅ 도구에 넣은 방식 — `tmask` 파싱이 아니라 `T` 프레임 유무로 판별한다**
```
🔴 `tmask` 필드 위치를 **모른다** — 내 로그 전체에 **한 번도 안 나왔다**(양성 대조 0)
🔴 그리고 **필드 수로는 못 잡는다** : ACK 이 뒤에 붙어 필드가 이미 **7/11/15/19/23** 으로 변한다
✅ 무장은 `T` 프레임으로만 된다 → **`T` 가 0건이면 예외 구간이 없다**
```
**검증**: 창 M **`T` 1,111건**(`T,17,S,A4,1,69`) · 창 AD·AC **0건**(`G` 만).
🔑 **창 AD 의 4,146 어긋남은 `T` 0건 구간의 값이라 교정값으로 깨끗하다.**

✅ **답 받았다 (arduino · 소스 `Modules.h buildStatus`)**
```
S,<seq>,<occ>,<res>,<up>,<dev>[,<tmask>],<ck>   ← **맨 끝 · ck 앞**. 🔑 `occ` 는 언제나 필드 2
```

**→ 내 `occ` 추출은 안전하다.** 그리고 **프레임 단위로** 예외를 적용한다:
```

   무장 중이어도 **A1 만 주입**했으면 B1↔LD 는 **그대로 검사** 한다
⚠ 무장했는데 아무 칸도 안 주입하면 `tmask=0` 인 채로 **필드는 나온다**
```

### 🔴🔴 그리고 **필드 수(`%4`)를 판별자로 쓰면 안 된다 — 실측으로 반증했다**
```
모형 : 평소 7+4k(%4==3) · 무장 8+4k(%4==0)
🔴 실측 : 전 로그에 `%4` 가 **0/1/2** 인 S 프레임 **322건** — **전부 UART 손상**이다
```

> ### **arduino 가 "`%4` 는 교차 확인용만"이라고 경고했고, 실제 원인은 그가 든 LF 소실보다 나빴다.**
✅ **도구는 ①형식 검사 → ②`8+4k` 일 때만 tmask → ③`&0x10` 만 제외** 로 짰다.
🔑 **주 판별자는 `T` 프레임 유무다.** `%4` 는 교차 확인으로만 쓰고, **어긋나면 `T` 쪽을 믿는다.**

**✅ 그리고 이 검사는 이미 교정됐다 — 발화하는 것을 확인했다:**
```
🔴 창 AD(옛 판 · 되읽기 훅 없음) : **어긋남 4,137 / 4,203** (손상 21건 제외) ← **예상대로다**
```

🔑 **"항상 초록인 검사"가 아니라는 것을 *알려진 양성 사례* 로 확인했다.**
**옛 판 4,146 ↔ 새 판 0 — 이 대조 자체가 되읽기 훅이 도는가의 측정이다.**

### 📌 `occ` 기대표 (arduino 가 소스에서 만들었다 · 내 역산과 일치)
| 비트 | 무엇이 만드나 | 언제 바뀌나 |
|---|---|---|
| `0x20` A1 | **시뮬 훅** `(slotNo % 20) < 10` | **24.0초 주기**(12초 1 / 12초 0) |
| `0x10` B1 | **LED 되읽기** `digitalRead(13)` | 🔴 **LD 명령 때만** |
| `0x08` LD | 에코 (`arg != 0`) | LD 명령 때 |
| `0x04` LC | 에코 (`arg != 0`) | ⚠ **7자리를 보내도 `1`** 이다 |
| `0x02` DR | 에코 (`echoIs(arg == 1)`) | 🔴 **열기(1)만 1. 닫기(2)는 0** |
| `0x01` L2 | 에코 (`arg != 0`) | L2 명령 때 |

⚠ **두 축이 독립이라 섞여도 마스크로 갈린다**:
**A1(0x20)은 `slotNo` 만 본다 — 명령과 무관** · **B1+LD(0x18)은 명령에만 반응 — 명령 없으면 안 움직인다**
⚠ **`occ` 가 늘 `00` 이면 ❌** — 그게 직전 판의 모양이었다(`srcReal=0` 이라 훅이 아예 안 불렸다).

### ✅ 🔴 **직전 판과의 전후 대조가 이미 섰다** (arduino · 예고 안 했던 소득)
```
직전 판 캡처 : `S,0,**00**,00,9,P1,3B`   ← 자리가 **늘** 비어 있었다
이번 판     : `S,0,**20**,00,9,P1,39`   ← 0x20 = A1
```
> ### **미측정이던 `A10`(센서 훅 사슬이 도는가)이 이 한 값으로 닫혔다.**
🔑 **예고 안 한 값인데 대조가 선 이유는 *직전 판 캡처를 파일로 남겨 뒀기* 때문이다.**
**§*"파괴적 계측 전에 다른 계층에서 스냅샷을 떠라"* 가 여기서 값을 냈다** — 그때는 몰랐던 용도로.
> ### **둘 다 "고장처럼 보이는 정상"이다. 안 적어 두면 그 자리에서 없는 결함을 만든다.**
🔑 오늘 `penddrop`·`hwrst 0/0`·`[LC] 부재` 에서 반복해서 겪은 형태다.

## 4. 🔑 **새 계측기가 하나 생겼다 — 사람 눈**
