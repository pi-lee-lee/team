# 사전 등록 · 창 L — **가상 O* 모듈 + G 명령** (2026-08-19)

🔴 **자료 전에 쓴다.** 굽기 전이고 캡처도 시작하지 않았다. **실행 기록칸은 측정 후에만 채운다.**

## 0. 축 — **경계가 *둘로 벌어진다***
```
① arduino 굽기 : 가상 O* 모듈 · **`n` 10 → 12**
② socket 배포  : G 명령 (`3c9e724`) — 🔴 **굽기 *뒤* 에 온다. 몇 분 벌어진다**
```
🔴 **`t0` 는 ②(서버 배포) 뒤로 잡는다. 그 사이 "장치만 바뀐 구간"은 판정에 안 쓴다.**
**판정문에 둘을 갈라 적고, 내 계측기로 못 가르는 것은 "귀속 불가"로 쓴다.**
⚠ **그리고 web 이 화면에 150ms 티커를 돌리고 있다 — 부하 축이 하나 더 있다**(원장 7.158).

## 1. 🔴🔴 **`>=64B` 는 이제 *다른 것* 을 센다 — 옛 창과 나란히 놓지 마라**
```
창 G/H/I  `>=64B` = **S 자체가 크거나** ACK 동봉    ← 두 경로
창 J       hex 이후 — 사실상 ACK 동봉만
창 K 이후  **ACK 동봉 하나뿐**   (S 실측 21~22B · 등록 프레임만 122B)
```
> ### **같은 이름의 지표가 세 창에서 다른 모집단을 가리킨다.**
> ### **비교는 `위험대역 진입률` 로만 한다** — 그 정의는 안 바뀐다(*"전체 거래 중 그 대역에 든 비율"*).
🔴 **`>=64B` 절대값을 창 J 이전 값과 같은 표에 넣으면 틀린다.**
⚠ **대조값**(전부 **주입 구간** 기준): 창 G(1차) 87.5% · 창 H 59.0% · 창 I 92.1% · 창 J 87.0%.
**창 K 무자극 1.3% 는 등록 프레임 1건이라 판정에 못 쓴다.**

## 1.5 🔴 **`n` 이 10 → 12 다 — 패딩 검증이 꺼진다**
```
n=10 → 폭 3, 패딩 2비트 **있음**       n=12 → 폭 3, 패딩 **0**  🔴 방어 없음
```
**`폭불일치` 가 잡을 수 있는 범위가 좁아졌다.** 🔴 **그 계수를 "안전하다"의 근거로 쓰지 마라.**
⚠ **창 J §10.4 에서 미리 적어 둔 그 조건이 이번에 실제로 성립한다** — *"모듈 수가 12·16 이 되면
이 검사는 조용히 무력해진다."* **예측이 아니라 지금 상태다.**

## 1.6 ⚠ 못 보는 것 — **미리 "미확인"으로 적는다**
**`tmask`(f[6])** — socket 이 고쳤으나 **확인 못 했다. 장치가 그 칸을 안 보낸다.**
**selftest 로 만들면 *시험만의 경로* 가 되므로 안 만들었다**(socket 판단).
🔴 **내 창에서도 못 본다. "미확인"으로 두고 밟으려 하지 않는다.**

## 1.7 굽기 뒤 새로 볼 것 (arduino 계산값 대조)
```
· `OBV` 두 줄이 등록에 뜨는가 (E1 · X1)
· occ 비트 **10 · 11** 이 움직이는가 — 차단봉 상태 에코
· 등록 **145B · 13줄** · S **21B** 가 실측과 맞는가
```

## 2. 분모 규칙 — **`0` 을 읽기 전에**
```
`치유 <재하달>/<검사>`   🔴 **`검사 0` 이면 `0/0` 이다 — "건강"이 아니라 "안 돌았다"**(원장 7.157)
`예약미해독 N`          ⚠ **`0` 이 정상이 아니다** — 세션마다 1쯤 나오는 것이 설계다(socket)
`pendfill` / `bigfill`  0 이면 `penddrop`·`bigdrop` 의 0 은 아무 뜻도 없다
`okstream`             ❌ 판정에 쓰지 않는다 — 탐지 총수다. `oklost` 가 그 자리
```

## 3. 예측
| # | 예측 | 반증 |
|---|---|---|
| **P1** | 자극이 붙으면 **진입률이 창 J(87.0%) 수준** | 크게 낮으면 O*/G 가 배치 구성을 바꾼 것 |
| **P2** | `>=64B` 대역 T2 **0건** — ⚠ **분모 30 미만이면 판정 안 함** | 1건이라도 나면 원문을 연다 |
| **P3** | `치유` 분모 > 0 (검사가 돈다) | `0/0` 이면 **배포 회귀** — 즉시 socket 에 알린다 |
| **P4** | 생존 신호가 **60초마다 끊김 없이** | 끊기면 그 시각이 탭이 죽은 시각이다(원장 7.156) |
| **P5** | 세 갈래 T2 합계 = 원시 T2 계수 | 어긋나면 내 도구가 또 분류를 흘린다(원장 7.125) |

## 4. 넘지 않을 것
```
❌ `>=64B` **절대값**을 창 J 이전과 비교하지 않는다 (§1)
❌ 자극 부재 구간과 주입 구간을 같은 분모에 묶지 않는다 — **구간 이름 없는 비율은 인용 금지**(원장 7.154)
❌ `0/0` 을 건강으로 읽지 않는다
❌ web 티커를 빼고 읽는다 — **부하 축이다**
```
