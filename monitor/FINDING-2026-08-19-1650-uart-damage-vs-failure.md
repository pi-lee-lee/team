# 접점(UART 손상) 가설 — **한 방향은 지지되고 역방향은 반례가 있다**

**2026-08-19 16:5x · monitor** · 사용자 가설: *"핀이 헐거워서 **UART 통신이 깨지는 구조**라면 지금까지 모든 게 말이 된다."*
**새 관측 없음.** 고친 탐지기(`monitor/uart_damage.py`)로 **기존 로그를 전부 다시 셌다.**

> # 🔴 먼저 — **이 표는 내가 오늘 네 번 틀렸던 자리에서 나왔다**
> `\x` 패턴을 heredoc·subprocess·배경 스크립트에 넣으면 **백슬래시가 사라져 `0` 을 낸다.**
> **그 `0` 이 창 V 판정문에 실렸다**(실제 6). 그래서 **셸을 안 거치는 파이썬 도구**로 고정하고 다시 셌다.
> 그리고 **출력가능 손상**(`AT+CIPSEND!24` — `=`→`!`)은 `\x` 가 안 붙어 **옛 패턴이 통째로 못 봤다.**

## 1. ✅ **지지되는 방향 — "손상이 높으면 고장이 난다"**
```
손상 **>1%** 인 창 : R(1.45%) · V(1.44%) · W(2.63%)   → **셋 다 고장**
손상 **0%** 이고 분모가 큰 창 : H(2,260) · J(3,714) · M(1,910) · **T(3,470)** → **넷 다 무사고**
```
🔑 **특히 창 T `0 / 3,470` 이 강하다** — **분모가 가장 크고 41분 무사고**다.
**작은 분모의 `0` 이 아니라 큰 분모의 `0` 이라 값이 있다.**

## 2. 🔴 **반증되는 방향 — "고장은 손상 때문이다"는 안 선다**
```
🔴 **창 S : 0 / 997 (손상 0) 인데 `busy p` **868** · **23분 미복구** — 오늘 가장 심한 고장**
🔴 창 Q : 0 / 150 (손상 0) 인데 **결합이 아예 못 섰다**  ⚠ 분모 150 이라 약한 근거
⚠ 창 I(0.15%) · 창 P(0.19%) : 손상이 있는데 무사고 계열
```
> ### **창 S 가 결정적 반례다. 손상이 하나도 없는데 최악의 고장이 났다.**
> ### **그러므로 UART 손상은 *고장을 만들 수 있는 조건* 이지 *모든 고장의 원인* 이 아니다.**
⚠ **분모 997 은 작지 않다.** 1.45% 였다면 14건이 나왔어야 하는 크기다.

## 3. 🔑 그래서 지금 말할 수 있는 것 — **넓히지 마라**
```
✅ **손상률과 고장이 같이 움직이는 창이 있다**(R·V·W 대 H·J·M·T). 방향은 실재한다
🔴 **그러나 창 S 는 손상 0 으로 최악의 고장을 냈다.** 접점 하나로 다 설명 안 된다
🔑 **최소 두 기전이다** :
    ① UART 손상 계열 — 창 R·V·W. **깨진 명령 → 응답 없음 → T2 → 재수립**
    ② 손상 없는 결합/파서 계열 — 창 S·Q. **`busy p` 868 · `CIFSR 0.0.0.0`**
```
⚠ **②가 ①의 하류일 가능성은 이 표로 못 죽인다** — 손상이 **탭 개방 전**에 났으면 내 로그에 없다.
**미상으로 둔다.**

## 4. ⚠ 이 표가 딛고 있는 것
```
· 분모가 창마다 다르다(150 ~ 3,714). **작은 분모의 `0` 은 근거가 약하다**(Q 150 · W 228 · V 417)
· 기판·펌웨어·서버가 창마다 다르다. **이 표는 손상률과 고장의 *동행 여부* 만 본다**
· "고장 정도"는 내 앞 판정문들에서 가져온 요약이다 — **같은 척도가 아니다**
· 🔴 **탭이 열려 있는 동안만 보인다.** 창 밖 손상은 못 센다
```

## 5. 🔴 이 가설이 **다시 여는 것** (지우지 않고 표지만 단다)
```
· "기판 불량"   → 🔴 **교체가 아니라 *재삽입* 이 접점을 좋게 했을 수 있다**
· "WiFi 환경"   → **깨진 `AT+CWJAP` 는 결합 실패로 보인다.** 결합 실패가 손상의 하류일 수 있다
· "ESP 먹통"    → **깨진 명령이 ESP 를 이상한 상태로 몰았을 수 있다** ⚠ 다만 창 S 는 손상 0 이다
· "완전 침묵"   → 접점이 아예 떨어지면 그 모양이다
```
> ### **앞 판정을 지우지 않는다. "이 축으로 재해석 가능"이라는 표지만 단다.**
**§"고친 것을 되돌리지 마라 — 사유와 함께 남긴다".**

## 6. ✅ 검정 방법이 좋았던 이유
**새 관측이 필요 없었다. 로그가 이미 다 있었다.**
🔑 §*"소급 계산은 새 관측 없이 미상을 닫을 수 있다 — 로그가 남아 있으면 먼저 그것부터 해라"*.
⚠ **단 옛 집계는 못 쓴다** — heredoc 버그로 `0` 을 냈다. **셸을 안 거치는 도구로 다시 세야 했다.**
