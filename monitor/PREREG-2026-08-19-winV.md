## 6. 🔴 **지금 하드웨어에는 4·5단이 *없다* — 결함이 아니라 사실이다** (arduino 지적 · 사용자 확정)
```
사용자 : **"리셋선은 없다"**(16:2x 직접 확인) → `ESP_RST_WIRED = 0`
→ 4단(HW 리셋)·5단(전원 재투입) **둘 다 실행 불가**
→ 🔴 **자력 복구의 실질 천장은 3단 `AT+RST` 되풀이**다
```
> ### **먹통이 또 나면 이번에도 자력 복구는 3단까지다. 그건 결함 보고가 아니라 현재 하드웨어의 사실이다.**
⚠ **안 적으면 다음 사람이 없는 기능을 고장으로 쫓는다.**

### 🔑 그래서 이 창의 판정은 **`busy p` 하나에 걸린다**
```
`busy p` **0** → 파서 살아 있음 → 3단이 먹는다 → **자력 회복 = 새 기준으로 정상**
`busy p` **>0** → 파서 먹통 → 3단이 안 먹는다 → **천장에 닿는다.** 4·5단이 없으므로 **사람이 개입해야 한다**
```
**이 창에서 `busy p` 가 0 이 아니면, 그것이 "지금 하드웨어로는 못 고친다"의 실측이 된다.**
