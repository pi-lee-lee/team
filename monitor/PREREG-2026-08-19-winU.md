# 사전 등록 · 창 U — **무너지면 스스로 일어나는가** (주입 창)

> # 🔴 머리 배너
> ### **기전 B 는 옛 기판에도 새 기판에도 났다 → 기판 축이 아닐 수 있다.**
> ⚠ 앞 창(T)이 깨끗할수록 이 함의가 묻힌다.

**발행** 주입 시작 **전** · **판정 자료를 보기 전에 적는다.**

## 0. 왜 이 창인가 — **창 T 는 이 물음에 못 답한다**
```
창 T(무자극) : "안 무너졌다" — **+37분 무사고**. 그러나 옛 분포(45·50분) *안* 이라 약한 증거다
창 U(주입)   : 🔴 **"무너지면 스스로 일어나는가"** — **이번 굽기의 원래 질문**
```
🔑 **`hwrst` 는 4단이 *올 때만* 움직인다. 고장을 만들어야 그 계수가 말을 한다.**
**무자극으로 60분을 채워도 영영 못 답한다.**

## 1. 경계 — **리셋이 아니라 자극이 경계다**
```
창 T 마감 : 주입 시작 직전   ·   🔴 창 U `t0` : **주입 첫 건 시각**(socket 이 로그에서 읽은 값)
⚠ **리셋 없다. 장치 세션은 이어진다.** 부팅 국면이 이 창에 없다
```
🔴 **무자극 구간과 주입 구간을 한 분모에 안 묶는다**(내 `SPEC-분모정의` §7).
**묶으면 "무자극 37분 무사고"가 주입 결과에 섞여 사라진다.**

## 2. 검정 — 셋
```
🔴 ① `hwrst=N/M`   N=0 아직 · **N>0·M=0 → 안 듣는다(전원 쪽·MOSFET)** · N>0·M=N → **듣는다**
   ② 주입 구간의 T2 · cksumng · 대역별(`<48`/`48~63`/`>=64`)
      **분모는 socket 의 "시도 − 미주입"과 내 대역 거래 수를 갈라 적는다**
   ③ `센서갈림` — 기준선 **3**. 🔴 신호는 `"0이 아니다"` 가 아니라 **`"3이 아니다"`**
      (0270 이 칩에 들어가면 3 → 0. **그 전이가 곧 도입 표지**다)
```

## 3. 🔴 정지 조건 — **"누가 보는가"를 같이 적는다**
```
`bigfill` 은 **내 탭에만 있다. socket 은 못 본다.**
→ 정지선(>=64B 300건)은 **내가 보고 `.team/STOP-U` 를 감시기가 직접 만든다**
→ socket 의 상한은 **socket 이 볼 수 있는 것**(라운드 수 · 시간)이어야 한다
```
⚠ **못 보는 것을 남의 조건으로 적으면 검사되지 않는 조건이 검사되는 것처럼 보인다.**

## 4. ⚠ 비교 규율
```

   **장치가 나쁘면 서버가 즉시 거절해 주입이 *늘어난다*.** 비율로 보고 분모를 적는다
🔴 창 O·P(옛 펌웨어·옛 기판)와 크기 비교하지 않는다. **"이만큼이다"로만**
⚠ 정지선 도달값은 300 이 아니라 **실제 넘긴 값**을 적는다(`[CNT]` 60초 주기 때문)
⚠ 정지 지연(진행 중 라운드 잔여)을 분모에 그대로 적는다 — **끊긴 것처럼 쓰지 않는다**
```
