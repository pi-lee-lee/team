## 1. 🔴 이 창의 물음 — **리듬이 참인가**
```
창 AA 손상 클러스터 시작 : 20:40 → 20:52 → 21:05  =  **12분 · 13분**
창 Z  결합 발작 시작     : 19:11 → 19:23 → 19:34  =  **12분 · 11분**
```
> ### **다른 창 · 다른 증상 · 그 사이에 *망을 바꿨는데* — 같은 대역의 리듬이다.**
🔑 **망을 바꿨는데 간격이 그대로면 AP 설정에 딸린 것이 아니다.**
**→ 장치 쪽 타이머이거나, 두 AP 가 같은 기본값(GTK rekey 600초는 흔하다)이거나 둘 중 하나다.**
⚠ **`n=3` 이라 "주기적이다"로 쓰지 않는다** — 창 Z 에서 **4차가 안 와 주기 주장이 깨졌다.**

## 2. 🔴 예측 · 관측 · 판정 — **셋을 지금 고정한다**
```

관측   : **21:20 시점**의 깨진 AT 수와 **시각**
판정   :
  · **21:17±2분에 2건 이상 몰림** → **n=4.** 리듬 주장이 처음으로 선다.
                                    후보가 **③접점 또는 장치 타이머**로 좁혀진다
  · **안 온다**                    → 🔴 **창 Z 와 같은 결말. 리듬 주장이 깨진다**
  ⚠ **둘 다 열어 둔다. `n=3` 으로는 못 정한다**
```
