## 1. 🔑 **⑤ 가 완전히 갈렸다 — 확장 인자가 실제로 돈다**
```
arg 분포 (하행 12건) :  0 ×4 · 1 ×5 · **1234567 ×2** · **12345678 ×1**
```
```
7자리 1234567  → `[G] idx=3 arg=1234567` **콜백 불림**  → `A,932,G3,**0**`   ✅ 확장 성립
🔴 8자리 12345678 → **콜백 없음**                        → `A,933,G3,**3**`   ✅ 거절 성립
```
> ### ~~**거절이 콜백 앞에서 일어난다. 아예 안 넘긴다.**~~ 🔴 **틀렸다. 콜백은 불렸다.**
> **철회 사유 (socket 이 장치 소스로 반증 · 22:0x):**
> ```c
> static bool cmdLcd(uint32_t arg) {
>   if (arg > 9999999UL) return false;   // 🔴 콜백 **안에서** 거절한다
> #if DEBUG
>   Serial.print(F("[LC] ")); ...        // ← print 가 **early return 뒤** 에 있다
> #endif
> ```
> ### ✅ **정본: 라우터는 정상적으로 콜백을 불렀고, 콜백이 첫 줄에서 `false` 를 냈다.**
> 🔴 **`[G]`·`[LC]` 가 둘 다 *성공 경로에만* 있어서 안 찍혔을 뿐이다.**
>
> ⚠ **왜 이 정정이 중요한가**: 내 원문대로면 *"라우터가 값 검사를 해 준다"* 로 읽힌다.
> 그러면 **콜백 계약을 "값 검사는 라우터 몫"으로 설계하고 그건 틀렸다** —
> **실제로는 기여자의 콜백이 정한다.**
🔑 **분모는 여전히 맞는다**: 하행 12 = **성공 11 + 거절 1**.
🔴 다만 **"콜백 11"이 아니라 "성공 11"이다** — **12번 다 불렸고 하나가 `false` 를 냈다.**

### 🔴 내 계측기의 한계를 여기 박아 둔다
```
내 시리얼 탭이 보는 것 : **성공한 콜백만**  (`[G]`·`[LC]` 가 성공 경로에 있다)
🔴 못 보는 것          : **거절한 콜백** — 조용하다. 안 불린 것과 **모양이 같다**
가른 것                : **장치 소스**(socket) — 관측이 아니라 판독이다
```
> ### **`ACK result=3` 은 "거부됐다"까지만 말한다. *어디서* 거부됐는지는 안 말한다.**
🔑 §*"계측기 강도 순서"* 대로 **소스 판독이 관측을 이겼다.** 관측만으로는 못 갈랐다.

⚠ **`0/1` 만 왔으면 이 항목은 못 갈랐다** — `0`·`1` 은 **옛 판과 구별이 안 된다.**
**`1234567` 이 와서야 "확장 인자가 돈다"가 성립한다.** 🔑 **socket 이 큰 값과 8자리를 둘 다 쏴 준 것이 판정을 만들었다.**

❌ **에코 확인 : 미측정.** `LD`·`LC`·`DR` 의 occ 에코 비트는 **항상 0** — 계약이 없다.
**빈칸이 아니라 의도적으로 안 잰 칸이다. `0` 을 고장으로 읽지 마라.**

## 2. 🔴 내가 찾은 결함 — **배너 `slots` 라벨이 자리 수가 아니다**
```
배너      `proto v1 / **2 slots** / 5 modules`
SLOT_N    = 2  ← **센서 수**(A1+B1)를 찍고 있다
SLOT_ROWS = 1  ← **자리 수**. 서버 지형(1자리)과 비교할 값은 이쪽이다
```
> ### **배너 `2` 를 자리 수로 읽으면 서버 지형과 어긋난 것처럼 보인다. 어긋난 것은 라벨이다.**
⚠ **이번 판의 문제가 아니라 계속 그랬다** — 옛 10센서 판도 배너는 `10 slots`, 실제 자리는 **5**였다.
🔑 **arduino 가 "고쳤다"고 보고한 적이 있는데 그때도 `SLOT_N` 을 자리 수로 믿었다. 한 층 아래에 같은 것이 있었다.**
**다음 굽기 경계에서 라벨을 고친다**(문구 변경 = hex 변경이라 이 경계에 못 실었다).

## 3. 📌 배경 두 축 — **마감값(22:31:04). 판정하지 않는다**
```

> ### 🔴 **이 33분은 아무것도 안 가른다.** 옛 분포에 **45분·50분 23초** 무사고가 이미 있다.
> ### **"더 짧다"이지 "달라졌다"가 아니다.** 손상 분모 1,659 도 목표 3,470 의 절반이다.

### ✅ 교차 검산 하나가 맞아떨어졌다 — 기록해 둔다
```
CIPSEND **1,659**  <  SEND OK **1,661**   ← 분자>분모. **불가능한 값**
원인 : 손상 2건이 `AT+CIPS\x..ND` 라 CIPSEND 정규식에 안 잡힌다. OK 는 그대로 온다
→ **1,659 + 손상 2 = 1,661** ✅
```
🔑 **손상 계수가 OK 수지로 독립 검산됐다** — 두 계측기가 만났고 어긋나지 않았다.
⚠ **`+IPD 18` = `SLOT-OOW 18` 은 일치를 주장하지 않는다** — 21:59 시점엔 8 대 12 였다.
**표본이 작고 기전을 확인 안 했다.**
> ### 🔴 **이 `0` 들을 "좋아졌다"로 읽지 마라. 2분짜리 표본이다.**
**`0/92` 는 §1.1 이 말하는 바로 그 `0`** — 건강인지 안 돌았는지 못 가른다. **"미달"이 아니라 "안 쟀다"다.**
