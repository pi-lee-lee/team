# UART 손상 — **사용자가 원인을 확인해 줬다. 빵판 점퍼 접점이다**

**2026-08-19 21:30 · monitor** · 새 관측 없음 — **사용자 진술 + 내 두 창 자료의 대조**

> ### 사용자 원문: **"빵판용 점퍼 케이블이다. *만지면 발생하는 게 확인된다. 가만히 두면 안정된다.*"**

## 1. 🔑 그 한 문장이 **두 창의 모양을 통째로 설명한다**
```
창 Z (옛 망 · 70분)  : 결합 발작 셋(19:11·19:23·19:34) → **4차 안 옴** → 뒤 22분 조용
창 AA/AB (새 망)     : UART 손상 셋(20:40·20:52·21:05) → **4차 안 옴** → 뒤 **22분 무결**
```
**두 창 다 "셋 몰리고 그친다"였고, 나는 그것을 `주기` 로 읽으려 했다.**
🔴 **주기가 아니었다. 손길이었다.**
```
20:32:55  사용자 위치 이동 (케이블을 만진다)
20:40~21:05  손상 세 다발 ← **이동 직후 흔들린 접점이 자리를 잡는 구간**
21:05:25 이후 : CIPSEND **1,096건 · 손상 0** (21:27 기준 · **22분 무결**)
```
> ### **"가만히 두면 안정된다"가 4차 미도래를 설명한다. 주기 가설로는 설명이 안 됐다.**

## 2. 후보 판 — **이 진술로 크게 움직인다**
```
🔴 ③ **접점(빵판 점퍼)**  → **가장 유력**. 사용자가 재현 조건(`만지면 발생`)을 직접 확인했다
❌ ⑤ 주기적 무엇(GTK rekey / 장치 타이머) → **죽었다.** 손길은 주기가 아니고,
     **4차 미도래가 두 창에서 반복된 것**이 그 증거다
🔻 ① 리팩터링  → 크게 약해짐(코드 그대로인데 창 AA 에서 결합 발작이 사라졌다)
⏳ ② 환경(결합 발작) → **여전히 강하다.** 이동 뒤 `esprst` **0** 이 **49분** 유지(20:38~21:27)
```
### ⚠ 그런데 **③은 아직 못 닫는다**
```
🔴 **납땜은 다음으로 미뤄졌다**(사용자 확정 · 지금은 리팩터링 샘플이 우선이다)
→ **접점을 안 고치므로 "고치면 사라진다"를 이 창들로 검정할 수 없다**
→ **"가장 유력"까지이고 "확정"이 아니다**
```

## 3. 🔑 **두 축이 서로 다른 개입에 반응했다** — 이게 오늘의 구조다
```
결합 축(esprst·CIFSR) : **망 이동**으로 사라졌다        → ② 환경
UART 축(깨진 AT)      : **케이블 손길**에 반응한다      → ③ 접점
```
> ### **한 고장이 아니라 두 고장이었고, 서로 다른 층에 있었다.**
**오늘 하루 "원인 하나"를 찾다가 여러 번 물린 이유가 이것이다** —
`창 S`(busy 868 · 손상 0)와 `창 W`(손상 6/228)가 같은 표에서 안 맞았던 것도 같은 얘기다.

## 4. 📌 마감 시점 값 (창 AA/AB · 20:38:11~21:27:31 · **49분**)
```
🔴 깨진 나가는 AT **10 / 2,411 = 0.41%**  (①비출력 7 + ②출력가능 3)
   마지막 손상 **21:05:25** → 그 뒤 **1,096건 무결**
✅ `esprst` **0** · `busy p` **0** · `CIFSR 0.0.0.0` **0** · `LADDER 실패` **0** · `T2` **0**
```
⚠ 손상 분모 2,411 — **목표 3,470 미달.** `0.41%` 를 **창끼리 크기 비교하지 않는다.**
🔑 **이 값이 납땜 뒤와 대조할 "전" 값이다.** 그래서 **접점을 안 고쳐도 계속 세야 한다.**

## 5. 🔴 내가 틀렸던 것 — 기록해 둔다
```
① "이동이 ③접점을 되살렸다"(루트) → 사용자가 잡았다: **이동 과도구간일 수 있다**
② "과도구간의 것이다"(루트)        → 내가 잡았다: **21:05 재개가 반증**
🔴 ③ "리듬이 같다 → 주기 후보"(나) → **사용자 진술이 죽였다. 손길이었다**
```
> ### **셋 다 "그럴듯한 하나의 설명"이었고, 셋 다 다음 자료에 물렸다.**
🔑 **살아남은 것은 예측을 미리 적어 둔 것뿐이다** — 창 Z·창 AB 의 4차 예측은 둘 다 빗나갔고,
**빗나간 것이 주기 가설을 죽여서 진짜 설명이 들어올 자리를 만들었다.**
