# 사전 등록 · 창 J — **hex 전환 이후. 축이 넷이다** (2026-08-18)

🔴 **자료 전에 쓴다.** 캡처는 아직 시작하지 않았다. **실행 기록칸은 측정 후에만 채운다.**

## 0. 🔴 이 창은 **장치만 바뀐 창이 아니다** — 축 넷
```
21:06:38  socket 서버 교체 — `D`/`Q` 등록 파서 · 요약줄 칸 추가        ← 서버 축
21:11:49  arduino 굽기 (커밋 def8093) — ① hex 인코딩 ② D 등록+Q ③ 모듈 표   ← 장치 축 셋
```
**판정문에 반드시 넷을 갈라 적고, 내 계측기로 못 가르는 것은 "귀속 불가"로 쓴다.**

## 1. 축 분담 (굽기 **전에** 정했다 — 창 I 에서는 사후에 알았다)
| 축 | 누가 가르나 |
|---|---|
| **hex 인코딩** | ✅ **내 시리얼** — `S` 프레임 크기 · `≥64B` 진입률 |
| **D 등록 + Q** | ✅ **socket 서버 로그** — `등록 완료/형식오류/질의/포기/폭불일치` |
| | ⚠ **간접 실기 표지 하나**: `D` 줄 수 = `moduleCount()` (arduino 제공) |
| **모듈 표** | 🔴 **표지 없음 → 내 관측 밖.** arduino 의 바이트 대조는 **호스트 시험이지 실기 관측이 아니다** |

## 2. 🔴 분모 규칙 — **`0` 을 읽기 전에 분모부터**
```
pendfill = 0  →  `penddrop=0` 은 **아무 뜻도 없다**(그 경로가 안 돌았다)
pendfill > 0  →  넘침률 = penddrop / (pendfill + penddrop)
bigfill = 0   →  `bigdrop`·`bigokst` 도 같은 뜻이다
```
🔑 **창 I 에서 `penddrop=0` 을 "발동 안 함"인지 "분모 0"인지 못 갈라 판정 불가로 남겼다. 이번에 열린다.**
🔑 **불변식 검사(arduino 요청)**: `pendfill ≥ bigfill` · `penddrop ≥ bigdrop`. **깨지면 펌웨어 이상.**
❌ **`okstream` 은 판정에 쓰지 않는다** — 바이트 매처가 줄 완성 **전**에 발화해 **항상 이기므로**
탐지 총수이지 구조된 수가 아니다. **`oklost`/`bigoklost` 가 그 자리다.**

## 3. 예측
| # | 예측 | 반증 |
|---|---|---|
| **P1** | **`≥64B` 진입률이 창 I(92.1%)보다 크게 떨어진다** | 안 떨어지면 hex 가 프레임을 못 줄인 것 |
| **P2** | `≥64B` 대역 T2 **0건** — ⚠ **분모가 30 미만이면 판정하지 않는다** | 1건이라도 나면 수정이 불완전 |
| **P3** | `pendfill > 0` (부하가 걸리면) | `pendfill=0` 이면 **그 경로 자체가 안 돈다** |
| **P4** | `oklost > 0` — **줄 경로였으면 잃었을 `SEND OK` 가 실재했다** | `0` 이면 대책 ②가 이 창에서 할 일이 없었다 |
| **P5** | 불변식 `pendfill ≥ bigfill` · `penddrop ≥ bigdrop` 성립 | 깨지면 🔴 펌웨어 이상 — 즉시 arduino 에 알린다 |
| **P6** | `S` 자리 폭 = `ceil(n/4)` 성립 | 어긋나면 선언과 실제가 갈렸다 |

⚠ **P6 은 내 로그만으로 못 닫는다** — **폭 3 은 `n ∈ [9,12]`** 다(`ceil` 때문).
**`D` 의 선언 `n` 은 socket 로그에 있다. 두 계측기를 합쳐야 닫힌다.**

## 4. 넘지 않을 것
```
❌ `≥64B` 가 `0/0` 이 되는 것을 "T2 소멸"로 읽지 않는다 → **진입률로 따로 말한다**
❌ `drain` 6→7 을 "하행이 늘었다"로 읽지 않는다 — `N ≤ 2D/3` 이 둘 다 4, **회복 속도만** 바뀐다
❌ 창 G/H/I 의 `≥64B` 와 **같은 축에 놓지 않는다** — 프레임 구성이 바뀌었다
❌ `등록 …` 칸들은 **이번 판에 처음 생긴다** — 이전 창과 크기 비교 불가
   🔴 `등록 완료 ≥ 1` 을 **먼저** 확인한다. 안 찍히면 "파서가 안 돎"과 "등록 안 됨"이 구분 안 된다
```
