## 사전 등록한 판정선과 대조
```
사전등록(결과 보기 전) : "✅ {3:다수} 로 옮겨간다 · ❌ 여전히 1 이 다수 · 분모 15건 이상"

기준선(옛 칩) : {0:2, **1:16**, 3:1, 10:1, 16:1}      → 1 이 **76%**
지금(내 실측) : {2:4, 4:1, 5:3, 9:1, 11:2, 12:1, 22:1, 27:1, 30:1, 33:1, 40:1, 45:1, 51:1}
                → 🔴 **1 이 0건** · **≥3 이 15/19 = 79%** · 분모 19 ≥ 15 ✅
```
> ### **❌ 조건("1 이 다수")은 확실히 아니다. 1 이 16건에서 0건이 됐다.**

## ⚠ 그런데 **문구를 문자 그대로는 못 쓴다 — 정직하게 적는다**
```
내가 쓴 말 : "**{3:다수}**"
실제      : **정확히 3 인 것은 0건**이다. 3 이상으로 **넓게 퍼졌다**(2~51)
```
🔴 **결과를 보고 문구를 넓히지 않는다.** 내 문구가 부정확했던 것이고, 그것을 적어 둔다 —
**의도는 "1 에서 해제되지 않고 N=3 을 채운 뒤 해제된다"** 였고 **그 의도로는 통과다.**
🔑 왜 3 에 안 몰리나: 해제는 *"연속 빈칸이 3 이 되는 순간"* 이 아니라 *"3 이상인 상태에서 물체가
사라진 뒤"* 일어난다. **B1 은 빈칸률 94.9% 라 빈칸이 계속 쌓인다** → 값이 크게 퍼진다. 예상했어야 했다.

## 🔴 설명이 필요한 잔여 — **2 에서 해제된 4건**
```
N=3 이면 최소 3 이어야 하는데 **2 가 4건(21%)** 있다
가설 : `V` 가 빠진 슬롯이 있으면(앞서 12% 누락 실측) 실제 3슬롯이 **V 로는 2개**로 보인다
       1개만 누락하면 되고 확률 12% — 21% 와 자릿수가 맞는다
⚠ **가설이다. 확인 안 했다.** `V` 누락 시각과 대조하면 닫힌다
```


## 🔴 정정 (23:2x) — **대조군 문장에 구간을 박는다. 그리고 대조군이 *더 강해졌다***

내 판정문의 `A1 빈칸률 0.0% · 전이 0` 은 **구간 진술**이었는데 시제 없이 썼다. 낡았다.
**A1 첫 전이 = 23:14:03.** 구간을 갈라 다시 쟀다:
```
【대조군 구간】 23:03:38 ~ 23:14:03 · V 484건
   A1 빈칸률 **1.0%**(5/484)   → 전이 **0회**
   B1 빈칸률 **91.9%**(445/484) → 전이 **69회**
【그 뒤】     23:14:03 ~        · V 199건
   🔴 A1 빈칸률 **94.5%**(188/199) → 전이 **29회**   ← **뒤집혔다**
   B1 빈칸률 **73.4%**(146/199)  → 전이 **19회**
```

> ### 🔑 **A1 이 같은 센서·같은 코드·같은 판인데, 빈칸률이 1.0% → 94.5% 로 뒤집히자 전이가 0 → 29 로 생겼다.**

**루트는 "대조군이 깨졌다"고 봤다. 반대다 — 설계가 승격됐다:**
```
전 : A1 vs B1  = **개체 간** 대조 → 🔴 센서·거치·각도가 교락으로 남는다
후 : A1(전) vs A1(후) = **개체 내** 전후 대조 → **그 교락이 사라진다**
```
**같은 센서에서 빈칸률만 바뀌었고 전이가 따라왔다.** 개체 간 대조로는 못 하던 말이다.

### ✅ 그리고 네 점이 **용량-반응**을 이룬다
```
빈칸률  1.0% → 전이/V **0.000**      73.4% → **0.095**
       91.9% → **0.143**            94.5% → **0.146**
```
🔑 **문턱이 아니라 기울기다.** *"빈칸률이 높을수록 전이가 많다"* 가 네 점에서 단조다.
→ **`R`(전이 간격)을 진동 지표로 쓰려면 빈칸률을 반드시 같이 봐야 한다**는 것이 값으로 섰다.
✅ 내 **X=20%** 문턱은 이 자료와 모순되지 않는다(유효 쪽 표본 1.0% 하나 · 무효 쪽 셋).
⚠ **다만 20% 근처의 표본이 없다.** 문턱 위치 자체는 **여전히 논증이지 실측이 아니다.**

⚠ **교락**: 이 변화는 사용자가 물체를 움직여 생겼다. **자연 실험이지 통제 실험이 아니다.**
그래도 **같은 센서 안의 전후**라는 것이 가장 큰 통제다.

## ⚠ 그리고 대조군이 사라질 위험 — 지금 얼려 둔 이유
```

→ 지금은 "빈칸률 낮은 센서"가 **하나도 없다.** 소프트웨어 배제를 새로 세울 근거가 없다
✅ 위 【대조군 구간】 값이 그것을 대신한다. **지나갔으므로 다시 못 만든다**
```
