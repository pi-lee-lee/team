# 사전 등록 · 창 AC — **샘플 검증. 성격이 앞 창들과 다르다**

> # 🔴 이 창은 **비율을 재는 창이 아니다**
> ### **지금까지(창 G~AB)는 *링크 관측* 이었다. 이 창은 *샘플이 성립하는가* 를 본다.**
> ### **목적은 비율 비교가 아니라 **왕복 성립 여부** 다 — 항목별 ✅/❌ 로 낸다.**
> ### 🔴 **창 AB 와 크기 비교하지 마라. 분모(모듈 수·자리 수)가 통째로 바뀐다.**

**발행 21:4x — 굽기 *전* 에 쓴다.** ⚠ **결과를 보고 해석을 고치면 사전 등록이 무의미해진다.**

## 0. 무엇이 바뀌나 — **축이 셋이다. 미리 센다**
```
🔴 장치 : 모듈 **12개 → 5개** (`A1`·`B1`·`LD`·`LC`·`DR`) · `MODULE_TABLE` 축소
🔴 서버 : 미배포 20커밋 + **샘플 `main.cpp`** (자리 **1개**)
🔴 봉투 : `G` 셋째 칸이 **0/1 → 임의 정수** (최악 23B · 한 줄 상한 64B 안)
```
> ### **셋 다 "분모를 바꾸는" 변경이다. 그래서 앞 창과 비교가 성립하지 않는다.**
🔑 **모듈 5개는 프레임이 짧아진다** — **상행 크기 대역 분포가 통째로 바뀐다.**
**`>=64B` 진입률·`N` 분포를 창 AB 이전과 대조하지 마라.** 이 창부터 **새로 뜬다.**

### 자리 수 이력 — **분모가 세 번 바뀌었다**
```
10자리(창 ~O) → **7자리**(창 P~AB) → **1자리**(창 AC)
```
⚠ **자리 기준 비율은 이 셋을 가로질러 비교할 수 없다.** 매번 분모가 다르다.

## 1. `t0` 와 개입
```
t0 : **굽기 리셋** — arduino 가 값으로 준다
🔴 개입을 **한 번으로 묶는다** : 굽기 + 배포가 같은 경계다
⚠ 내 탭 개방도 DTR 리셋이다 → **실질 t0 는 내 탭 개방**이 된다. 그 시각을 값으로 적는다
⚠ 첫 `[CNT]` 줄이 부팅 60초 기여분(§7.174) · `up=60` 을 리터럴로 안 잡는다(§7.174.5)
❌ **접점 납땜은 이 경계에 없다** — 사용자가 뒤로 미뤘다(*"납땜 지금 안 한다고"*)
```

## 2. 🔴 이 창이 답할 것 — **항목별 ✅/❌**
```
① 장치가 붙는가        — CWJAP OK · IP 확보 · online · 등록
🔴 ② 모듈 수가 **arduino 굽기 보고의 값과 일치**하는가 — `D,<모듈>,…` 를 세어 **그 값과 대조**한다
     ✅ **굽기 보고 값으로 확정됐다(21:5x)** : 모듈 **5**(`A1 B1 LD LC DR`) · `VIRTUAL_MODULES` **0**
        등록 **65B** / BATCH_CAP 160 · flash **26,566**(82%) · RAM **1,230**
     🔑 **출처는 그대로 "굽기 보고"다** — 값만 채웠다. `LC` 안전성이 확인돼 5 로 확정.
③ 자리 1개가 서는가    — 서버 `지형 판` · 등록 응답
④ 왕복이 되는가        — 하행 `G` → 에코 → `SEND OK`
🔴 ⑤ `G` 확장 인자가 도는가 — **넷으로 갈라 잰다**(아래 §2.1)
```
🔑 **비율이 아니라 "됐다/안 됐다"다.** 표본이 작아도 답이 나오는 물음만 넣었다.

### 🔴 ②를 **숫자가 아니라 *출처* 로 적은 이유** (루트 지적 · 21:5x)
```
❌ "모듈 **5개**가 등록되는가"      → 5 는 루트가 **지시한** 값이지 **확인된** 값이 아니다
                                     🔴 5 가 틀리면 **멀쩡한 장치를 ❌ 로 판정한다**
✅ "모듈 수가 **굽기 보고의 값과** 일치하는가"  → 정본의 *자리* 를 못 박았다
```
> ### **사전 등록의 값은 *검증 가능한 출처* 를 가리켜야 한다. 숫자를 박으면 그 숫자가 판정을 오염시킨다.**
⚠ **그렇다고 "굽고 나서 정한다"로 열어 두면 사전 등록이 아니다.**
**값이 아니라 *출처* 를 미리 정하는 것**이 답이다.
🔑 §*"틀린 합격선은 실패보다 나쁘다"* — **실패는 보이고 틀린 합격선은 안 보인다.**

## 2.1 🔴 ⑤ 를 **넷으로 갈랐다 — 내 첫 기준이 틀렸다** (arduino 가 소스에서 잡았다)
```
❌ 내 첫 기준 : "다음 상태 프레임 **에코**로 확인"
🔴 그런데 : **`LD`·`LC`·`DR` 은 occ 비트가 *항상 0* 이다.**
            액추에이터 상태를 occ 에 싣는 것은 **가상 차단봉뿐**이다
→ 그 기준으로 재면 **정상 동작이 ❌ 로 판정된다**
```
> ### **또 "틀린 합격선"이다. `② 모듈 5개` 에 이어 오늘 둘째다 — 실패보다 나쁘다.**
**✅ 고친 기준:**
```
⑤-a  `G` 프레임이 **전선에 나간다**        ← 내 시리얼 탭
⑤-b  **장치 콜백이 불린다**                ← `[LC] 1234567` 등 DEBUG 출력
⑤-c  **ACK `result=0`**                    ← 서버 로그
🔴 ⑤-d  **거절 갈래 : 8자리 → `result=3`**  ← **양성만 재지 않는다**
❌ 에코 확인 : **"미측정"으로 명시한다** — **계약이 아직 없다.** 다음 경계 항목이다
```
🔑 **`⑤-d` 가 핵심이다** — **양성만 재면 "거절이 되는가"를 영영 못 본다.**
오늘 `격리 0`·`hwrst 0/0` 에서 반복해서 겪은 자리다.
⚠ **에코를 빈칸으로 두지 않는다** — *"안 적은 값은 아무도 안 찾는다"*.

## 2.2 ⚠ **배포본과 커밋본이 다르다 — 알고 하는 차이다**
```
배포 : socket 이 ⑤ 를 쏘려고 **루프 본문 주석을 푼 판**
커밋 : **주석 처리된 판**
→ 판정문에 **배포 해시 + "루프 본문 주석 해제 1건"** 을 값으로 적는다
```
🔑 §*"어느 트리를 배포했나"* — **알고 하는 차이라서 더더욱 적어야 한다.**
**나중에 해시로 되짚는 사람이 안 적으면 반드시 어긋난다.**

## 3. 계속 세되 **판정하지 않는 것**
```
결합 축 : `esprst`·`CIFSR 0.0.0.0`·`LADDER 실패`·`T2`·`busy p`
UART 축 : 깨진 나가는 AT (`uart_damage.py` · 두 기준 · 분모 같이)
```
🔴 **둘 다 창 AB 와 비교하지 않는다.** **나중에 납땜 뒤와 대조할 "전" 값으로 계속 쌓을 뿐이다.**
⚠ **③접점은 이 창에서도 못 닫는다** — 납땜을 안 했으므로 **변화를 기대하지 않는다.**

## 4. 창 AB 마감 — **미달로 종료**
```
창 AA/AB (20:38:11 ~ 정지 시각) :
  🔴 깨진 나가는 AT **10 / 3,461 = 0.29%**(21:49:25 마감 기준 · ①7 + ②3)
     ⚠ **목표 3,470 미달 — 9건 차이(99.7%).** **미달은 미달로 적는다**
     🔑 그래도 **"99.7%" 를 같이 적는다** — 다음 사람이 이 `0.29%` 를 얼마나 믿을지 스스로 정하게
  마지막 손상 **21:05:25** → 그 뒤 **44분 · 2,100건 넘게 무결**
     🔑 사용자의 *"가만히 두면 안정된다"* 와 정확히 맞는다
  `esprst` **1**(21:29:22) · `busy p` **0** · CIFSR 0.0.0.0 2 · LADDER 실패 3 · T2 1 · okto 14
  결합유지 단0 **3023s = 50분 23초**(프로젝트 최장)
```
🔴 **분모를 채우려고 굽기를 늦추지 않는다. 비교를 안 하면 된다.**
🔑 §**"못 쟀다가 빨강보다 낫다"** — 미달을 적고 넘어간다.

## 5. ⚠ 오늘 배운 것 중 이 창에 바로 걸리는 셋
```
① **값을 뜬 시각을 붙인다** — 오늘 낡은 값이 세 번 결론을 만들 뻔했다(루트 5초 · socket · 나 2분)
② **판별 시험에 셋째 갈래를 열어 둔다** — 루트가 둘만 적었는데 **셋째가 실측으로 왔다**
   (결합만 오고 손상은 안 왔다 → **두 축 독립**)
③ **표지가 없으면 없다고 먼저 선언한다** — 리팩터링 굽기 때 표지가 하나도 없었다(§42)
   ⚠ 이번 굽기는 **모듈 수·자리 수가 바뀌므로 표지가 있다.** 그래도 **무엇이 표지인지 미리 적는다** →
   **`D,<모듈>` 다섯 · 자리 1개 · `MODULE_TABLE` 축소가 로그에 비치는 형태**
```
