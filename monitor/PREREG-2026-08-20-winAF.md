
## 2. 🔴🔴 **사라지는 것 셋 — 미리 선언한다. 결함으로 읽지 않는다**

**arduino 가 굽기 전에 값으로 줬다. 안 적으면 셋 다 "고장"으로 보인다.**
```
🔴 ① `occ` 가 **안 움직인다** — 시뮬 훅을 뺐다. 자리는 미배선이라 **늘 0**
     → **직전 창의 24.0초 주기는 사라진다.** ❌ 아니다
🔴 ② **교차 불변식이 성립하지 않는다** — `0x10`(B1)이 이제 **LED 를 안 읽는다**(훅 제거)
     `0x08`(LD)만 명령을 따라간다 → **둘이 갈리는 것이 정상**
     ⚠ **`occ_period.py` 의 불변식 검사를 이 창에 돌리지 마라. 적용 조건이 사라졌다**
🔴 ③ 비트 배치가 바뀐다 (n=3 · 모듈 i → 비트 2−i · 폭 **1**, `ceil(3/4)=1`)
     **A1 `0x4` · B1 `0x2` · LD `0x1`**   ← 창 AE 의 `0x20/0x10/0x08` 은 **낡았다**
```
> ### **셋 다 "없어진 것"이라 예고 안 하면 결함으로 보인다.** §*"표지의 부재도 선언해야 한다"*.

## 3. 판정 — **둘뿐이다**
```
🔴 ① **8888 접속 유지** — `CIPSTART` → `CONNECT` → 등록 · **세션이 이어지나**
   ② **표지 6/6 + ❌목록 0건**
⚠ `occ` · 교차 불변식 · 24초 주기 → **이 창에서 미측정.** **분모에 넣지 않는다**
```
⚠ **①에 "N분 동안"을 붙여 적는다** — 사다리가 단계마다 30초씩 기다린다.
**짧은 창의 "안 붙는다"를 상태 진술로 쓰지 않는다**(창 AE 에서 물렸다).

## 4. 명령 왕복은 아직 밟을 수 있다
```
`LD` 는 남아 있다 → `srv.send("P1","LD",1)`
  → **보드 LED 가 켜진다(눈 · 로그와 독립)** + `[G] idx=2 arg=1` + ACK `0` + 에코 **`0x1`**
⚠ **자리 값은 안 바뀐다**(되읽기 훅 제거). **정상이다**
```
