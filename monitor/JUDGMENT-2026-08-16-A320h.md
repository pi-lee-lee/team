```
균등성 KS:  D = 0.183 · p = 0.826  → '발생률 일정'을 기각하지 못한다
임계값   :  D* = 0.415
```

| 후반 발생률이 X배로 바뀌었을 때 | 잡아낼 확률 (n=10) |
|---|---|
| 2배 | 0.14 |
| 3배 | 0.29 |
| 5배 | 0.49 |
| 10배 | 0.74 |

### **0.80 을 넘는 칸이 하나도 없다 → 이 자료는 10배 변화조차 배제하지 못한다.**

**"기각 못 했다"를 "일정하다"로 바꿔 읽지 마라**(원장 1.15 — 내가 n=7 에서 그렇게 읽고 철회했다).
`p=0.826` 은 **변화가 없다는 증거가 아니라 검정이 아무것도 못 봤다는 뜻**이다.

**얼마나 더 재야 하나** — 3.13/h 에서 검정력 0.80 을 넘기려면:

| 잡고 싶은 변화 | 필요 사건 수(대략) | 필요 노출 |
|---|---|---|
| 5배 | ~24건 | **~8h** ← 원래 계획이 겨눴던 것 |
| 3배 | ~40건 | ~13h |
| 2배 | 100건+ | 30h+ |

**즉 8시간 계획 자체는 옳았다. 우리는 그 40% 에서 잘렸을 뿐이다.**

### 사건 간격

```
20.0 · 3.3 · 37.6 · 3.7 · 7.8 · 31.9 · 17.3 · 14.0 · 13.5 (분)
평균 16.6 · CV = 0.67
```
균질 포아송이면 CV≈1.0 이 기대값이다. 0.67 은 **약간 규칙적** 쪽이지만
**표본 10 에서 CV 는 크게 흔들린다. 여기에 기전을 붙이지 마라.**
