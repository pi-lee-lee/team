**단별로 갈라 다시 뽑았다:**
```

✅ **그래도 패턴은 다른 각도가 받쳐 준다**: 오염 가능한 값도 전부 **12~27초 대역**이고,
**서버가 독립으로 본 최대공백(25.5·25.0·25.0·31.0·27.8초)** 과 같은 대역이다.

그것이 **`esprst 6`** 이 되고, 사다리가 쉬지 않고 도는 것이 **사용자가 본 `RX/TX 상시 점등`** 이다.

## 3. ⚠ 내 DTR 리셋 — **"회복한다"와 "유지된다"는 다른 진술이다**
```
12:04:31 리셋 → **57초** 뒤 online (사다리 2단 경유 · 실패 1회)

```
**회복은 반복해서 하고 유지를 못 한다.** 리셋은 이 고장을 안 고친다.

**같은 문서에 "최소 30분은 봐야 한다"를 적어 놓고 45초에 골랐다.** 값은 유효했고 **갈래 판정만 틀렸다.**

배경 스크립트 패턴 : `결합유지 [0-9]*초`     ← 🔴 원문은 `8s` 다. **안 잡힌다**
내가 분석 때 고친 것 : `결합유지 [^·]*`      ← ✅ 이건 고쳤다
```
> ### **패턴 버그를 발견해 고쳤는데, *이미 돌고 있던* 스크립트에는 안 옮겨졌다.**
> ### **고침이 전파되지 않았고, 그 결과가 *빈 출력* 이라 "값이 없다"로 읽힌다.**
⚠ **이게 부재 주장의 가장 나쁜 형태다** — **깨진 계측기가 낸 `없음`.**
**출력이 비면 대상이 없는 것인지 도구가 못 찾는 것인지부터 갈라라.** 오늘 이 자리에서 두 번 걸렸다.
🔑 **처방**: 같은 패턴을 여러 곳에 쓰면 **한 곳을 고칠 때 나머지를 같이 찾아라.**
**돌고 있는 배경 작업은 고침이 안 닿는다** — 고칠 때 그것부터 확인한다.
