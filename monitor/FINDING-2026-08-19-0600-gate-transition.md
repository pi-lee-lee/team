# 발견 · **차단봉 상태 전이를 잡았다 — "아무도 못 봤다"는 틀렸다** (2026-08-19)

**socket 보고**: *"`05:57:45~05:57:52` occ = `60A` 로 명령 전후 안 변한다. 이미 열려 있었다.
→ **명령이 실제로 상태를 바꾼다는 것은 실물에서 아직 미검증이다.** `close_gate` 를 걸어야 보인다."*

## 1. 🔴 내 창 L 에 **전이가 있다** (`05:44:26`)
```
05:44:24  [TX] S,183,**608**,800,229,P1,37          ← occ = 608
05:44:26  [AT] "+IPD,12:G,3,10,1,44"                ← G 명령 (E1 열기)
05:44:27  [TX] S,185,**60A**,000,231,P1,49          ← 🔑 occ = **60A** — **바뀌었다**
05:44:27  [AT] " S,185,60A,…**A,3,G0,0,35**"        ← ACK `G0` (result=0)
```
```
0x608 = 0110 0000 1000        0x60A = 0110 0000 1010
차이 = 비트 1 (값 2) = **idx 10 = E1**   ← socket 이 말한 그 비트다
```
> ### **명령 → 에코 변화 → ACK 이 한 슬롯 안에서 다 보인다. 실물에서 검증됐다.**
⚠ **`close_gate` 를 걸 필요가 없다** — 이미 자료가 있다. **web 에 그렇게 전해야 한다.**

## 2. 세 건의 갈래가 전부 나온다 (창 L)
```
05:44:26  G,3  → occ 608 → **60A**   **전이 있음** · ACK G0
05:46:46  G,6  → occ 60A → 60A       이미 열림   · ACK G0
05:55:54  G,9  → occ 60A → 60A       이미 열림   · ACK G0
```
🔑 **socket 이 본 `05:57:47` 은 네 번째이고, 셋 다 이미 열린 뒤였다.**
**첫 건에서만 전이가 보이는 것이 당연하다** — **가상 차단봉이 첫 명령에서 자율 토글을 멈추고
열린 상태로 굳기 때문**(arduino 설계). **그 굳는 순간이 `05:44:26` 이다.**

## 3. 🔴 그래서 socket 의 `장치거절 0/1` 을 **"첫 시도"로 읽으면 안 된다**
```
`M = 1` 은 **그 서버 인스턴스가 띄운 수**다 (05:57:12 기동)
실제 `G` 는 그 전에 **최소 3건** 더 있었다 (05:44 · 05:46 · 05:55)
```
> ### **계수기는 프로세스와 함께 0 으로 돌아간다. "처음"이 아니라 "이 인스턴스에서 처음"이다.**
⚠ **오늘 `세션 번호` 에서 같은 것을 겪었다**(socket 서버가 재기동 안 하면 번호가 누적). **분모는 프로세스 수명에 묶인다.**

## 4. ⚠ 부수 관측 — **두 번째 필드도 움직인다**
```
05:44:24  S,183,608,**800**,…        05:44:27  S,185,60A,**000**,…
```
**`occ` 옆 칸이 `800` → `000` 으로 같이 바뀌었다.** ⚠ **내가 그 필드의 정의를 모른다 — 추정하지 않는다.**
**arduino·socket 에 무엇인지 물어야 한다.**
