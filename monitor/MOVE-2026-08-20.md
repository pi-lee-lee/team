```
이동 명시 : **2026-08-20 07:55:16** (루트 통보 **수신** 시각)
⚠ **사용자의 원 발화 시각은 못 받았다.** 이 값은 그보다 늦다 — **하한으로만 쓴다**
⏳ 안정 구간 : 07:55:16 + 5분 = **08:00:16 이후**  → 🔴 **하한이다. 상한이 아니다**
🔴 이 구간 자료는 **관측에서 제외**한다. 로그·원장에는 남긴다(제외 ≠ 삭제)
```

## 🔴 이번 이동은 5분으로 안 끝난다 — 미리 적는다
```
· **SSID · 비밀번호** 바뀐다 → `Config.h` 는 **컴파일 상수** → 🔴 **굽기 필요**
· **서버 IP** 바뀐다 → 같은 이유로 굽기
· 서버 포트는 안 바뀐다 (8888 · 9990 · 8911)
```
> ### **그래서 t0 는 "이동 + 5분"이 아니라 **굽기·배포가 끝난 시각** 이다.**
**어제 이동 실측 : 약 20분** (5분이 아니었다). **그것을 예상값으로 적어 둔다.**
