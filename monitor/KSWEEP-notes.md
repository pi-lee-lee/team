# k 스윕 표 — 각주와 조건 (2026-08-20)

## 🔴 표 머리에 반드시 붙일 조건
```
"**액추에이터 2개(LD·L2)를 포함한 모듈 상한 13** 에서의 센서 **11**"
→ 액추에이터가 0이면 센서 13 이다. **"센서는 11개까지" 를 절대 상한으로 옮기지 마라**
구조식 : 11n + 11 <= 160 (한 배치) → n <= 13
```

## 정박
```
굽기 t0        2026-08-20 23:29:36   ← ⚠ 스윕 정박이 **아니다**
그 뒤 400초 캡처가 리셋을 하나 더 만들었다
✅ 스윕 정박   등록 재발생 **23:35:52** − (부팅~등록 21초) = **23:35:31**
k 경계 : 정박 + 180초 × n  ·  2 → 4 → 6 → 8 → 10 → 11(=선언 13, 2개 거부)
```
🔑 정박 규칙: **등록 재발생 = 장치 재부팅 → k=2 재정박.**
🔴 **단 갈래가 둘이다** — `⏱ 소크 관측 시작` 이 같이 뜨면 **서버 재기동**이지 장치 재부팅이 아니다.
**실측으로 그 갈래를 밟았다**(아래 각주 ①).

## 각주
```
① 🔴 **23:41:00 정지 → 23:41:09 기동** (socket 배포 860841b · pid 88775)
   → **k=4 구간(23:38:31~23:41:31) 한가운데**다. 그 행은 **서버 재접속을 안고 있다**
   ✅ 장치는 재부팅 안 했다 → **k 경계는 안 밀린다**(`⏱ 소크 관측 시작` 으로 갈랐다)
   ⚠ 내 측정에는 약 10초 공백이 생긴다 → 절사(>3초 제외)로 빠진다. **행은 살리되 표시한다**
② 🔴 `버린줄(모름)` — 23:41:09 **전**에는 서버가 `V` 를 안 읽어 전량 `모름` 으로 셌다(누계 4,791)
   그 뒤로는 **증가가 멈춘다.** **누계가 0 이 된 것이 아니다.** 앞뒤를 합치면 거꾸로 읽힌다
③ ⚠ `못쟀다 N` 의 분모는 **전체 칸**이다. 스윕이 가상 11칸을 쓰므로 대부분 빈 칸이다
   → **센서 품질로 읽지 마라.** 모듈별 분리는 다음 판이다
```

## 계측기 구분 (합치지 마라)
```
arduino `up/slot` = **장치가 센 슬롯**       (시리얼 · 정본)
monitor 절사평균  = **도착한 프레임 간격**   (서버 로그 · 독립)
🔑 둘의 차이가 곧 **손실**이다. 교차 실측: k=2 1.208 vs 1.220(+1.0%) · k=4 1.200 vs 1.204(+0.3%)
🔴 내가 못 내는 열 : ssovf · smiss · ramLow · flash → **미계측**(시리얼 전용)
```

## ⚠ 추정량 이력 — 왜 절사평균인가
```
❌ 생평균 : 리셋 21초 공백 하나가 130프레임 평균을 0.17초 밀었다 (1.388)
❌ 중앙값 : 로그 1초 · 슬롯 1.2초 → 간격이 1초/2초뿐 → **항상 1.000. 양자화가 신호를 죽인다**
           🔴 그 1.000 은 그럴듯하다. 모든 k 가 같아 보여 "부하가 슬롯을 안 민다" 가 된다
✅ 절사평균(>3초 제외) : 1초와 2초의 **비율**이 1.2 를 만든다
🔑 잡은 것은 통찰이 아니라 **arduino 값과의 대조**다. 혼자였으면 못 잡았다
```

## 🔴 각주 ④ — **k=10 구간의 큰 공백 둘은 링크다. 부하가 아니다**
```
23:48:47→23:49:12 (25초) · 23:49:12→23:49:34 (22초)
k=2~8 에는 없던 크기라 **부하 신호 후보**였다. 갈랐다:
✅ 서버가 직접 판정했다 :
   `= 재연결 판정: **링크 재접속**(장치는 안 죽었다) — uptime 664 → 710 (+46초) · 공백 22초`
   `-ARD 세션#1 종료(상대가 닫음) 지속 8분22초` → `+ARD 세션#2`
🔑 **`uptime` 이 664→710 으로 계속 늘었다 = 장치는 멈추지 않았다.** 링크만 끊겼다
```
> ### **그러므로 k=10 행의 공백을 부하 증거로 쓰면 안 된다.**
🔑 **서버에 내장된 판별자를 처음 썼다** — `재연결 판정: 링크 재접속 / 재부팅`.
**내 "등록 재발생 = 재부팅" 규칙보다 이쪽이 정확하다**(uptime 을 직접 본다). 앞으로 이것을 쓴다.
⚠ 다만 그 줄은 **재접속이 일어나야** 찍힌다. 재접속 없는 정지에는 여전히 내 규칙이 필요하다.

## ⚠ 관찰 — 확인 안 한 것 둘 (arduino·socket 몫)
```
① `미결속모듈 **9/13**` 🔴 — 스윕이 가상 모듈을 선언하니 예상되지만 **확인 안 했다**
② `occ` 값에 `0C00` 이 보인다 = 비트 11·10. n=13 에서 i=1(B1)·**i=2**
   → i=2 는 가상(미배선) 센서인데 점유로 섰다? **내 비트 매핑이 틀렸거나 뭔가 있다**
   ⚠ **단정 안 한다.** 매핑 정본은 arduino 다
✅ 확인된 것 : `V,,03D,,,…` = 칸1(B1) **0x3D = 61cm** — B1 은 값을 낸다
```
