## 1. 전제 — 이것이 깨지면 나머지 예측은 판정하지 않는다

**P0 `devid거절 = 0`** (socket 신판이 처음 내보내는 칸)
> 🔴 **0 이 아니면 같은 망에 동일 `devid` 보드가 붙은 것이고, 그 창의 장치 지표는 우리 것이 아니다.**
> 그때는 **예측 판정을 중단하고 오염 구간을 기록만 한다.** (오늘 오전에 이것을 못 봐서 4시간을 잃었다)
⚠ **이 칸은 이번 판에 처음 생긴다 — 이전 창과 크기 비교 불가.**

## 2. 예측 — 전부 분모와 함께 판정한다

| # | 예측 | 반증 조건 |
|---|---|---|
| **P1** | **정상 순서 거래의 T2 = 0** (창 F: 0/3,772) | 정상 순서 거래에서 T2 가 **1건이라도** 나면 분리 가설이 깨진다 |

## 3. 🔴 `0` 을 읽는 규칙 (원장 1.1)
```
T2 = 0  →  ① 정말 안 났다        ② 창이 짧아 표본이 없다      ③ 표지가 안 찍혔다
```
**분모를 먼저 적는다**: 짝지어진 거래 수 · 창 길이 · `[CNT]` 표본 수.
🔴 **거래 1,000건 미만이면 P1·P2 를 판정하지 않는다** — 창 F 분모가 3,783 이었다.

## 4. 정지 조건 — **손으로 보지 않는다. 도구가 본다**
```
① devid거절 > 0            → 즉시 오염 표시 · 예측 판정 중단
② 짝지어진 거래 ≥ 1,000    → P1·P2·P4 판정 가능
③ 창 길이 ≥ 60분           → P3 판정 가능
```
`monitor/sendok_order.py` 가 ②를 분모로 찍는다. ①은 서버 요약줄에서 읽는다.
⚠ **①을 보는 코드가 없으면 조건으로 적지 않는다**(팀 규약) — 서버 요약줄에 있으므로 볼 수 있다.
