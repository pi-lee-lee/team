# 창 L·M 축 재귀속 — `espInit`(축 B)이 부팅 국면에 걸리는가 (REQ-0239 산출물)

**요청** `REQ-0239`(root) · **계기** arduino `REQ-0237` 철회 — 05:37:03 굽기(칩 `9edbcca`)의
장치 축은 **하나가 아니라 둘**이었다. `A = 가상 O* 모듈(6498b52)` · `B = espInit(b2d6574)`.

**축 B 의 실체(arduino 소스 판독, 실측 아님)**: `setup()` 에서 `netStepAt = millis()` 가 29줄
앞당겨지는 **부팅 1회성 시점 이동**. `netStepWait = 500`, 이후 사다리가 시각을 다시 잡는다.

> **그래서 내가 답할 물음은 하나다: 창 L·M 판정문 중 *부팅 국면* 에 걸리는 문장이 있는가.**

---

## 0. 🔴 방법 — 로그를 자르기 전에 계측기의 성질을 먼저 봤다

**장치의 `[CNT]` 줄은 부팅 이후 *누적* 이고 60초마다 찍힌다**(`up=` 이 부팅 후 초).
```
→ 그러므로 **첫 줄(up=60)의 값이 곧 "부팅 60초 동안 쌓인 양"** 이다.
→ 로그를 자를 필요가 없다. **장치가 이미 갈라서 찍어 준다.**
```
로그 슬라이스(`slice_window.py`)는 `T2`·`CIPSEND` 확인에만 썼다.
**새 파서를 만들지 않았다** — 같은 계측기에 두 입력을 준 차분이다.

### ⚠ 함정 하나를 밟았다가 원문을 열어 잡았다
```
grep -ac 'cksumng' monitor/serial-winM.log  →  38
🔴 이 38 은 **체크섬 실패 38건이 아니다. `[CNT]` 출력 줄이 38개**라는 뜻이다.
   `cksumng` 은 사건 줄이 아니라 **CNT 한 줄 안의 필드**다.
```
**그리고 이 오독은 그럴듯하게 틀린다**: 슬라이스한 부팅 60초 구간의 `cksumng` 이 `0` 으로 나오는데,
그건 "부팅 국면에 실패가 없었다"가 아니라 **첫 CNT 가 아직 안 찍혔다**(첫 줄이 `05:59:19` = t0+63초)는 뜻이다.
**원장 1.1 의 `0` 셋 가르기가 그대로 재현됐다.**

## 1. 창 M — **판정 문장 전부가 부팅에서 14분 이상 떨어져 있다**

**창** t0 `05:58:16`(탭 개방 DTR 리셋 = 부팅) · **주입 `06:12:23~06:35:53`** · 로그 `serial-winM.log`

### 계수의 시간 전개 (장치 `[CNT]` · 누적)
```
시각      up      cksumng  penddrop  pendfill  bigfill  bigdrop
05:59:19    60      0        0         43        1        0     ← 🔑 **부팅 60초의 기여분**
06:01:19   180      0        0        142        1        0
06:10:21   720      0        0        590        1        0     ← 주입 전. 여전히 전부 0
06:16:21  1080     19        0        888      161        0     ← 주입 시작 뒤
06:28:24  1800    108        0       1487      626        0
06:34:25  2160    154        2       1784      845        2     ← penddrop 발동 (부팅 +36분)
06:35:25  2220    163        2       1834      882        2     ← 판정문이 인용한 자리 ✅ 일치
```

### 문장별 재귀속
| 창 M 판정 문장 | 부팅 60초 기여 | 판정 |
|---|---|---|
| `cksumng` 165 (4.10%) | **0** (부팅 12분 뒤까지도 0) | ✅ **축 B 무관 — 재서 확인** |
| `penddrop 2` · `bigdrop 2` | **0** (부팅 +36분에 발동) | ✅ **축 B 무관 — 재서 확인** |
| `>=64B` 분모 `bigfill 882` | **1 / 882 = 0.11%** | ✅ **축 B 무관 — 분모 오염 무시 가능** |
| `SEND OK` 축 `T2 = 0` | 부팅 60초 안 `T2 0` · 밖도 `T2 0` | ✅ **축 B 무관 — 재서 확인** |
| 조작 사슬 4쌍 (`06:03~06:07`) | 부팅 +5~9분 | ✅ **축 B 무관** |
| 도착 오프셋 중앙 264ms | 주입 구간(부팅 +14분~) | ✅ **축 B 무관** |

### `T2` 재계산 — 로그를 실제로 잘라서 다시 셌다
```
전체       05:58:16~06:36:35   CIPSEND 1,910   T2 **0**
부팅 60초  05:58:16~05:59:16   CIPSEND    42   T2 **0**
부팅 제외  05:59:16~06:36:35   CIPSEND 1,869   T2 **0**
```
> **부팅 60초를 빼고 다시 세도 `T2` 는 0 이고, 분모는 2.2% 만 줄어든다.**
⚠ **`CIPSEND 1,910` 을 판정문의 `거래수 1,185` 와 크기 비교하지 마라** — 앞은 `AT+CIPSEND` **줄 수**이고
뒤는 **거래 짝짓기 결과**다. 정의가 다르다(원장 §숫자 둘을 비교하기 전에). 여기서 쓴 것은 **차분뿐**이다.

🔑 **`bigfill` 이 주입 전까지 `1` 로 고정이다** — `>=64B` 대역은 **주입이 만든 것**이고
주입은 부팅 14분 뒤에 시작한다. **부팅 국면에는 그 대역이 사실상 존재하지 않는다.**

## 2. 창 L — 🔴 **여기 하나가 걸린다**

**창** t0 `05:40:32`(탭 개방 = 부팅) ~ `05:56:56` · **자극 없음(자율 구간)** · 로그 `serial-winL.log`

```
시각      up     cksumng  penddrop  pendfill  bigfill
05:41:34    60      0        0         43       1     ← 🔴 **bigfill 이 여기서 이미 1**
05:54:36   840      1        0        692       1     ← cksumng 0→1 (부팅 +14분)
05:56:37   960      1        0        792       1     ← 끝까지 **bigfill 은 1 그대로**
```

> ### 🔴 **창 L 의 `bigfill = 1 · bigokst = 1` 은 부팅 60초 안에서 났고 그 뒤로 한 번도 안 늘었다.**
> ### **이 값은 축 B 에서 배제할 근거가 없다 — 부팅 국면 사건이다.**

### ✅ 다만 그 문장은 원래부터 판정 근거가 아니었다
그 값이 쓰인 곳은 창 M 판정문 §2 의 *"창 H·I·J·**L** 에서는 `penddrop` 이 계속 0"* 이다.
```
창 L 의 penddrop 0 은 **분모가 1 이다**(bigfill=1). → `0/1`
```
**`0/1` 은 "버림이 드물다"를 말할 수 없다.** 원장 1.1 그대로 — **자극이 없어 분모가 안 찬 것**이지 건강이 아니다.
> **그래서 축 B 재귀속이 필요한 문장은 하나이고, 그 하나는 애초에 결론을 지탱하지 않는다.**

**창 L 의 `cksumng = 1`** 은 부팅 +14분이라 ✅ 축 B 무관.

## 3. 🔴 못 재는 것 — **미상으로 둔다**

```
❌ 내가 잰 것 : "부팅 60초 구간이 각 지표에 기여한 양"
❌ 내가 못 잰 것 : **축 B 가 정상상태에 영향을 남기는가**
```
축 B 가 부팅 1회성으로 끝난다는 것(`netStepWait=500`, 사다리 재조정)은 **arduino 의 소스 판독**이고
**내 계측기에는 축 B 의 표지가 아예 없다.** 즉 위 표의 ✅ 들은
**"부팅 국면에 안 걸린다"까지가 실측**이고, **"그러므로 축 B 와 무관하다"는 arduino 의 소스 판독을 빌린 것**이다.

> **배제는 후보를 하나 줄일 뿐이다. 오늘 `hex → cksumng` 이 정확히 그렇게 무너졌다.**
> **축 B 가 정상상태에 무언가를 한다면 위 판정은 다시 봐야 한다 — 그 가능성은 닫지 않는다.**

⚠ 그리고 **부팅 60초는 내가 고른 폭**이다. 축 B 의 소스상 영향 폭은 `~500ms` 라 60초는 넉넉하지만,
**넉넉한 폭을 골랐다는 것과 폭이 옳다는 것은 다른 진술이다.**
