## 4. 🔑 그래도 이 로그는 **버리지 않는다** — 두 가지 증거다

루트 지시: *"로그는 지우지 마라."*

1. **원인 진단의 유일한 근거다.** 서버 로그에는 `세션 0 · 프레임 0` 밖에 없어서
   *"보드가 죽었나 / 새 펌웨어가 고장인가 / 서버가 문제인가"* 를 **가를 수 없었다.**
   장치가 **어느 주소를 부르고 있는지**는 시리얼에만 찍힌다:
   ```

   00:05:07  [AT] "ERROR" (5)
   00:05:07  [AT] "Unlink" (6)
   ```
   → **원장 6.10("시리얼 탭이 없으면 구분이 원리적으로 불가능")의 새로운 사례다.**
   이번에 갈린 것은 자해/리셋이 아니라 **"장치 고장" 대 "설정 불일치"** 였다.

2. **새 칩 `539ac53` 의 부분 검증 기록이다.** 부팅 · Wi-Fi 결합 · CIFSR 까지는
   **정상으로 확인됐다**(배너 1 · IP 확보 89). 이 구간이 없었으면 창3 에서
   그 셋까지 처음부터 의심해야 했다.
