## 1. 🔴 **표지가 없다 — 그 사실을 미리 선언한다**
```
[REG] 등록 전송 **143B**              → 칩과 같다
[PARKING NODE] 10 slots / 12 modules  → 같다
[BOOT] 사다리 4단 … **미배선**         → 같다
```
**리팩터링이라 관측 가능한 문자열이 하나도 안 바뀐다. 그게 이 굽기가 성공했다는 뜻이기도 하다.**
> ### 🔴 **그러므로 "구워졌나"를 내 계측기로는 확인할 수 없다.**
> ### **근거는 arduino 의 hex 대조(IDENTICAL)와 굽기 시각뿐이다. 그것이 유일한 근거다.**
⚠ **표지의 부재를 사전에 선언해 두지 않으면 다음 사람이 침묵을 결함으로 읽는다.**
🔑 이것은 §*"표지는 산출물에서 온 것이어야 한다"* 의 **뒷면**이다 — **없을 때도 선언해야 한다.**
⚠ `[RAM] 최저 여유` 2B 감소는 **표지로 안 쓴다**(최저 수위라 잡음이 있다). 참고만.

🔴 **분모를 채우기 전에는 "유지됐다"를 쓰지 않는다.** 창 X(451)·창 Y(762)에서 두 번 못 채웠다.
🔴 **두 기준으로 센다** — ①비출력(`\x`) + ②**출력가능**(`AT+CIPSEND!24`). ①만 세면 절반을 놓친다.
🔴 **`uart_damage.py` 로만 센다** — heredoc·subprocess 안에서 세면 `0` 이 나온다(창 V 판정문에 틀린 `0` 이 실렸다).

### ⚠ 그리고 **컴파일러가 답한 것을 창으로 다시 재지 않는다**
```

```

## 3. 판정 축 — `busy p`
```
`busy p` **0**  → 파서 살아 있음 → 3단이 먹는다 → 자력 회복 = **정상**
`busy p` **>0** → 파서 먹통 → 🔴 **천장. 4·5단이 없으므로 사람이 개입해야 한다**
```
