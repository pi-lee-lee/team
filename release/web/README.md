# 0. 🔴 **여기는 정본이 아니다. 사진이다**

```
정본 : 서머리/server/*.html        ← **지금 도는 서버가 읽는 파일**
사진 : 릴리즈/web/*.html           ← 여기
```

> ### ★ **여기서 고치지 마라.** 정본을 고치고 아래 명령으로 내린다.
> ### 🔑 사진을 고쳐서 원본을 바꾸지 않는다 — 방향은 **한쪽뿐**이다.

```bash
node web/tools/release-sync.mjs           # 갈렸나 검사만 (다르면 exit 1)
node web/tools/release-sync.mjs --sync    # 정본 → 릴리즈로 맞춘다
```
⚠ **사본이 둘이면 갈린다.** 갈리면 릴리즈가 **조용히 옛것**이 되고, 릴리즈 폴더는 평소에
아무도 안 열어서 **아무도 모른다.** 그래서 믿음이 아니라 **검산기**로 지킨다.

# 1. ✅ 자립한다 — **값으로 보인다**

## 외부에서 가져오는 것이 **0 이다** (실측 2026-08-27)

| 세는 것 | index | user8080 | user8081 |
|---|---|---|---|
| `<script src=` | **0** | **0** | **0** |
| `<link href=` | **0** | **0** | **0** |
| `import … from` | **0** | **0** | **0** |
| `url(http` | **0** | **0** | **0** |
| CDN(`googleapis`·`unpkg`·`jsdelivr`) | **0** | **0** | **0** |

```bash
# 다시 세는 법 — 숫자가 하나라도 0 이 아니면 그 파일은 자립하지 않는다
for f in 릴리즈/web/*.html; do
  grep -c '<script[^>]*src=' "$f"; grep -c '<link[^>]*href=' "$f"
done
```

> ### 🔴 **SPEC 은 "번들한 라이브러리 하나를 빼고 빌드해서 실패를 보여라" 고 요구한다.**
> ### ★ **여기는 뺄 것이 없다** — 라이브러리가 0개인 단일 HTML 파일이다.
> ### 🔑 그래서 **"뺄 것이 없다" 를 값으로 보이는 것**이 이 화면의 빨간불에 해당한다.
> 위 표의 모든 칸이 `0` 이라는 것, 그것이 증명이다. 하나라도 `0` 이 아니면 **그 항목이 빠질 수 있는 것**이다.


# 2. 🔴 런타임 의존 — **파일이 아니라 URL 이다**

화면이 밖에서 가져오는 것은 **딱 둘**이고, 둘 다 **브라우저가 푸는 상대 경로**다.

```js
index.html:6245   fetch(LOG_FILE + '?t=' + …)     LOG_FILE = 'data_log.json'
셋 다             new WebSocket(ws://<이 페이지가 온 곳>/ws)
```

> ### ★ 그래서 **파일 시스템 배치는 서버가 정해도 된다.** 화면이 지키는 것은 **URL 경로**뿐이다.

```
✅ 서버가 보장할 것 : `/index.html` 과 `/data_log.json` 이 **같은 URL 경로 아래**
✅ 화면이 지키는 것 : 절대 주소를 **안 쓴다** — 포트도 호스트도 하드코딩하지 않는다
🔴 그러니 서버 실행 폴더가 어디든 상관없다. **화면은 릴리즈 이동에 제약을 안 건다**
```
⚠ `?ws=<포트>` 질의를 주면 그 포트로 붙는다 — **시험용 덮어쓰기**다. 배포에서는 안 쓴다.

# 3. 이 폴더를 검증하는 법

```bash
# ① 정본과 같은가
node web/tools/release-sync.mjs

# ② 화면이 도는가 (주입 · 서버 없이)
node web/tools/boards.mjs    --file 릴리즈/web/index.html      # 249 pass
node web/tools/user8080.mjs  --file 릴리즈/web/user8080.html   #  52 pass
node web/tools/user8081.mjs  --file 릴리즈/web/user8081.html   #  50 pass

# ③ 🔴 자립 — **저장소 밖에서**
D=$(mktemp -d); cp -R 릴리즈/web "$D/"
node web/tools/boards.mjs --file "$D/web/index.html"

# ④ 서버가 실제로 내주는가 (릴리즈 서버가 뜬 뒤)
node web/tools/live-all.mjs
```

> ### 🔑 ④의 첫 절이 **"배포가 됐나"** 다 — 서버가 내주는 표지와 이 폴더의 파일을 대조한다.
> ### 그게 안 닫히면 그 아래 측정이 전부 공허하다.
