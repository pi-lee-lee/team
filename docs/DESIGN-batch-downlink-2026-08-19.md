# 묶음 하행 (batch downlink) — 설계 요청

**사용자 지시 2026-08-19 (원문 인용)**

> *"우리 네트워크 환경 특성상 서버에서 노드(아두이노)로 송신하는 경우 **send함수 외에 묶음으로
> send하는 함수**가 필요하다. 동일시점에 3개의 명령이 들어가야한다면 최악의 ?? 거의 희박하지만
> **1개당 1.2초씩 밀린다.** 하나의 윈도우프래임에 3명령어를 담아서 보낼수 있어야한다.
> **딱 3개가 아니다 예를 든것이다. 최대 명령어 갯수가 필요하고** 해당 명령을 한윈도우에 묶어서
> 보낼수 있는 기능이 필요하다."*

## 🔴 이번 굽기에 넣지 않는다

```
지금 굽기의 목적 : **샘플이 성립하는가** — 항목 다섯을 값으로 확인한다
축을 하나 더 넣으면 : ⑤(왕복)가 실패했을 때 **원인 후보가 둘**이 된다
```
사용자가 *"**미리** 지정한다"* 고 했다 — **지금 만들라는 뜻이 아니라 설계에 넣으라는 뜻이다.**
**다음 굽기 경계로 묶는다.** 전선이 바뀌면 양쪽이 같이 움직여야 하므로 같은 경계다.

## 🔴 먼저 답할 것 — 이게 굽기 필요 여부를 가른다

### Q1. 지금 장치가 **한 번의 읽기에서 여러 줄**을 처리하는가 (arduino)

```
갈래 (B) 여러 줄을 한 번에 write     →  전선 형식 **무변화**
   `G,r1,3,1,ck\nG,r2,4,0,ck\nG,r3,5,7,ck` 를 한 AT+CIPSEND 로
   🔑 참이면 **장치 굽기가 필요 없다.** 서버만 고치면 된다 — 가장 싼 길

갈래 (A) 한 줄에 여러 명령           →  전선 형식 **변경** · 양쪽 굽기·배포
   `G*,<rid>,<idx>:<arg>,<idx>:<arg>,…,<ck>`
```
**(B)가 되면 (A)는 안 만든다.** 되는지부터 값으로 답해라 — 추정하지 마라.
확인할 것: `RxBuf` 가 한 읽기에서 여러 `\n` 을 끊어 내는가 · 버퍼 크기가 상한을 얼마로 만드는가.

### Q2. 🔴 **ACK 도 같이 밀리는가** (arduino)

사용자가 말한 것은 하행이다. 그런데 **ACK 가 슬롯마다 하나씩 올라가면 왕복은 그대로 밀린다.**
```
`AckQueue` 가 한 슬롯에 **여러 ACK** 를 싣는가?
🔑 이미 싣고 있으면 하행만 고치면 끝이다. 아니면 그쪽도 축이다
```
⚠ **묶음 하행을 만들고 ACK 가 직렬이면 사용자가 겪는 지연은 안 없어진다.**

### Q3. **최대 명령어 개수** — 사용자가 명시적으로 요구했다 (socket + arduino)

**추정하지 말고 계산해서 값으로 내라.** 상한을 만드는 것이 무엇인지 같이 적어라:
```
(B) 라면 : 장치 수신 버퍼 · 한 AT+CIPSEND 의 상한
(A) 라면 : MAX_LINE 64 — 머리 `G*,999,` + 체크섬을 빼고 항목당 최악 `255:4294967295`
```
🔴 **최악값과 실제값을 갈라 적어라.** `3:1` 같은 실제 명령은 훨씬 짧다.
**API 에 박는 상한은 최악 기준이어야 한다** — 안 그러면 긴 인자에서 조용히 잘린다.

### Q4. **부분 실패를 어떻게 답하는가** (socket)

```
3개 중 2번이 `result=3` 이면? 나머지 둘은 수행됐나 안 됐나
```
- **원자적이어야 하나, 각각 독립인가.** 정하고 **명세에 적어라.**
- 🔑 **`send()` 하나의 반환값으로는 못 나른다.** 묶음의 반환 모양을 따로 정해라.

## API 모양 — 사용자 요구를 지켜라

> *"복잡한 구조는 **은닉화** 하여 개발자에게는 **간단한 구조로**"* ·
> *"코드 작성 시점에 해당 코드의 **흐름이 보인다**"*

```
🔒 감춘다  : 포장·분할·재시도·슬롯 배치 — **호출자가 바꿀 수 없는 순서**
🔓 보인다  : **무엇을 묶는가** — 그건 호출자의 선택이다
```
- 🔴 **상한을 넘기면 조용히 자르지 마라.** 거절하거나 나눠 보내되 **어느 쪽인지 명세에 적어라.**
- ⚠ **`send()` 를 없애지 마라.** 하나 보낼 때 묶음 문법을 쓰게 하면 샘플이 어려워진다.

## 계산 주체

**최대 개수를 누가 계산하나** — 서버 상수인가, 장치가 등록 때 선언하나.
🔑 **장치 버퍼가 상한을 만든다면 장치가 선언하는 것이 맞다.** 정하고 적어라.
