### 🔴🔴 비밀번호에 `!!` 가 있다 — **셸에서 그대로 치지 마라**

앞 판 주석이 *"이번 값엔 `!` 가 없다(히스토리 확장 걱정 없음)"* 라고 적어 뒀다.
**이번 값에는 있다. 그 전제가 뒤집혔다.**

```bash
❌ echo "0424719222!!"          # 대화형 bash 에서 히스토리 확장이 일어난다
❌ req.sh --body "…0424719222!!…"   # CLAUDE.md 가 이미 금지한 형태 (2026-08-16 사고)
✅ 작은따옴표 · 인용된 heredoc(<<'EOF') · 파일에 적어 --body-file 로 넘긴다
```
🔑 **펌웨어에 들어간 뒤에는 반드시 값으로 확인해라** — 확장이 일어나면 **조용히 다른 문자열이 박힌다.**
`arduino` 는 굽기 전에 소스에서, 굽고 나서 접속 성공으로 두 번 확인해라.

## 2. 순서 — 🔴 **IP 를 먼저 확정하고 나서 굽는다**

```
① 새 망에 이 PC 를 붙인다
② 새 IP 를 **값으로** 확인한다 :  ipconfig getifaddr en0
③ 서버를 새 IP 로 기동/확인한다 (bind 는 0.0.0.0 이라 대개 그대로 뜬다)
④ arduino 가 client.ino 셋을 같이 고친다 — WIFI_SSID · WIFI_PASS · SERVER_IP
⑤ 굽는다  → ⑥ 등록 D 프레임이 서버 로그에 뜨는지로 확인
```
⚠ **④를 ②보다 먼저 하면 IP 를 두 번 굽게 된다.** 굽기는 관측 경계를 만든다 — 한 번으로 묶어라.

### 고칠 자리 (arduino 소유 · 루트는 못 고친다)
```
조별과제샘플/client.ino:91  #define WIFI_SSID   "SK_WiFiGIGA50DC_2.4G"
조별과제샘플/client.ino:92  #define WIFI_PASS   "2011050796"
조별과제샘플/client.ino:97  #define SERVER_IP   "192.168.35.21"
```
⚠ `client.ino:93~95` 에 **앞뒤 공백 금지** 경고가 있다 — 실제로 `" 192.168.35.21"` 로 구워진 적이 있다.

⚠ `arduino/client/client.ino` 와 `requests/recovery-2026-08-16/` 에도 같은 상수가 있다.
**그건 잔재다**(arduino §27.5 — `client.ino` 가 저장소에 일곱 개). **굽는 것은 `조별과제샘플/client.ino` 다.**

## 3. 🔴 이 굽기는 **A[1] 배포와 같은 경계에 묶어라**

미배포 다섯이 대기 중이다(§0-A). **굽기도 서버 재기동도 둘 다 관측 경계를 만든다.**
```
✅ 한 경계 : 서버 IP 변경 + A[1] 다섯 배포 + 펌웨어 굽기(SSID·PASS·IP)
             → 그 뒤 새 창 하나
❌ 따로    → 창이 세 번 조각난다
```
⚠ **그러면 A[1] 판정에 "망 이동"이라는 축이 하나 붙는다. 판정문에 그것을 적어라.**
🔑 판별자는 §"축이 하나 느는가"다 — **망 이동은 축이다.** 다만 **묶지 않으면 창이 더 조각나므로**
이번에는 묶고 **축을 명시**하는 쪽이 낫다. 이 판단의 근거를 판정문에 남겨라.
