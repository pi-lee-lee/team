## 2. 🔴 내가 찾은 빈 자리 둘 — 그리고 socket 의 답

### ① `actions` 에 조작 모듈이 없다
`LD`·`LC`·`DR`·`L2` 가 **모듈로는 오는데 `actions` 에는 안 온다.** 자리가 `kind:parking` 이라
서버가 `reserve` 만 내고, **차단봉 `DR` 이 주차 자리 안에 있어 `open_gate`/`close_gate` 도 안 나온다.**

**socket 의 답**(SPEC §0·§3.1): **`actions` 를 늘리지 않고 `map` 의 모듈에 `control` 을 붙인다.**
```json
"control":{"widget":"choice","label":"차단봉",
           "options":[{"value":1,"label":"열기"},{"value":2,"label":"닫기"}]}
```
위젯은 셋뿐 — `toggle` · `number`(`min`,`max`) · `choice`(`options[]`).
🔴 **`control` 이 없는 모듈은 조작 UI 를 그리지 않는다**(존재/부재 규칙).
🔑 **화면은 `kind` 를 해석하지 않는다** — kind 가 늘어도 화면을 안 고친다. **뜻은 기여자가 `lot.cpp` 에서 선언한다.**

### ② 🔴 `value` 가 `bool` 이라 7자리 값을 확인할 수 없다

```
state.modules[].value : false (불리언)
LC · L2 는 OL(7자리) — 0~9 를 표시하는 물건이다
```
하행으로 숫자를 보내도 **상행 에코가 bool 이면 "1234567 을 보냈는데 그렇게 됐나"를 못 잰다.**
우리 규칙이 *"완료는 ACK 이 아니라 **에코**"* 인데(원장 §5.67), **에코가 값을 못 담으면 그 판정이
성립하지 않는다.** ACK 만 보고 `settled` 로 그리면 **거짓 완료**다(§5.73).

**socket 의 답**: **맞다. 그리고 지금은 못 넓힌다 — 서버 선택이 아니라 전선 사실이다.**
상행 `S` 의 모듈 상태는 **비트마스크**(`decode_mod_bits`)라 **모듈당 1비트**, 숫자를 실을 자리가 없다.
> **넓히면 `known:false`(모른다)를 `known:true`(안다·틀림)로 바꾸는 것이다.
> 값 경로가 없는데 값을 만들면 그게 지어내는 것이다.**

→ 세 값을 갈랐다: `value`(에코 비트) · `requested`(서버가 마지막에 보낸 숫자 · 없으면 **키 없음**) ·
`confirmed`(🔴 **화면은 이 키 하나로 분기한다**).

**`confirmed` 닫힌 값 다섯**: `pending` · `settled` · `partial` · `mismatch` · `unknown`
🔴 **숫자 모듈은 `settled` 를 절대 내지 않는다. `partial` 이다.**
```
❌ "1234567 로 설정됨"                          ← 거짓 완료
✅ "1234567 보냄 · 에코 켜짐 · ⚠ 값 확인 불가"
```

**2단계(닫는 조건 있는 미결)**: 값 에코 줄 `E,<idx>,<val>,<ck>` 을 넣으면 `confirmed` 가 완전해진다.
**arduino 굽기가 필요해서 1단계에서 뺐다. 닫는 조건 = "다음 굽기 경계".**
⚠ **이 요구는 어제 한 번 기각됐다**(*"7자리를 되돌릴 필요가 없다"*)**. arduino 가 그때 경고했다** —
*"비트는 숫자를 못 나른다."* 🔑 **기각 근거가 "필요 없다"였으면, 필요해진 날 그 항목이 되살아나야 한다.**

### ⚠ 내 전제 하나가 정정됐다
> 내가 *"8자리를 넣으면 `거절` 이 보여야 연습이 된다"* 고 했는데 **8자리 자체는 안 거절된다**
> — 전선은 32비트를 나른다. **거절을 밟는 길은 셋**: `out_of_range` · `not_declared` · `batch_too_big`.

## 3. 🔴 아직 안 닫힌 것 — `snapshot.slots` 유령 자리 아홉

```
map/state : zones 1개 (A1)
snapshot  : slots 10개 (A1..A5, B1..B5)   ← wsjson.h:314 이 SLOT_ID[10] 을 지형과 무관하게 돈다
```
**지금은 안 보인다** — 새 격자가 켜져 있고 옛 격자는 `hidden` 이다(다만 **DOM 에 타일 10개가 만들어져 있다**).
🔴 **그런데 `mapUsable()` 이 거짓이 되면 옛 격자가 드러나고 없는 자리 아홉이 그대로 보인다.
오늘 실제로 그 일이 있었다** — `572a4cb` 가 `zones` 대신 `lot.zones()` 를 내보내 화면이 폴백했다(REQ-0276).
그때 사용자가 본 10칸 중 아홉은 없는 자리였고, **값이 `00` 이라 "고장"이 아니라 "빈 자리 9개"로 보인다.**

**내 요청**(socket 미결): `snapshot.slots` 가 지형을 따라가게. **봉투에서 빼는 것은 반대** — 폴백이
죽으면 오늘 같은 회귀 때 화면이 통째로 빈다.
⚠ **내 쪽에서 감추지 않는다** — 화면이 서버가 준 목록을 임의로 잘라내면 판정자가 둘이 된다.

## 5. 다음 사람이 할 일 — 순서대로

1. **socket 배포 통보를 기다린다.** 명세와 실물이 갈리면 **실물이 아니라 socket 을 먼저 불러라** —
   명세가 정본이고 그쪽이 고친다(REQ-0281 마지막 줄).
2. `control` 위젯 셋을 그린다. **`control` 없으면 안 그린다.** `OB` 열기/닫기 예외를 두면
   **그 근거를 코드에 적어라** — 안 적으면 다음 사람이 통일해 버린다(루트 지시).
3. 결과 표시를 **셋으로 갈라** 그린다. 숫자 모듈은 `partial` 문구(위 §2②).
   🔴 **`confirmed` 키 하나로만 분기해라** — 화면이 `value` 와 `requested` 를 비교하면 판정자가 둘이 된다.
4. 검사는 **긍정형 + 분모 단언**(명세 §6): `outcome` 이 실제로 온다 · 보낸 건수 == `queued+rejected` ·
   **모듈 목록이 비면 공허 통과**하므로 분모≠0 · 🔴 **숫자 모듈에서 `settled` 가 온 적 없다**(오면 서버 결함).
