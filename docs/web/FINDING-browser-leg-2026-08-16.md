## 1. 🔴 시작 전에 막고 고친 것 — 시험 페이지가 운영 서버로 붙었다

**판독 → 수정 → 실측으로 확인.** 자세한 것은 REQ-0129(통보).

서버는 HTTP 와 WS 가 같은 포트인데 화면은 포트를 상수 `9900` 으로 박아 뒀다. 그래서
시험 인스턴스(:10000)가 준 페이지를 열면 **WebSocket 만 운영(:9900)으로** 붙는다.
폴백 폴링은 상대경로라 :10000 으로 가므로 **한 화면이 두 서버를 섞는다.**

> **브라우저를 한 번 열고 예약을 한 번 누르는 것만으로 관측 창 A 가 깨진다.**
> 더 나쁜 것은 시험 인스턴스 로그에는 아무 흔적도 안 남는다는 점이다.

- 고침: `resolveWsPort()` = `?ws=` → `location.port` → 9900
- 화면이 **접속 대상 URL 을 스스로 말하게** 했다(푸터). 표시와 접속이 같은 함수를 쓴다
- `?ws=` 가 페이지 포트와 다르면 빨간 경고를 띄운다
- 루트가 운영 로그로 확인: **A 창 안에 브라우저발 하행 0건 — 오염 없었다**

## 3. 안 되는 것 — 서버 쪽 둘 (REQ-0132 로 요청)

### 3.1 WS 스냅샷에 `last_frame_ts` 가 없다 — 실측(브라우저)

```
WS   device = { online, device_id, uptime, seq }     ← 없다
파일 device = { online, last_frame_ts }              ← 있다
```

화면의 "마지막 프레임" 칸: `"알 수 없음 (이 경로에는 이 정보가 없습니다)"`

**신선도 표시가 폴백에서만 돌고 정상 운영 중에는 영영 모름이다.** REQ-0067 이
"죽은 데이터를 살아있는 것처럼 보여주지 않는다"고 넣은 기능이 **주 경로에서 미달**이다.
REQ-0122 때는 판독으로 추정만 했던 것을 오늘 원문으로 확정했다.

### 3.2 `GET /?쿼리` 가 404 — 실측(브라우저 + curl)

`GET /` 200 · `GET /index.html?demo=1` 200 · **`GET /?demo=1` 404**
시연에서 `호스트:9900/?demo=1` 을 치면 빈 페이지가 뜬다. 오늘 내 시험도 여기서 한 번 죽었다.

## 4. 숙제 — `slots[]` 결손을 화면이 말하는가

### 4.1 전제가 틀렸다 — 이미 갈리고 있었다 · 실측(주입)

"지금은 조용히 10칸이 비어 보인다"는 인상이었는데, **측정 결과 그렇지 않다.**

| 넣은 것 | 화면 |
|---|---|
| `slots` 키 없음 | 10칸 전부 `상태 미상 / 데이터 없음` (빈 자리 0칸) |
| `slots: []` | 같음 |
| 3칸만 실림 | 7칸 미상 · 3칸만 정상 |
| 비트열만 있고 `slots` 빔 | 10칸 전부 미상 |

근거는 `normalizeSnapshot()` 의 `known: bySlot.has(id)` 다. **결손 칸이 빈자리로 그려지는 일은 없다.**

### 4.2 그런데 진짜 빈틈은 다른 데 있었다 — 고쳤다

그 말이 **칸 안에만** 있었다. 10칸 중 3칸만 미상이면 나머지 7칸이 정상이라
**화면 전체는 멀쩡해 보인다.** 시연에서 발표자는 못 알아챈다.

→ 격자 위에 **집계 배너**를 추가했다(`#slots-banner`).

```
전부 미상  : "자리 데이터가 없습니다 — 이 기록에 slots 가 없어 10칸 전부 상태를 모릅니다.
              비어 보이는 것이 아니라 모르는 것입니다."
일부 미상  : "7칸의 상태를 모릅니다 (A4 · A5 · B1 · B2 · B3 · B4 · B5).
              이 칸들은 빈자리가 아니라 데이터가 오지 않은 칸입니다."
```

- 배너는 **집계만** 한다. 칸의 문구를 대신하지 않는다
- **스냅샷이 오기 전에는 침묵**한다 — 그건 결손이 아니라 "아직 안 왔다"이고 연결 줄이 이미 말한다
- 같은 문구를 매초 다시 쓰지 않는다(`aria-live` 노드라 스크린리더가 다시 읽는다)
- 정상 운영에서 뜨지 않는 것을 **실측으로 확인**했다(e2e §2)
