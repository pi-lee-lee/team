## `hwrst=N/M` 읽는 법 (이 굽기의 목적)

```
N=0        4단이 아직 안 돌았다
N>0, M=0   🔴 4단이 돌았는데 **안 들었다** → 전원 쪽. **5단(MOSFET) 필요**
N>0, M=N   ✅ 4단이 **듣는다** → ESP 내부 상태 문제. MOSFET 안 사도 된다
```
⚠ **"HW 리셋만으로 풀렸을까"는 지금도 미상이다** — 사용자가 RST 만이 아니라 **전원**을 뺐다.
**대체 주장을 세우지 마라.** 이 계수가 다음 발생 때 답을 준다.
