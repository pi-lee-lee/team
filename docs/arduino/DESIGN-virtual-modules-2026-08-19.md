# 가상 `O*` 모듈 설계 — REQ-0227 (2026-08-19)

**왜**: 실기 등록 10개가 **전부 `IP`(관측 전용)** 이라 **명령 가능 모듈이 0개**다.
그래서 **조작 사슬이 한 번도 안 돌았다** — `open_gate` 가 `module_absent` 로 막힌다.
`modules[].value`·`known`·`completion`·`actions` 가 **실제 값으로 흐른 적이 없다.**

⚠ **이 문서는 장치 쪽만 정한다.** 전선 형식은 `docs/net/DESIGN-bridge-node-module-zone.md` 가 정본이다.

---

## 1. 무엇을 만드나 — **둘만. 근거는 전선 예산이다**

```
D,E1,OBV,<ck>     ← 입구 차단봉 (가상)
D,X1,OBV,<ck>     ← 출구 차단봉 (가상)
```
| | 지금 | 추가 후 |
|---|---|---|
| `n` | 10 | **12** |
| 등록 배치 | 121B | **143B** (≤ `BATCH_CAP` 160) |
| `S` hex 폭 | `ceil(10/4)=3` | **`ceil(12/4)=3` — 그대로** |
| `S` 크기 | 21B | **21B — 안 변한다** |

> ### 🔑 **`n=12` 가 공짜 상한이다.** `n=13` 부터 폭이 4가 되어 `S` 가 3B 늘고
> ### `≥64B` 대역 진입이 그만큼 빨라진다. **그래서 둘만 만든다.**
⚠ `OG`(안내등)·`OL`(유도등)은 **안 만든다** — 차단봉만으로 `open_gate` 사슬이 끝까지 돈다.
**사슬을 도는 데 필요한 최소**가 기준이다.

### ⚠ 이름은 `E1`·`X1` 이어야 한다 — 바꾸면 조용히 끊긴다

**서버 결속 규칙이 `모듈 name == 자리 id`** 다(원장 §20). **다른 이름을 쓰면 등록은 성공하고
자리에는 아무것도 안 붙는다.** 오류가 안 뜬다.

---

## 2. 🔴 가상임을 전선에 드러낸다 — `V` **접미**

```
kind[0]                        → 명령을 받는가 (O/I)     ← 안 바뀐다
kind[0..1]                     → 종류 (IP·IX·OG·OL·OB)   ← 표가 안 는다
kind.length == 3 && 끝이 'V'   → **가상**
```
> ### **"3글자 종류를 새로 만든다"가 아니다.** 그러면 `OBV`·`OGV`·`OLV`·`IPV`… 로 **표가 두 배**가 된다.
> ### **`V` 는 종류와 직교하는 한 비트다** (socket 정의 · 내 첫 제안을 그가 고쳤다).

### ⚠ `tmask` 를 쓰지 않은 이유 — **구조적으로 안 된다**

```
tmask  : **조건부 존재** — "무장 중에만 붙는 선택 필드"(§2.4)
가상성 : **영구 속성**
```
**영구 속성을 사라지는 필드에 실을 수 없다.** `testArmed=false` 면 그 칸이 통째로 없다.

---

## 3. 값 패턴 — **결정적. 무작위 금지**

⚠ **무작위면 재현이 안 되고, 어긋났을 때 원인을 못 찾는다.**

```
자율 모드 : 명령을 **한 번도 안 받았으면** 슬롯 번호로 토글한다
수동 모드 : 🔴 **첫 명령을 받으면 자율을 영구 정지**하고 명령대로만
```
> ### **자율 토글이 남아 있으면 명령 효과가 나중에 되돌려져 "안 먹었다"로 보인다.**
> **명령 반응이 주(主)이고 자율은 그것이 오기 전까지의 대용이다.**

### 주기 — **서로 소로 잡는다**

```
E1 : slotNo % 20 < 10     →  24.1초 주기 (20 슬롯 × 1.2056s)
X1 : slotNo % 14 <  7     →  16.9초 주기 (14 슬롯)
```
🔑 **서로 소(20, 14 → lcm 140슬롯 ≈ 168초)라 네 조합(00·01·10·11)이 전부 나타난다.**
**같은 주기면 둘이 항상 같이 움직여 "하나만 도는지"를 못 가른다.**
⚠ **`slotNo` 는 부팅부터 세므로 리셋하면 위상이 처음으로 돌아간다** — 재현 가능하다.

---

## 4. 끄는 법

```c
#define VIRTUAL_MODULES 1      // 0 이면 n=10 으로 돌아간다
```
⚠ **끄면 `n` 이 바뀌므로 서버가 다시 등록을 받아야 한다.** 재접속이 그 일을 한다.
🔴 **실물 모듈이 생기면 반드시 꺼라** — 켜 둔 채 실물을 붙이면 **같은 자리에 둘이 붙는다.**

---

## 5. ⚠ 핀 — 가상 모듈은 핀이 없다

```
MODULE_TABLE 의 pin = 0xFF   (없음)
```
🔴 **`applySlotPinMode`·`slotPin` 은 실물 범위(`SLOT_N`)까지만 돈다.**
**`SLOT_PIN[]` 은 크기가 `SLOT_N`(10) 이라 `i=10,11` 로 읽으면 배열 밖이다** — 조용히 쓰레기를 읽는다.

### 🔴 표에 **끝에만 붙인다. 중간 삽입 금지**

`idx` 는 **등록 순서**이고 **서버의 자리 결속과 `G,<rid>,<idx>,<op>` 가 둘 다 그것을 쓴다.**
**중간에 넣으면 기존 자리의 `idx` 가 전부 밀려 지금 되는 결속이 조용히 깨진다.**

---

## 6. 상태 비트 — 출력도 비트열에 들어간다

```
occ 비트 0~9  : 자리 점유 (실물 센서)
occ 비트 10   : E1 차단봉이 **열려 있다**
occ 비트 11   : X1 차단봉이 **열려 있다**
```
⚠ **같은 비트열인데 의미가 다르다** — 앞은 "차가 있다", 뒤는 "열려 있다". **`kind` 로 구분한다.**
> ### 🔑 **완료 판정은 이 에코가 한다. ACK 이 아니다.**
> **`ACK` 은 "받았다"이지 "됐다"가 아니다.**

---

## 7. 🔴 미해결 — `n` 이 바뀌면 기존 비트 위치가 전부 이동한다

```
n=10 : 슬롯0 → 비트 9        슬롯9 → 비트 0
n=12 : 슬롯0 → 비트 **11**   슬롯9 → 비트 **2**
같은 점유(0x346) → n=10 이면 "18B" · n=12 면 **"62C"**
```
> ### **첫 `S` 는 `D` 보다 먼저 온다. 서버는 그때 `n` 을 모른다.**
> ### **`n=10` 으로 가정해 디코딩하면 폭 3 그대로 · 체크섬 통과 · 모든 비트가 두 칸 어긋난다.**

⚠ **가상 모듈이 만든 결함이 아니다** — **원래 있던 구멍을 처음 밟게 하는 것**이다.
지금 `n` 이 10 하나뿐이라 안 드러났다. **다음 사람이 가상 모듈을 원인으로 쫓지 않게 여기 적는다.**

**socket 답 대기 중.** 권고는 **"등록 전 `S` 는 디코딩하지 않는다"** —
**모르는 값으로 디코딩하느니 안 하는 것이 낫다.** 자리 상태가 한 슬롯 늦어질 뿐이다.

### ⚠ 그리고 패딩 검증이 `n=12` 에서 무력해진다

> ### 🔴 **이것은 `n` 의 함수다. 가상이냐 실물이냐와 무관하다.**
> **가상 모듈이어도 전선으로 나가고 들어오는 형식은 실물과 완전히 같다** — 가상성은
> **아두이노 안에서 값을 만드는 방식**일 뿐이다(사용자 확정 2026-08-19).

```
n=10 → 패딩 2비트  ✅ 검증이 산다
n=12 → 🔴 **패딩 0비트** — `(v >> n) != 0` 이 절대 발동 안 한다. 검사할 대상이 없다
n=13 → 패딩 3비트  ⚠ 되살아나지만 폭이 4가 되어 `S` 가 커진다
```
⚠ **~~"가상 모듈을 넣으면 패딩 검증이 꺼진다"~~ 로 적으면 안 된다.**
> ### **다음 사람이 "실물로 바꾸면 방어가 돌아온다"로 읽는다. 안 돌아온다.**
> ### **실제 모듈 둘을 달아도 `n=12` 면 똑같이 꺼진다.**
**되살리려면 `n` 을 4의 배수가 아니게 만들어야 하고, 그건 `S` 크기와 맞바꿈이다.**
