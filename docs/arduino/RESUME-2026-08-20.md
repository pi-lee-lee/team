## 2. `occ` 비트 배치 — 판정의 열쇠 (n=6, 모듈 i → 비트 5−i)

| 비트 | 무엇이 만드나 | 무엇에 반응하나 |
|---|---|---|
| `0x20` A1 | 시뮬 훅 `(slotNo % 20) < 10` | **`slotNo` 만** — 24.0초 주기 |
| `0x10` B1 | 센서 훅이 읽은 `digitalRead(LED_BUILTIN)` | LD 명령 |
| `0x08` LD | 라우터 에코 | LD 명령 |
| `0x04` LC | 에코 | ⚠ **7자리를 보내도 `1`** |
| `0x02` DR | 에코 (`echoIs(arg==1)`) | 🔴 **열기만 1 · 닫기는 0** |
| `0x01` L2 | 에코 | L2 명령 |

**🔴 교차 불변식**: `(occ&0x10)!=0 == (occ&0x08)!=0` — **경로가 다른데 같은 물리량(핀 13)이다.**
갈리면 하나가 거짓말이다. **예외는 `tmask & 0x10` 인 프레임뿐**(주입이 훅을 이긴다).
`tmask` 는 `S` 의 **맨 끝, 체크섬 바로 앞**이다. `occ` 는 언제나 필드 2.
