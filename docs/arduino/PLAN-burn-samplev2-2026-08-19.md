# 다음 굽기 — 장치 샘플 2판 (표지 사전 선언)

**상태**: 준비 완료 · **루트 신호 대기**(socket 이 에코를 **읽는 쪽**을 만든 뒤 같은 경계로 낸다)

**왜 기다리나**: 장치는 에코 비트를 세우는데 서버가 아직 그것을 읽지 않을 수 있다.
지금 구우면 **"에코가 안 온다"와 "서버가 안 읽는다"를 못 가른다.** 읽는 쪽을 같이 내면
그 갈래가 아예 안 생긴다.

---

## 구울 것

| | 값 |
|---|---|
| flash | **27,232B (84%)** — 칩(26,566) 대비 **+666B** |
| RAM | **1,243B** — +13B |
| 구성 | 모듈 **6** (A1 B1 LD LC DR **L2**) · `SAMPLE_ACTUATORS=1` · `VIRTUAL_MODULES=0` |
| 등록 | **76B** (= 10 + 11×6) / `BATCH_CAP` 160 — 여유 84B<br>⚠ 구조식이고 실측 두 점(n=7→87 · n=8→98)으로 검산했다 |
| hex 폭 | **2** (= ceil(6/4)) — 안 바뀐다 |

**실린 축 다섯**
```
① 입력 훅 `sensors.on()`      — 미등록이면 flash·RAM +0B
② 에코 A + `router.echoIs()`  — 전선 +0B · flash +144B
③ 배너 문구 (자리·센서·모듈 셋을 따로) — +30B
④ 거절 로그 (라우터 3분기 + 핸들러) — +336B
⑤ `SLOT_N`→`SENSOR_N` · `SLOT_ROWS`→`SPOT_N` — **hex 0** (축이 아니다)
🔴 ⑥ 넷째 명령 모듈 `L2` (둘째 표시기) — +156B/+10B
```

## 🔴 표지 — **무조건**(반드시 보여야 한다)

```
[PARKING NODE] proto v1 / 1 spots / 2 sensors / 6 modules / dev=P1
[REG] 등록 전송 76B
D,*,7,6,
D,A1,IP,  D,B1,IP,  D,LD,OG,  D,LC,OL,  D,DR,OB,  D,L2,OL,
S 의 자리 필드 폭 2   (예: S,0,00,00,10,P1,03)
```
🔑 **모듈 수 5 가 배너·`D,*` 머리·`D,` 줄 수 세 각도에서 같아야 한다.**

## ❌ 표지 — **없어야 한다** (부재를 *세어서* 확인한다)

```
`2 slots`             ← 옛 배너 문구.  0건
`D,E1,` `D,X1,`       ← VIRTUAL_MODULES=0 이다.  0건
`12 modules` `5 modules` ← 옛 구성.  0건
```

## ⚠ 표지 — **조건부**. 🔴 이번엔 **일부러 밟는다**

**안 밟으면 부재가 아무 뜻도 없다.** socket 이 아래를 쏘기로 하면 **그때부터 부재는 신호다.**

| socket 이 쏠 것 | 장치가 찍어야 할 줄 | ACK |
|---|---|---|
| `LC` ← `1234567` | `[G] idx=3 arg=1234567` **그리고** `[LC] 1234567` | `0` |
| `LC` ← `12345678` | `[G] 거절 idx=3 — 콜백이 거절 arg=12345678` **그리고** `[LC] 거절 — 7자리 초과: 12345678` | `3` |
| `DR` ← `1`(열기) | `[G] idx=4 arg=1` · `[DR] arg=1` | `0` · **에코 비트 섬** |
| 🔴 `DR` ← `2`(닫기) | `[G] idx=4 arg=2` · `[DR] arg=2` | `0` · 🔴 **에코 비트 내려감** |
| `DR` ← `9`(표 밖) | `[G] 거절 idx=4 — 콜백이 거절 arg=9` · `[DR] 거절 — 명령표에 없는 값: 9` | `3` |
| `A1` ← 아무거나 | `[G] 거절 idx=0 — **등록 없음**` | `3` |

🔴 **`DR ← 2` 가 이번 굽기의 핵심 시험이다.** `arg=2` 는 0 이 아닌데 **에코가 내려가야** 한다.
`echoIs()` 가 없으면 여기서 **문은 닫혔는데 에코는 켜진 채**가 된다 — 조용히 틀린 자료다.

⚠ **거절 사유 셋이 섞이면 안 된다**: `등록 없음` 이 뜰 때 `콜백이 거절` 은 안 떠야 하고 그 반대도 같다.

## ⚠ 판정할 때 조심할 것

```
· 에코 비트는 **`occ` 필드 안**에 있다. 자리 점유와 같은 필드다 — `kind` 로 구분한다
  LD(idx2)→비트 2 · LC(3)→비트 1 · DR(4)→비트 0   (슬롯 i → 비트 n−1−i, n=5)
· 🔴 **에코 == 요청** 은 "장치가 그 값을 갖고 있다" 이지 **"명령이 상태를 바꿨다"가 아니다**
· `LC` 의 에코는 **"0이 아니다"** 만 말한다. 1234567 을 못 되돌린다 (안 A 의 한계)
· 칩이 26,566 → 27,076 으로 **늘어난다** — 이번엔 꼬리 잔재 문제가 없다
  (⚠ 줄어드는 굽기에서만 optiboot 잔재를 조심한다)
```

## 🔴 시험 각본 — **결과를 보기 전에 적는다**

**왜 미리 적나**: 결과를 보고 해석을 고치면 사전 등록이 아무것도 안 막는다.

| # | socket 이 하는 것 | 장치가 보여야 할 것 | 판정 |
|---|---|---|---|
| ㉠ | **4건 묶음** (`LD`·`LC`·`DR`·`L2`) | `[G]` 넷이 **같은 슬롯 안**에 · 콜백 넷 · ACK 넷 `result=0` | ✅ 4건 동시 성립 |
| ㉡ | **5건** | 🔴 **서버가 거절.** 장치까지 안 온다(`[G]` 0건) | ✅ 상한이 실재한다 |
| ㉢ | 4건 중 하나를 **8자리**로 | 셋 수행 · 하나 `[LC] 거절 — 7자리 초과: <값>` · ACK 3×0 + 1×3 | ✅ 부분 실패가 나머지를 안 깬다 |
| ㉣ | **단건** `srv.send` | 종전과 같다 | ✅ 회귀 없음 |

**계수** (창 전체)
```
`ssovf` **0**      ⚠ 하한이다 — 플래그가 읽히면 지워진다
`penddrop` **0**   🔑 분모 `pendfill` 과 **같이** 봐라. `0/0` 은 "안 버렸다"가 아니라 "셀 일이 없었다"다
```

### 🔴 호스트 시험에서 이미 밟은 것 (실기 전 사전 통과)

실기와 같은 사슬(`wifi.deliver()` → `espRead()` → 줄 조립 → `+IPD` 벗기기 → 평문 경로 → 콜백):
```
묶음 64B → `[G]` **4개** · ACK **4건 전부 result=0** · `ssovf` 0 · `penddrop` 0     ✅
🔴 송신 중에 같은 묶음이 오면 → `penddrop=3` · 살아남는 것 **한 건**              ← 위험의 실증
```
**그래서 ㉠ 이 실기에서 실패하면 후보는 "장치가 못 받는다"가 아니다** —
남는 것은 **타이밍(수신 창 밖에 보냈다)** 과 **서버 쪽**뿐이다.

⚠ **㉠ 이 실패하면 `penddrop` 을 먼저 봐라.** 3 이 올라 있으면 **수신 창 밖에 보낸 것**이고,
0 인데 `[G]` 가 모자라면 그때가 진짜 새 결함이다.
