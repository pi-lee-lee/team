# arduino — 미룬 것 목록

> **왜 이 파일이 있나**: *"막지 않는다"* 가 *"안 해도 된다"* 로 읽혀 조용히 잊히는 일이
> 반복됐다(CLAUDE.md 의 그 절). 대화 안에만 두면 다음 화제에 덮인다.
>
> **칸 셋을 반드시 채운다**: 무엇을 · 왜 미뤘나 · 🔴 **무엇이 이것을 되살리나**
> 마지막 칸이 없으면 이 파일도 같은 방식으로 낡는다.

| # | 무엇을 | 왜 미뤘나 | 🔴 무엇이 되살리나 |
|---|---|---|---|
| D1 | `host_test` 를 지금 지형으로 되살리기 | 시험이 **옛 10칸 지형**을 가정한다(`"옆칸 B4(인덱스 8)"`). 컴파일은 살렸고(`52 PASS / 86 FAIL`) 실패는 회귀가 아니라 지형이다. 지형을 하네스가 정의할 수 없다 — `SAMPLE_EXTRA_MODULES` 는 표 **끝에만** 붙는데 센서는 **앞쪽 연속**이어야 한다 | **모듈 표 자체를 하네스가 정의할 수 있게** 하면 된다(`#ifndef MODULE_TABLE_OVERRIDE` 류). 또는 센서 확장점을 표 앞쪽에 하나 더 두기. ⚠ **커버리지가 줄어든 사실**이다 — 지금 살아 있는 자가검증은 `stage1_test`(343 PASS)뿐이다 |
| D2 | `FrameCodec2.h` 를 `FrameCodec.h` 에 합치기 | 분리 이유(*"`MODULE_TABLE` 이 이 둘 사이에 와야 한다"*)가 **REQ-0299 로 사라졌다** — 표가 `client.ino` 머리로 올라갔다. 근거 문장은 고쳤고 합치기는 안 했다: **코드 이동이라 `hex` 가 또 바뀐다** | **다음 굽기 경계.** 그때 산출물 차이가 이 통합 하나에서만 오게 단독으로 실어라 |
| D3 | 자리 어휘 → 모듈 어휘 개명 | `slotPin`·`readSlotSensor`·`slotIndexOf`·`slotOverride*` 의 `slot` 이 **세 뜻**을 겸한다(센서 칸 · 자리 · 1.2초 반송파 슬롯). REQ-0299 ② 와 같은 커밋에 넣으면 diff 가 커져 *"무엇이 무엇을 깼나"* 를 못 가른다 | **구조 변경이 실기에서 확인된 뒤.** 개명은 `hex` 0 을 목표로 걸 수 있다(§57) — 그것이 판별자다 |
| D4 | `kind` 상수 목록 정리(서버 쪽) | 장치는 `kind[0]` 만 본다. 목록은 서버·화면의 관례다 | socket 이 그 목록을 정리할 때. **내 쪽은 REQ-0298 로 닫혔다** |

| D5 | `543fbe7` 판의 **런타임 부팅 표지 미계측** | 굽기 세션에서 부팅 로그를 안 떴다. 나중에 뜨려면 포트를 다시 잡아야 하고 그 리셋이 창 AM(t0 16:07:14)을 자른다. monitor 는 탭을 안 연다(루트 상시 지시) — **넘겼다가 돌려받은 축이다** | **다음 굽기 세션.** 절차서에 `5-b 부팅 로그를 같은 포트 세션에서 뜬다` 를 박았다. ✅ 컴파일 상수 표지는 `.elf` 문자열로 이미 확인했다(`spots` 0건 · `[SIM]` 새 문구 1건 · `9991` 0건). 🔴 남은 것은 **런타임 값**뿐: `[SENS]` 의 핀 번호 · `[REG] … 54B` 의 크기 |
