# 다음 굽기의 **축별 기대** — 굽기 *전에* 적는다 (2026-08-18)

**왜 지금 적나**: 배포가 묶여 있어 **네 축이 한 굽기에 실린다.** 돌아왔을 때
*"무엇이 무엇을 움직였나"* 를 말하려면 **축이 아직 머릿속에서 갈라져 있을 때** 적어야 한다.
🔑 원장 §16.4 의 셋째 물음(*"그 물음에 답하나"*)을 **굽기 전체에 적용한 것**이다.

⚠ **사후에 고치지 마라.** 빗나가면 빗나간 대로가 자료다.

---

## 축 1 — `S` 자리 비트열의 **hex 인코딩** `[socket 명세 · 프로토콜]`

```
바뀌는 것 : S 프레임 폭   n=10 에서 60B → 39B
기대      : 배출률 D 6 → 7 · 배치가 작아져 >=64B 대역 표본이 **줄어든다**
```
### 🔴 정정 (2026-08-18 · socket 이 진입률 자료를 주고 나서)

~~부작용 예측: `big*` 의 분모가 줄어든다~~ ← **"부작용"이라고 쓴 것이 틀렸다.**

> ### **그 감소가 곧 이득이다.** hex 의 효과는 *"그 대역에서 덜 깨진다"* 가 아니라
> ### **"그 대역에 덜 들어간다"** 로 나타난다.

```
≥64B 진입률 : 창 G 4.1%  ·  창 H 59.0%  ·  창 I 92.1%    (monitor 계측)
```
⚠ **뒤(그 대역 안의 T2 율)만 재면 이 이득이 "판정 불가"로 보인다.**
**분모가 줄어드는 것을 지표로 같이 봐야 한다** — monitor 가 진입률을 더해 이 구멍을 막았다.
🔑 **`big*` 이 0/0 이 되는 것을 "T2 소멸"로 읽으면 안 된다.** 분모를 반드시 같이 적는다.

### 🔴 그리고 **창 I 의 범위** — 인용할 때 반드시 같이 옮겨라

```
창 I 진입률 92.1%  대  실사용 4.1%   → **20배 다르다**
```
> ### **창 I 는 "포화에서 견딘다"이지 "실사용에서 괜찮다"가 아니다.**
**이 범위가 빠지면 결론이 근거보다 넓어진다** — 오늘 하루 세 번 밟은 형태다.

## 축 2 — **`D` 등록 프레임** `[프로토콜]`

```
바뀌는 것 : 접속 후 첫 슬롯이 D 전용. S 는 둘째 슬롯부터
기대      : 접속~첫 S 까지 **한 슬롯(1.2초) 늘어난다**
```
⚠ **서버 쪽 "첫 프레임까지의 시간"이 늘어난다.** 그건 고장이 아니다.
🔴 **`REG_TIMEOUT = 3 × 슬롯주기`(3600ms)와 헷갈리지 마라** — 그건 서버 몫이다.

## 축 3 — **자리 유동화** `[구조]`

```
바뀌는 것 : n 이 SLOT_N(컴파일 상수) 이 아니라 **등록된 모듈 수**가 된다
기대      : 지금은 값이 같아 **거동 변화 0** 이어야 한다
```
> ### 🔴 **이 축의 기대는 "아무 일도 안 일어난다"다.** 무언가 바뀌면 그것이 결함이다.
**socket 이 `cells` 를 길이 1 강제로 연 것과 같은 규율** — 열어 두되 검증 안 된 경로를 안 만든다.

## 축 4 — **계측기**(`pendfill`·`big*`·`oklost`) `[계측]`

```
바뀌는 것 : [CNT] 에 칸 6개. 거동은 안 바뀐다
기대      : penddrop=0 의 뜻이 갈린다 · oklost 가 대책 ②의 실제 효과를 준다
```
⚠ **`[CNT]` 가 209B → 약 220B.** 블로킹 계산은 원장 §16.5 에 있다. **300B 를 넘기면 다시 계산한다.**

---

## 🔴 굽고 나서 **이 순서로 읽는다**

```
1. 축 3 먼저  — 거동 변화 0 인가? 아니면 나머지 판정이 전부 오염된다
2. 축 4 다음  — 계측기가 오르는가? pendfill=0 이면 다른 칸은 못 읽는다
3. 축 1·2    — 그 다음에야 프로토콜 효과를 본다
```
🔑 **계측기와 구조를 먼저 확인하지 않으면, 프로토콜 판정이 무엇 위에 서 있는지 모른다.**

## ⚠ 이 굽기로 **답할 수 없는 것** — 미리 적어 둔다

```
· "T2 가 준 것이 대책 ① 때문인가" → 창 H 가 그 축을 이미 갈랐다. 여기서 다시 안 묻는다
· hex 와 D 는 **같이 배포**된다 → 둘을 서로 가를 수 없다. 가르려면 굽기가 하나 더 필요하다
· 자리 유동화의 **N:1** 경로 → 지금 안 만든다. 만들지 않은 것은 시험도 못 한다
```
