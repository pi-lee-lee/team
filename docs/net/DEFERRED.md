> **왜 이 파일이 따로 있나.** 연기한 항목은 대화 안에만 있으면 **다음 화제에 덮인다.**
> 원장(`LEDGER.md`)은 *"시간이 지나도 참인 것"* 만 모으고, 그날의 상태는 `STATUS-`·`HANDOFF-` 다.
> **보류는 둘 다 아니다** — 참인 사실도 아니고 그날의 상태도 아니다. **조건이 오면 깨어날 것**이다.
>
> ### 🔴 그래서 칸이 셋이다: **무엇을 · 왜 미뤘나 · 무엇이 이것을 되살리나.**
> 셋째 칸이 없으면 *"필요 없다"* 로 읽히고, 그러면 **필요해진 날 아무도 안 본다.**
> (원장 §"기각의 근거가 '필요 없다' 였으면 필요해진 날 자동으로 되살아나야 한다")

⚠ **닫을 때는 지우지 말고 줄을 그어라.** 왜 깨어났는지 / 왜 영영 안 하기로 했는지가 근거가 된다.

```

⚠ 이 항목은 한 번 *"요구가 없다"* 로 기각됐다가 **하루 만에 요구가 생겼다.** 다시 그러지 않게 적어 둔다
```

### ⑥ 차번호를 **문자열로** 표시하기 — 지금은 숫자만
```
지금 결정  : 차번호 표시는 **숫자만**.  `12가3456` → `123456`
             🔑 **계약 변경 0** — `L2` 문턱 `0~9999999` 이 이미 그것을 받는다.
                장치·서버·화면 **변경 없음**
🔑 자릿수가 우연이 아니다 : **신형 번호판은 앞 3 + 뒤 4 = 정확히 7자리**이고
             **앞 3자리가 100 이상**이라 **선행 0 손실이 없다.** `9999999` 와 정확히 맞는다.
             ⚠ 구형(2+4=6자리)은 앞이 `01` 처럼 0 으로 시작할 수 있다 —
               그때는 숫자로 옮기면 **선행 0 이 사라진다.** 신형만 무손실이다
🔴 왜 미뤘나 : **"필요 없다" 가 아니라 "하드웨어가 없다"** 다 —
             사용자: *"보유중인 디스플레이가 한글이 출력되는게 없다."*
되살리는 것: ⑴ **한글 표시 가능한 LCD/OLED 가 생기면** → 문자열 전송을 다시 본다
             (프레임 타입 하나 + `,` 이스케이프 규칙. 전선이 `,` 구분이라 그 규칙이 먼저다)
             ⑵ **카메라(DigitCam) 경로가 붙으면** → 변환 함수 하나가 필요해진다
```
**🔴 변환 주체를 지금 못박는다 — 붙일 때 지어내지 않게:**
```
카메라(DigitCam) : 문자열 원본 `12가3456` 을 인식한다 (한글 UTF-8)
🔴 **서버**        : **여기서** 숫자로 변환한다
장치 · 화면       : 숫자만 받는다. 변환을 **모른다**
```
🔑 **원본을 가진 쪽이 계산한다.** 장치나 화면이 각자 변환하면 규칙이 두 곳에 생기고,
갈리는 순간 어느 쪽이 맞는지 알 수 없다.
⚠ **아직 카메라 경로가 없다**(DigitCam 은 별도 프로젝트 · 실기기 미검증).
   그래서 이 변환은 **명세에 적힌 것이 아니라 여기 적힌 결정**이다 — 구현 0. 혼동하지 마라.

### ⑦ 초음파 기준선이 `0` 이 아닐 때 — 점유 변화 콜백이 **안 움직인다**
```
기전 : US_NEAR_CM = 60. 초음파 앞 60cm 안에 벽·책상이 있으면 그 센서는 **영구 점유**다
       → 변화가 없으니 콜백이 안 불린다. 🔴 **콜백 결함이 아니다**
왜 미뤘나 : 지금 값을 모른다. 장치가 붙어야 기준선이 나온다
되살리는 것: **손 안 댄 상태의 `occ` 기준선.** 0 이 아니면 그 자리에서 판별을 시작한다
```
**🔴 기준선을 *언제* 읽나 — 이것부터 틀리기 쉽다**(arduino 값):
```
장치가 붙으면 **등록 `D` 줄이 먼저** 온다. `occ` 는 그 뒤 **첫 `S`** 가 싣는다
🔴 `D` 만 보고 판정하지 마라 — 그 줄에는 점유 정보가 없다
⚠ 지금 `n=4` 이므로 `occ` 는 **hex 한 자리**다(`ceil(4/4)`).
  **두 자리로 오면 기준선 문제가 아니라 판본이 다른 것이다** — 그때는 판정을 멈추고 판본부터 맞춘다
```

**🔴 판별 순서를 지켜라**(arduino 가 미리 계산해 뒀다 · `docs/arduino/DEFERRED.md` D11):
```
① 기준선이 0 이면 → **아무것도 안 한다**
② 0 이 아니면 → 🔴 **어느 비트인지 먼저 본다**(`8`=A1 만? `4`=B1 만? 둘 다?)
   한쪽만이면 **그 센서만 옮긴다**. 굽기 0회. 가장 싸다
③ 둘 다면 → 자리가 좁다 → `US_NEAR_CM` 문턱 축소를 **사용자에게 제안**한다
   (30cm 로 줄이면 UART 점유가 7.0% → 3.5% 로 정확히 절반이 된다 — 예산 개선을 겸한다)
⚠ **②를 건너뛰고 ③으로 가지 마라** — 한 센서 문제를 전체 문턱 변경으로 풀면
  굽기 하나에 **"검출 거리 축소"라는 대가**가 붙고, **그 대가는 우리가 판단할 수 없다**(사용자 몫)
❌ 자동 교정(부팅 때 빈 상태를 학습)은 탈락이다 — **부팅 때 차가 있으면 반대로 학습하고 조용하다**
```

### ⑧ 정적 자원·영속 상태를 **절대경로로** 연다 (REQ-0248 ③ 에서 이관)
```
지금  : `serve_file()` 이 **cwd 상대경로**로 연다 → 다른 디렉터리에서 띄우면 **실체가 통째로 바뀐다**
✅ 이미 있는 것 : 기동 로그의 `cwd=`(listen.h) — **어디서 도는지는 보인다**
🔴 없는 것      : 경로 자체를 절대경로로 여는 것
```
**🔴 이건 가정이 아니라 실제로 난 사고다**(2026-08-19): 아무도 그 파일을 안 고쳤는데
서버 cwd 가 바뀌어 **이틀 낡은 `index.html` 을 내주고 있었다.** 존재형 검사 둘이 다 통과했다.
```
왜 미뤘나 : 루트가 2026-08-20 에 *"지금 넣지 마라"* 로 명시 보류(축을 늘리지 않으려고)
되살리는 것: ⑴ 배포 경로가 또 바뀔 때  ⑵ **또는 다음 정리 배포에 묶어서**
             🔑 기동 1회이고 측정 대상에 안 닿는다 — **축이 아니다**(§"축이 느는가" 판별자)
```
⚠ **REQ 에서 뺀 이유**: 미결 REQ 로 두면 *"누가 하고 있나"* 로 보이는데 **아무도 안 한다.**
보류 목록은 **아무도 안 하고 있다는 것이 기본값**이라 거짓말을 안 한다.
