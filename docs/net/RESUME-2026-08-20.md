## 3. 🔴🔴 멈추기 직전에 찾은 것 — **미실측. 소스 판독뿐이다**

> ### **화면의 차단봉 버튼이 새 지형에서 **구조적으로 거절**될 수 있다.**

```
gate_index_of()  →  park.mods 의 색인을 돌려준다  (지금 지형에서 DR = **4**)
wsapi.h:126      →  if (gidx < 10) { ... send_err("not_supported") }
                    주석 : "장치가 idx >= SLOT_N 만 받는다"  ← **옛 12자리 지형의 사실**
🔴 지금 모듈 색인은 0~5 다(web 실측: A1#0 B1#1 LD#2 LC#3 DR#4 L2#5)
   → 4 < 10 → **open_gate 가 항상 not_supported 로 거절된다**
```
**반증 후보(이것부터 확인해라)**: `open_gate` 는 `E1`(입구) 자리에만 뜨는데
지금 web 이 보는 `actions` 에는 `reserve` 뿐이라 **버튼이 아예 안 그려져서 아무도 안 밟았을 수 있다.**
⚠ **그러니 "고장 났다"가 아니라 "밟히면 거절된다"로 적는다.** 실측 전에 결론 내지 마라.
🔑 **확인 방법**: `{"type":"open_gate","slot":"E1","rid":"t1"}` 를 WS 로 넣고 응답을 본다.
**`send_cmd` 경로(`send_to_module`)에는 이 가드가 없다** — 그래서 샘플의 `srv.send("P1","DR",1)` 은 돈다.
