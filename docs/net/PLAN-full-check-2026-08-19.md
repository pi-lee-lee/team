## 0. "전수"의 뜻과 목록의 출처

> ### **표본을 늘리는 것이 아니라 *목록에서 빠진 것이 없게* 하는 것이다.**
> **각 기능을 한 번씩만 밟아도 전수다. 대신 하나도 안 빠져야 한다.**

🔴 **목록은 기억이 아니라 소스에서 뽑았다** — `parking.h` 의 public 전부 + `spot.h`·`cmdresult.h`.
그 파일이 자기 머리에 *"이 파일만 읽으면 주차장을 만들 수 있어야 한다"* 고 적었으므로

## 4.5 🔴 **LED — 계측기 셋이 만나는 자리** (2026-08-20 추가)

사용자 확정: *"**13번 led 로 하자. 아두이노 기본 led 이다.** 그리고 **해당 led on/off 체크를 콜백으로** 하자."*

```
srv.send("P1","LD",1) → 장치가 핀 13 HIGH → 🔴 **보드의 LED 가 실제로 켜진다**
                      → ACK result=0 → **콜백이 불린다** → 에코 비트가 선다
```
> ### **눈(LED) · 콜백 · 에코 — 셋이 같은 사건을 말한다.**

| # | 기능 | 확인 방법 | 상태 |
|---|---|---|---|
| LD1 | `send LD 1` | 🔴 **LED 가 켜진다(눈)** + 콜백 `LD 1 → 성공` + 에코 `value:true` | |
| LD2 | `send LD 0` | 🔴 **LED 가 꺼진다(눈)** + 콜백 `LD 0 → 성공` + 에코 `value:false` | |

🔑 **이것이 §"에코 == 요청은 *장치가 그 값을 갖고 있다* 이지 *명령이 상태를 바꿨다* 가 아니다"를
처음으로 닫는다** — **LED 는 물리적으로 바뀌는 것을 눈이 확인한다.**
⚠ **로그가 거짓말해도 LED 는 안 한다.** 그래서 사람 눈이 여기서 가장 강한 계측기다.
🔴 **다만 `LD` 하나에 대해서만 닫힌다.** `LC`·`L2`·`DR` 은 여전히 미상이다.


## 5. 🔴 아직 한 번도 안 밟은 것 — 밟는 방법

```
A5 gate + 차단봉   `lot.cpp` 주석을 켠다. E1 을 자리로 만들고 `E1` 모듈을 붙인다
                   ⚠ 지금 칩에 `E1` 모듈이 없다(가상 차단봉을 껐다) → **미결속으로만 확인**되고
                     실제 조작은 못 한다. **그 한계를 명시한다**
A6 behavior        `lot.cpp` 에서 A1 에 AND 판정을 꽂고, 센서가 갈린 상태에서
                   `occupied` 가 **false** 인지 본다(기본 OR 이면 true)
B6 deviceReady F   기동 직후(등록 전)에 부른 결과를 로그로 찍는다 — **재기동만 하면 밟힌다**
🔴 B11 무응답      **장치가 ACK 을 안 보내야** 한다. 개입이 필요하다:
                   (가) 명령 직후 **장치 전원/연결을 끊는다** — 사용자 조작
                   (나) 없는 모듈 idx 로 억지 발행 — 🔴 **API 가 막는다**(이름을 먼저 푼다)
                   (다) `--max-line` 등으로 프레임을 깨뜨린다 — 🔴 **다른 축을 오염시킨다**
                   → **(가) 외에는 방법이 없다.** 사용자 조작이 없으면 **미측정으로 낸다**
```

## 5.5 🔴 **미측정 항목 옆에 "무엇이 이것을 닫는가"를 적는다**

**이것이 없으면 미측정은 영영 미측정이다.** 있으면 다음 사람이 몇 분 만에 닫는다.

| 항목 | 무엇이 이것을 닫는가 | 비용 |
|---|---|---|
| **A6** `.behavior()` 실기 | 🔑 **핀 2 ↔ GND 점퍼 1개** — 센서가 `1/0` 로 갈려야 OR(찼다)와 AND(비었다)가 **다른 답**을 낸다 | 점퍼 1개 |
| **A10** 센서 실물 경로 | 위와 같은 점퍼. 센서 값이 **서버·화면까지** 올라가는 전 경로가 열린다 | 점퍼 1개 |
| **A11** 초음파 | 초음파 모듈 배선 | 부품 |
| **A3** `.sensor(name)` 1인자 | 샘플에서 그 형태로 자리를 하나 선언하고 기동 | 코드 1줄 |
| **B11** 무응답 콜백 | 🔴 **명령 직후 장치 전원/연결 차단** — 사용자 조작 1회. 그 외 방법은 없다 | 조작 1회 |
| **LC·L2·DR 의 물리 확인** | 🔑 `LD` 는 LED 라 눈으로 닫혔다. **나머지 셋은 물리 출력이 없다** — 표시기·차단봉 실물이 있어야 한다 | 부품 |

🔑 **A6·A10 이 점퍼 *하나*로 같이 닫힌다** — 두 항목이 같은 전제를 공유한다.
⚠ **"밟았는데 구분이 안 됐다"는 안 밟은 것이다.** A6 가 정확히 그 경우다 —
센서가 `0/0` 이면 OR 도 AND 도 `false` 라 **판정이 갈리지 않는다.**
§*"조건이 이미 만족돼 있어서 통과"* 의 거울상이다(조건이 양쪽 다 거짓이라 안 갈린다).

⚠ **못 밟은 것은 "미측정"으로 낸다.** §*"선행 조건이 깨졌으면 항목 판정을 내지 마라"* —
**틀린 ✅ 는 사람을 안심시키고, 미측정은 아무도 안 속인다.**

## 6. 측정 판과 커밋 판이 다르다

```
측정 : `lot.cpp` 의 `onTick`·`onCmdResult`·gate·behavior 를 **켠 판**
커밋 : **주석 판**(기여자가 받는 것)
🔴 판정문에 두 판 차이를 값으로 적는다
```
