**작성** socket-engineer · 2026-08-18 · **목적** arduino 의 SEND OK 수정 **전/후 대조**
🔴 **이 문서가 존재하는 이유: 조건이 세션과 함께 사라지면 대조가 성립하지 않는다.**
루트 지시 — *"라운드 수·인스턴스 수·건수를 이번과 똑같이 맞춰라. 다르면 비교가 안 된다."*

## 1. 실행 명령 — **그대로 친다**

```
sh net/winG-rounds.sh 8
```
그 안이 하는 일(바꾸지 마라):
```
라운드      8
인스턴스    8   (슬롯 A1 A2 A3 A4 A5 B1 B2 B3 — 같은 칸이면 already_pending 으로 거절된다)
건수        60 / 인스턴스 / 라운드      → 상한 3,840건
--interval  0.3      --start-delay 0
정지 조건   오프라인연속 5 · result≠4 누적 2 · 응답없음 누적 3 · 알수없는거절+예외 5 · queue_full 연속 20
rid 접두    injG<라운드>-<인스턴스>      ⚠ 대조군은 접두를 바꿔라(예: `injH…`) — 안 그러면 회차가 섞인다
기록        net/inject-winG-2026-08-18.log
```

## 2. 🔴 **"같은 조건"이 "같은 부하"를 뜻하지 않는다 — 비교 전에 반드시 읽어라**

감독기는 **주입기가 정지 조건으로 멈추면 새 라운드를 연다.** 그래서:
```
장치가 건강하면 → 왕복이 느려 라운드가 오래 간다 → 총 주입 **적다**
장치가 나쁘면   → 오프라인 거절이 즉시 반환된다   → 총 주입 **많다**
```
> ### **총 건수는 장치 상태의 함수다. 두 창의 총 건수를 크기 비교하면 인과가 뒤집혀 읽힌다.**
**비교는 반드시 비율로 하고 분모를 같이 적는다.** 분모는 **`시도 − 미주입`** 이다(미주입은 전선에 안 나갔다).

## 3. 🔴 이번 창(기준선)의 수 — **읽는 법까지 같이 적는다**

```
시도 496 · ACK(result=4) 136 · ACK(다른 result) 0 · 미주입 360 · 응답없음 0 · 예외 0 · queue_full 0
분모(시도 − 미주입) = **136**
구간 : 16:46:45~16:47:11(1차) · 16:49:17~16:51:28(2차 8라운드)
```

### ⚠ **`미주입 360` 을 "73% 오프라인"으로 읽으면 틀린다**

```
같은 구간 서버 소크 : 오프라인 판정 13회 · **링크없음 00:00:13** (14분 중)
```
**미주입은 *시도 수*이고 링크없음은 *시간*이다. 다른 단위다.**
🔑 기전: 장치가 오프라인이면 서버가 **즉시** 거절한다(왕복 없음) → 같은 시간에 **훨씬 많은 시도**가 들어간다.
**→ 오프라인 구간이 시도 표본을 과대표집한다.** 시간 비율은 대략 **8%**(오프라인 13회 × 약 5초 / 14분)다.
⚠ 이 함정은 **어느 창에서도 같은 방향으로 작동한다** — 대조군에서도 그대로 조심해라.

### ⚠ `queue_full 0` 의 뜻

**내 건수 상한(4건/창)이 한 번도 안 걸렸다.** 큐가 찰 만큼 부하가 지속되지 못했다는 뜻이다
(장치가 자주 끊겨 큐가 계속 비워졌다). **"상한이 잘 동작한다"는 증거가 아니다** — 시험된 적이 없다.

## 4. 이 창에서 **말할 수 있는 것 / 없는 것**

```
✅ T2 재현됨 : 16:47:11 세션 종료 · 최대공백 8.3초 (주입 중)
✅ 대조도 있음 : 16:46:07 세션 종료 · 최대공백 8.5초 (**주입 시작 전**)
   → **주입은 T2 의 필요조건이 아니다**
🔴 말할 수 없는 것 : **`tx ≥ 48B` 가 몇 건인가**
   내 `rx=NNB` 는 **줄 단위**, monitor 의 `[SLOT] tx=` 는 **CIPSEND 배치 단위**다. 다른 것을 센다.
   내가 아는 사실은 `16:47:02` 에 **ACK 4건이 같은 초에 준비됐다**는 것뿐이다.
```

## 5. 굽기 전후 절차

```
① 굽기 통보 오면      → 주입 중지(`pkill -f downlink_inject` · 감독기도 함께)
② 굽기·monitor 새 창  → 기다린다
③ 대조군             → 위 1번을 그대로. **rid 접두만 바꾼다**
④ 비교              → **비율 + 분모.** 총 건수 크기 비교 금지(2번 이유)
```

⚠ **범위**: 이 문서는 **기준선 확보**를 적은 것이지 수정이 효과 있다는 판정이 아니다.
그리고 T2 재현은 **n=2** 다(16:46:07 · 16:47:11).
