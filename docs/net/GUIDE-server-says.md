# 서버가 무엇을 보고 무엇을 말하는가 — 기여자용 한 장

> **범위**: 서버가 **기여자의 선언을 어떻게 검사하고 어떻게 말하는가**.
> ❌ 아두이노 스케치 쓰는 법은 **여기 없다** — arduino 도메인이다.
> **두 문서를 한 장에 섞으면 도메인이 섞이고, 한쪽이 낡을 때 아무도 모른다.**

작성: socket-engineer · 2026-08-19 · 대상 서버 판: `feb3a85` 이후

---

## 0. 🔴 먼저 — **여기 있는 것 중 서버를 못 뜨게 하는 것은 하나도 없다**

```
🗣 아래 검사 다섯은 전부 **말만 한다.** 서버는 뜨고, 등록은 성공하고, 하행도 정상이다
🔴 막는 것은 딱 하나뿐이다 — `--port-offset` 범위 (§5)
```
**왜 안 막나**: 기여자가 *"내 것 때문에 서버가 안 뜬다"* 로 겁을 먹으면 아무도 안 건드린다.
🔑 **판별자는 "증상이 보이는가"다** — 보이면 말하고, **안 보이면 막는다.**
`--port-offset` 만 막는 이유는 **틀린 값이 조용히 엉뚱한 포트를 잡아 증상이 아예 없기 때문**이다.

---

## 1. 자리를 하나 더하려면 — `조별과제샘플/server/main.cpp` 한 곳

```cpp
ParkingLot lot;
lot.spot("A1").sensor("A1").sensor("B1");   // 자리 A1 · 센서 둘(이중화)
lot.spot("A2").sensor("A2").sensor("B2");
…
lot.gate("E1", Gate::IN);      // 입구
lot.gate("X1", Gate::OUT);     // 출구

ParkingServer srv(lot);
```
```
· `spot(id)` 는 **같은 id 로 두 번 불러도 안전하다** — 있으면 그것을 돌려준다
· `sensor(name)` 은 **그 센서가 어느 자리에 속하는지**를 선언한다
· `gate(id, IN|OUT)` — 입출구는 **센서가 없어도 정상**이다
```
🔑 **위에서 아래로 읽으면 배치가 그대로 보인다.** 자동 배선을 일부러 안 썼다 —
한 줄로 줄일 수 있지만 그러면 **언제 무엇이 붙는지 안 보인다.**

⚠ **이름이 자리 id 와 같을 필요는 없다.** `sensor("Q7")` 도 된다 — 조립 표가 사상을 준다.
🔴 **다만 그 이름을 장치도 그대로 보내야 한다**(§2 ③).

---

## 2. 서버가 하는 검사 다섯 — 문구와 **그때 볼 곳**

### ① 조립 표: 같은 센서 이름이 두 자리에 — **기동 때**
```
🔴 조립 표 — 센서 이름 `S1` 이 자리 A1 와 A2 에 둘 다 적혀 있다.
   **앞엣 자리(A1)가 이기고 A2 는 이 센서를 영영 못 받는다.** `main.cpp` 의 조립 표에서 한쪽을 고쳐라
```
**왜 이렇게 되나**: 이름→자리 조회가 **처음 맞는 것**을 돌려준다. 둘째는 도달할 수 없다.
**볼 곳**: 서버 기동 로그. **막지 않는다.**

### ② 조립 표: 센서가 하나도 없는 주차 자리 — **기동 때**
```
🔴 조립 표 — 자리 A3 에 **센서가 하나도 없다.** 화면에는 자리가 보이지만 점유는
   **영원히 `unknown`** 이다 (고장이 아니라 선언이 빈 것이다). `lot.spot("A3").sensor("...")` 로 붙여라
```
⚠ **이게 가장 헷갈리는 증상이다** — 자리는 보이는데 값이 안 채워지니 *"센서가 고장났나"* 를 쫓게 된다.
**볼 곳**: 기동 로그 + 화면의 그 자리가 계속 `unknown`. **막지 않는다.**

### ③ 등록: 어느 자리에도 안 붙는 모듈 — **장치가 등록할 때마다**
```
🔴 모듈 `B7` (idx 2, 노드 P9) 은 **어떤 자리에도 안 붙는다** — 지형에 그 이름이 없다.
   **등록은 성공했고 하행도 정상이지만 이 모듈은 화면에 안 나타난다.**
   지금 지형의 자리: A1, A2, A3, A4, A5, E1, X1
   · 자리에 붙이려면 그 자리 id 와 같은 이름을 쓰거나(현행 규칙) 대장에 할당을 걸어라(4단계)
```
> ### 🔴 **이것이 가장 조용한 고장이었다. 오늘 전까지 아무 말도 안 했다.**
> **장치는 `등록 완료` 를 받고, 서버는 정상이고, 그 모듈만 없다.**

**고치는 법 둘 중 하나**:
```
(가) 장치가 보내는 이름을 조립 표의 센서 이름과 맞춘다
(나) 조립 표에 그 이름을 센서로 더한다 — `lot.spot("A3").sensor("B7")`
```
**볼 곳**: 서버 로그 · 요약 줄 `미결속모듈 N`. **막지 않는다.**

### ④ 등록: 한 장치 안에서 이름이 중복 — **장치가 등록할 때마다**
```
🔴 장치 안 모듈 이름 중복 — 노드 P1 의 idx 0 와 1 가 둘 다 'A1' 이다.
   **`(devid,name)` 조회가 애매해진다.** 전선 주소는 `idx` 라 동작은 하지만
   **화면이 둘 중 하나를 임의로 집는다**
```
⚠ **증상이 "가끔 엉뚱한 모듈이 보인다"라서 결함으로 안 보인다.**
**볼 곳**: 서버 로그 · 요약 줄 `이름중복 N`. **막지 않는다.**

### ⑤ 등록: 두 장치가 같은 이름을 주장 — **장치가 등록할 때마다**
```
🔴 모듈 이름 충돌 — 자리 A1 의 이름 'A1' 을 노드 P2 가 다시 주장한다.
   **먼저 잡은 노드를 유지하고 이것은 결속하지 않는다.**
```
🔑 **먼저 잡은 쪽이 이긴다** — 조용히 덮으면 뒤엣것이 앞엣것을 지워 **원인을 못 찾는다.**
**볼 곳**: 서버 로그 · 요약 줄 `이름충돌 N`. **막지 않는다.**

## 3. 정상일 때도 한 줄 찍는다 — **그게 검사가 있다는 증거다**

```
= 조립 표 검사 — 자리 7개 · 문제 없음
```
🔴 **안 찍으면 검사가 있다는 것을 아무도 모른다.** 그리고 문제가 없을 때와
**검사가 아예 안 돈 때가 똑같이 보인다.**
🔑 요약 줄도 같은 규율이다 — `미결속모듈 0` 처럼 **`0` 을 찍는다.**
**칸이 아예 없으면 `0` 이 아니라 *아무것도* 안 나오고, 받는 쪽은 "안 일어났나 보다"로 읽는다.**

---

## 4. 요약 줄에서 이 다섯을 한 번에 본다

소크 요약(60초마다 · 종료 시 한 번)에 이 칸들이 있다:
```
… · 이름중복 0 · 미결속모듈 0 · 조립표문제 0 · 이름충돌 0 · … · 대장 2노드(신규 0/재확인 0) 할당 0 저장 2
```
_(위는 실제 출력에서 그대로 뜬 것이다. **순서를 포함해 실물과 맞춰 뒀다** — 순서가 다르면 눈으로 찾을 때 헤맨다.)_
```
이름중복    ④   미결속모듈  ③   조립표문제  ①+②   이름충돌  ⑤
대장        재기동을 건너 기억하는 노드 수. `재확인` 은 **구성이 대장과 달라 사람이 봐야 하는** 것
```
🔴 **하나라도 0 이 아니면 그 줄에 🔴 가 붙는다.** 붙어 있으면 위 문구를 로그에서 찾아라.

## 5. 🔴 유일하게 **막는** 것 — 손잡이 범위

`--port-offset` 이 범위 밖이면 **서버가 안 뜬다.**
```
--port-offset 은 1 ~ 55544 사이여야 한다 (받은 값: -3)
```
**왜 여기만 막나**: 음수면 0번 포트로, 큰 값이면 `htons` 에서 잘려 **아무 포트에나 붙는다.**
그리고 **아무 증상이 없다** — 나중에 *"서버가 이상하다"* 로 보고된다.
> ### **증상이 보이면 말하고, 증상이 안 보이면 막는다.** 그 판별자로 갈랐다.

`--max-line` · `--down-cap` 도 같은 이유로 범위를 검사하고, 값이 범위 안이면 **시험 전용이라고 크게 찍는다.**

---

## 6. ⚠ 이 문서가 답하지 **않는** 것

```
· 아두이노 쪽에 모듈을 더하는 법 → arduino 도메인 (루트가 색인을 만든다)
· 관리자 화면에서 할당하는 법   → 아직 없다(온보딩 4단계). `assignments` 는 기록만 된다
· 정책(자리 판정·차단봉 동작) 고르기 → 아직 없다(5단계)
· 🔴 **장치는 "내 이름이 지형에 있나"를 검사할 수 없다** — 지형은 서버만 안다.
  그래서 ③ 은 **서버에만 있을 수 있는 검사**다
```

## 7. 이 문서를 고쳐야 할 때

**검사를 더하거나 문구를 바꾸면 여기도 고쳐라.** 문구는 기여자가 검색할 유일한 단서다.
⚠ **문구와 이 문서가 갈리면 기여자는 검색에 실패하고 "아무 말도 없다"로 읽는다** —
그건 검사가 없는 것과 같다.
