# 묶음 하행 — `srv.batch(devid)` 설계

> 사용자: *"**묶음으로 send 하는 함수**가 필요하다. 3개 명령이면 **1개당 1.2초씩 밀린다.**
> 하나의 윈도우프레임에 담아 보낼 수 있어야 한다. **최대 명령어 갯수가 필요하고**…"*

작성: socket-engineer · 2026-08-19

## 1. 🔴 최대 개수 — **8건**. 계산으로 나온 값이다

```
한 줄 최악 : G,999,255,4294967295, + 체크섬 2 = **23B**
             (rid 3자리 · idx 3자리 · 인자 **10자리** = uint32 최대)
줄 사이 LF 1B
서버 하행 배치 상한 DOWN_BATCH_CAP_B = 192B
  → 23 + 7×24 = 191B  ⇒ **8줄**
```
🔴 **최악값으로 계산했다.** 실제 인자가 `1` 이면 15B 라 12줄이 들어가지만,
**그 수를 API 에 박으면 긴 인자에서 조용히 잘린다.** 상한은 **항상 최악으로 잡는다.**

### ⚠ 묶는 제약이 둘인데 **작은 쪽이 하행이다**
```
하행 배치 상한  192B → **8건**    ← 🔴 이쪽이 먼저 걸린다
ACK 되돌림 용량 139B → 약 9건     (arduino 계산: BATCH_CAP 160 − S 21)
```
🔑 **8을 넘기면 하행이 두 슬롯으로 쪼개져 "묶었는데 왜 여전히 느리지"가 된다.**
**9를 넘기면 ACK 가 다음 슬롯으로 밀려 같은 증상이 난다.** 둘 중 **8이 먼저**다.

### 🔴 상한을 **상수로 박지 않는다**
`DOWN_BATCH_CAP_B` 는 `--down-cap` 으로 바뀐다. 리터럴로 박으면 **손잡이를 돌렸을 때 어긋난다.**
→ `srv.maxPerBatch()` 가 **그 순간의 상한에서 계산해 돌려준다.**

## 2. 왜 묶으면 빨라지나

하행은 **슬롯당 한 창**(1.2초 주기)에만 나간다. 낱개로 N건이면 **N슬롯 = N × 1.2초**.
묶으면 **하행 1슬롯 + ACK 1슬롯 ≈ 2.4초**(N ≤ 8) 로 끝난다.

## 3. 🔴 부분 실패 — **원자적이 아니다. 독립이다**

```
각 명령이 **자기 rid** 를 갖고 **자기 ACK** 를 받는다
3건 중 2번이 `result=3` 이어도 1·3번은 그대로 수행된다
```
**왜 원자적으로 안 만드나** — 🔴 **되돌릴 수단이 없다.** 전선에 나간 뒤에 취소할 방법이 없고,
"전부 성공했을 때만 적용" 을 하려면 장치가 **2단계 커밋**을 해야 한다. 그건 다른 설계다.
> ### **못 지키는 보장을 API 가 약속하면, 그 약속을 믿고 쓴 코드가 조용히 틀린다.**

### 반환 모양
```cpp
struct BatchResult {
    int queued;      // 전선 큐에 들어간 건수
    int rejected;    // 보내기 전에 거절된 건수(모듈 없음 · 이름 틀림 · rid 고갈)
};
```
⚠ **`queued` 는 "보냈다"이지 "됐다"가 아니다.** 수행 여부는 각 건의 ACK 이 답한다.
🔑 거절된 건은 **모듈 이름을 지목해 로그에 남긴다** — 숫자만 주면 어느 것인지 모른다.

## 4. 🔴 배치는 손실 **크기**를 N배로 만든다 (arduino 가 찾았다)

```c
if (inSend) { if (!pendReady) {…한 줄 미룸…} else { pendDrops++; } }   ← 깊이 1
```
```
지금  : 우리 CIPSEND 와 겹치면 **한 줄** 손실
묶으면 : 같은 한 번의 겹침이 **N−1 줄** 손실
```
> ### **배치는 손실 *확률* 을 안 바꾸고 손실 *크기* 를 키운다.**
🔑 그래서 **수신 창 안에서만 보낸다** — 지금 하행 경로가 이미 그 규율을 지키므로 **묶음도 그 위에 얹는다.**
⚠ **`penddrop` 계수기를 봐라.** 묶기 시작하면 그 값이 오르는지가 첫 신호다.

## 5. 무엇을 감추고 무엇을 보이나

```
🔒 감춘다 : 포장 · 분할 · 재시도 · 슬롯 배치 · 상한 계산
🔓 보인다 : **무엇을 묶는가** — 호출자의 선택이다
```
```cpp
ParkingServer::Batch b = srv.batch("P1");
b.add("LD", 1).add("LC", 1234567).add("DR", 2);
BatchResult r = b.send();
```
⚠ **`send()` 하나짜리를 없애지 않는다.** 하나 보낼 때 묶음 문법을 쓰게 하면 샘플이 어려워진다.

## 6. ⚠ 이 설계가 답하지 **않는** 것

```
· 순서 보장 — 한 배치 안의 줄 순서는 유지되지만 **ACK 도착 순서는 아니다**
· 상한을 넘겼을 때 자동 분할 — **안 한다.** 넘치면 거절하고 말한다
  🔑 자동 분할은 "묶었는데 왜 느리지"를 조용히 만든다. **거절이 정직하다**
· 액추에이터가 실제로 그렇게 됐는가 — 에코 계약이 아직 없다(별도 설계)
```
