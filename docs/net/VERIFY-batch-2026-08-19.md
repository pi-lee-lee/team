## 1. 각본 — 넷 다 성립

### ㉠ 4건 묶음 = 상한 ✅
```
22:35:52  →G,700,2,1          (LD)
22:35:52  →G,701,3,1234567    (LC)
22:35:52  →G,702,4,1          (DR)
22:35:52  →G,703,5,7654321    (L2)
22:35:52  ⇉ 배치 **4줄 · 64B · 한 거래** · cap 192B · 남은 큐 0줄
22:35:53  ←A,700,G2,**0** / A,701,G3,**0** / A,702,G4,**0** / A,703,G5,**0**
```
🔴 **한 `write` 다.** `wire.h:319` 가 `send_raw(ard, payload.data(), payload.size())` 로
**64B 를 한 호출에 내보낸다.** 나눠 쓰지 않는다.

### 🔴 재측정 (22:42:31) — **진짜 묶음이 확인됐다**

첫 측정 때는 시리얼 탭이 닫혀 있어 **`+IPD` 를 아무도 못 봤다.** 그래서 다시 쐈다.
```
22:42:32  [AT] "+IPD,**64**:G,468,2,1,7E"     ← 🔴 **헤더가 여기 한 번만**
22:42:32  [AT] "G,469,3,1234567,7F"            ← 🔑 **헤더 없이** 이어진다
22:42:32  [AT] "G,470,4,1,71"                  ← 없다
22:42:32  [AT] "G,471,5,7654321,70"            ← 없다
```
> ### **연발이었으면 `+IPD` 헤더가 네 번 나온다. 한 번뿐이다.**

**바이트가 세 계측기에서 맞았다:**
```
서버    `send_raw` **64B 한 호출**        (소켓 계층)
ESP     `+IPD,**64**:`                     (AT 파서 계층)
monitor 본문 60B + 개행 4 = **64B**        (문자를 셈)
```
🔑 **"한 `write` 였다"와 "한 조각으로 도착했다"는 다른 진술이고, 둘 다 참으로 확인됐다.**
**TCP 는 스트림이라 한 번 쓴 것이 여러 조각으로 도착할 수 있다** — 그래서 갈라 놓아야 했다.

### ✅ 덤 — **ACK 도 한 거래로 돌아왔다**
```
AT+CIPSEND=76
S,68,0F,00,94,P1,47 A,468,G2,0 A,469,G3,0 A,470,G4,0 A,471,G5,0
```
> ### **하행 4건 한 거래 · 상행 ACK 4건 한 거래 — 왕복이 각각 1회다.**
**사용자 요구가 정확히 이것이었다.** `ackQ` 배치가 하행 묶음과 대칭으로 맞아떨어졌다.

### ⚠ 그런데 **손실 위험은 안 닫혔다**
```

🔴 **`n=1` 이다. "묶음 손실이 없다"로 쓰지 마라** — **송신 창과 안 겹쳤을 뿐**일 수 있다

arduino 실측으로는 겹치면 **4건 중 3건이 사라진다.** 그 위험은 그대로 남아 있다.

## 2. 🔴 에코 — `echoIs(arg==1)` 이 값으로 갈렸다

```
22:36:40  →G,709,4,**1**(열기) → ←A,709,G4,0   →  봉투 `"name":"DR","idx":4,"value":**true**`
22:36:52  →G,710,4,**2**(닫기) → ←A,710,G4,0   →  봉투 `"name":"DR","idx":4,"value":**false**`
```
🔑 **`arg != 0` 규약이었으면 닫기(2)에서도 에코가 켜진 채 남았다** —
*"문은 닫혔는데 서버는 열린 줄 안다"* 가 됐을 것이다. **뜻을 아는 쪽(핸들러)이 정한 것이 옳다.**

⚠ **에코가 답하지 않는 것**: `LC`·`L2` 는 비트 하나라 **"0이 아니다"만** 말한다.
`1234567` 은 안 돌아온다. 그리고 **에코 == 요청은 "장치가 그 값을 갖고 있다"이지
"명령이 상태를 바꿨다"가 아니다** — 차단봉이 걸려도 에코는 선다.

```

③ 센서 둘   `value_known 2 · value_total 2 · value_state "known"`

기동 줄     `**묶음 상한 4건**`  ← 🔑 주석이 아니라 **값이 말한다**
