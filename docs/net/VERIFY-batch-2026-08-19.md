## 1. 각본 — 넷 다 성립

### ㉠ 4건 묶음 = 상한 ✅
```
22:35:52  →G,700,2,1          (LD)
22:35:52  →G,701,3,1234567    (LC)
22:35:52  →G,702,4,1          (DR)
22:35:52  →G,703,5,7654321    (L2)
22:35:52  ⇉ 배치 **4줄 · 64B · 한 거래** · cap 192B · 남은 큐 0줄
22:35:53  ←A,700,G2,**0** / A,701,G3,**0** / A,702,G4,**0** / A,703,G5,**0**
```
🔴 **한 `write` 다.** `wire.h:319` 가 `send_raw(ard, payload.data(), payload.size())` 로
**64B 를 한 호출에 내보낸다.** 나눠 쓰지 않는다.
⚠ **장치 쪽 `+IPD` 가 1건인지는 시리얼 탭이 답한다** — 그것이 "묶음이냐 연발이냐"의 최종 판별자다.

### ㉡ 5건 → 통째로 거절 ✅
```
22:36:03  ! 묶음 거절 — 5건 74B 는 한 창에 안 들어간다 (건수 상한 4 · 바이트 상한 192B)
→ 전선에 **한 줄도 안 나갔다**
```
🔑 **상한을 넘겨 본 것이 상한이 있다는 증거다.** 안 넘겨 보면 4가 우연일 수 있다.

### ㉢ 4건 중 하나만 8자리 → 셋 수행 ✅ — **실행 원자성 없음의 실증**
```
22:36:16  →G,704,2,1 · →G,705,3,**12345678** · →G,706,4,1 · →G,707,5,1234567
          ⇉ 배치 4줄 · 65B · **한 거래**
22:36:17  ←A,704,G2,**0** · ←A,705,G3,**3** · ←A,706,G4,**0** · ←A,707,G5,**0**
```
> ### **하나가 거절돼도 나머지 셋은 수행됐다. 명세와 일치한다.**

### ㉣ 단건 회귀 ✅
```
22:36:28  →G,708,2,0  →  22:36:29  ←A,708,G2,0
```
**묶음이 단건을 안 깼다.**

## 2. 🔴 에코 — `echoIs(arg==1)` 이 값으로 갈렸다

```
22:36:40  →G,709,4,**1**(열기) → ←A,709,G4,0   →  봉투 `"name":"DR","idx":4,"value":**true**`
22:36:52  →G,710,4,**2**(닫기) → ←A,710,G4,0   →  봉투 `"name":"DR","idx":4,"value":**false**`
```
🔑 **`arg != 0` 규약이었으면 닫기(2)에서도 에코가 켜진 채 남았다** —
*"문은 닫혔는데 서버는 열린 줄 안다"* 가 됐을 것이다. **뜻을 아는 쪽(핸들러)이 정한 것이 옳다.**

⚠ **에코가 답하지 않는 것**: `LC`·`L2` 는 비트 하나라 **"0이 아니다"만** 말한다.
`1234567` 은 안 돌아온다. 그리고 **에코 == 요청은 "장치가 그 값을 갖고 있다"이지
"명령이 상태를 바꿨다"가 아니다** — 차단봉이 걸려도 에코는 선다.

## 3. ⑤ 재측정 ✅

```
① 등록      `n=6 · drain=7 · 명령가능 4개 (device=P1)`
② 자리      `map.zones` **1개**(A1)
③ 센서 둘   `value_known 2 · value_total 2 · value_state "known"`
④ 미결속    **0/6**
계수기      `G 띄움 9·도달 9·응답 9·거절 1` · `명령결과 성공 8/거절 1/무응답 0` · `묶음미룸 0`
기동 줄     `**묶음 상한 4건**`  ← 🔑 주석이 아니라 **값이 말한다**
```
🔑 `성공 8 / 거절 1` 이 각본과 정확히 맞는다: ㉠4 + ㉢3 + ㉣1 = 8, ㉢의 8자리 하나 = 1.

## 4. ⚠ 재지 않은 것

```
· 🔴 **장치 쪽 `+IPD` 건수** — 서버는 한 write 로 냈지만 **장치가 한 조각으로 받았는지**는
  시리얼 탭만 답한다. **"묶음이냐 연발이냐"의 최종 판별자가 그것이다**
· `penddrop` — 이번 구간에 0 이었지만 **송신 겹침을 일부러 만들지 않았다.**
  arduino 실측으로는 겹치면 **4건 중 3건이 사라진다**
· 무응답 콜백 — 실기에서 한 번도 안 났다(`무응답 0`). 자가검증 ⓹ 에서만 밟았다
· `[G]` 줄 수 — **멱등 재수신은 `[G]` 를 안 찍고 ACK 만 낸다**(arduino).
  `[G]` 가 넷보다 적으면 **재전송 섞임부터 배제해야 한다**
```
