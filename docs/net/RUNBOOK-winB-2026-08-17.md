## A. 3차 재실행 — **명령을 여기 박아 둔다. 한 글자도 바꾸지 않는다**

```bash
python3 net/downlink_inject.py \
  --port 9900 --allow-production --slot A1 \
  --interval 1.15 --count 300 --start-delay 0 --ack-timeout 10 \
  --rid-prefix <회차> \
  --log /Users/idong-u/learn/net/inject-winA-2026-08-17.log
```

🔴 **`--interval 1.15` · `--count 300` · `--slot A1` · `T,S 무장 안 함` 을 바꾸면 대조가 깨진다.**
창 A 3차와 **계측기(또는 큐)만 다른 상태**여야 한다. 바꾸는 것은 `--rid-prefix` 뿐이다.

| 회차 | `--rid-prefix` | 무엇이 달라진 상태인가 |
|---|---|---|
| 창 A 3차(완료) | `inj3` | 계측기 고장 · 큐 없음 |
| 재실행 ① | `inj4` | **계측기 수정** · 큐 없음 |
| 재실행 ② | `inj5` | 계측기 수정 · **큐 있음** |

⚠ **자동 정지가 이제 붙어 있다**(문턱: 오프라인 연속 5 · result≠4 누적 2 · 응답없음 누적 3 · 예외합 5).
→ **`시도` 가 300 미만으로 끝나면 그 자체가 결과다.** 요약의 `계획대로 끝났다`/`중단으로 끝났다` 를 먼저 읽는다.

### 갈래 셋 — **루트가 골라야 한다**

| | 방법 | 대가 |
|---|---|---|
| **(가)** | **루트가 배포를 직접 친다**(빌드+교체). 내가 해시와 명령을 넘긴다 | 가장 확실. 루트 한 번의 손 |
| **(나)** | 내 트리에서 빌드해 **내가 띄운다** — `net/srv_parking_qb` · 운영 포트 · `--log` 는 운영 로그 | ⚠ `--log` 가 프로젝트 밖 인자다. **훅이 명령 전체를 막을지 안 해 봤다** |
| **(다)** | 내 트리 빌드 + **로그도 내 트리**(`net/parking-server-winB.log`) | 훅 확실히 통과. 🔴 **로그가 갈려 monitor 의 연속성이 끊긴다** |

**내 권고: (가).** 이유는 **로그 연속성**이다 — monitor 가 창 A·B 를 같은 파일에서 `INSTANCE` 경계로
가르는 것이 가장 안전하고, (다)는 그 경계를 파일 경계로 만들어 **창4 에서 겪은 "어느 파일에 썼나"
문제를 다시 만든다**(§1.4).
⚠ **(나)를 고르면 먼저 훅을 시험해야 한다** — 배포 순간에 막히면 그때 갈래를 다시 고르게 된다.

### 배포 절차 (갈래가 정해진 뒤 · 원장 §6 순서)

```
1. monitor 에게 "배포한다" 통보 → monitor 가 관측을 멈춘다   (CLAUDE.md 개정 규약)
2. 커밋 확인 — build= 가 깨끗한 해시여야 한다 (§6.1). dirty 로 띄우지 않는다
3. 현 인스턴스 SIGTERM → `INSTANCE-END reason=normal` 확보
4. 새 인스턴스 기동 → **세 포트 리슨 + 실왕복 1회** 확인
5. 커밋 해시·배포 시각을 monitor·루트에 통보 → monitor 가 새 t0 로 관측 시작
6. 그 다음에 재실행 ②
```
