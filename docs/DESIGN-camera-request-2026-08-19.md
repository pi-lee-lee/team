# 카메라 — 요청 기반 번호판 조회 (설계 요청)

**사용자 지시 2026-08-19 (원문 인용)**

> *"해당 영역 내에서 **카메라 지원**이 필요하다. 카메라는 **완전 별개 모듈**이다.
> 카메라를 이용하여 **요청하면 해당 시점의 번호판 촬영하여 번호판 번호를 받아오는** 로직이다."*

## 🔴 먼저 — 기존 계약과 **방향이 반대다**

우리에게 이미 `DigitCam` 이 있다(`docs/digitcam-contract.md` 개정 8 · `docs/net/digitcam-protocol.md` v1).
```
v1  : 방향 **단방향 앱 → 서버** · **무응답**
      *"버전 문자열은 없다. v1 은 단일 방향·무응답이라 **협상할 여지가 없기 때문**이다"*
      카메라가 **상시 켜져 있다가 인식되면 밀어 올린다**
🔴 요구 : **서버가 요청 → 그 시점 촬영 → 번호를 돌려준다**
```
> ### **밀어 올리는 것과 물어서 받는 것은 다른 프로토콜이다. v2 가 필요하다.**
⚠ **그리고 v1 이 "협상할 여지가 없다"를 근거로 버전 필드를 뺐다.** v2 는 양방향이므로
**그 근거가 사라진다 — 버전을 어떻게 가를지가 첫 항목이다.**

🔑 **v1 을 없애지 마라.** 상시 감지(입차 자동 인식)와 요청 조회는 **둘 다 쓸 자리가 있다.**
**둘을 한 연결에서 어떻게 공존시킬지**를 정해라.

## 🔴 정할 것

### Q1. **요청 주체** — 누가 요청하나
```
· 기여자 코드(`onTick`)가 부른다        → `srv.requestPlate("CAM1", cb)`
· 서버가 조건을 보고 자동으로 부른다     → 조건을 누가 정하나
```
🔑 **사용자 요구는 "요청하면"이다 — 기여자가 부르는 쪽으로 읽힌다.** 확인하고 적어라.

### Q2. 🔴 **비동기 — 콜백이다. 우리가 방금 만든 그 형태를 재사용해라**
```
촬영 + OCR 은 느리다(수백 ms ~ 초). **즉시 반환은 불가능하다**
→ 명령 콜백(`onCommandResult`)과 **같은 모양**이어야 한다. 기여자가 한 번만 배운다
```
🔴 **갈래를 반드시 갈라라** — 명령 콜백에서 세운 것과 같은 이유다:
```
✅ 성공        번호판 문자열 + 신뢰도
❌ 인식 실패   찍었는데 못 읽었다      ← **카메라는 살아 있다**
❌ 촬영 실패   카메라가 못 찍었다
🔴 무응답      폰이 안 붙어 있거나 답이 안 온다  ← **고치는 곳이 다르다**
```
⚠ **하나로 뭉치면 기여자가 "카메라 고장"과 "번호판이 더러움"을 못 가른다.**

### Q3. 🔴 **"정지 상태에서만 인식한다" 와 충돌한다 — 이게 가장 큰 빈칸이다**
기존 계약 §1: *"**정지 상태에서만 인식한다.** 움직이는 동안에는 인식 자체를 건너뛴다."*
```
🔴 서버가 **움직이는 순간**에 요청하면?
   · 즉시 "못 읽었다"로 답한다        → 요청이 자주 헛돈다
   · 정지할 때까지 기다렸다 답한다     → **얼마나 기다리나. 그 상한은 누가 정하나**
   · 흔들린 프레임으로라도 읽는다      → 🔴 계약이 금지한 것이다
```
**셋 다 가능하고 안 정하면 받는 쪽이 메운다.** 정하고 **명세에 적어라.**
🔑 **기다린다면 그건 "타임아웃 있는 요청"이고, 그 값의 계산 주체를 같이 적어라.**

### Q4. **영역과 어떻게 묶나**
```
lot.spot("A1").camera("CAM1");        ← sensor/actuator 와 같은 모양?
lot.gate("E1").camera("CAM1");        ← 입출구에 붙는 것이 자연스럽나?
```
🔑 **`sensor`·`actuator` 와 같은 모양이면 기여자가 한 번만 배운다.**
⚠ **다만 카메라는 ESP 모듈이 아니다** — devid 가 없고 슬롯도 안 탄다.
**같은 모양으로 보이게 하되 *다른 것* 임을 이름이나 주석이 말해야 한다.**

### Q5. **완전 별개 모듈이라는 것의 뜻**
```
✅ ESP 링크(1.2초 슬롯·64B 줄)를 **안 탄다** → 묶음·`penddrop`·`ssovf` 제약이 **없다**
✅ 별도 TCP(폰 포트 5500+N) → 크기 제약이 다르다(JSON)
🔴 그러므로 **카메라 지연을 아두이노 예산으로 재지 마라** — 다른 축이다
```
