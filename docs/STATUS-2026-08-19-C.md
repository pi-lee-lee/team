## §0-A 무엇을 기다리다 멈췄나
**아무것도 안 기다린다.** 사용자가 **20:00 위치 이동**을 정했고 재개도 **사용자가 고지**한다.
진행 중이던 것은 전부 안전한 지점에서 끊었다. **굽기·배포 없음. 작업본 깨끗.**

## §1 🔴 재개하면 가장 먼저 — 이동 굽기
```
이동하면 **SSID · 서버 IP 가 바뀔 수 있다** → 안 맞으면 장치가 아예 안 붙는다
필요한 것 : ① 새 SSID/비밀번호 (같으면 "같다") ② 이동 후 이 PC 의 IP (내가 잰다)
그 둘로 굽는다. ⚠ `!!` 같은 문자는 셸 치환되니 `--body-file` 로 넘긴다
```
🔴 **그리고 상시 규칙**: 사용자가 자리이동을 명시하면 **환경 안정 5분**은 **관측에서 제외**한다.
기록에는 남긴다. **이동 직후는 고장처럼 보이는 것이 가장 많고 대부분 셋업이다.**
