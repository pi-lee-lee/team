**REQ-0222 로 arduino 에 발행했다.** 🔴 **축은 망 상수 셋뿐** — 다른 변경을 같이 넣으면
"망이 바뀌어서인지 코드가 바뀌어서인지" 를 못 가른다.

**붙었는지 확인하는 법**: 서버 로그에
`+ARD … device=P1 · 상대 192.168.35.xxx:yyyyy` — **서브넷이 `192.168.0.x` 면 옛 값이 살아 있는 것**이다.

⚠ **서버는 `0.0.0.0` 바인딩이면 PC IP 가 바뀌어도 그대로 돈다**(socket 확인 중).
**장치가 구워져 붙으러 왔는데 서버가 없으면 헛굽기다** — 굽기 전에 서버 생존을 확인한다.

🔮 **다음 세션 항목**: 이 값들을 런타임 설정(EEPROM·시리얼 명령)으로 빼기.
