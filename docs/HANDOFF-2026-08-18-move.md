## 🔴 0. 이동 후 **가장 먼저** 할 일 — 안 하면 아무것도 안 붙는다

`조별과제샘플/client.ino` 의 셋이 **컴파일 상수**다. 망이 바뀌면 **재굽기 없이는 못 붙는다.**

```
:91  WIFI_SSID   "3F_302"          ← 새 망 이름
:92  WIFI_PASS   "0424719222!!"    ← 끝의 느낌표 둘까지가 비밀번호다
:97  SERVER_IP   "192.168.0.29"    ← PC 의 새 IP
```

**절차는 `docs/arduino/` 의 "이동 후 복구 절차"** 에 arduino 가 썼다(17:55 마감).
없으면 위 세 줄을 고치고 빌드 → `--selftest` → upload → hex 대조 순이다.

**사용자에게 물어야 할 것**: 새 SSID · 비밀번호 · PC 의 새 IP.
(PC IP 는 `ipconfig getifaddr en0` 로 직접 확인할 수 있다.)

⚠ **서버는 `0.0.0.0` 바인딩이면 PC IP 가 바뀌어도 그대로 돈다** — socket 이 확인 중.
**바뀌는 쪽은 장치다.**

🔮 **다음 세션 항목**: 이 값들을 런타임 설정(EEPROM·시리얼 명령)으로 뺄 수 있는지.
**이동이 반복되면 매번 재굽기는 비용이다.** 오늘은 안 했다 — 새 값을 모르는 채 고치면 검증이 안 된다.

## 2. 🔴 걸려 있는 것 — **창 H 판정이 미완일 수 있다**

**주입 8라운드는 17:40 에 끝났다.** monitor 가 17:52 까지 판정을 마감한다.

**대리 지표(판정 아님)**: 세션 #17 이 33분 이상 유지됐다. 창 G 는 28분에 16회 갈렸다.
⚠ **세션 지속으로 결론 내지 마라. 판정선은 `T2` 계수다.**

**읽는 법:**
```
okstream>0 AND penddrop>0  →  (나) 확정 (버려질 뻔한 SEND OK 를 매칭이 구했다)
T2 14 → 4 근처             →  성공
🔴 T2 0                    →  오히려 의심해라. 자극이 충분했는지부터 본다
```
⚠ **뒤집힘은 창 G 에서 T2 14건 중 10건만 설명했다.** 나머지 4건(에코실종/지연)은 **별개 기전**이다.
⚠ **지연이 남는 것은 실패가 아니다** — 이번 수정은 **실종**만 겨눈다.

🔴 **창 H 는 여기서 닫는다.** 이동 후에는 망도 서버 IP 도 달라서 **이어 쓸 수 없다.**
