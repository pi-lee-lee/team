> **실제 확보 노출과 그 노출에서의 검정력을 다시 계산해서 적어라.**

## ⛔ 7.0-K 전원 갈래는 **전부 닫혔다. 다시 열지 마라** (08:3x · 루트 결정)

**사용자가 사진 둘과 배선 설명을 줬다. 다섯 갈래 전부 닫혔다.**

```
XL4015(전압 표시 달린 모듈) → 굵은 실리콘 선 직결 → 만능기판
100µF ×2  →  0.1µF 세라믹  →  ESP 전원      (벌크 → 로컬, 세라믹이 ESP 에 가장 가깝다)
ESP↔우노 3핀 = GND 1 · TX/RX 2              (ESP 전원은 우노에서 안 온다)
```

| 갈래 | 판정 | 근거 |
|---|---|---|
| 공급 용량 | ⛔ 닫힘 | XL4015 5A급 ≫ 피크 0.3A |
| 벌크 디커플링 | ⛔ 닫힘 | 200µF + 0.1µF · 순서가 교과서 배치 |
| 공통 GND | ⛔ 닫힘 | 1핀이 아두이노 GND |
| 접지 기준 흔들림 | ⛔ 닫힘 | **정량 2자릿수 부족**(≈10mV 대 문턱 1.65V) · 귀환 전류가 그 선으로 안 흐른다 |
| 레일 과도 응답 | ⛔ 닫힘 | 전용 벅 + 굵은 선 + 세라믹이 ESP 바로 앞 |

🔴 **새 증거 없이 다시 열지 마라. 재개하려면 실측 파형이 있어야 하고 우리에겐 없다.**

루트가 우회했다. **사용자가 "전원 문제 아니다"를 열 번쯤 말했고 그 말이 맞았다.**

### 창3 대 창4 — 세 축이 전부 다르다 (socket)

| | 창3 (`64fc70b`) | **창4 (`0fba51f`)** |
|---|---|---|
| ACK | **왔다**(`result=4`) | **안 왔다**(재전송 3회 후 최종 실패) |
| 세션 종료 | **상대가 닫음**(장치 FIN) | **재접속으로 대체**(장치가 사라졌다) |
| 재접속 | 즉시(+2초) | **8초 침묵 후**(ESP 재결합 시간) |

**서버측 셋이 다른 기전을 가리켰고 시리얼이 확정했다.** ACK 가 안 온 이유는 **장치가 하행을
못 받았기 때문**이고, 8초 침묵은 **ESP 리셋·재결합 시간**이다.
