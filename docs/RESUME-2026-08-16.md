## 5. A 창이 끝나면 (약 21:53) — 순서

1. **monitor** — A 판정 산출(λA·링크 끊김/h·`busy` 런 분포). 이 값이 다음 단계의 기준선이다.
2. **socket** — 미배포 변경 배포. **커밋 먼저**(`build=` 가 깨끗한 해시여야 한다) →
   SIGTERM → 새 인스턴스 → 세 포트·실왕복 → monitor 에 시각 통보.
3. **arduino** — 1단계 수정 플래싱. 굽기 전 루트 통보 → `INTERVENTIONS.md` 기록 →
   monitor 에 포트 통보 → 굽고 hex 대조 → 결과 보고. 그 뒤 같은 규칙으로 재계수.
4. **web** — 브라우저→서버→장치 **종단 시험**. 시연 경로에서 유일하게 안 재본 구간이다.
   (서버→장치는 5/5 도달 확인됨. 브라우저 구간만 남았다)

**2 와 3 을 같은 창에 하지 마라.** 둘 다 관측 경계를 만든다 — 섞으면 어느 쪽 효과인지 못 가른다.
