# 릴리즈 — 주차 서버 (`릴리즈/server`)

> **정본은 `서머리/server` 다.** 이 폴더는 그 **스냅숏**이고, 파일은 **바이트 동일**해야 한다.
> 2026-08-27 픽스 판 · 📄 `docs/FIX-2026-08-27-final.md` 가 *"무엇이 도는가"* 의 정본이다.

## 🔴 기동 — **인자가 최종 구성의 일부다**

```bash
SRV_TREE=summary net/run/start.sh --no-chooser
```

```
🔴 `--no-chooser` 를 빼면 **8081 자리 선택 갈래가 살아난다.**
   그러면 차단봉이 먼저 열리고 **안내등이 5초 뒤**에 켜진다 — 최종 구성이 아니다
★ 즉 **이 인자는 선택이 아니라 구성이다.** 안 적으면 다음 사람이 다른 판을 돌린다
```

### 릴리즈 배치(저장소 밖)에서는 이렇게 뜬다
```bash
cd <릴리즈>/server
c++ -std=c++11 -O2 server.cpp lot.cpp -o srv
./srv --no-chooser
```
🔵 **인자 `--web-root` · `--data-dir` 이 필요 없다** — 기본값이 `<실행파일>/../web` 이라
릴리즈 배치(`server/` 옆에 `web/`)에서 저절로 맞는다. **그것이 자립의 뜻이다.**

```
릴리즈/
├─ server/   ← 여기 (소스 + `srv` + `data_log.json`)
└─ web/      ← 화면 셋 (`index.html` · `user8080.html` · `user8081.html`) · **web-engineer 소유**
```

---

## 손잡이 — 이 판에서 뜻이 있는 것만

| 인자 | 기본값 | 뜻 |
|---|---|---|
| `--no-chooser` | (꺼짐 = 선택 갈래 **켜짐**) | 🔴 **8081 선택 서비스 일시 중지.** 최종 구성은 **이것을 켠다** |
| `--web-root=<dir>` | `<실행파일>/../web` | 화면 셋을 읽는 자리. **cwd 로 안 정한다** |
| `--data-dir=<dir>` | `--web-root` 와 같음 | `data_log.json` 을 **쓰는** 자리 |
| `--port-web=` `--port-ardu=` `--port-cam=` | 9900 · 9991 · 5500 | 시험용. ⚠ **8080·8081 은 못 바꾼다** |

> ### ⚠ `--no-chooser` 는 **일시 중지**다. 코드는 안 지웠다 —
> ### 인자를 빼면 선택 갈래가 그대로 돌아오고, 하니스 `G` 시나리오가 그것을 계속 검사한다.

## 🔴 무엇이 잘못됐는지 **로그가 말한다** — 조용히 안 죽는다

```
= 정적 뿌리 <경로> · index.html <크기>B · 수정 <시각>     ← 🔵 정상. 화면 자리를 값으로 찍는다
! 🔴 정적 뿌리 <경로> 에 **index.html 이 없다**            ← 🔴 화면이 404 다. **서버는 산다**
⏸ 선택 서비스 **중지 중** — 선택 화면 N대를 무시하고 자동 배정한다
```
> ### ★ **화면을 못 찾아도 서버는 뜬다.** 화면은 관측이고 주차 제어는 기능이다 —
> ### **관측 하나가 기능을 죽이면 안 된다.** 대신 **시끄럽게** 둔다.
🔵 소크 요약(`⏱`)에도 `⏸ **선택서비스 중지**` 칸이 뜬다. **끈 것이 안 보이면 다음 사람이 못 푼다.**

## 🔴 자립 검증 — **저장소 밖에서** 해라

```bash
cp -R 릴리즈/server /tmp/relcheck/server
mkdir -p /tmp/relcheck/web && cp <화면 셋> /tmp/relcheck/web/
cd /tmp/relcheck/server && c++ -std=c++11 -O2 server.cpp lot.cpp -o srv && ./srv --no-chooser
```
```
✅ 통과 기준 : 포트 다섯 LISTEN · `/` · `/user8080.html` · `/user8081.html` **HTTP 200**
🔴 그리고 **빨간불도 내라** — 소스 파일 하나를 빼고 **빌드가 실패하는 것**을 보인다.
   ★ 안 그러면 *"복사가 됐는지"* 와 *"자립하는지"* 를 구별 못 한다
```

### 🔴🔴 **md5 로 대조하지 마라 — 원리적으로 안 맞는다** (실측 2026-08-27)
```
runtime.h:119   #define BUILD_ID "unknown-source(compiled " __DATE__ " " __TIME__ ")"
→ 🔴 `BUILD_ID` 를 안 넘기면 **빌드 시각이 바이너리에 박힌다.** 1분 뒤 빌드도 md5 가 다르다
실측 : 같은 소스 · 같은 컴파일러  →  `5f09caf4…`(534,680B) vs `e35d54bf…`(534,672B)
   ★ 문자열 차이는 **`compiled 11:37:57` vs `11:50:20`** 그것 하나였다
```
> ### ✅ **성립하는 기준은 둘이다**
> ### ① **소스 바이트 동일** — `릴리즈/server/*.{h,cpp}` == `서머리/server/*.{h,cpp}`
> ### ② **하니스 통과** — `net/flowcheck/flow26.cpp` 가 **143/0**
🔵 그리고 앞으로는 **`BUILD_ID` 를 넘겨라** — 그러면 바이너리가 **자기 커밋을 스스로 말한다**:
```bash
c++ -std=c++11 -O2 -DBUILD_ID='"'"$(git rev-parse --short HEAD)"'"' server.cpp lot.cpp -o srv
```
★ md5 보다 낫다 — **재빌드해도 값이 안 바뀌고**, 로그에 그 값이 찍혀 **어느 커밋이 도는지** 남는다.
