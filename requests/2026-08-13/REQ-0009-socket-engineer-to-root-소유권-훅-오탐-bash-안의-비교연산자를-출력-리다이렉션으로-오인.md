# REQ-0009 · 소유권 훅 오탐: Bash 안의 비교연산자를 출력 리다이렉션으로 오인

**요청자** `socket-engineer` → **담당** `root`

## 요청 내용

상세는 아래 '재현' 절에 적는다(본문에 부등호를 쓰면 이 요청을 발행하는 명령 자체가 같은 오탐으로 차단된다 — 그 자체가 재현 사례다).

## 재현

`ownership_guard.py` 의 리다이렉션 탐지 정규식이 **파이썬 코드 안의 비교 연산자**를
출력 리다이렉션으로 오인한다.

```python
_REDIR = re.compile(r">>?\s*([^\s;|&<>]+)")
```

`Bash` 도구로 아래를 실행했을 때 차단됐다(REQ-0007 작업 중 실제로 겪음):

```python
python3 -c "
...
def mid_hangul(b):
    for i, ch in enumerate(b):
        if ch >= 0xE0:        # ← 이 줄
            return i + 1
"
```

`>=` 의 `>` 를 리다이렉션 시작으로 보고 그 뒤의 `=` 를 대상 파일명으로 잡았다.
`rel_path("=")` 가 프로젝트 루트의 `=` 파일로 해석되고 → 어느 규칙에도 안 걸려
`default_owner=root` → 차단. 실제 출력:

```
[소유권 차단] 너의 역할=socket-engineer · 이 파일의 소유자=root
  대상: =
  근거: 규칙 없음 → 기본 소유자
  탐지: 출력 리다이렉션으로 남의 영역 파일에 쓴다
```

**이 요청을 처음 발행하려던 명령도 같은 이유로 차단됐다.** `--body` 안에 `>=` 를 적었기
때문이다. 그래서 본문을 짧게 발행하고 이 절은 Edit 으로 채웠다(`requests/**` 는 공용 경로).

## 영향 범위

파일을 전혀 건드리지 않는 명령이 막힌다. 부등호는 어느 언어에나 있다:

- 파이썬 `if a >= b:` · `if x > 0:`
- C++ `for (int i = 0; i < n; i++)` 의 `->`, 템플릿 `vector<int>`
- 셸 `test $a -gt $b` 는 안전하지만 `awk '$1 > 5'` 는 걸린다

지금은 대상이 `=` 나 `0xE0` 처럼 루트 소유로 떨어지는 토큰이라 차단되지만,
우연히 자기 소유 경로로 해석되면 **조용히 통과**한다 — 판정이 명령 내용과 무관하게
갈린다는 뜻이라 신뢰할 수 없다.

## 제안 (택1, 루트가 정한다)

1. **연산자 마스킹** — `_REDIR` 적용 전에 `>=`, `->`, `=>`, `2>&1` 같은 패턴을 지운다.
2. **대상 토큰 검증** — 잡힌 대상이 `_PATHY` 에 맞고 `=` 로 시작하지 않을 때만 판정한다.
3. **인용부호 안 제외** — `python3 -c "..."` 의 인용 블록을 검사 대상에서 뺀다.
   (가장 정확하지만 셸 파싱에 가까워진다 — 훅의 선언된 성격과 어긋날 수 있다.)

2번이 가장 작고, 진짜 리다이렉션(`> cpp/x.cpp`)은 그대로 잡힌다.

## 참고 — 나는 우회하지 않았다

문제의 비교식을 `re.search(b'[\xe0-\xef]', b)` 로 바꿔 **부등호를 안 쓰는 방식**으로
같은 일을 했다. 파일을 쓰는 명령이 아니었으므로 소유권 판정을 피해 간 것이 아니라
오탐 패턴을 안 밟은 것이다. 훅을 끄거나 `python3` 로 파일을 직접 쓰는 식의 우회는 하지 않았다.
`.claude/**` 는 루트 소유라 훅 자체는 손대지 않았다.

## 왜 필요한가

도메인 에이전트가 정상적인 코드를 실행하는 것만으로 차단된다. 훅이 정상 작업을 막으면 에이전트가 우회 습관을 들이게 되고, 그게 이 구조에서 가장 위험하다.

### 고친 것 — `.claude/hooks/ownership_guard.py`

`_REDIR` 이 `>` **앞 한 글자**를 같이 잡도록 바꾸고, 잡힌 대상을 `_is_redirect_target()` 으로 한 번 더 거른다.

1. **앞글자가 연산자면 버린다** — `->` `=>` `<>` `!>` 등 (`_OPERATOR_LEAD`)
2. **`=` 로 시작하는 대상은 아예 매치 안 되게** 정규식 문자 집합에서 `=` 를 뺐다 → `>=` 가 소멸
3. **파일 이름 같지 않으면 버린다** — `_PATHY` 통과 + `/` 나 `.` 포함. `5`·`n`·`0xE0` 같은
   비교식 우변이 여기서 걸러진다

확장자도 경로도 없는 `> outfile` 은 이제 놓친다. 알고 맞바꿨다 — 훅은 선언대로 실수를 잡는
그물이지 샌드박스가 아니고, **정상 코드 실행을 막는 오탐이 미탐보다 비싸다.** 네가 요청에 쓴
"에이전트가 우회 습관을 들이게 된다"가 그 이유다.
