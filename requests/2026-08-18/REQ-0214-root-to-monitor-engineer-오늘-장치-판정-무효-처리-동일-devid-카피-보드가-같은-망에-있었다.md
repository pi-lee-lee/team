# REQ-0214 · 🔴 오늘 장치 판정 무효 처리 — 동일 devid 카피 보드가 같은 망에 있었다 (사용자 확정)

**요청자** `root` → **담당** `monitor-engineer`

## 요청 내용

🔴 **사용자 확정: 오늘 관측 구간에 다른 사람의 동일 카피 보드가 붙어 있었다. 그 구간 자료를 무효로 한다.**

> *"다른 사람이 아두이노 동일 카피를 기동했다. 아마도 그 원인일 것이다."*
> *"**특정할 수 없다. 해당 이슈는 모두 다른 사람 접속으로 처리하라.** 지금 네트워크에 동일 조원들이 테스트 중이었다."*

## 왜 특정이 안 되나 — 구조가 그렇다

```
서버 판별 : first-S-wins — device_id 로 주차 노드를 정한다
그런데    : 두 보드가 똑같이 device=P1 이다
→ 🔴 서버는 둘을 같은 장치로 본다. 충돌 로그조차 안 남는다(실제로 0건)
→ 세션 17회 · "재부팅감지 17" 이 전부 이것으로 설명될 수 있다
```

**그리고 우리 탭은 한 보드만 본다.** **서버 로그와 시리얼 로그가 다른 장치를 보고 있었다.**

## 🔴 무효 처리 — 이렇게 한다

**대상**: 오늘 조원 테스트가 겹친 구간의 **장치 관련 판정 전부.**
⚠ **어느 시각부터인지 특정 불가**(사용자 확정) → **보수적으로 오늘 전 구간을 의심 대상으로 둔다.**

```
❌ 무효 : "SEND OK 8초 침묵" · "페이로드가 CIPSEND 보다 먼저" · "0.0.0.0 대 FIN/RST 두 종류"
          "ackdrop 43/86" · "esprst 증가" · "stuck 증가" · 세션 17회 · 재부팅감지 17
          → 🔴 전부 "우리 보드의 것인지 남의 보드의 것인지 모른다"
❌ 무효 : 사용자 연타 검증 결과 전부 (어느 보드가 응답했는지 모른다)
✅ 유효 : 소스 판독으로 확인한 것 (ACKQ_N=4 의 주석 · cmdPending 구멍 · CIPSEND 규약 21,971건)
✅ 유효 : selftest 로 확인한 것 (사용자 16건 막힘 · 중요 통과)
✅ 유효 : 주기 1.2056초 실측 — ⚠ 다만 이것도 남의 보드 프레임이 섞였으면 재확인 대상
```

🔑 **판정문·원장에서 그 구간을 인용하는 항목에 무효 표시를 붙여라.** 지우지 마라 —
**"이 자료는 다중 장치 오염으로 무효"** 라고 사유와 함께 남긴다.

## ⚠ 그리고 이것이 오늘 최대 교훈이다

```
우리는 화면·ACK 큐·배치 상한 셋을 고쳤다 — 셋 다 소스로 확인된 실제 결함이었다
그런데 "고쳤는데 왜 안 낫나"를 반복해 쫓았고, 그 답이 "관측 대상이 우리 것이 아니었다" 였다
```

> ### 🔴 **`device_id` 가 전역 고유가 아니면 관측 자체가 성립하지 않는다.**
> **우리는 그것을 설계 개정 항목으로 알고 있었다**(`devid` 전역 고유 · `(devid,name)` 복합 키).
> **그런데 그것이 "지금 당장 관측을 무효로 만드는 것"인 줄은 몰랐다.**

**이 사실을 설계 문서와 원장에 올려라** — **`devid` 충돌은 기능 문제가 아니라 관측 문제다.**

## 🔴 앞으로 — 관측 재개 조건

**같은 망에 동일 `device_id` 보드가 없다는 것을 확인할 방법이 필요하다.** 후보:
```
· 서버가 접속 IP·포트를 로그에 남긴다 → 세션별로 세면 즉시 갈린다  ← socket 확인
· devid 를 보드마다 다르게 굽는다 → 조원 협조가 필요하다
· 서버가 같은 devid 의 동시 접속을 감지해 경고한다
```
⚠ **이것 없이는 다음 관측도 같은 함정에 빠진다.** **재개 전에 하나는 있어야 한다.**

## 지금 할 것

```
1. 무효 표시 (판정문 · 원장 · 이 사건을 인용하는 모든 자리)
2. devid 충돌 감지 방법을 제안 (socket: 서버 로그에 IP 가 남는가부터)
3. 🔴 새 조사·굽기·배포 금지 — 관측 기반이 없다
```

## 왜 필요한가

다른 사람이 동일 카피(device=P1)를 기동했고 서버는 first-S-wins 를 devid 로 판정하므로 둘을 구분 못 한다 — 충돌 로그조차 0건이다. 우리 탭은 한 보드만 보므로 서버 로그와 시리얼이 다른 장치를 보고 있었다
