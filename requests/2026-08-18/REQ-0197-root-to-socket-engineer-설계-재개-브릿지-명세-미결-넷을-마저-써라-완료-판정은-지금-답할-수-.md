# REQ-0197 · 설계 재개 — 브릿지 명세 미결 넷을 마저 써라 · 완료 판정은 지금 답할 수 있다

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

**사용자 지시: "설계 진행하자" → "재개해라."** 측정이 종료됐다. **브릿지 명세를 마저 써라.**

## 네 §7 미결 다섯 — 넷이 남았다

```
1. ~~등록 프레임 형식~~ ✅ 닫혔다
2. ⬜ 자리 하나가 여러 노드에 걸칠 때의 완료 판정   [네 초안 §3 · 합의 안 됨]
3. ⬜ 노드 수 상한                                  🔴 실측 필요 — 지금 못 닫는다
4. ⬜ cap 이 노드마다 다를 수 있는가
5. ⬜ 재시도 예산과 열화 구간                       창 B 자료로 정한다고 적어 뒀다
```

### ② 완료 판정 — **지금 답할 수 있다. 액추에이터 에코가 확정됐기 때문이다**

네가 §6.5 에 세 줄 판별표를 넣었다:
```
ack + 다음 S 비트 변화   → 동작이 났다
ack + 비트 변화 없음     → 받았지만 못 했다
ack 없음 + 비트 변화     → ACK 만 유실됐다
```
**자리 하나가 두 노드에 걸치면 "그 자리의 완료"는 각 노드의 판정을 조합한 것**이다.
🔴 **조합 규칙을 정해라** — 전부 성공해야 완료인가, 부분 완료가 있는가, **부분 완료를 화면에 어떻게 주는가.**
⚠ **그리고 이건 web 의 `actions`·`known` 모듈 단위와 맞물린다** — **네가 계산 주체이므로 네가 정한다.**

### ③ 노드 수 상한 — **답을 내지 마라. 무엇을 재야 하는지만 적어라**

**측정이 이것을 확정해 줬다**(설계 문서 §측정 종료):
```
🔮 추론  : 노드가 독립이므로 N 개로 늘려도 각 노드 안에서는 같을 것이다
           근거 — 충돌은 장치 내부 UART 를 둘이 다툴 때 생겼고 노드가 분리되면 그 자원이 각자다
⚠ 미측정 : WiFi 대역은 공유된다. 실물이 P1 한 대뿐이라 못 잰다
뒤집힐 조건 : 왕복이 슬롯 주기(1200ms)를 위협할 만큼 늘어나면 다시 본다
```
**그 층을 그대로 명세에 옮기고**, **"보드 두 대가 생기면 무엇을 어떻게 재는가"** 를 절차로 적어라.
🔑 **지금 왕복 1230ms 중 대부분이 슬롯 대기이고 전파 구간은 짧다** — **그 구간을 따로 재는 방법이
있으면 그것도 적어라.** 그게 N 의 상한을 계산 가능하게 만들 유일한 길이다.

### ④ `cap` 이 노드마다 — **판단만 적어라**

지금 전역 하나다. **노드마다 다르게 할 수 있는 구조인지, 그럴 필요가 있는지**를 판단해 적어라.
⚠ **`cap` 은 지금 이론 최악으로 20배 보수적**이고 **`d1+d2` 실측이 아직 없다**(`[ACK] lag=` 대기).
**그 상태를 명세에 남겨라.**

### ⑤ 재시도 예산 — **창 B~E 자료가 나왔다**

*"창 B 자료로 정한다"* 고 적어 뒀는데 **창 E 까지 나왔다.** 지금 정할 수 있으면 정하고,
**부족하면 무엇이 더 필요한지 적어라.** ⚠ 참고: **재전송이 창 E 에서 2건이고 둘 다 늦은 ACK 계열**이다.

## 🔴 그리고 §6(web 계약)이 "합의 아직"으로 남아 있다

web 이 원장 §5.32·§5.36 에 **네 계약을 고정했다**(`actions` 조작별 · 계열 셋 · `kind` 별 유효 조작 표).
**즉 합의는 사실상 끝났다** — **명세의 그 표시를 갱신해라.** 안 하면 다음 사람이 미합의로 읽는다.

## ⚠ 하지 말 것

- **코드를 고치지 마라.** `ACK_TIMEOUT` 수정은 **구현 단계**이고 지금은 명세다.
- **관측·배포를 열지 마라.**
- **서술 층을 갈라라**: ✅확정 / 🔮추론(근거 포함) / ⚠미측정. 사용자가 정한 형태다.

## 왜 필요한가

측정이 끝나 사용자가 설계 재개를 지시했고, 액추에이터 에코 확정으로 '자리가 여러 노드에 걸칠 때의 완료 판정'을 지금 답할 수 있게 됐다. 그리고 web 이 계약을 원장에 고정해 §6 의 '합의 아직' 표시가 낡았다
