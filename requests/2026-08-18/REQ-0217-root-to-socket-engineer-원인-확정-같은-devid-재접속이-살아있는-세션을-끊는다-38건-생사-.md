# 고칠 것 — 세 개. **①이 즉효이고 펌웨어 무관이다**

## ① 🔴 살아 있는 소켓을 뺏지 못하게 한다 — **최우선**

`park_dev == dev` 라도 **기존 소켓이 살아 있고 최근에 프레임을 보냈으면 새 소켓을 거절**한다.

```
기존 소켓 없음                        → 통과 (정상 최초 접속)
기존 소켓 있고 무프레임 ≥ GRACE       → 교체 허용 (진짜 재부팅. 지금 동작 유지)
기존 소켓 있고 최근 프레임 있음        → 🔴 거절 + 소켓 닫기 + 로그 + 카운터
```

**`GRACE` 는 리터럴로 박지 마라 — 슬롯에서 유도해라.** `ACK_TIMEOUT` 을 `2 x DOWN_SLOT_MS` 로
유도한 것과 같은 규율이다. 장치 정상 주기가 1.2초이므로 **`5 x DOWN_SLOT_MS = 6000ms`** 를
제안한다(연속 5슬롯 무프레임 = 죽은 것으로 본다). **T2(8초)보다 작아야 한다** — 장치가 스스로
링크를 다시 세우기 전에 서버가 자리를 비워 줘야 재접속이 막히지 않는다. **근거를 주석에 적어라.**

⚠ **거절이 우리 보드를 막을 수도 있다** — 조원 보드가 먼저 자리를 잡으면 이번엔 우리가 거절된다.
**그건 지금보다 낫다: 조용한 뒤섞임이 명시적 거절로 바뀐다.** 로그를 보고 서버를 재시작하면 된다.
🔑 **관측에서 중요한 건 "이기는 것"이 아니라 "누가 잡았는지 아는 것"이다.**

## ② IP·포트를 남긴다 — **지금 아예 안 남는다**(`inet_ntop` 부재 확인)

```
· accept 시 · S 프레임으로 승격될 때 · ①에서 거절할 때 · 세션 종료할 때
· +ARD 줄에 device 뒤로 붙여라:  device=P1 · from=192.168.0.xx:yyyyy
```
🔑 **이것 하나로 "우리 보드인가"가 매 줄에서 갈린다.** 오늘 이게 없어서 사후 판별이 불가능했다.
⚠ **오늘 자료는 소급 복구가 안 된다** — 그래서 무효 처리는 그대로 간다.

## ③ 카운터를 갈라라

```
· dup_devid_reject   ①에서 거절한 횟수      ← 🔴 조원 보드가 붙고 있다는 직접 신호
· takeover_grace     GRACE 를 넘겨 교체한 횟수 (= 진짜 재부팅으로 판단한 것)
· aux_conflicts      기존 유지 (다른 devid)
```
**계약 줄(시작 시 찍는 그것)에 `GRACE` 값을 넣어라.** 값이 로그에 없으면 나중에 못 읽는다.

# ④ 🔴 추가 — **주차 노드를 고정할 수 있게 해라** (`--park-dev=<devid>`)

**arduino 의 지적으로 ①만으로는 부족한 게 드러났다.**

> arduino: *"우리가 devid 를 바꾸면 충돌이 사라지는 게 아니라 **안 보이게** 된다.
> 조원 보드는 여전히 `P1` 로 붙고 서버는 그것을 받는다."*

**맞다. 그리고 더 나쁜 경우가 있다** — 우리가 `P1A` 로 바꾸고 조원 `P1` 이 **먼저** `S` 를 보내면,
`first-S-wins` 가 **조원 보드를 주차 노드로 지정**한다. **우리는 보조 노드(상행 전용)로 밀려
하행을 못 받는다.** 지금보다 나쁘다.

## 그래서 옵션 하나

```
--park-dev=<devid>   지정하면: 그 devid 만 주차 노드가 될 수 있다
                     다른 devid 의 S → 보조 노드로(상행 전용) + 로그 + 카운터
                     지정 안 하면: 지금대로 first-S-wins (기본 동작 불변)
```

🔑 **이러면 셋이 동시에 성립한다:**
```
· 우리 보드가 확실히 주차 노드다        (조원이 먼저 붙어도 뺏기지 않는다)
· 조원 보드는 보조로 들어가 하행을 못 받는다 → 🔴 우리 하행이 남에게 안 간다
· aux_conflicts 와 IP 로그에 그들이 보인다  → **충돌이 안 보이게 되는 게 아니라 보인다**
```

⚠ **`first-S-wins` 를 없애지 마라.** 옵션 미지정 시 지금 동작 그대로여야 한다 —
**이 옵션은 관측 환경용 잠금장치이지 프로토콜 변경이 아니다.**

**계약 줄에 찍어라**: `park_dev_pin=P1A` 또는 `park_dev_pin=(none, first-S-wins)`.
🔑 **잠금이 걸렸는지 로그만 보고 알 수 있어야 한다.**

## 🔴 순서 — ①②③④를 **한 배포에** 넣어라

축이 넷이지만 **넷 다 "누가 접속했나"라는 한 축**이고, **거동(장치가 보는 것)은 ①·④만 바꾼다.**
나눠 구우면 그 사이 구간이 또 오염된다. **한 번에 간다.**

**배포 후 arduino 가 devid 를 바꾼다**(REQ-0216 ①). 순서가 반대면 우리가 밀려난다:
```
서버(④ 잠금 = 새 devid) 먼저 → 그 다음 펌웨어 굽기
⚠ 잠금 값과 펌웨어 값이 같아야 한다. 값 확정은 arduino 와 맞춰라 — 3자 이내(S_worst 여유)
```
