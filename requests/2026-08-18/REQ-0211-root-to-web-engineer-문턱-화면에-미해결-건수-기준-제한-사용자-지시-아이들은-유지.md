# REQ-0211 · 🔴 문턱 ① — 화면에 미해결 건수 기준 제한 (사용자 지시) · 아이들은 유지

**요청자** `root` → **담당** `web-engineer`

## 요청 내용

🔴 **사용자 지시. 화면에 문턱을 만든다.**

> *"**1. 스크립트에서 문턱 생성** 2. 서버에서 송신 시점에 문턱 생성하라. 수치는 모두 확인되었을 것이다."*

**①이 네 몫이다.** ②(서버 송신 시점)는 socket 에 냈다(REQ-0210).

## 왜 화면에도 필요한가

**지금 화면 제한은 아이들 1초뿐이고, 그건 "다음 클릭까지의 최소 간격"이다.**
🔴 **누적을 안 본다** — 1초 간격으로 30번 누르면 30건이 다 나간다.

```
서버 큐 상한(16건)   : 🔴 한 번도 안 걸렸다 (queue_full 0건)
서버 배치 상한(4건)  : 걸린다 — 배치 150B → 36B
그런데 끊김은 계속된다
```

**즉 유입이 서버까지 그대로 간다.** 사용자 지시가 그 앞단을 막으라는 것이다.

## 할 것 — **미해결 건수 기준 문턱**

**아이들(시간 간격)이 아니라 "지금 응답을 기다리는 건수"로 막아라.**

```
· 미확정(pending + cmdPending) 이 N 건을 넘으면 새 조작을 막는다
· 🔴 조용히 막지 마라 — 이유를 말한다. 화면에 이미 그 언어가 있다
  (queue_full 문구와 같은 계열: "앞의 요청을 기다리는 중입니다" 같은 형태)
· ACK/거절이 오면 카운트가 줄고 다시 눌린다
```

⚠ **아이들 1초를 없애지 마라.** **둘이 다른 것을 막는다** — 아이들은 연타 속도, 이건 누적 부하.

### 수치 — **네가 가진 것으로 유도해라**

```
서버 배치 상한 : 창당 4건 (지금 실제로 걸린다)
슬롯 주기      : 1.2초
장치 배출      : 슬롯당 6개 (부하에선 그 밑)
왕복 실측      : 1229 · 1225 · 1230ms — ACK 하나 돌아오는 데 약 1.2초
```

🔑 **왕복이 1.2초이고 배치가 창당 4건이면, 화면이 4~8건 이상 미확정으로 들고 있을 이유가 없다** —
**그 위는 전부 대기열에서 늙는 것**이다. **그 논리로 값을 유도해라.**
⚠ **감으로 정하지 마라.** 유도가 안 되면 **"유도 못 했고 이유는 이것"** 이라고 적어라.

## 🔴 그리고 문구가 고리를 만들지 않게 해라 — 네가 이미 지적한 것

**네가 `queue_full` 문구의 `"잠시 뒤 다시 눌러 주세요"` 를 걱정했다:**
> *"사용자가 이미 과하게 누르고 있는 상황이면 그 안내가 고리를 이을 수 있다."*

🔴 **이번 문턱은 그 상황을 정면으로 다룬다** — **막는 순간이 곧 "과하게 누르는 중"이다.**
**"다시 눌러라"가 아니라 "기다리면 자동으로 풀린다"** 는 언어가 맞다.
**그리고 남은 대기 건수나 해제 시점을 보여 주면 사용자가 안 누른다** — 아이들 1초에서
**남은 시간을 보여 준 것과 같은 원리**다(§5.16).

## ⚠ 배포

**socket 의 ②와 같은 배포여야 하는지 socket 과 직접 정해라.**
**둘 다 유입을 막는 것이라 하나만 올리면 효과가 반쪽일 수 있다.**
⚠ **다만 화면은 서버 재시작 없이 새로고침만으로 반영된다**(네가 확인했다) — **순서가 자유롭다.**

## 참고 — 진단이 하나 뒤집혔다

**monitor 판정**: 배치를 36B 로 줄였는데도 **`SEND OK` 가 8초를 넘겨 안 오는 구간이 분당 1회** 있다.
→ **`SEND OK` 지연은 배치 크기 때문이 아니었다.** **ESP 가 분당 한 번 8초 침묵하는 것이 진짜 원인이고
아직 정체를 모른다.**

🔴 **그러니 네 문턱이 끊김을 없앨 것으로 기대하지 마라.** **유입 제한 자체가 사용자 지시이고
별개로 값이 있다** — **사용자가 조용히 실패하는 대신 "지금은 못 받는다"를 보게 된다.**

## 왜 필요한가

화면 제한이 아이들 1초뿐이라 누적을 안 본다 — 1초 간격 30번이면 30건이 다 나가고 서버 큐 상한 16 은 한 번도 안 걸렸다. 사용자가 그 앞단을 막으라고 지시했다

## 완료 기준

① 미해결 건수 기준 문턱(아이들 1초는 유지) ② 조용히 막지 않고 이유를 말함 ③ 문구가 재클릭 고리를 잇지 않게(기다리면 풀린다 · 남은 건수/시점 표시) ④ 수치를 왕복 1.2초·배치 4건에서 유도(감 금지) ⑤ socket 과 배포 순서 직접 조율
