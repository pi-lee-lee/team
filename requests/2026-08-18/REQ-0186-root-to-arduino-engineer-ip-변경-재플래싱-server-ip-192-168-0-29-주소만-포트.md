# REQ-0186 · IP 변경 재플래싱 — SERVER_IP 192.168.0.29 (주소만) · 포트 이름도 바뀌었다 usbmodem1101

**요청자** `root` → **담당** `arduino-engineer`

## 요청 내용

🔴 **사용자 지시**: *"pc ip가 192.168.0.29로 변경되었다. 서버 ip 변경, 아두이노 재 플래싱,
서버 인스턴스 재기동이 필요하다."*

## 확인한 것 (루트 실측)

```
맥 현재 IP    192.168.0.29        ← ifconfig 실측
client.ino:97 SERVER_IP "192.168.35.81"   ← 낡았다
```

⚠ **서브넷이 바뀌었다**(`192.168.35.x` → `192.168.0.x`). 주소 한 자리가 아니라 망이 다르다 —
**AP 도 바뀌었을 가능성이 있다.** `WIFI_SSID "SK_WiFiGIGA50DC_2.4G"` 가 여전히 맞는지
**굽기 전에 사용자에게 확인하거나, 굽고 나서 `CWJAP` 실패로 드러나면 즉시 보고해라.**

## 할 것

1. **`SERVER_IP` 를 `192.168.0.29` 로.** 🔴 **앞뒤 공백 절대 금지** — 그 주석(§93~95)이
   경고하는 그 사고가 실제로 있었다(`" 192.168.35.21"`).
2. **다른 것은 아무것도 바꾸지 마라.** 지금 칩은 `slot4` 이고 **주소 한 줄만 다른 판**이어야 한다.
   계측 넷도, `cntTick` 슬롯 묶기도 넣지 마라 — **축이 늘어난다.**
3. **평소 순서 그대로**: 굽기 직전 통보 → monitor 정지 확인 → 굽기 → hex 대조 →
   **완료 통보(monitor·루트 양쪽)**.
4. **`INTERVENTIONS.md` 사전 기록**에 *"주소 변경만, 거동 변경 없음"* 을 명시해라.

## ⚠ 관측 상태 — 탭이 이미 죽어 있다

```
07:22:37  «tap» 포트 복구 실패 6회 (SerialException: could not open port)
```

**창 C 는 그 시각에 끝났다.** 즉 **지금 관측이 안 돌고 있으니 굽기 전에 내릴 것이 없다.**
다만 monitor 에게 통보는 해라 — **창 D 를 새 `t0` 로 여는 것이 그쪽 일이다.**

🔴 **포트가 사라진 이유를 굽기 전에 확인해라**: USB 가 뽑혔거나 보드 전원이 나갔을 수 있다.
 **안 보이면 굽기 전에 보고해라** —
사용자가 실물을 만졌을 수 있고 그러면 **그것도 기록해야 할 개입**이다.

## 창 C 결과 — 네 ①이 파괴를 다 없애지는 못했다

```
01:19 주입 전   oow=0    ssovf=0   cksumng=0
01:34 주입 후   oow=304  ssovf=4   cksumng=4     ← inj7 300건 · 주입 구간에서만 증가
```

🔴 **socket 의 예측 1번(`cksumng → 0`)이 빗나갔다.** ①(`sendAck` 슬롯 묶기)만으로는 파괴가 안 없어진다.
**→ `[CNT]` 가 독립 원인일 가능성이 올라간다** — 네가 예상한 그 갈래다(*"①을 고친 뒤에도 파괴가
남으면 `[CNT]` 가 독립 원인임이 확정되고 그 사건은 60초 주기라 깔끔하게 보인다"*).

**판정은 monitor 가 한다. 결론을 먼저 내지 마라.** 다만 **다음 굽기(② `cntTick` 슬롯 묶기)의
근거가 강해졌다**는 것은 기록해 둘 값이 있다.

## 왜 필요한가

사용자가 PC IP 를 192.168.0.29 로 바꿨고 서브넷까지 달라졌다 — 펌웨어에 박힌 192.168.35.81 로는 서버에 못 붙는다. 그리고 USB 재연결로 포트 이름이 usbmodem21201 에서 usbmodem1101 로 바뀌어 탭이 07:22 에 죽었다

**계측 넷도 `cntTick` 슬롯 묶기도 안 넣었다** — 창 C 대비 거동은 `slot4` 와 동일하다.

### 🔴 굽기 전 세 겹 검증 — §93~95 의 앞공백 사고를 막는 절차

| 검증 | 결과 |
|---|---|
| `diff` 대비 `slot4` | **정확히 3줄** |
| `od` 바이트 | 따옴표 안 앞뒤 공백 **없음** · `!!` **둘 다 온전** |
| **`strings` ELF** | `AT+CWJAP="3F_302","0424719222!!"` · `AT+CIPSTART="TCP","192.168.0.29",9991` |

⚠ **`!` 는 셸 히스토리 확장 문자라 `sed`/셸을 거치지 않고 편집 도구로 직접 썼다.**
★ **`slot4` 소스를 `.burn/slot4/client.ino.SOURCE` 로 보존**했다 — 그 hex 의 근거가 사라지지 않게.

### 🔴 굽고 나서 한 번 막혔다 — 그리고 그것이 자격증명이 아니었다

굽기 직후 `CWJAP` 가 **무응답**이었다. monitor 관측: **`[AT]` 0줄 · `rx=0 lines=0`**.
> **ESP 가 한 바이트도 안 보냈다. 비밀번호가 틀렸으면 `FAIL`/`ERROR` 라도 온다.**
> **→ 자격증명 가설이 배제됐고, 재굽기가 낭비임이 확정됐다.**

**소프트웨어 경로가 없음도 소스로 확정**: `ESP_RST_WIRED 0`(`client.ino:781`) —
2026-08-15 에 리셋선을 의도적으로 분리했으므로 **사다리 4단(하드리셋)은 구조적으로 못 간다.**
→ **실물 조작으로만 풀리는 상태**였고, 사용자 조치 뒤 09:33 에 복구됐다.

⚠ **그 실물 조치의 내용이 기록되지 않았다** — 루트에 질의했다(아래 미결).

### 포트 이름 변경

`/dev/cu.usbmodem21201` → **`/dev/cu.usbmodem1101`**. USB 재연결로 macOS 가 다른 이름을 줬고,
**monitor 의 탭이 `07:22:37` 에 죽은 원인**이 이것이다. 내 문서의 하드코딩 자리는 별도 정리한다.
