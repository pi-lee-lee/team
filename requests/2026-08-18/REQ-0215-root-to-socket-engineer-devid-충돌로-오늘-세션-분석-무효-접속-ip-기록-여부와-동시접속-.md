# REQ-0215 · 🔴 devid 충돌로 오늘 세션 분석 무효 — 접속 IP 기록 여부와 동시접속 감지를 답하라

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

🔴 **사용자 확정: 같은 망에서 조원들이 동일 카피 보드를 돌리고 있었다. 오늘 장치 판정을 무효로 한다.**

> *"**특정할 수 없다. 해당 이슈는 모두 다른 사람 접속으로 처리하라.** 지금 네트워크에 동일 조원들이 테스트 중이었다."*

## 🔴 이것이 네 `first-S-wins` 규칙에 정확히 꽂힌다

네가 서버에 적어 둔 문장이다:

> *"전선에는 '내가 주차 노드다'라고 말하는 필드가 없다. 그래서 첫 `S` 를 보낸 장치가 그 서버 수명 동안
> 주차 노드다. **두 번째 장치가 `S` 를 보내면 충돌로 로그에 크게 남기고 하행을 주지 않는다.**"*

**그 방어가 devid 로 판정한다. 그런데 두 보드가 똑같이 `P1` 이다.**

```
→ 서버는 둘을 같은 장치로 본다 → 🔴 충돌 로그 0건 (확인함)
→ 세션 #10~#17 · "재부팅감지 17" 이 전부 이것으로 설명될 수 있다
→ 우리 시리얼 탭은 한 보드만 본다 → 서버 로그와 시리얼이 다른 장치를 보고 있었다
```

🔑 **네 방어가 실패한 게 아니다 — 전제(devid 가 고유하다)가 깨졌다.**
**너는 "필드가 없다"를 알고 그 자리에 규칙을 세웠는데, devid 자체가 고유하지 않을 줄은
설계가 가정하지 않았다.**

## 무효 처리 — 네 57세션 분석이 여기 걸린다

```
❌ 무효 : "FIN/RST 25 대 무신호 28 — 고장이 두 종류다"
          🔴 **장치가 둘이었으면 당연하다.** 두 고장이 아니라 두 장치일 수 있다
❌ 무효 : 세션 최대공백 8.3s×9 / 8.4s×7 클러스터 (어느 장치의 것인지 모른다)
❌ 무효 : 사용자 연타 검증 (어느 보드가 응답했는지 모른다)
✅ 유효 : CIPSEND 규약 21,971건 (프레임 형식은 장치가 섞여도 성립)
✅ 유효 : selftest 결과 (외부 장치 무관)
✅ 유효 : 소스 판독 · ACK_TIMEOUT 유도식 · 문턱 구현
```

**⚠ 지우지 마라. "다중 장치 오염으로 무효" 라고 사유와 함께 남긴다.**

## 🔴 지금 답해야 할 것 — 관측 재개의 전제다

### ① **서버가 접속 IP·포트를 남기는가**

**남으면 이 문제가 즉시 갈린다** — 두 보드는 IP 가 다르다.
```
· 남는다  → 세션별 IP 를 세어라. 오늘 자료를 사후에 갈라낼 수 있는가?
            (갈라낼 수 있으면 무효 범위가 줄어든다 — 그것만으로 큰 회수다)
· 안 남는다 → 🔴 즉시 추가해라. 이것 없이는 다음 관측도 같은 함정에 빠진다
```

### ② **같은 devid 동시 접속을 감지해 경고할 수 있는가**

`first-S-wins` 를 **devid 가 아니라 소켓 기준**으로 바꾸면:
```
· 이미 주차 노드 소켓이 살아 있는데 다른 소켓에서 같은 devid 의 S 가 오면
  → 🔴 충돌 로그 + 하행 차단 (지금 규칙이 의도한 그대로)
```
⚠ **다만 재접속과 구별해야 한다** — 진짜 재부팅도 새 소켓으로 온다.
**기존 소켓이 아직 살아 있는가**가 판별점일 것이다. **네 판단을 달라.**

### ③ 이것이 설계에 주는 함의

**`devid` 전역 고유 · `(devid, name)` 복합 키**는 이미 설계 개정 항목이었다.
🔴 **그런데 우리는 그것을 "기능 요건"으로만 알고 있었다. 실제로는 관측 요건이다** —
**devid 가 충돌하면 무엇을 고쳐도 검증이 안 된다.** 오늘이 그 증명이다.
**이 문장을 네 설계 명세에 넣어라.**

## 🔴 하지 말 것

```
· 새 배포·굽기 금지 — 관측 기반이 없다 (①②는 코드 작성까지만, 배포는 루트 승인 후)
· 오늘 자료로 새 결론 만들지 마라
· 세 층 수정(화면 cmdPending · ACK 큐 · 하행 문턱)은 되돌리지 마라
  → 셋 다 **소스로 확인된 실제 결함**이었다. 무효인 것은 "그것이 증상을 고쳤는가"이지
    "그것이 결함이었는가"가 아니다
```

## 왜 필요한가

first-S-wins 가 devid 로 판정하는데 조원들의 동일 카피가 모두 device=P1 이라 서버가 구분하지 못한다 — 충돌 로그 0건이 그 증거다. IP 가 로그에 남으면 오늘 자료를 사후에 갈라낼 수 있고, 안 남으면 다음 관측도 같은 함정에 빠진다
