# REQ-0225 · 🔴 설계 재개 — 전선 명세 확정(D 배출률 · S hex 인코딩) + 확장 구조 이름을 먼저 박아라

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

🔴 **측정이 끝났다. 설계·구현을 재개한다. 네가 사슬의 머리다.**

사용자가 8/18 오전에 세워 뒀던 *"설계를 멈춰라, 측정을 완전히 마무리해라"* 가 풀렸다.
창 I 로 재검증까지 닫혔다(`>=64B` 1,067 거래 → T2 0건).

## 순서 — **네가 먼저다. 3·4 는 네 이름을 참조한다**

```
① socket : 전선 명세 확정 (이 REQ)          ← 지금
② socket : 노드별 리팩터링 (REQ-0203)        ← ① 뒤, 단독 배포
③ arduino·web : ①이 확정되면 그것을 참조해 병행
④ 통합 검증
```

🔴 **반대로 하면 명세가 코드를 따라가고, 같은 개념에 세 도메인이 다른 이름을 붙인다.**
**8/18 에 이미 그럴 뻔했고 web 이 `docs/net/` 을 grep 해서 막았다.** 이번엔 순서로 막는다.

# ① 확정할 것 — **네가 REQ-0203 선행 조건으로 스스로 건 둘**

```
1. 등록 `D` 프레임의 **배출률 선언**
2. `S` 비트열 **hex 인코딩 명세** — 대소문자 · 고정폭 · 비트순서 · 패딩 0 검증
```
**네가 "먼저 확정하고 코드를 만져야 한다. 반대로 하면 명세가 코드를 따라간다"고 적은 그대로다.**

# ② 그리고 확장 구조의 **이름**을 여기서 박아라

사용자 요구(8/18): **주차구역 5개 · 입구/출구 · 격자 지도 · 모듈이 구역에 붙는다 ·
🔴 모듈이 여러 아두이노에 흩어진다(1보드 = 1구역이 아니다)**.

**확정된 것:**
```
✅ 자리 : 격자칸 = **1 : 1** (사용자 2026-08-18)
   🔮 나중에 큰 자리가 여러 칸을 차지할 수 있다 — **구조가 막지만 마라. 지금 만들지는 마라**
   🔑 좌표를 (row,col) 한 쌍으로 두고 **자리 식별자와 칸 좌표를 분리**해 두면 나중에 안 깨진다
✅ devid 전역 고유 · (devid, name) 복합 키 — **기능 요건이 아니라 관측 요건이다**
   오늘 그 증명을 치렀다. 명세 맨 앞에 이 문장을 둬라
✅ 모듈 ID 는 고유값이 아니라 **명칭**이다 (사용자 확정)
✅ 격자 5x5 · 입구/출구 가장자리 — **기본값이고 설정 파일로 바뀐다.** 구조가 여기 묶이면 안 된다
```

**정할 것:**
```
· 노드 · 구역(zone) · 모듈 · 자리 · 칸 의 이름과 관계 (무엇이 무엇을 소유하나)
· 🔴 **계산 주체** — 파생값을 누가 계산해 누구에게 주나
  ⚠ 이걸 비우면 받는 쪽이 자기가 계산하게 되고 **같은 규칙이 두 곳에 생긴다.**
    두 구현이 갈리면 어느 쪽이 맞는지 알 수 없고 **관대한 쪽이 이기면 위험한 동작이 통과한다**
  🔑 `ack_budget_ms` 를 서버가 상수에서 계산해 내려보낸 것이 옳은 형태다
· 모듈이 여러 아두이노에 흩어질 때 **조작 가능성 판정** — 누가 계산하나
```

# 🔴 하지 말 것

```
· 배포하지 마라 — ①은 문서다. ②(REQ-0203)도 코드까지만, 배포는 별도 승인
· 지금 N:1(자리가 여러 칸) 을 구현하지 마라 — **쓰이지 않는 일반화는 검증되지 않은 코드다**
· 결론 문장에 **근거의 범위**를 적어라 — 종속(n·창·계측기·방향)이 결론까지 미치는지도
```

**①이 끝나면 루트에 알려라. 그때 arduino·web 에 착수를 건다.**

## 왜 필요한가

측정이 창 I 로 닫혔고 설계 확장이 재개된다. arduino·web 이 참조할 이름과 전선 명세를 서버가 먼저 정해야 한다 — 반대로 하면 명세가 코드를 따라가고 같은 개념에 세 도메인이 다른 이름을 붙인다

## 완료 기준

① D 프레임 배출률 선언과 S 비트열 hex 인코딩 명세 확정 ② 노드·구역·모듈·자리·칸의 이름과 관계 확정 ③ 파생값마다 계산 주체 명시 ④ devid 고유성이 관측 요건이라는 문장을 맨 앞에 ⑤ 자리:칸=1:1 이되 구조가 N:1 확장을 막지 않을 것(지금 구현은 금지) ⑥ 배포 금지 ⑦ 완료 시 루트 통보
