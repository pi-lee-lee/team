**확정된 것:**
```
✅ 자리 : 격자칸 = **1 : 1** (사용자 2026-08-18)
   🔮 나중에 큰 자리가 여러 칸을 차지할 수 있다 — **구조가 막지만 마라. 지금 만들지는 마라**
   🔑 좌표를 (row,col) 한 쌍으로 두고 **자리 식별자와 칸 좌표를 분리**해 두면 나중에 안 깨진다
✅ devid 전역 고유 · (devid, name) 복합 키 — **기능 요건이 아니라 관측 요건이다**

```

· 🔴 **계산 주체** — 파생값을 누가 계산해 누구에게 주나

    두 구현이 갈리면 어느 쪽이 맞는지 알 수 없고 **관대한 쪽이 이기면 위험한 동작이 통과한다**

## 처리 결과 (socket-engineer · 2026-08-18) — ✅ **①②③④⑤ 완료 · 배포 없음**

**문서**: `docs/net/DESIGN-bridge-node-module-zone.md` · 커밋 `9625e27`. **코드 변경 0 · 배포 0.**

### ④ `devid` 고유성을 **명세 맨 앞(§-1)** 에 올렸다

> **`devid` 가 충돌하면 무엇을 고쳐도 검증이 안 된다.**

🔑 그리고 그날 **회수한 것이 전선의 식별자가 아니었다는 사실**을 같이 적었다 — 회수는
**장치가 스스로 세는 `uptime`** 과 **커널이 주는 IP** 가 했다. → 명세는 셋을 다 요구한다:
`devid` 고유 · `(devid, name)` 복합 키 · **접속 IP 기록**. **하나라도 빠지면 사후 판별이 안 된다.**

### ② 이름과 관계 — **`자리`와 `칸`을 갈랐다**

```
노드   통신 단위(ESP 하나 = 소켓 하나 = 자기 1.2초 주기)
자리   주소를 갖는 장소(주차 자리·입구·출구) — **신원**
칸     격자 좌표 (row, col) 그 자체 — **기하**. 자리가 옮겨 가도 칸은 그 자리에 있다
모듈   노드에 달린 장치 하나. 신원은 **(devid, name)**. `name` 은 **명칭이지 고유값이 아니다**
```
**소유 관계**: `Node → modules` · `Zone → cells[] · modules[(devid,name)]`.
🔴 **`zone.modules` 를 `[name]` 으로 적으면 안 된다** — 어느 장치인지 사라져 보낼 곳을 모른다.

### ⑤ 자리 : 칸 = **1 : 1**, 구조는 N:1 을 막지 않는다 — **그러나 지금 구현하지 않는다**

`cells` 를 **목록**으로 두되 **길이 1 을 코드가 강제하고 위반 시 거절+로그**한다.
> **목록으로 두는 것과 아무 길이나 받는 것은 다르다.** 후자는 **검증되지 않은 경로를 여는 것**이다.
🔑 좌표를 필드에 하나 박으면 나중에 **자료형이 바뀌어 읽는 모든 곳이 같이 바뀐다.** 목록이면 **길이 제한만 푼다.**
⚠ 격자 `5×5`·입구/출구 가장자리는 **기본값**이다 — **코드에 `5` 를 박지 않고 설정에서 읽는다.**

### ① 전선 명세 둘 — 확정

**(가) `D` 가 그 노드의 배출률을 선언한다.**
서버가 `D = (BATCH_CAP − S_worst − 1) ÷ (ACK_worst + 1)` 를 들고 있으면 **장치 값의 사본**이 되어
`BATCH_CAP` 이 바뀔 때 **두 곳이 갈린다.** → **장치가 값으로 선언, 서버는 유도식(`N ≤ 2D/3`)에만 넣는다.**
🔴 **선언값은 설계 보장 하한이지 관측 최대가 아니다**(실측 `8` 은 조건부였고 보장은 `6` 이었다).
⚠ **형식(어느 줄에 싣나)은 arduino 최종 합의가 남았다. 의미는 확정.**
⚠ 이행 중에는 **전제 감시**로 버틴다(`S` 실측 > 가정치면 경고 · 커밋 `97585c2` 미배포).
**감시는 한 방향이다 — "위험해졌다"만 잡고 "여유가 생겼다"는 안 잡는다.**

**(나) `S` 비트열 hex 인코딩 — 넷을 못 박았다.**
```
① 대문자만(0-9A-F)   ② ceil(n/4) 고정폭 + 왼쪽 0 채움
③ 슬롯 i = 비트 (n−1−i)   ④ 남는 상위 비트는 0 이고 **받는 쪽이 검증**한다
```
🔴 **③④ 가 본체다 — 둘 다 길이도 체크섬도 통과하고 값만 틀리는 부류다.**
10진 1칸=1비트는 순서가 눈에 보여 이 함정이 없었다 — **압축과 함께 들어오는 위험**이다.
왕복 예제를 명세에 박았고 **`0000…`·`1111…` 만으로는 ③을 검증할 수 없다**(뒤집혀도 같다)고 명시했다.
**비대칭 패턴이 순서를 검증하는 유일한 것**이고, **패딩 위반 예제(`58B`)도 넣었다.**

### ③ 계산 주체 표 (§6.9) — **파생값 9개에 주체를 박았다**

**원칙 한 줄: 파생값은 원본을 가진 쪽이 계산해서 값으로 내려보낸다.**
그중 REQ 가 물은 것: **모듈이 여러 노드에 흩어질 때의 조작 가능성 → 🔴 서버가 자리 단위로 계산해 값으로 준다.**
화면이 "모듈 목록 + 노드 생사"로 **조합하지 않는다** — 조합 규칙이 화면에도 생기면 두 답이 갈리고
**관대한 쪽이 이기면 죽은 노드에 명령이 나간다.**
🔑 **판정과 설명을 갈랐다**: 판정은 하나여야 하고 설명(어느 모듈이 왜 막혔나)은 여러 개여도 된다.
⚠ **표에 없는 파생값이 생기면 표에 줄을 먼저 넣어라. "화면이 계산하는 게 편한데"가 나오는 순간이
규칙이 두 곳에 생기는 자리다 — 편의는 근거가 아니다.**

### ⚠ 범위 — 결론에 붙인다

- **`D` 형식은 열려 있다**(의미만 확정). arduino 합의 전에는 **`drain` 미선언 시 보수적 기본값 + 로그**로 간다.
- **hex 전환은 프로토콜 변경**이라 socket·arduino·web·monitor 가 **같이 움직여야 한다.** 단독 배포 불가.
- **N:1 은 구조만 열어 뒀고 검증된 경로가 아니다.** 지금 그것을 쓰는 코드를 만들면 **미검증 경로가 운영에 들어간다.**
- 이 문서는 **설계 확정**이고 **거동을 바꾸지 않았다.** 배포 대상이 아니다.
