# REQ-0306 · 차단봉을 없앤다 — lot.cpp 의 DR 선언 제거 (사용자 지시)

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

사용자 지시: **"차단봉은 없애라"**

## 지금 상태 — 루트가 값으로 정리했다

```
서버 lot.cpp : lot.spot("E1").label("입구").module("P1","DR")
               lot.spot("E2").label("출구").module("P3","DR")
               🔴 **`DR` 은 어느 장치 표에도 없다.** 영원히 안 붙는다
장치         : {"E1","OB",PIN_NONE} · {"X1","OB",PIN_NONE}  ← **가상**. `VIRTUAL_MODULES` 로 켠다
               지금 **꺼져 있다** · 주석: *"실물 없이 명령 사슬을 밟아 보려면 1 로 켠다"*
로그 흔적    : `D,E1,OBV` · `D,X1,OB` — 켜진 판에서 실제로 붙었던 적이 있다
🔴 이름 충돌 : 자리 `E1`(입구) 과 장치 모듈 `E1`(가상 차단봉) 이 **같은 이름**이다
```

## 할 것 — 네 도메인 몫

```
✅ lot.cpp 의 `.module("P1","DR")` · `.module("P3","DR")` 두 줄 제거
   → 🔑 `E1`(입구)·`E2`(출구) 자리 자체는 **남긴다.** 일반영역이고 격자에 필요하다
   → 모듈이 없으므로 `active:{ok:false, reason:"no_modules"}` 가 실린다
     ⚠ **그게 맞는 값이다** — 일반영역이라 `parking()` 이 없고 점유 판정 대상이 아니다
     🔴 **화면이 그것을 어떻게 그리는지 확인해라** — 주차 자리의 "비활성 회색"과 같게 그리면
        입구·출구가 고장처럼 보인다. 갈려야 하면 web 에게 값을 붙여 넘겨라
✅ `choice` API 는 **남긴다** — 공개 API 이고 기여자가 쓸 수 있다
   ⚠ 다만 **샘플에서 그것을 보여 주는 자리가 없어진다.** 그 사실을 명세에 적어라
     (예시를 무엇으로 만들지는 주석·예제 작업에서 정한다)
✅ 차단봉 특례가 서버 코드에 있으면 같이 걷어라 — `seam.h:127` 의 `"차단봉을 열었습니다"` 등
   🔑 그 문구는 `p.kind == 'G'`(하행 프레임 타입)로 갈리고 **모듈 종류와 무관**하다.
     지우기 전에 그 갈래가 다른 명령에도 쓰이는지 확인해라
```

## 범위
```
✅ 조별과제샘플/server/** · docs/net/** (명세)
❌ 장치 — arduino 가 컴포넌트 작업에 합쳐서 한다(같은 파일을 두 번 안 만진다)
❌ 화면 — 값이 필요하면 web 에게 REQ 로 넘겨라
❌ 관측 · 판정 문서
```
배포 직전 한 줄을 monitor 와 루트에게. **화면 배포가 필요하면 내가 한다.**

## 왜 필요한가

DR 은 어느 장치 표에도 없어 영원히 안 붙는다. 실물 차단봉이 없고 사용자가 요구를 없앴다. 선언만 남으면 다음 사람이 그것을 정답으로 베낀다

## 대상 파일

- `조별과제샘플/server/lot.cpp`
## 완료 기준

lot.cpp 에 DR 선언이 없다. E1·E2 자리는 남아 있고 화면에서 입구·출구가 고장처럼 보이지 않는다. choice API 는 유지되고 샘플 예시가 없어진 사실이 명세에 적혀 있다

#### ① 한 것 — `lot.cpp`
`E1` 의 `.module("P1","DR")` 제거. **자리 `E1` 은 남겼다**(일반영역 · 격자에 필요).
```

```

#### ② 🔴 확인사항 ②의 답 — **그 갈래는 다른 명령에도 쓰이고, 지금 거짓말을 하고 있었다**
```
seam.h  else if (kind=='G') m = (top=='1') ? "차단봉을 열었습니다" : "차단봉을 닫았습니다";

`G` 는 **모든 모듈 명령**의 하행 타입이다 — 차단봉 전용이 아니다
🔴 그런데 send_to_module() 은 **p.top 을 안 세운다** → 항상 0 →
   화면에서 LD 토글·L2 숫자를 눌러도 ACK 문구가 **"차단봉을 닫았습니다"** 로 나갔다
```
→ **`"장치가 명령을 수행했습니다"`** 로 바꿨다. 🔑 **값의 뜻은 기여자가 정한다**(제1계약).
   서버가 모르는 것을 이름 붙이면 반드시 틀리고, **그 틀림이 사용자에게 문장으로 보인다.**
→ **`top` 인자를 없앴다**(`seam.h` 시그니처 + `uplink.h` 호출부). 읽는 곳이 여기뿐이었다.
   **세우지 않는 값을 읽는 코드가 이 결함의 기전이었다** — 원천을 고쳤지 방어를 덧대지 않았다.
⚠ **사용자가 그 문장을 봤을 수 있다**(화면에서 LD 를 눌렀다). `ack.message` 표시 여부는 **web 만 안다** — 루트가 확인시킨다.

#### ③ `wsapi.h` — `open_gate` 거절 문구에서 차단봉 중심 표현 제거(안내는 유지)

#### ④ `choice` 는 남겼고, **예시가 없어진 사실을 명세에 박았다**
`docs/net/SPEC-web-control.md` 머리에 표시. 🔑 **예시 없는 공개 API 는 없는 것과 같다.**
기여자 가이드의 DR 예시는 **가상이라고 명시**하고 남겼다(devid `KIM01`) —
지우면 `choice`·명령표를 가르칠 자리가 통째로 없어진다.
