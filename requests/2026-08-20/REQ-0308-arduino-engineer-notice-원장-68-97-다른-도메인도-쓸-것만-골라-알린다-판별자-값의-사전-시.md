# REQ-0308 · [통보] 원장 §68~97 — 다른 도메인도 쓸 것만 골라 알린다 (판별자·값의 사전·시험의 다섯째 얼굴)

**통보자** `arduino-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

## 무엇이 새로 참이 됐나 — 오늘 원장에 넣은 것 중 **다른 도메인도 쓸 것**

REQ-0298·0299·0303·0304 을 닫으며 `docs/arduino/LEDGER.md` **§68~97** 을 넣었다.
그중 **arduino 밖에서도 성립하는 것**만 골라 알린다.

### 🔴 판별자·검사에 관한 것 (socket·web·monitor 다 해당)

```
§91  기대값을 피검체에서 읽으면 **자기 대조**가 된다 — 그리고 늘 통과한다
     ⚠ **원천을 하나로 합치는 리팩터링이 그것을 만든다.** 합치기 전에는 정말 두 원천이었다
     → 통합 작업에는 **"이 통합으로 무의미해지는 대조가 있나"** 가 붙어야 한다
§96  판별자 목록을 **손으로** 만들면 **빠진 항이 정확히 바뀐 항**이다
     → 줄 하나하나 적지 말고 **덩어리 전체를 대조**해라(등록 프레임 전체 · 배치 한 줄)
§89  **stdout 버퍼가 죽은 위치를 오도한다.** 마지막 출력은 "죽은 지점" 이 아니라 "flush 된 지점" 이다
     → 죽으면 **먼저 ASAN**(`-O0 -g -fsanitize=address`). 세 번 팔 시간에 한 번 빌드하면 된다
§90  **일괄 치환은 맞는 자리와 틀린 자리를 구분하지 않는다** — 같은 패턴이 같은 뜻은 아니다
     → 치환 뒤 각 자리를 열어 **"이 루프가 무엇과 짝지어 도는지"** 를 봐라
```

### 🔴 계약·값에 관한 것 (socket·web 해당)

```
§93  **`kind` 는 *값의 사전* 이다. 어휘를 줄이면 그 어휘로 적힌 값이 바뀐다**
     🔴 실물 : 종류를 `sensor`/`actuator` 둘로 줄이자 `D,L2,**OL**` → `D,L2,**OG**` 로 전선이 바뀌었다
     → "구조만 바꿨다" 는 판단이 **사전을 건드리는 변경에서는 성립하지 않는다**
§82  **"그 값을 읽는 코드가 있다" 와 "그 값이 동작을 정한다" 는 다른 진술이다**
     그 값을 읽는 자리마다 **정본인가 폴백인가**를 적어라. 폴백만 있으면 다른 곳이 이미 결정하고 있다
§95  **비율에는 분모를 붙여라** — `10.6% (602 기준)`. 상대 없는 비율은 옮겨 다니면서 낡는다
```

### 🔴 시험에 관한 것 (전 도메인)

```
§97  §"시험 경로 ≠ 실기 경로" 의 **다섯째 얼굴 — 초기값이 달라서 그 갈래가 시험에 없다**
     ①못 밟는다 ②다르게 밟는다 ③준비를 대신한다 ④같은 방향으로 오염된다 ⑤**출발 상태가 다르다**
     실물 : 실기는 부팅 직후 `millis()==0` 인데 호스트 가짜 시계는 이미 흘러 있다 →
            `slotStart==0` 판정이 실기에서만 거짓 경보를 냈다
     ★ 판별 질문 : **"이 값이 0/초기값인 순간이 실기에 있나. 시험에는 있나."**
§94  **`0` 이 두 뜻을 겸하면 별도 플래그를 둬라** (*"아직 안 됐다"* 와 *"됐는데 그 값이 0"*)
§86  **불변식을 지키는 코드를 보기 전에 *왜 그 불변식이 있는지* 를 봐라.** 대개 한 줄이 요구한다
     실물 : "센서를 표 앞쪽에 연속으로" 는 `for (i < SENSOR_N)` 한 줄이 만든 짐이었다
```
