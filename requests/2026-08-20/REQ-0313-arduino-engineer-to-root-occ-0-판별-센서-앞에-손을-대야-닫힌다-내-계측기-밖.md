# REQ-0313 · 🔴 occ=0 판별 — 센서 앞에 손을 대야 닫힌다 (내 계측기 밖)

**요청자** `arduino-engineer` → **담당** `root`

## 요청 내용

## 무엇이 안 닫혔나

18:43:58 굽기(`414a8a6`)로 초음파 샘플(HC-SR04 · Trig 2 · Echo 4)이 켜졌다.
코드 경로는 산다 — 부팅 로그가 `[SENS] A1=함수있음` 이고 등록도 정상이다(`[REG] 54B`).

**그런데 `S` 프레임의 `occ` 필드가 전부 `0` 이다:**

```
S,0,0,0,10,P1,03
S,2,0,0,13,P1,02
S,3,0,0,14,P1,04      ← 필드 2(occ) 가 계속 0
```

## 🔴 이 `0` 은 두 가지를 구분하지 못한다

```
㉠ 센서 앞 60cm 안에 아무것도 없다  →  **정상 동작이다**
㉡ 센서가 안 읽힌다                 →  결함
```

**내 계측기로는 이 둘을 가를 수 없다.** 물체를 놓는 것은 물리 개입이고,
`T` 프레임 주입으로도 못 닫는다 — 오버라이드가 센서 경로를 건너뛰기 때문이다.

## 🔑 가르는 방법 — 한 동작이면 된다

**센서 앞 60cm 안에 손(또는 판)을 대고 화면이나 시리얼을 본다.**

```
바뀐다  : occ 가 0 → 8   →  ㉠ 이다. 지금 로그가 정상이고 이 축은 닫힌다
안 바뀐다 :               →  ㉡ 이다. 그때 내가 배선·타이밍을 판다
```

**근거(값)**: 지금 구성은 모듈 4개(A1 B1 LD L2)이므로 `n=4`.
A1 은 인덱스 0 → `occ` 비트 (4−1−0) = 3 → `0x8`. hex 폭 1자리이므로 `8` 로 보인다.

문턱은 `US_NEAR_CM = 60`(cm)이고 타임아웃이 그것에서 유도된다(6,960µs).
**60cm 보다 먼 것은 설계상 "비었다"로 읽는다** — 그래서 빈 방에서는 `0` 이 정상이다.

## 왜 내가 못 하나

```
센서 앞에 물체를 놓는 것 = 물리 개입 → 내 도구 밖이다
그리고 관측하려면 시리얼 탭이 필요한데 그것은 배타적 자원이다
```

monitor 도 같은 판정을 냈다: *"①은 사람이 손을 대야 닫히므로 루트나 사용자에게
올려야 할 축이다 — 내가 못 닫는다."*

## 지금 상태 — 이 축을 뺀 나머지는 값으로 서 있다

```
✅ hex     : 빌드가 쓴 27,462B 기준 0 = IDENTICAL (음성대조 확인)
✅ 표지 넷 : [SENS] 문구 변경 · 배너 불변 · [REG] 54B 불변 · [CFG] 0건(D7)
✅ 예산    : slot=50 / up=60 → 블로킹이 슬롯을 안 깼다
✅ 버퍼    : ssovf=0 (pendfill=42 가 하행이 왔다는 증거라 '못 셈' 이 아니다)
✅ RAM     : 539B (537B 대비 +2B · 정적 -2B 예측과 일치)
✅ 전선    : 등록 프레임 전체 바이트 대조 cmp 0
🔴 이 축   : occ 가 실제 물체에 반응하는가 — **미계측**
```

## 완료 판정을 어떻게 적을 것인가

`0 → 8` 이 확인되면 **초음파 샘플이 실물로 동작한다**가 값으로 선다.
확인이 안 되면 그것도 값이다 — 그때 내가 팔 자리가 정해진다(배선 · pulseIn 반환 · 문턱).

⚠ **어느 쪽이든 "미계측"으로 남기는 것보다 낫다.** 지금은 정상인지 고장인지 모르는 상태이고,
그 상태에서 다음 굽기를 하면 이 축이 그 창으로 넘어간다.

## 왜 필요한가

초음파 샘플이 켜졌는데 occ 가 전부 0 이다. 이 0 은 '빈 자리'(정상)와 '안 읽힘'(결함)을 구분하지 못한다. 물체를 놓는 것은 물리 개입이고 T 주입으로도 못 닫는다(오버라이드가 센서 경로를 건너뛴다). 이 상태로 다음 굽기를 하면 이 축이 그 창으로 넘어간다.

## 대상 파일

- `조별과제샘플/ardu/client.ino`
## 완료 기준

센서 앞 60cm 안에 손을 대고 occ 가 0 → 8 로 바뀌는지 확인한다. 바뀌면 ㉠(정상)으로 이 축이 닫힌다. 안 바뀌면 ㉡(결함)이고 그때 내가 배선·pulseIn 반환·문턱을 판다. 어느 쪽이든 '미계측'보다 낫다.
