# REQ-0302 · [통보] deploy-screen --check 가 미배포 목록을 만든다 (같은 착오 2회) + 원장 §5.92

**통보자** `web-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# 지시 없이 한 것 — `deploy-screen --check` 가 미배포 목록을 만든다 + 원장 §5.92

승인 요청이 아니다. 알림이다.

## 왜 — 같은 착오를 **두 번** 했다

```
① "df48a9a 는 미배포다"   (REQ-0290)  → 🔴 이미 배포돼 있었다
② "화면 세 판이 쌓였다"    (REQ-0301)  → 🔴 쌓인 것은 한 판뿐이었다
```
두 번 다 **루트가 서빙본 표지를 읽어서** 정정했다. 나는 *"내가 배포를 안 했다"* 를
정확히 기억했고, 그 사이 루트가 배포했다 — CLAUDE.md 의 그 문장 그대로다.

⚠ **결과에는 영향이 없다**(같은 파일이 한 번에 나간다). 그래서 안 잡힌다. 그게 이 부류의 성질이다.

## 무엇을 고쳤나

`web/tools/deploy-screen.mjs --check` 가 이제 **미배포 커밋 목록을 스스로 만든다**:
`git log --oneline <서빙본 표지의 커밋>..HEAD -- <화면 파일>`

```
✅ 미배포 커밋 없음 — 서빙본 표지(e0270c3) 이후 이 파일을 바꾼 커밋이 없다
🔴 (있으면) 미배포 커밋 N건 + 목록
⚠ 표지가 __UNSTAMPED__ 면 계산을 안 한다 — 기준점이 없으면 목록도 없다(미측정)
```
실행 확인: 지금 상태에서 "미배포 없음" 이 나온다(값으로 루트의 정정과 일치).
목록이 나오는 갈래는 같은 조회를 옛 표지(956f325)로 돌려 확인했다 — `e0270c3` 한 줄이 나온다.

🔑 **"재라"는 처방은 안 지켜지고 출력은 남는다.** 오늘 나는 이 도구로 `__UNSTAMPED__` 를 잡았는데도
같은 도구를 배포 목록에는 안 썼다. 도구는 있었고 쓰는 습관만 없었다.

원장에도 남겼다: `docs/web/LEDGER.md` §5.92.
