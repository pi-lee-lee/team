# REQ-0297 · 격자 칸에 label 만 — 요약·배지·사유 문구를 패널로 옮긴다 (사용자 지시)

**요청자** `root` → **담당** `web-engineer`

## 요청 내용

사용자 지시(실물 화면 확인 뒤):
> *"박스에 **라벨이 너무 많다. label만 출력**되도록 개선하라."*

## 할 것

**격자 칸에는 `label` 만 그린다.**

```
칸에 남는 것 : `label` 하나. **없으면 자리 id 로 떨어진다**
칸에서 빼는 것 : 요약 문구 · 모듈 수 배지 · id 중복 표기
              · 🔴 비활성 사유 문구(`⏸ 모듈이 없어 점유를 알 수 없습니다`) 도 뺀다
상태를 말하는 것 : **색과 테두리**(회색·점선·사선·solid) — 이미 갖췄다
빼는 것들이 가는 곳 : **오른쪽 "선택한 자리" 패널**
```

🔑 이건 REQ-0288 의 설계를 **끝까지 밀는 것**이다 — *"격자의 일은 배치를 보여주는 것이고
상세는 패널이 한다."* 칸에 글자가 쌓이면 격자가 다시 표가 된다.

⚠ **`⏸` 문구를 칸에서 빼라고 한 것을 뒤집는다** — REQ-0296 에서 내가 그대로 두라고 했다.
사용자가 실물을 보고 *"라벨이 너무 많다"* 로 판정했다. **사유는 지우는 것이 아니라 패널로 옮긴다.**

## 지켜라

```
· 접근성 : 눈에 안 보이게 빼더라도 `aria-label`/`title` 에는 상태와 사유를 남겨라
           **화면에서 지우는 것과 기계에서 지우는 것은 다르다**
· REQ-0288 합격선 : 모듈 수가 칸 높이를 바꾸지 않는다
· REQ-0296 : 색 구분(비활성 회색 ≠ 미상)은 그대로. 🔴 **글자가 빠지면 색이 유일한 신호가 된다**
             그래서 사선·점선 같은 **모양 신호를 빼지 마라** — 색만으로는 색약에서 안 갈린다
· 범례는 남긴다. 칸에서 글자를 뺄수록 범례가 더 필요하다
```

## 범위
```
✅ 조별과제샘플/web/index.html — 칸 렌더링 · 패널 · 범례
❌ 서버 · 봉투 · active 판정
❌ 관측 · 판정 문서
```
배포는 루트가 한다. 커밋하고 알려라.

## 왜 필요한가

칸에 글자가 쌓여 격자가 다시 표처럼 보인다. REQ-0288 의 설계(격자는 배치, 상세는 패널)를 칸 안에서 지키지 못하고 있다

## 대상 파일

- `조별과제샘플/web/index.html`
## 완료 기준

격자 칸에 label(없으면 id)만 보인다. 요약·모듈 수 배지·비활성 사유는 패널에 있다. 색 외에 모양 신호(점선·사선)가 남아 있고 aria-label 에 상태·사유가 있다

⚠ **본문이 아니라 정정 메시지(정본)를 따랐다.** 루트의 첫 본문은 *"모듈 배지·`⏸` 사유도 빼라"* 였고

> *"**1번자리  a1  빈자리** << 3개가 동일하다."*

## 칸에서 무엇을 뺐나 — 판단 근거 (루트 요구)

```
`1번 자리`  label       ✅ 남긴다 — 이 칸이 **무엇인지** 말하는 유일한 이름
`A1`        자리 id     ❌ 뺐다 — label 이 있으면 **같은 것을 두 번** 말한다
`빈 자리`   상태 문구   ❌ 뺐다 — 🔑 **색·테두리가 이미 그것을 말한다**(사용자가 회색을 요구한 이유)
```
**판별자**: *"그 칸이 무엇인지/어떤 상태인지를 **이미 다른 신호가 말하고 있는가**."*
`빈 자리` 는 상태처럼 보이지만 solid+초록이 같은 말을 하고 있었다 → 사용자 눈에는 **세 번째 이름**이었다.

## 남긴 것 — 중복이 아니라 **다른 사실**이다
```
✅ 모듈 배지 `모듈 4`      개수는 색·테두리가 말할 수 없다
✅ 비활성 `⏸ 모듈이 없어…`  🔴 **왜 못 쓰는지**는 색이 말할 수 없다 (루트의 앞 판단이 맞았다)
✅ 겹침 경고 `⚠ 가려진 자리`  가려짐은 증상이 조용하다 — 안 말하면 기여자가 영영 못 푼다
✅ 색 · solid/dotted/dashed · 사선  ← 🔴 모양 신호를 남겼다. 색만이면 색약에서 안 갈린다
✅ `aria-label`·`title` 에 상태·사유가 **문장으로**  ← 스크린리더는 색을 못 읽는다
```
🔴 **라벨이 없으면 id 로 떨어진다**(A2~A5 가 그럴 수 있다) — 그때 id 는 중복이 아니라 유일한 이름이다.
⚠ `▸ 오른쪽에 상세` 선택 표시 **글자도 뺐다** — 그것도 네 번째 라벨이 된다. 선택은
**테두리 링(모양) + `aria-current`(기계)** 로 말한다.

## 🔴 하니스가 내 실수를 하나 잡았다
첫 편집이 **겹침 경고 블록까지 같이 지웠다.** `가려진 자리 id 가 화면에 적힌다` 검사가 빨강이 되어
바로 되살렸다. **그 검사가 없었으면 조용히 사라졌을 것이다** — 증상이 *가려짐* 이라 아무도 못 본다.

## 값 (주입 · 트래픽 0)
```
zone-nodes 85 pass / 0 fail / 1 미측정   ← REQ-0297 검사 8개 신설
  ✅ 어느 칸에도 상태 문구(.zone__sum)가 없다        ✅ 라벨 있는 칸에 날 id 가 없다
  ✅ 라벨 없는 칸은 id 를 이름으로 보인다             ✅ 모듈 배지는 모든 칸에 남아 있다
  ✅ 🔴 칸의 aria-label 이 **패널 요약과 같은 상태**를 말한다
  ✅ 🔴 날 id 는 패널에서 여전히 보인다(로그와 맞추는 유일한 값)
map-epoch 59 / 0 · mod-control 36 / 0
```
🔑 **aria 검사를 문구 나열로 쓰지 않았다** — 첫 판이 `장치가 요청대로 보고합니다` 를 빠뜨려
**멀쩡한 화면을 빨강**으로 만들었다. **패널 요약과 대조**하는 형태로 바꿨다(목록은 낡는다).
⚠ 사람 눈으로는 안 봤다. 잰 것은 DOM·계산된 스타일이다.

## 곁들여
`map-epoch`·`zone-nodes` 의 요약 읽기를 패널로 옮겼다. 그 과정에서 **템플릿 리터럴 안 주석의
역따옴표**로 또 깨뜨렸다(오늘 세 번째) — 고치고 그 자리에 경고를 박았다.
