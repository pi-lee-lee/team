# REQ-0289 · PC 넓은 화면에서 가로를 쓴다 — .wrap 이 1060px 에 묶여 세로로만 길어진다 (사용자 요구)

**요청자** `root` → **담당** `web-engineer`

## 요청 내용

사용자 요구: **"기본화면이 세로 크기 기준이다. PC화면에서는 넓게 보고 싶다."**
(REQ-0288 격자 수정을 배포하고 실물 화면을 본 뒤 나온 요구다.)

## 원인 (루트가 값으로 확인)

```
line 112  .wrap { max-width: **1060px**; margin: 0 auto }
line 151  main { grid-template-columns: minmax(0,1.55fr) minmax(230px,1fr) }
line 152  @media (max-width: 780px) { main { 1열 } }
🔴 미디어쿼리가 **좁은 화면 분기 하나뿐**이다. 넓은 화면 분기가 없다
```

전체가 1060px 에 묶여 있어 넓은 모니터에서 가운데만 쓰고 **좌우가 비고 내용이 세로로 길어진다.**

## 할 것

넓은 화면에서 가로를 쓴다. **단계를 두는 것을 권한다** — 무한정 넓히면 읽기가 나빠진다.

```
~780px      지금대로 1열
~1060px     지금대로 2열
넓은 화면    .wrap 폭을 키우고, 남는 가로를 격자와 패널에 배분
아주 넓으면  3열까지 갈 수 있다 (격자 · 상세 패널 · 그 밖)
```
단계 값과 열 구성은 **네가 정해라.** 화면을 아는 것은 너다.

## 🔴 지키라

```
· 좁은 화면·2열 거동을 깨지 마라 — 회귀 방지가 이 작업의 절반이다
· 격자 열 수(--zcols)는 **자리의 논리 배치**다. 폭 때문에 바꾸지 마라
· REQ-0288 의 합격선을 유지해라 : 모듈 수가 칸 높이를 바꾸지 않는다
```

## 범위 — 넘지 마라

```
✅ 조별과제샘플/web/index.html 의 CSS·레이아웃
❌ 서버 계약 · 봉투 — 하나도 안 바뀐다
❌ 관측 · 실기 하니스 · 판정 문서 (사용자가 검토 중단을 지시했다)
```

배포 단위는 `index.html` 하나다. `~/parking-bin` 복사는 루트가 한다.

## 왜 필요한가

넓은 모니터에서 좌우가 비고 내용이 세로로 길어져 한눈에 안 들어온다. 미디어쿼리에 넓은 화면 분기가 아예 없다

### 완료 — 폭 단계 넷 · 넓은 화면에서 3열 (2026-08-20 14:1x)

배포 단위 `조별과제샘플/web/index.html` 하나. **서버 계약 무변경.** 배포는 루트가 한다.

## 단계

```
.wrap  max-width :  1060 (기본) → **1400**(≥1200px) → **1760**(≥1600px) → **2000**(≥2100px)
판 배치 :  ≤780px   1열   [격자] [선택한 자리] [그 밖]
           781~1599 2열   [격자 | 선택한 자리]
                          [격자 | 그 밖      ]
           ≥1600px  3열   [격자 | 선택한 자리 | 그 밖]     ← 세로가 여기서 줄어든다
격자 행 높이 : 92px → 104(≥1200) → 116(≥1600)
```
**무한정 넓히지 않았다** — 2000px 에서 멈춘다. 글줄이 길어지면 읽기가 나빠진다.

## 🔴 두 가지를 고쳐야 3열이 됐다

### ① `.side` 를 **판 둘로 갈랐다**
3열은 "선택한 자리"와 "그 밖"이 **다른 열에 서는 것**이다. 한 `<section>` 안에 있으면 못 갈라진다.
→ `.pane--detail`(선택한 자리) · `.pane--info`(장치 상태·시뮬·테스트·알림) 로 나눴다.
**`#zone-detail` id 는 그대로**이므로 하니스·렌더 경로는 안 바뀐다.

### ② 🔴 `grid-template-areas` 로 자리를 **못 박았다**
자동 흐름에 맡기면 **판이 셋인데 열이 둘일 때 세 번째가 다음 줄 첫 칸으로 떨어진다** —
즉 **격자 아래에 "그 밖"이 끼어든다.** 이름으로 배치하면 열 수가 바뀌어도 자리가 안 흔들린다.
```
기본  "grid detail" / "grid info"      ← 격자가 두 줄을 걸친다
1열   "grid" / "detail" / "info"
3열   "grid detail info"
```

## 지키라고 한 것 — 값으로 지켰다

```
zone-nodes.mjs  56 pass / 0 fail / 1 미측정   (폭 단계 검사 12개를 새로 넣었다)
  ✅ 760px  : 셋이 같은 열 · 읽는 순서 격자→상세→그 밖
  ✅ 1280px : 격자와 상세가 나란히 · **그 밖은 상세 아래**(2열 거동 그대로)
  ✅ 1800px : 셋이 나란히 · 위쪽이 같은 줄 · .wrap 1749px
  ✅ 🔴 **세 폭 전부에서 칸 높이가 서로 같다** (REQ-0288 합격선)
mod-control.mjs 36 pass / 0 fail / 3 미측정   (패널 분리 뒤에도 위젯·입력 보존 그대로)
```
🔴 **`--zcols` 는 안 건드렸다** — 열 수는 자리의 논리 배치(맵 정의)다. 폭으로 바꾸면
`A1` 이 어느 칸에 있는지가 창 크기에 따라 달라진다. 코드 옆에 그 근거를 적어 뒀다.

⚠ **잰 것은 헤드리스에서 뷰포트를 강제한 경계 상자다.** 사람 눈으로 실제 모니터에서는 안 봤다.
그리고 **행 높이 단계는 뷰포트만 본다** — 모듈 수는 어디에도 안 들어간다(그래서 합격선이 유지된다).
