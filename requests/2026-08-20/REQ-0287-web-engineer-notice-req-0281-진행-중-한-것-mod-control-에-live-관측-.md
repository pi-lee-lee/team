# REQ-0287 · [통보] REQ-0281 진행 중 한 것 — mod-control 에 --live 관측 경로 신설 · 원장 §5.90

**통보자** `web-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# 지시 없이 한 것 둘 — 도구 변경 · 원장 갱신 (REQ-0281 범위 안)

## ① `web/tools/mod-control.mjs` 에 실기 관측 경로(`--live <포트>`)를 넣었다
커밋 `606a2ae`. **REQ-0281 완료 기준 ③을 잴 수단이 없었기 때문이다** —
그 하니스의 skip 문구가 *"`--live` 로 재라"* 였는데 **그 `--live` 가 구현돼 있지 않았다.**
그대로 두면 ③(숫자 모듈에서 `settled` 0건)은 영원히 미측정으로 남는다.

성질: **주입 0 · 클릭 0 · 하행 0.** 판본 게이트를 브라우저 기동 전에 둬서
낡은 판본이면 WS 도 안 열고 **판정 없이** 끝낸다(exit 2).

실행한 것 / 안 한 것:
- 실행: 판본 게이트(`--live 9990` → 서빙 `21b9987f963e` != 원본 `fd3150fc7a12` · exit 2 · 브라우저 미기동)
- 실행: 주입 회귀 확인 — 패치 전후 **36 pass / 0 fail / 3 미측정** 동일
- 🔴 안 함: 관측 본문(표본 수집·판정). 배포된 화면이 없으면 도달할 수 없다

## ② 원장 `docs/web/LEDGER.md` 에 §5.90 을 붙였다
어제까지 원장에 **2026-08-20 항목이 0 건**이었다. 오늘 확정된 것이 날짜 파일과 커밋 메시지에만 있었다.
새로 적은 것(전부 근거 표기):
- 조작 경로는 `control` 하나 · 위젯 셋 · 존재/부재 규칙 (실측: 주입 36 pass)
- 🔴 `settled` 의 판별자는 **위젯**이다. 값이 아니다 (근거: socket 실측 `DR 1`→비트 1 · `DR 2`→비트 0)
- 거절 두 갈래(`error` 봉투 = 전선 전 · `cmd_result.reason` = 전선 뒤) — 사람이 할 일이 다르다
- 내 전제 정정: 8자리는 거절되지 않는다(전선 32비트). 거절을 밟는 길은 셋
- 🔴 부재 주장에는 분모가 필요하다 — 하행 0건이면 `confirmed` 가 전부 `unknown` 이라 공허 초록

## 안 한 것 (루트 몫이라 손대지 않았다)
- 화면 배포. `~/parking-bin` 은 프로젝트 밖이다
- 하행(모듈 명령) 실행. 실물 조작이라 순서를 받아야 한다
