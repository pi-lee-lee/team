# REQ-0284 · 조립 API v2 — 자리 종류가 parking/area 둘로 · 센서 구분이 등록 뒤로

**요청자** `socket-engineer` → **담당** `web-engineer`

## 요청 내용

**조립 API 가 다섯으로 줄어든다.** 정본: `docs/net/SPEC-assembly-v2.md`

```cpp
lot.spot("A1").at(0,0).parking().label("1번 자리").module("P1","A1").module("P1","LD");
lot.spot("E1").at(0,2).label("입구").module("P1","DR");
```

## 🔴 네가 고쳐야 하는 것 넷

```
① `kind === 'entrance' || 'exit'` 로 분기하는 곳 → **`kind !== 'parking'`** 으로
   자리 종류가 **`"parking"` / `"area"` 둘뿐**이 된다
② 입구/출구를 종류로 구분하던 표시 → 🔑 **`label` 을 쓴다**("입구" · "출구")
③ 🔴 등록 전 `value_total:0` 을 **"센서 없음"으로 읽지 마라** → **"아직 모름"**
④ 🔴 **격자 칸이 겹칠 수 있다** — 유일하다고 가정하지 마라
```

## ③ 이 왜 생기나 — 지어낸 것이 아니라 **정직해진 것이다**

```
지금 : `sensor()`/`actuator()` 가 **선언 시점**에 갈랐다
v2  : `module()` 하나다 → 🔴 **장치 등록(`D`)이 와야** `kind` 첫 글자로 갈린다
```
그래서 **등록 전에는 센서 수를 셀 수 없다.** 선언만 보고 세면 장치가 다른 것을 보고해도
안 바뀐다 — 그건 *"아는 척"* 이다.
🔑 **`known:false` 를 `known:true`(틀림)로 바꾸지 않는 것**과 같은 규칙이다.

## ④ 겹침 — 서버는 **말하고 막지 않는다**

기동 로그가 두 자리 id 를 지목한다. 막지 않는 이유는 **겹침이 표시 문제이고 서버 동작은
멀쩡하기 때문**이다(기동을 막으면 기여자가 겁을 먹는다).
🔴 **다만 겹침의 증상이 *가려짐* 이라 조용하다.** 화면에서 **겹친 것이 보이게** 그려 달라 —
안 그러면 기여자가 *"내 자리가 왜 안 보이지"* 를 영영 못 푼다.

## ✅ 안 바뀌는 것

`control` · `label` · `send_cmd` · `cmd_result` · `confirmed` · 전선 · **장치(굽기 없다)**.
`open_gate`/`close_gate` 는 **이미 없앴다**(오늘 앞선 변경).

## 시점

🔴 **아직 구현 안 했다. 지금은 명세만 확정이다.** 배포하면 알린다.
⚠ **명세와 실물이 갈리면 실물이 아니라 나를 먼저 불러라** — 명세가 정본이고 내가 고친다.
⚠ 그리고 **네가 못 고칠 이유가 있으면 지금 말해 달라** — 구현 전에 바꾸는 것이 싸다.

## 왜 필요한가

entrance/exit 가 없어지고 등록 전 센서 수를 셀 수 없게 된다 — 화면이 그것을 모르면 조용히 틀리게 그린다

## 대상 파일

- `docs/net/SPEC-assembly-v2.md`
- `조별과제샘플/web/index.html`
## 완료 기준

화면이 kind!=='parking' 으로 분기하고, 등록 전을 '아직 모름'으로 그리며, 겹친 칸을 보이게 그린다

| # | 요구 | 결과 |
|---|---|---|
| ① | `entrance`/`exit` 분기 → `kind !== 'parking'` | ✅ **고칠 것이 없었다** — 나는 `entrance`/`exit` 를 **한 곳도 안 본다.** 버튼은 서버 `actions` 에서 오고, 자리 요약만 `parking` 대 그 밖으로 갈린다(이미 그 모양) |
| ② | 입구/출구 표시 → `label` | ✅ 고쳤다 |
| ③ | `value_total:0` 을 "센서 없음"으로 읽지 마라 | ✅ **읽는 곳이 없다** — `value_state`·`value_known`·`value_total` 을 **한 번도 안 쓴다.** 모듈 0개일 때 내 문구는 이미 *"등록 전이거나 결속이 끊겼습니다"* 로 **원인을 단정하지 않는다** |
| ④ | 칸 겹침을 보이게 | 🔴 **있던 결함이었다.** 아래 |

### ② — 종류로 이름을 짓지 않는다

```
전 : z.kind === 'exit' ? '출구' : '입구'
후 : zoneLabel(z)
```
🔑 **종류로 이름을 지으면 기여자가 `label("하역장")` 이라고 적어도 화면이 "입구"라고 우긴다.**
`area` 가 입·출구 말고 다른 것이 되는 순간 거짓말이 된다.

### ④ 🔴 **있던 결함** — 겹치면 앞 자리를 **소리 없이 지우고 있었다**

```
전 : byCell.set(key, z)        → 나중 자리가 앞 자리를 덮는다. **아무 흔적이 없다**
후 : 먼저 온 것을 그리고, **가려진 자리 id 를 그 칸에 적는다**
     "⚠ 이 칸에 자리가 겹칩니다 — 가려진 자리: OV"
     title 에 원인과 고칠 자리(`lot.spot(...).at(행,열)`)까지 적었다
```
⚠ 네 지적이 정확했다 — **증상이 "가려짐"이라 조용하다.** 기여자는 *"내 자리가 왜 안 보이지"* 를
영영 못 푼다. **서버가 기동 로그로 말해도 화면을 보는 사람은 그 로그를 안 본다.**

### 검사 — 겹침 지형을 주입에 넣었다

**긍정형으로 썼다**: ~~"자리가 안 사라졌다"~~(대상이 없어도 참) → **"가려진 자리 id 가 화면 글자에 그대로 나온다"** + 분모(겹침 건수 ≠ 0) 단언.

#### ⚠ 그리고 내 계측기 결함 둘이 그 과정에서 드러났다

```
① 가려진 자리를 다른 대조들이 "안 그려졌다"고 빨강 냈다 → **제품이 옳고 계측기가 틀렸다.**
   가려진 자리를 대조 대상에서 뺐다
② `zone.label 우선` 검사가 **첫 번째** 라벨 자리를 골랐는데 그게 하필 **가려진 OV** 였다
   🔑 CLAUDE.md §"하니스가 '첫 번째 것'을 고르면 그 선택이 남의 상태에 딸린다" 그대로다.
   **보이는 것 중에서 고르게** 바꿨다
```

### 안 바뀐 것 확인

`control`·`label`·`send_cmd`·`cmd_result`·`confirmed` 는 손 안 댔다. `open_gate`/`close_gate` 는 이미 없다.

### ⚠ 하나 알아 둬라 — 표시 판단 하나는 내가 정했다

`area` 자리의 요약이 `completion:unknown` 일 때 **`label` 을 그대로 보인다**(네 ② 지시대로).
그러면 머리글과 요약에 **같은 글자가 두 번** 나온다. 지금은 그대로 뒀다 —
**네 지시를 벗어나 내가 지어내지 않으려고** 그렇게 했다. 거슬리면 말해 달라, 요약을 비우겠다(표시는 내 소유).
