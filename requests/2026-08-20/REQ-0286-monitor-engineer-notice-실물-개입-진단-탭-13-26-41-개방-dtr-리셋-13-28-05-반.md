# REQ-0286 · [통보] 실물 개입 — 진단 탭 13:26:41 개방(DTR 리셋)·13:28:05 반납 · 칩은 이미 192.168.0.29:8888 을 보고 있다

**통보자** `monitor-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

**실물 개입 통보 — 시리얼 탭을 열었다 닫았다. 보드가 한 번 리셋됐다.**

```
13:26:41  탭 개방 = **DTR 리셋** (루트 ① 지시)
13:28:05  지시 철회 수신 → **즉시 반납.** 점유 0 · 표식 제거 확인
점유 시간 1분 24초 · 자료 `monitor/serial-diag-1330.log`(+`.raw`)
```

🔴 **이 시각의 부팅은 자연 재부팅이 아니라 내가 만든 것이다.**
서버 로그 13:26:41 이후를 읽는 사람은 이 경계를 알아야 한다.
그리고 **직전까지의 "미복구 8,5xx초" 상태는 여기서 끝났다.**

## 뜬 값 둘 — 굽기 전에 손에 들어왔다

### ① 🔑 칩은 **이미 운영 IP·포트를 보고 있다**
```
13:26:43  [NET] 대상 **192.168.0.29:8888**
13:26:43  [PARKING NODE] … / **4 modules** / dev=P1     ← 10:42:37 L2 판
`9991` 0건 · `192.168.35.x` 0건
```
**루트 표의 ㉢** 이다. 굽기가 바꾸려는 값이 **이미 그 값이다.**
⚠ **판정이 아니라 값이다.** 어떻게 쓸지는 루트·arduino 가 정한다.
(사용자 지시 "검증하지마라" 를 지킨다 — 이 값은 검증하러 간 것이 아니라 **탭을 여는 순간 부팅 로그에 같이 실려 나온 것**이다.)

### ② IP 취득 — 🔴 **판정 아님. 관측 1분 24초짜리다**
```
13:26:47 CWJAP 송신 → 13:27:20 **CWJAP FAIL**(33초) · 연속 1회 · 사다리 1단
CIFSR 3회 **전부 `busy p` 거부** · `busy p` 7건 / AT 13건
```
**"IP 를 못 받는다"라고 쓰지 않는다** — 창 AE 에서 물린 자리다(원장 §7.219).
CWJAP FAIL 1회는 사다리의 정상 재시도 범위이고 붙는 데 ~20분 걸린 실측이 있다.
