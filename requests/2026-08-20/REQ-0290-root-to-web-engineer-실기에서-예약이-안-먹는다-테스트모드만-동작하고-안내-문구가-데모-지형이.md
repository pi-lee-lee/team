# REQ-0290 · 🔴 실기에서 예약이 안 먹는다 — 테스트모드만 동작하고 안내 문구가 데모 지형이다 (사용자 실물 보고)

> ### 테스트모드가 되고 실기가 안 되는 것은 §"시험이 실기가 안 하는 준비를 대신해 준다" 의 실물이다.
> **테스트모드는 자료를 스스로 만들고 안내 문구도 그 지형을 설명한다. 실기 경로는 한 번도 안 밟혔다.**

## 할 것 — ① 층을 가르고 ② 네 몫을 고치고 ③ 남으면 넘겨라

```
① 층 구분 (이것부터)
   · 칸을 눌렀을 때 화면이 예약 요청을 **실제로 보내는가** (WS 프레임)
   · 서버가 응답을 주는가 · 그 응답에 무엇이 담기나
   · state 봉투에 `reserved` 가 실려 오는가
② web 몫이면 고쳐라
   · 안내 문구가 **실기 지형을 따라가게** 해라 — 정적 문구로 지형을 설명하지 마라
     🔑 지형은 map 봉투가 준다. 문구를 그것으로 만들면 낡지 않는다
   · v2 에서 자리 종류가 parking/area 둘로 줄었다. **예약은 parking 에만** 성립한다
     area 칸을 눌렀을 때 무슨 일이 나는지 확인하고, 눌러도 안 되는 것이면 **그렇게 보이게** 해라
③ socket 몫이면 넘겨라
   요청이 나가는데 서버가 안 받거나 state 에 reserved 를 안 싣는 것이면 그쪽이다.
   **값(보낸 프레임 · 받은 응답)을 붙여서 REQ 로 넘겨라.** 말로 넘기지 마라
```

## ① 층 구분 — 어디서 끊겼나

```
화면이 요청을 보내는가   🔴 **아니다. 여기서 끊겼다** (그래서 서버 로그가 0건이다)
서버가 응답하는가        — 요청이 안 갔으니 물을 수 없다
state 에 reserved 가 오나 — 같은 이유로 물을 수 없다
```
**재현(주입, `map`/`state` 만 넣고 옛 `snapshot` 은 없는 세계 = 실기와 같은 조건):**
예약 버튼을 누르고 확인을 눌러도 `window.__sent` 가 **비어 있었다.**

## 🔴 기전 — 여는 판정자와 보내는 판정자가 갈려 있었다

```js
async function requestReserve(slotId) {
  ... 확인 대화상자 ...
  const slot = currentSlot(slotId);                      // 🔴 옛 격자의 snapshot.slots 를 뒤진다
  if (!slot || tileView(slot).action !== 'reserve') {     // 🔴 새 봉투만 오면 slot 이 null
    showMessage('그 사이 자리 상태가 바뀌어 예약하지 않았습니다'); return;   // 조용히 반환
  }
  transport.send({type:'reserve', ...});                  // ← 여기까지 못 온다
}
```
```
격자(여는 쪽)   : 서버 `zone.actions.reserve.ok` 로 버튼을 연다   ← 새 판정자
requestReserve  : 옛 `snapshot.slots` + `tileView` 로 재검증      ← 🔴 옛 판정자
```
> **원장 §5.52("판정자를 하나로 둔다")의 나머지 반쪽이었다. 그때 *여는 쪽* 만 모았고 *보내는 쪽* 은 그대로였다.**

**고침**: `zoneActionOk(zoneId, act)` 를 만들어 **개정 격자에서는 여는 쪽과 같은 판정자**(서버 `actions`)로
재검증한다. 폴백(옛 격자)에서는 옛 경로를 그대로 쓴다 — **경로마다 판정자가 하나**다.

## ② 안내 문구가 없는 동작을 시키고 있었다 — 이게 사용자가 본 것이다

```
있던 문구 : "2열 5행 · 10칸 · **빈자리를 눌러 예약합니다**"   ← 정적
🔴 ① 지형이 v2 로 바뀌어 행·열·자리 수가 다르다
🔴 ② **칸을 눌러도 예약이 안 된다.** REQ-0288 부터 칸 클릭은 *선택* 이고 조작은 우측 패널이다
```
→ **`map` 봉투로 만든다**: `3행 × 3열 · 자리 2개 (주차 1 · 일반 영역 1) · 칸을 누르면 오른쪽
“선택한 자리”에 상세와 조작이 열립니다`. 폴백일 때는 옛 격자 문구를 쓴다.
🔑 *"안내대로 동작하지 않는다"* 는 보고가 정확했다 — **안내가 틀린 쪽이었다.**

## ③ 일반 영역을 누르면 조용하지 않다
`actions` 가 비면 **왜 없는지** 말한다(원인은 지어내지 않는다):
```
parking     → "지금 이 자리에 가능한 조작이 없습니다 — 서버가 이 자리의 조작을 내려보내지 않았습니다"
그 밖(area) → "일반 영역입니다 — 예약은 주차 자리에만 있습니다 (모듈 조작은 위 목록에서 합니다)"
```

## ④ 데모 자료가 이 결함을 가리고 있었다 — 지우지 않고 적었다
`DEMO_SNAPSHOT` 은 **옛 봉투(10칸 `A1..B5`)의 세계**다. 그 세계에서는 `currentSlot()` 이 자리를 찾아
**재검증을 통과했다** → 데모·폴백에서는 예약이 됐다. 실기(새 봉투만)에서만 끊겼다.
🔑 §"시험이 실기가 안 하는 준비를 대신해 준다" 의 실물. **폴백이 쓰므로 안 지운다.** 그 자리에 경고를 박았다.
