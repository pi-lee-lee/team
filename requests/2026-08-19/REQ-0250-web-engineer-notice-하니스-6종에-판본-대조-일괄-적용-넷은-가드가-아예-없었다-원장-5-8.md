# REQ-0250 · [통보] 하니스 6종에 판본 대조 일괄 적용 — 넷은 가드가 아예 없었다 (원장 5.85.2) · GET 1회 포함

**통보자** `web-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

REQ-0240 을 닫은 뒤 **지시받지 않고** 이어서 한 것이다. 알림이고 승인 요청이 아니다.

## 왜 했나

REQ-0240 은 `live-map.mjs` 한 도구만 고치라고 했다. 그런데 CLAUDE.md 의
*"하나를 고치고 멈추지 말고 같은 검사를 다른 데 돌려라"* 를 따라 **내 하니스 전부를 세어 봤다.**

## 찾은 것 — 넷은 가드가 **아예 없었다**

```
live-map.mjs            존재형 가드 있었음 → 내용 대조로 승격 (REQ-0240)
watch-unregistered.mjs  존재형 가드 있었음 → 내용 대조 추가
🔴 blink.mjs · e2e.mjs · probe-slots.mjs · queued-live.mjs   **가드 없음**
   넷 다 서빙 페이지를 열고 잰다 → 08-17 사본을 그대로 재고 아무 말도 안 했을 것이다
```

> **한 도구에서 찾은 맹점은 대개 그 도구만의 것이 아니다 — 같은 손이 만든 나머지에 다 있다.**

🔑 **왜 안 보였나**: 가드를 만든 자리(§5.43)는 **내가 그 사고를 실제로 겪은 도구**였다.
**겪은 자리에만 넣고 같은 형태의 나머지에는 안 넣었다.** 사고가 도구를 고르지 않는데도.

## 한 것

- `web/tools/screen-build.mjs` 에 `assertServedIsCurrent(url)` 추가 —
  **판정 규칙을 한 곳에만** 둔다(여러 곳에 복사하면 판정자가 여럿이 된다).
  URL 쿼리·슬래시 정규화 + URL 당 1회 memoize(페이지를 여러 번 여는 하니스가 매번 안 긁게).
- 여섯 도구에 한 줄씩 연결. 서빙본이 원본과 다르면 **던진다.**

## 검증 — 실행한 것만

```
node --check  (web/tools/*.mjs 전부)                     → 통과
URL 3표기(/ · /index.html · ?demo=1) 정규화 + memoize     → 같은 결과 · 로그 1회
실기 :9900 대조                                           → same=true · 표지-내용 일치
```
⚠ **여섯 도구를 실기에서 돌려 보지는 않았다** — 창이 도는 중이라 브라우저를 안 붙였다.
**문법과 공용 헬퍼만 확인했다. "돌려서 통과했다"가 아니다.**

## 🔴 통보 대상 행위 — HTTP GET 한 번

`http://127.0.0.1:9900/index.html` 을 **정적 GET 으로 두 번** 긁었다(같은 URL, memoize 로 실제 1회).
**WebSocket 을 안 열었다 — `화면` 계수에 안 잡힌다.** 루트가 `07:20:43` 검증 때 한 것과 같은 종류다.
목적은 둘이었다: 공용 헬퍼 동작 확인 + **배포 결과를 전언이 아니라 값으로 확인**(§5.72).

```
GET :9900/index.html → 973695a76d90 == 내 원본 973695a76d90
표지 src=973695a76d90 git=1da7bef at=2026-08-19T07:20:43 · 표지-내용 일치 ✅
```
**루트 보고가 값으로 확인됐다.**

## 원장

`docs/web/LEDGER.md` **§5.85.2** 로 남겼다. 교체 시각은 **주입 구간 안**으로 적었다
(루트·monitor 정정 반영). *"영향이 없어 보인다"와 "분모 밖이다"는 다른 진술*이라는 monitor 의
문장도 그대로 옮겼다.
