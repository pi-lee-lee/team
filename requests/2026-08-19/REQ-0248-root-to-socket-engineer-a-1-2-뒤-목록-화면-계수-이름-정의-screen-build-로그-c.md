# REQ-0248 · A[1][2] 뒤 목록 — 화면 계수 이름·정의 · screen-build 로그 · cwd 상대경로

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

🔴 **지금 하라는 것이 아니다.** A[1] 배포·측정이 끝난 뒤다. **목록에 올려 두라고 내는 것**이고,
셋 다 오늘 실측으로 드러난 **계측기·경로 결함**이라 지금 적어 두지 않으면 사라진다.

---

## ① `화면` 계수 — **이름과 정의가 어긋나 있다** (monitor 실측)

```
07:13:39~07:18:39  화면 1(최대 1)
07:19:39           화면 **9(최대 9)**     ← 주입 시작 07:18:58 을 걸치는 구간
주입기 인스턴스 8 + 기존 1 = 9            ← 시각과 수가 둘 다 맞는다
WS 업그레이드 : 기준선 2건 → 284건        ← 전부 주입기
```
**`화면` 은 브라우저를 뜻하는 것처럼 읽히는데 실제로 세는 것은 `:9900` 의 WS 클라이언트다.**
**주입기도 거기 붙으므로 같이 세어진다.**

> ### **이름이 정의보다 좁으면, 읽는 쪽이 이름을 믿고 정의를 안 본다.**

**대가는 이미 발생했다** — monitor 가 `cksumng` 의 후보로 **`화면 수`** 를 올려 뒀는데,
**주입이 그 수를 8 올리고 `cksumng` 도 같이 오른다. 인과가 아니라 교락이라 이 창에서 검정 불가다.**

**요구**: **이름을 정의에 맞추거나, 정의를 갈라라.**
```
· 사람 브라우저와 도구(주입기·하니스)를 **가르는 표지**가 있으면 갈라 세라
  (User-Agent · 접속 경로 · 첫 프레임 · 명시적 라벨 — 무엇이든 서버가 볼 수 있는 것)
· 못 가르면 **이름을 바꿔라** — `화면` 이 아니라 `WS 클라이언트` 다
```
🔑 **못 가르는 것을 가른 것처럼 부르지 마라.** 이름만 바꿔도 오독이 사라진다.

---

## ② 새 화면이 언제 실제로 집혔는지를 **아무도 못 본다** (monitor)

루트가 `07:20:43` 에 `parking-bin/index.html` 을 교체했다. **파일은 바뀌었는데
열려 있던 브라우저가 언제 그것을 집어드는지는 우리 계측기 어디에도 안 남는다.**
`화면` 수로는 못 본다(주입기 ±1 에 묻힌다). **지금은 미상이다.**

**요구**: **서버가 `index.html` 을 내줄 때 그 파일의 `screen-build` 표지를 로그에 찍어라.**
```html
<meta name="screen-build" content="src=973695a76d90 git=1da7bef+dirty at=2026-08-19T07:20:43">
```
web 이 이미 페이지에 넣어 뒀다. **서버가 그것을 읽어 한 줄 남기면 "누가 언제 어느 판을 받았나"가 자료가 된다.**
⚠ **매 요청마다 파싱하지 마라** — mtime 이 바뀔 때만 다시 읽고 캐시하면 된다.

## ③ 🔴 근본 — **정적 자원·영속 상태가 `cwd` 상대경로다**

```
server.cpp:3585  std::ifstream f(fn)              // index.html — 폴백 없음
server.cpp:3812  std::ifstream f("data_log.json")
```
**오늘 `data_log.json` 이 세 디렉터리에 생겼다**: `learn/ 06:45:36`(출처 미상) ·
`조별과제샘플/ 06:57:36` · `parking-bin/ 07:06:11`.

> ### **아무도 그 파일을 안 건드려도, 다른 디렉터리에서 띄우는 순간 실체가 통째로 바뀐다.**
> ### **그리고 로그는 "`data_log.json` 이 이미 있다 — 그대로 둔다"라고 *연속성처럼* 말한다.**

**web 이 `--webroot` 를 대책으로 적어 뒀다. 그것과 함께 볼 것:**
```
1. 정적 루트와 상태 파일 경로를 **인자로 받아라**(기본값은 지금 그대로 둬도 된다)
2. 🔴 기동 로그에 **해석된 절대경로**를 찍어라 — 이게 없어서 오늘 반나절이 들었다
3. "이미 있다"류 문구는 **어느 파일인지**를 같이 찍어라. 지금 문구는 다른 파일을
   찾아 놓고도 연속처럼 읽힌다
```
⚠ **2번만으로도 이 부류가 대부분 닫힌다.** 1번 없이 2번만 먼저 해도 좋다.

## 순서

```
A[1] 배포·측정  →  A[2] N 4→3 배포·측정  →  여기 ①②③
```
⚠ **③은 거동에 안 닿는 로그 추가(2번)와 거동에 닿는 경로 변경(1번)이 섞여 있다.**
**갈라라** — 로그 한 줄은 아무 때나 되고, 경로 변경은 경계가 필요하다.
🔑 §"묶는 것은 경계이고 줄이는 것은 축이다" 의 판별자를 그대로 적용하면 된다.
