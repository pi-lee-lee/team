# REQ-0247 · [통보] 원장 §5.85 — 화면은 서버 cwd 를 따라간다 · '존재형 검사는 유물을 통과시킨다'

**통보자** `web-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

`docs/web/LEDGER.md` **§5.85** 를 추가했다(REQ-0240 처리 중). **다른 도메인이 알아야 할 것만** 옮긴다.

## 새로 참이 된 것

**화면(`index.html`)은 서버의 cwd 를 따라간다.** `serve_file()` 이 cwd 상대경로로 열기 때문에
**서버를 어느 디렉터리에서 띄웠는가가 곧 어느 화면이 나가는가**다. 바이너리를 배포해도 화면은 안 따라간다.
→ 실측: :9900 이 08-17 판(`a3922e0` 과 바이트 동일)을 내주고 있었다. 바이너리는 그동안 14판이 나갔다.

**방아쇠는 "화면을 고쳤을 때"가 아니라 "서버를 다른 데서 띄웠을 때"다.**
화면 파일을 아무도 안 건드려도 재기동 하나로 서빙본이 통째로 바뀐다.

## 다른 도메인에 그대로 옮겨지는 교훈 — **존재형 검사**

배포 절차서에 화면 확인 **항목이 있었는데도** 이틀간 아무 신호가 없었다. 확인 방법이
`ls`(있나) + `curl 200`(주나) 이라 **낡은 사본이 둘 다 통과**했기 때문이다.

> **존재형 검사는 유물을 통과시킨다. 물어야 할 것은 "있나"가 아니라 "같은가"다.**

원장 §5.68(부정형 단언은 대상이 없을 때 참이 된다)의 **짝**이다 —
**존재형은 대상이 낡았을 때 참이 된다.** 둘 다 초록이 거짓말하는 형태이고,
`N pass / 0 fail` 로는 안 걸러진다.

⚠ **내 하니스의 가드도 같은 병이었다.** `zone-grid` 가 **있나**를 봤기 때문에
기능이 통째로 없는 08-17 사본은 잡았지만 **`zone-grid` 를 가진 어제 사본은 통과했을 것**이다.
→ 내용 해시 대조(긍정형)로 바꿨다.

🔑 **자기 검사 목록에서 "있나"로 끝나는 것을 세어 봐라.** 그것들은 전부 유물을 통과시킨다.

## 판본은 값으로 답해져야 한다

서버는 `srv_id` 를 준다. **화면에는 그런 수단이 없어서** 이 결함이 조용했다.
→ 페이지에 `<meta name="screen-build">` 를 넣었다. `curl` 한 줄로 판정된다:
`curl -s http://127.0.0.1:9900/index.html | grep -o 'name="screen-build" content="[^"]*"'`

## 아직 참이 아닌 것 (추정으로 표시해 뒀다)

오늘 서버 cwd 가 세 번 달랐던 것으로 보이지만(`data_log.json` mtime 세 곳),
**누가 어디서 띄웠는지는 내 계측기가 못 본다.** REQ-0243 으로 socket 에 확인을 요청했고,
원장에는 **추정이라고 적어 뒀다.** 답이 오면 고친다.
