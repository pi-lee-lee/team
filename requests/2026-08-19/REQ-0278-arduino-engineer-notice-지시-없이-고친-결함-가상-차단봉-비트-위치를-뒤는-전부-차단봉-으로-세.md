# REQ-0278 · [통보] 지시 없이 고친 결함 — 가상 차단봉 비트 위치를 '뒤는 전부 차단봉' 으로 세고 있었다

**통보자** `arduino-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

## 무엇을 했나

지시받은 두 작업(주석 정리 · 장치 샘플)을 하다가 **지시에 없던 결함 하나를 고쳤다.**

### 고친 결함 — `buildStatus` 의 가상 차단봉 비트 위치

`조별과제샘플/ardu/Modules.h` 의 루프가 **"`SLOT_N` 뒤는 전부 차단봉"** 으로 세고 있었다.

    for (uint8_t k = 0; k + SLOT_N < mn; k++)
        if (gates.isOpen(k, slotNo)) occOut |= 1u << (SLOT_N + k);

센서와 차단봉 사이에 다른 모듈이 끼는 순간 무너진다. 샘플 액추에이터(`LD`·`LC`·`DR`)를
넣자 실측 `occ = 1F` 가 나왔다 — **액추에이터 셋이 전부 "열림"으로 에코**됐고,
`gates` 의 범위 밖까지 읽었다.

고친 모양: 개수와 시작 자리를 **표 끝에서 거꾸로** 센다.

    static const uint8_t GATE_N    = 2;
    static const uint8_t GATE_BASE = MODULE_N - GATE_N;

### 이 결함이 구워진 적은 없다

기본 빌드는 `VIRTUAL_MODULES=0` 이라 이 루프가 **전처리에서 사라진다.**
시험 구성에서만 살아 있었고, 그래서 지금까지 아무도 못 봤다.
즉 **관측 자료를 오염시킨 적이 없다.** 되돌릴 것도 없다.

### 왜 지시 없이 고쳤나

방아쇠가 **가장 흔한 정상 작업**이기 때문이다 — 모듈을 하나 더 붙이는 것.
남겨 두면 다음 사람이 액추에이터를 붙이는 순간 **없는 조작이 서버에 보고된다.**

### 검증

회귀 265 PASS / 0 FAIL. 고치기 **전에** 손으로 예측한 값(`occ` 칸 `03`·`02`,
차단봉 idx 5·6)이 고친 뒤에 그대로 나왔다 — 예측이 맞은 것이 이 수정의 근거다.

커밋 `23b6465` · 원장 §45.
