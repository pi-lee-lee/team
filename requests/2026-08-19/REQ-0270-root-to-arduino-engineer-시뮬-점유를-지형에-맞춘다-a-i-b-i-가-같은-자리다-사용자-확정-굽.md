## 요청 내용

# 시뮬 점유를 **지형에 맞춘다** — `A_i` 와 `B_i` 가 같은 자리다 (사용자 확정)

> 사용자: *"지금 아두이노는 1대이다. 나머지는 가상일 거다. **테스트 설정 문제**일 거다."* → **(나) 선택**

## 0. 확인된 사실

```c
#define SLOT_SRC_DEFAULT 0x0000   // 10칸 **전부 시뮬** — 실물 센서 0개
simOcc = (1<<1)|(1<<2)|(1<<8);    // 부팅 초기값 A2·A3·B4
:335  if ((resMask & bit) && !(simOcc & bit)) simOcc |= bit;   // 예약 → 점유
:348  simOcc ^= (uint16_t)1 << i;                              // 토글
```

## 1. 🔴 문제 — 시뮬이 지형과 어긋난다

```
확정 지형(사용자) : **A_i 와 B_i 는 같은 자리의 두 센서**(이중화)
                    영역1 ← A1·B1 … 영역5 ← A5·B5
🔴 지금 시뮬      : **열 칸을 서로 독립으로 굴린다**
→ A_i 와 B_i 가 다른 값이 되는 것이 **정상 동작**이 된다
```
**실측**: `센서갈림 2자리` 가 7분 연속. **구조적으로 항상 켜진다.**

> ### **감시가 있는데 아무것도 못 본다. 진짜 이중화 고장이 나도 이 계수로는 못 가른다.**
🔑 §"조건을 적었으면 그것을 보는 감시를 같은 자리에 만들어라" 의 **뒤집힌 형태**다 —
감시는 만들었는데 **그 감시가 잡음으로 가득 차 있다.**

## 2. 할 일

**`A_i` 와 `B_i` 가 같은 값으로 굴러가게 한다.** 형식은 네가 정해라. 후보:
```
(a) 다섯 자리만 굴리고 각 자리를 두 비트에 **복제**한다 (bit i 와 bit i+5)
(b) 시뮬 상태를 5칸으로 두고 12비트로 펼칠 때 복제한다
```
🔑 **(b)가 지형과 같은 모양이다** — 자리는 5개이고 모듈이 10개다. **자료구조가 지형을 닮으면
다음 사람이 안 헷갈린다.** 다만 **비용이 크면 (a)로 가라. 근거를 적어라.**

⚠ **가상 모듈 `E1`·`X1`(bit 10·11)은 차단봉이라 복제 대상이 아니다.** 지금대로 둬라.

## 3. 🔴 그러면 무엇이 달라지나 — **미리 적어라**

```
· `센서갈림` 이 **0 이 기본**이 된다 → 그때부터 **1 이상이면 진짜 신호**다
· 자리 `occupied`(OR)는 값이 안 바뀐다 — 둘이 같으니 OR 도 같다
· 🔴 **예약→점유 경로(:335)가 두 비트를 다 올려야 한다.** 한쪽만 올리면 다시 갈린다
· 토글(:348)도 마찬가지다
```
**둘 다 고쳐라. 하나만 고치면 갈림이 남고, 그게 더 나쁘다**(진짜인 줄 알게 된다).

## 4. 검증

```
① 회귀 시험 — `센서갈림` 이 0 인 것을 **단언으로** 넣어라
   🔴 긍정형으로: "모든 i 에 대해 bit_i == bit_(i+5)"
   ⚠ 기대값을 피검체에서 읽지 마라 — 분모가 0 이 아닌 것도 같이 단언해라(web 이 오늘 찾은 함정)
② 예약을 넣어 :335 경로를 밟고 **두 비트가 같이 오르는지** 본다
③ 🔴 **hex 대조** — 이건 거동 변경이라 hex 가 **당연히 다르다.** 다른 것이 문제가 아니라
   **어디가 다른지 설명할 수 있어야** 한다
```

## 5. 🔴 굽기 — 다른 둘과 **한 번에**

```
지금 대기 중인 굽기 항목 셋:
  ① ESP_RST_WIRED 0 → 1      (사용자가 A2↔ESP RST 선을 물렸다)
  ② 배너 "10 slots" → 12      (실제 등록은 D,*,7,12)
  ③ 이 건 (시뮬 지형 정합)
```
**셋 다 축이 다르지만 굽기는 관측 경계라 한 번으로 묶는다.** 🔑 §"개입은 한 번으로 묶어라".
⚠ **판정문에 축 셋을 명시해라** — 묶는 것과 안 세는 것은 다르다.

🔴 **창 R 이 끝나고 루트가 시각을 준 뒤에 굽는다.** 지금은 코드와 시험만.

## 왜 필요한가

실물 센서가 0개라 열 칸을 독립으로 굴리는데 지형은 A_i+B_i 를 한 자리로 묶어서 센서갈림 계수가 구조적으로 항상 켜진다
