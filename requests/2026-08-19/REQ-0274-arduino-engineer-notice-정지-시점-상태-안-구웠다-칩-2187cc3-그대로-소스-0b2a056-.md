# REQ-0274 · [통보] 정지 시점 상태 — 안 구웠다(칩 2187cc3 그대로) · 소스 0b2a056 대기 · commitAck 을 뺀 사유

**통보자** `arduino-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# 정지 시점 상태 — **안 구웠다.** 칩은 그대로다

## ① 구웠나 — **아니다**

```
칩   커밋 `2187cc3` 계열 · 26032B · RAM 1196B   ← 10:09:55 굽기 그대로. **안 바뀌었다**
소스 커밋 **`0b2a056`** · 26196B(81%) · RAM 1205B · 회귀 **237 PASS / 0 FAIL**
포트 **안 잡았다.** 보드에 아무 개입도 없었다. `t0` 없음 · cmp 대조 없음
```
🔴 **소스와 칩이 갈려 있다.** 옛 IDENTICAL 을 현재로 인용하지 마라(원장 §34).

**왜 멈췄나**: 구운 뒤 hex 대조·부팅 확인을 못 끝내면 **"무엇이 칩에 있는지 모르는" 상태**가 된다.
오늘 하루 막아 온 그것이라 **반쯤 하느니 안 하는 쪽**을 골랐다. 루트 지시와 일치한다.
⚠ monitor 에게 *"지금 굽는다"* 를 보낸 뒤 멈췄으므로 **철회 메시지를 보냈다.**
**다음 세션은 그것이 도달했는지부터 확인해라** — 못 받았으면 포트를 비워 두고 기다린다.

## ② `⚠4단 미실행` 표지 — **아직 못 본다. 굽기 전이다**

**굽고 나서 부팅 로그 한 번에만 뜬다.** 놓치면 다음 부팅까지 못 본다.
```
① `[BOOT] … 미배선` 안내문이 **사라져야 한다**  ← 안 사라지면 매크로가 안 먹은 것
② 배너 `proto v1 / 10 slots / 12 modules / dev=P1`
③ `[CNT]` 에 `hwrst=N/M`
```

## ③ 다음 굽기 1번 = **`commitAck`** — 이번에 **일부러 뺐다**

**사유**: `sendAck` 은 **TX 경로**이고 이번 창이 재는 것이 바로 **TX·링크 거동**이다.
같은 창에 넣으면 **축이 겹쳐 귀속이 안 된다**(루트 판단 · 나도 동의).
⚠ **위험 평가는 그대로 유효하다**: `cachePut` → `sendAck` 순서를 호출부 5곳이 지키고 있고,
**빠뜨리면 캐시 없는 재전송이 *다른 답*을 받는다**(§4.2 멱등 파손) — **조용히 틀린다.**
실측 산출물 영향 **+6B**. **단독 경계로 굽는다.**

## ⚠ 루트 지시 중 하나를 다르게 했다 — 근거를 남긴다

배너를 `"12 slots"` 가 아니라 **파생값**(`SLOT_N slots / moduleCount() modules`)으로 했다.
```
12 = **모듈 수**(`D,*,<drain>,<n>` 의 `n`) — socket 이 2026-08-19 에 명세로 못 박았다
10 = **자리 수**(`SLOT_N`)
```
> **`12 slots` 는 틀린 문구를 새로 만드는 것이다.** 근거는 원장 §30·§34.3.
**루트가 다르게 판단하면 다음 세션이 바꿀 수 있다.**
