# REQ-0258 · 🔴 관측 기준선 재설정 — 10:20 이후만 관측 자료. 절단은 사용자 환경 셋팅이었다

**요청자** `root` → **담당** `arduino-engineer`

## 요청 내용

# 🔴 관측 기준선 재설정 — 사용자 지시 (2026-08-19 10:20)

> 사용자 원문: *"오늘도 이전 데이터는 관측에서 제거한다. **현 시점부터 관측 데이터로 이용한다.**
> 절단 관련은 **내가 이동후 환경셋팅시 발생한 것이다.** 이부분들은 관측데이터에서 제거한다."*

## 1. 🔴 여러 "미상"이 한 번에 닫힌다 — **개입할 수 있는 쪽이 답했다**

우리가 미상으로 달아 둔 절단들이 **전부 사용자의 이동 후 환경 셋팅**이다:
```
09:42:30  세션#8 종료(errno=54)      ← 미상으로 달아 뒀다
09:57:48  세션#9 종료(상대가 닫음)    ← socket 이 "미상" 확정했다
10:14:17  세션#1 종료(errno=54)      ← socket 이 "못 가른다" 했다
10:15:21  세션#2 종료(errno=54)      ← [DROP-OVF] 를 후보로 달아 뒀다
```
> ### **`[DROP-OVF]` 는 원인이 아니었다. 그 후보를 승격시키지 않은 것이 옳았다.**

🔑 **CLAUDE.md §"아무도 건드리지 않았다는 관측할 수 없는 문장이다" 가 그대로 값을 냈다** —
*"개입 여부는 개입할 수 있는 쪽에게 물어라. 부인할 수 있는 것은 그쪽뿐이다."*
**우리 계측기 셋(서버 로그·시리얼·칩 판독) 중 어느 것도 이걸 볼 수 없었다.**

## 2. 새 기준선

```
🔴 관측 자료의 시작 = **2026-08-19 10:20 이후**
그 앞의 모든 것 = **관측 자료가 아니다**
```
**대상**: 창 O · 창 P(10:15:11 개방분) · 09:xx~10:2x 의 모든 세션·절단·계수.

### ⚠ 지우지 마라 — **자격을 낮추는 것이지 삭제가 아니다**
```
✅ 남긴다 : 파일 · 판정문 · 원장. 사유와 함께
❌ 안 한다 : 인용해서 새 판정을 세우는 것
```
**CLAUDE.md §"자료를 무효화할 때 — 셋을 갈라라"** 를 적용해라:
```
✅ 살아남는 것 : 소스 판독 · 자기 프로세스 안에서 닫히는 실측 · selftest
                 (예: hex 인코딩이 S 를 38B→21B 로 줄였다 · rid 계약 줄 · 굽기 hex 대조)
❌ 자격 상실   : 창 O·창 P 의 **관측 비율과 그 위에 세운 인과 귀속**
```

## 3. 🔴 그래서 A[1] 판정 방식이 바뀐다 — **대조가 아니라 절대 기준으로**

창 O 의 `>=64B 진입률 69.8%` 는 **더 이상 대조군이 아니다.** A[1] 은 이미 배포됐으므로
**A[1] 이전 기준선을 다시 뜰 방법이 없다**(되돌리지 않는 한).

**그러니 A[1] 은 절대 기준으로 판정한다 — 다행히 1차 판별자가 원래 절대값이다:**
```
🔴 `rid` 4자리 = **0**            ← A[1] 이 도는가. 하나라도 나오면 안 도는 것
   `rid` 범위가 [0,999] 안인가
   격리가 발동하는가 / 재사용이 일어나기는 하는가 (안 일어나면 그 0 은 **표본 없음**)
   `ACK 미상rid` · `자리불일치` · `건너뜀` · `강제`
```
⚠ **`>=64B` 진입률은 새 기준선의 첫 값으로 뜬다 — "좋아졌다"가 아니라 "이만큼이다"로 적어라.**
**비교 대상이 없으므로 변화량을 주장하지 마라.**

## 4. 각자 할 일

```
monitor : 창 P 를 닫고 **10:20 이후로 새 창(창 Q)** 을 연다
          ⚠ 탭을 다시 열면 DTR 리셋이 또 생긴다 — **지금 탭을 유지한 채 구간만 가르는 편이 낫다**
          그 판단은 네 것이다. 어느 쪽이든 **t0 를 값으로 적어라**
socket  : 주입(REQ-0254)은 그대로 간다. **새 창 안에서** 돈다
          요약 계수의 기준 시각을 명확히 해라 — 소크 누적은 10:00:22 기동부터다
arduino : 굽기는 끝났다. 새 지시 없다
```

## 5. ✅ 앞으로 — **이 부류를 먼저 물어라**

**이번에 우리가 넷을 미상으로 달고 시간을 썼다.** 사용자에게 한 줄 물었으면 즉시 닫혔다.
> ### **관측 창에 설명 안 되는 사건이 생기면, 코드를 뒤지기 전에 "그 시각에 누가 무엇을 했는가"를 물어라.**
> **그 목록에 사용자가 든다.** 특히 **이동·재기동·환경 변경 직후**에는 사용자가 가장 유력한 개입자다.
