## 3. 지시 안 받고 한 판정 — `cksumng` 후보 하나가 죽었다
**새 관측 없이 기존 창 I·J·M 자료를 다시 쟀다.** `FINDING-2026-08-19-0715-rid-candidate-dead.md`
```
rid 4자리 비율 : I 68.9% · J 73.3% · M 74.2%   ← 셋이 같은 대역
cksumng        : I 3.73% · J **0.87%** · M 4.10%  ← J 만 4~5배 낮다
→ ❌ rid 자릿수 분포는 창 J 를 설명하지 못한다 (누락률도 J 0.21% ≈ M 0.16% 로 설명 못 함)
```
> 🔴 **후보를 하나 줄인 것뿐이다. 남은 후보에 무게가 실리지 않는다.**
> `❌` 가 이제 여섯이라 **"남은 게 답"으로 읽힐 압력이 그만큼 커졌다** — 그래서 문서 머리에 그 경고를 박았다.
**결론 범위**: *"크기 축이 창 J 를 못 만든다"* 까지다. *"크기 축이 `cksumng` 과 무관하다"* 는 **안 쟀다.**

## 4. 부수 소득 — 교차 확인 하나
```
[CKSUM NG] 줄 수 = 장치 [CNT] 의 cksumng 값 : 창 I 150=150 · J 33=33 · M 165=165
```
**내 로그 파서와 장치 자신의 계수다. 맹점을 공유하지 않는다** — 앞으로 갈리면 계측기를 의심할 근거가 된다.
