## 1. 🔴🔴 루트의 첫 요청서가 틀렸다 — **사용자가 정정했다. 이 절이 정본이다**

> 사용자 원문: *"더 많은 자리는 별개이다. **새 노드는 디바이스이다. n 은 주차자리이다.**
> **주차자리와 디바이스노드는 개별구조이다. 연결되지 않는다.**"*

**루트가 *"새 노드가 합류해서 자리가 늘어난다"* 라고 썼다. 그것이 틀렸다.**

```
❌ 루트가 쓴 것 : 노드 추가 → 자리 증가        (둘을 하나로 묶었다)
✅ 정본         : **디바이스 노드**와 **주차 자리** 는 **개별 구조다. 연결되지 않는다**
                  노드를 늘려도 주차 자리는 안 늘어난다
```

### 🔴 그런데 **지금 코드가 정확히 그 잘못된 결합을 하고 있다** (루트가 값으로 확인)

```
server.cpp:3459  park.reg_drain = atoi(f[2]);      ← 🔴 **장치가 `D,*,drain,n` 으로 n 을 선언한다**

```
> ### **지금은 "주차장에 자리가 몇 개인가"를 *장치가* 말한다.**
> ### **주차 자리 수는 주차장의 성질이지 거기 붙은 아두이노의 성질이 아니다.**

⚠ **네 TODO 가 이미 그 냄새를 맡고 있었다**:
> *"모듈-자리 결속이 지금 **이름 기반**이다(`name` == 자리 `id`). **설정이 대체하면 이 종속이 사라진다**"*

**사용자가 가리킨 것이 바로 그 종속이다.** 다만 **설정 적재를 지금 다 하라는 뜻은 아니다** —
아래 범위를 지켜라.

## 1-B. 🔴 **확정 지형 — 사용자가 값으로 정했다. 이것이 정본이다**

> 사용자: *"주차장은 서버 코드로 관리되고 **5개의 주차영역**을 선언, 5개의 주차영역에 각 아두이노
> 내부에 선언된 **모듈들을 맵핑**하여 **주차영역이 모듈을 갖는 방식**으로 개선하라고 했는데
> 적용이 되지 않은 것인가?"* / *"주차영역이다. **입/출 을 포함하면 7개의 영역이다.**"*

```
영역1 ← A1, B1        영역4 ← A4, B4
영역2 ← A2, B2        영역5 ← A5, B5
영역3 ← A3, B3
입구  ← E1            출구  ← X1
= 🔴 **7개 영역** · 장치 모듈 12개 전부 배정 · **한 주차영역이 모듈 2개를 갖는다**
```

### 지금 코드는 이렇다 (루트가 값으로 확인)

```
✅ 들어간 것 : struct Zone 에 `std::vector<std::pair<devid,name>> modules` 가 **이미 있다**
               (server.cpp:833 · 주석에 "**name 만 쓰면 안 된다**" 까지 박혀 있다)
               주차장이 서버 코드로 관리된다 — build_default_zones()
🔴 안 된 것 ① : 영역이 **7개가 아니라 12개**다 (주차 10 = 자리 1개당 영역 1개 + E1 + X1)
🔴 안 된 것 ② : 결속이 **이름 일치**다 — 코드 주석이 스스로 임시라고 적고 있다:
               *"결속 규칙은 지금 **부트스트랩**이다: 모듈 name 이 자리 id 와 같으면 붙는다 …
                 🔴 **설정이 생기면 이 규칙을 설정이 대체한다**"*
               → 자료구조는 1:N 인데 **규칙이 1:1 을 강제한다**
🔴 안 된 것 ③ : 장치가 `D,*,drain,n` 으로 **n(주차 자리 수)을 선언한다** (server.cpp:3459)
```
> ### **그릇은 만들었고 내용물 규칙이 옛것이다.**
> ### **그래서 이건 구조 재작성이 아니라 *지형 정의 + 결속 규칙 교체* 다.**

### 🔴 그리고 이것이 **자리 점유 판정을 바꾼다** — 여기가 진짜 설계 지점이다

**한 영역에 센서가 둘이면 "그 영역이 점유인가"는 새 물음이다.**
```
· 둘 다 1 이어야 점유인가 · 하나만 1 이어도 점유인가 · 하나가 죽으면?
· 🔑 **설계 문서에 이미 자리가 있다** — §3.5 가 *"자리가 여러 모듈에 걸칠 때"* 를 다루고
  `ok/total`·`missing[]` 을 준다(DESIGN 1337행). **새로 짓지 말고 그 절을 쓰고, 없으면 채워라**
· ⚠ 그 절이 **"확정·미구현"인지 "확정·구현됨"인지 표지를 박아라** — 우리가 이미 밟은 부류다
```

### ⚠ 하행 주소는 **바뀌지 않는다** — arduino 축을 안 건드린다

전선 하행(`R`·`C`·`T`·`M`·`G`)은 **모듈/자리 번호로 주소를 정한다.** 영역은 **서버 개념**이다.
🔑 **그러니 이 변경으로 전선이 안 바뀌고 굽기도 필요 없다.** 대신 **영역 단위 명령이 오면
서버가 그 영역의 모듈들로 펼쳐야 한다** — 그 펼침 규칙을 명세에 적어라.
**틀리면 arduino 에 물어라. "안 바뀐다"를 내 말로 받지 말고 네 코드에서 확인해라.**

## 1-A. 이번 범위 — **좁게 잡는다**

```
✅ 이번에 한다 : ① **7영역 지형**(위 표) · ② **결속을 이름 일치 → 명시 매핑으로**
                 ③ **장치의 `n` 선언과 주차 자리 수의 결합 끊기**
                 ④ map<devid,Node> · 가상 아두이노 — **①②③ 이 됐는지 확인하는 수단**
❌ 이번에 안 한다 : **영역 수를 늘리는 것**(사용자: *"더 많은 자리는 별개이다"*)
                 설정 **파일** 적재(지형은 코드로 선언해도 된다 — 사용자: *"서버 코드로 관리"*)
```
🔴 **판별자 둘**:
```
① 영역이 **7개**이고 영역1 이 모듈 **둘**(A1·B1)을 갖는가        ← 지형·결속
② 가상 아두이노를 붙였을 때 **영역 수가 7 그대로인가**            ← 분리
   변하면 아직 묶여 있는 것이다
```
**둘 다 시험 인스턴스의 `state`·기동 로그에서 *값으로* 보여라.** selftest 통과로 갈음하지 마라.

### ⚠ 그러면 `D,*,drain,n` 의 `n` 은 무엇이 되는가 — **네가 정하고 명세에 적어라**

**한 가지가 아니다. 갈라서 이름을 붙여라:**
```
· 주차장의 자리 수        ← 주차장의 성질. 장치가 말할 것이 아니다
· 그 장치가 붙인 모듈 수  ← 장치의 성질. 지금 n 이 사실상 이것도 겸하고 있다
· drain 유도에 쓰는 값    ← 장치 성질(BATCH_CAP·S_worst·rid 폭에서 나온다)
```
🔑 **한 이름이 세 가지를 겸하고 있으면 갈라야 정본이 생긴다.** 우리 §"같은 문서 안에서도" 그대로다.
⚠ **arduino 축에 닿는다면 알려라** — 전선 의미가 바뀌면 그쪽이 같이 움직여야 한다.

## 2. 🔴 이름을 **네가 먼저 박아라** — 병렬 발행의 비용을 줄인다

이 변경은 **web(화면 격자)·monitor(분모 정의)에 그대로 번진다.** CLAUDE.md §"병렬로 도는 설계 작업"
그대로다 — **셋이 같은 개념에 다른 이름을 붙이면 그 뒤로 문서마다 다른 말을 한다.**

**그러니 순서를 준다:**
```
① socket 이 명세에 이름을 박는다  ← 지금. 다른 도메인은 착수하지 않는다
② 루트가 그 명세를 web·monitor 에 참조로 넘긴다
```
**이름을 지어야 하는 것들**(빠진 것이 있으면 네가 채워라):
```
· 노드 목록을 화면에 어떻게 주는가 (키 이름·타입·전달 시점)
· 자리 id 의 유일성 — A1 이 두 노드에 다 있으면? **전역 유일인가 노드 안에서만인가**
· 노드가 사라졌을 때 그 자리들의 상태 (없어지는가 · 남아서 offline 인가)
· 🔴 **자리 추가/삭제를 화면이 언제 어떻게 아는가** — 접속 시 1회인가 변경 시 밀어주는가
  ⚠ §"전달 시점도 빈 자리다" — 안 적으면 받는 쪽이 가장 편한 시점을 고른다
```

## 3. `first-S-wins` 를 어떻게 할 것인가 — **정하고 적어라**

지금은 **첫 `S` 를 보낸 장치가 유일한 주차 노드**다. 다중 노드가 되면 그 규칙의 뜻이 바뀐다.
```
· 모든 devid 를 받아들이는가?  → 그러면 조원 보드가 섞여 들어오는 위험이 돌아온다
· 허용 목록(`--node-allow`)을 두는가?
· 🔴 **관측 요건이었다는 것을 잊지 마라** — CLAUDE.md §"식별자가 고유하지 않으면 관측이 성립할 수 없다"
  08-18 에 `devid` 충돌 여부를 가리는 데 반나절이 들었다
```
**루트 의견**: 시험 노드는 **명시 허용**이 안전하다. 다만 **네 판단이 우선이고 근거를 적어라.**

## 6. 완료 기준


⚠ **`3b` 의 알려진 함정을 네가 이미 적어 뒀다**: *"접근자로 바꾸면 인라인 여부가 달라져
