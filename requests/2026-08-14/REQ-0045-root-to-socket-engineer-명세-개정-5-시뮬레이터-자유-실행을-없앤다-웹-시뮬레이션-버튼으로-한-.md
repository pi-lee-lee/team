# REQ-0045 · 명세 개정 5: 시뮬레이터 자유 실행을 없앤다 — 웹 '시뮬레이션' 버튼으로 한 걸음씩

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

## 사용자 요구 (실물에서 나온 것)

> 시뮬레이션 데이터가 계속해서 주입되고 있다. 해당 구조는 **화면 전환이 너무 빨라 테스트가 되지 않는다.**
> 웹 화면에 **시뮬레이션 버튼**을 만들고, 그 버튼을 누르면 자리 현황이 랜덤하게 바뀌도록 해 달라.

즉 **자유 실행을 없애고 명시적 트리거로 바꾼다.** REQ-0043/0044(무장 중 시뮬 정지)는 이걸로 철회했다 —
자유 실행이 없으면 멈출 대상이 없고, 오히려 무장 중에 버튼을 막게 된다.

## 이 요청의 범위 — 명세만

`docs/net/parking-protocol.md` 개정판만 쓴다. `server.cpp` 는 아직 건드리지 마라.
얼면 아두이노·서버·웹에 병렬로 요청이 나간다. REQ-0016·0028 때와 같은 순서다.

## 루트가 정한 것

### 1) 시뮬레이터는 스스로 전진하지 않는다

지금 `simAdvance()` 가 칸마다 타이머를 두고 알아서 뒤집는다. **그 자율 전진을 없앤다.**
센서가 없는 칸의 값은 **트리거를 받을 때까지 그대로 유지**된다.

**근거를 명세에 적어라**: 센서가 없으면 자리 상태는 원래 안 바뀌는 것이 정직하다.
지금까지의 자율 변화는 "주차장처럼 보이게" 하려던 연출이었고, 그 대가로 **시험이 불가능**해졌다.

### 2) 전진은 웹에서 내려오는 트리거로만

```
브라우저 [시뮬레이션] 버튼 → 서버 → 아두이노 → 한 걸음 전진 → 다음 S 프레임에 반영
```

**한 번 누르면 한 걸음이다.** "한 걸음"이 정확히 무엇인지 네가 정하고 명세에 못 박아라 —
칸 하나만 바뀌는 것이 시험에 가장 좋다고 본다(무엇이 바뀌었는지 눈으로 따라갈 수 있다).
여러 칸이 한꺼번에 바뀌면 지금 문제가 그대로 재현된다. 다르게 정하려면 근거를 적어라.

### 3) 테스트 모드와 **별개**다 — 이게 요구의 핵심이다

사용자가 "테스트 모드와 별개로"라고 명시했다. 이유가 있다: **무장하면 화면이 빨간 경고로 덮인다**(§12A.6).
평상시 시연에서 그 경고를 감수하지 않고도 데이터를 통제하고 싶다는 것이다.

- 시뮬 트리거는 **무장 여부와 무관하게** 동작한다
- 시뮬로 바뀐 값은 **주입값이 아니다** → `tmask` 에 넣지 마라. 무장 경고도 뜨지 않는다
- 실물 센서가 배정된 칸(`srcReal`)은 트리거의 영향을 받지 않는다 — **그건 진실이고 사람이 흔들 것이 아니다**

### 4) 전선 설계

`T` 타입에 하위 연산이 이미 있다(`A`/`D`/`S`/`X`). 시뮬 트리거를 거기 얹을지 새 타입을 쓸지
네가 정해라. **판단 근거를 적어라.** 참고로 §2.1 규칙 7 덕분에 모르는 타입은 조용히 버려지므로
옛 펌웨어와의 호환은 어느 쪽이든 깨지지 않는다.

⚠ **`S` 프레임에 필드를 또 붙이지 마라.** 최악 61B / 상한 64B 로 여유가 3B 뿐이다(§2.5).
이번엔 상태를 되돌려 보낼 필요가 없어 보이지만, 필요하다고 판단되면 **먼저 루트에게 물어라.**

### 5) WS 메시지

브라우저 → 서버 트리거를 §5.4 에 추가한다. 기존 `rid` 상관 방식(§4.1)을 그대로 쓴다.
ACK 도 기존 방식이다.

## 판단이 필요하면 만들지 말고 물어라

특히 이것들: 트리거가 연달아 눌렸을 때(연타), 아두이노 미연결 중 눌렸을 때,
"한 걸음"의 정의. 답이 갈리는 것은 루트에게 올려라 — 예약 은퇴 때처럼 나중에 통합에서 갈린다.

**명령을 엮지 마라(a && b).** 하나씩 실행한다.

## 왜 필요한가

시뮬레이터가 자율적으로 계속 바뀌어 화면 전환이 빨라 실물 시험이 불가능하다. 사용자가 실제로 그 문제를 겪고 버튼 방식을 지정했다. 세 도메인(아두이노·서버·웹)이 모두 바뀌므로 명세를 먼저 얼려야 각자 다르게 해석하지 않는다.

### 내가 정한 것과 근거

**① "한 걸음" = 칸 하나** — 루트 권고대로. **무엇이 바뀌었는지 눈으로 따라갈 수 있어야**
시험이 성립한다. 여러 칸이면 지금 문제가 그대로 재현된다.

**② 새 타입 `M` (T 에 얹지 않았다)** — 이유가 셋이다:
- **`T` 는 "테스트 모드 제어"**이고 §12A.2 가 `S`/`X` 에 **무장 안 하면 `result=4`** 를 못 박아 뒀다.
  시뮬 트리거는 **무장과 무관해야 하는데**(요구의 핵심), 같은 타입에 두면 구현자가 무장 검사를
  그대로 붙일 위험이 크다. **"별개"라는 요구가 설계에 드러나야 한다.**
- 프레임이 짧다: `M,60,4B` = **8바이트**(전체 최단). `T` 형식이면 자리표식 때문에 15바이트.
- 규칙 7 로 옛 펌웨어 호환은 어느 쪽이든 유지된다.

**③ ACK 의 `slot` 에 "바뀐 칸"을 실었다** — 필드가 이미 있어 **비용 0**이고,
서버가 로그로 남기고 화면이 "A3 이 바뀌었습니다"를 띄울 수 있다.
바꿀 시뮬 칸이 없으면 `slot="??"`, **`result=5`**(추가 enum — 아래 veto 항목).

**④ 연타는 막지 않는다** — 한 번 누르면 한 걸음이 사용자가 기대하는 동작이고,
합치면 버튼이 고장 난 것처럼 느껴진다. 근거는 계산이다:

| | 바이트(+AT) | 시간 |
|---|---|---|
| `M` 수신 | 9+14 = 23 B | 23.96 ms |
| `A` 송신 | 13+15 = 28 B | 29.17 ms |
| **왕복 1회** | | **53.12 ms** |

초당 5회 연타해도 **26.6%**(하트비트 7.92% 와 별개). 사람 손으로 그보다 빠르기 어렵다.

**⑤ 미연결은 새 규칙을 만들지 않았다** — 예약과 같은 `device_offline`(§7.1).

**⑥ `S` 프레임은 안 건드렸다** — 되돌려 보낼 상태가 없다. 결과는 다음 `S` 의 `occupied` 에
이미 있고 바뀐 칸은 ACK 가 말한다. 여유 3B 라 붙일 자리도 없다.

### ⚠ 루트가 veto 할 수 있는 것 — `result=5` 추가

`result` 에 값을 하나 더 늘렸다(**바꿀 시뮬 칸이 없다**). `result=2`·`4` 때와 같은 성격이라
표시해 둔다. 대안은 "시뮬 칸이 없으면 `result=0` 에 `slot="??"`" 인데,
그러면 **성공과 무동작이 구분되지 않는다** — 버튼을 눌렀는데 아무 일도 안 일어난 것을
화면이 "성공"으로 표시하게 된다. 이 프로젝트에서 반복해서 문제가 된 **"실패가 성공처럼 보이는"**
모양이라 값을 나눴다.

### arduino-engineer 의 지적을 반영한 것 (§12B.2)

**자유 실행을 없애면 `occupied=1 ∧ reserved=1` 을 볼 경로가 같이 사라진다.**
그 조합이 뜨던 유일한 경로가 자유 실행의 "예약되면 몇 초 뒤 입차"였다.
그런데 그건 §1.1 이 정의한 **이 시스템의 성공 상태**이고 데모의 주 서사다.

→ **버튼은 `reserved=1 ∧ occupied=0` 인 시뮬 칸을 우선해서 채우고, 없으면 무작위로 뒤집는다.**

편법이 아니라 **의도를 모델링하는 것**이라고 근거를 적었다 — 버튼이 흉내내는 사건 중
**예약한 자리에 차가 들어오는 것이 가장 의미 있는 사건**이다. 순수 무작위면 평균 열 번쯤
눌러야 보이는데, **도달 가능하지만 사실상 안 보이는 상태는 도달 불가와 실질적으로 같다.**
REQ-0018 에서 같은 조합이 도달 불가라 완료 기준이 철회된 적이 있어 더 그렇다.

### 검증 — 예제 26개 BNF·체크섬·길이 통과 (26/26)

```
예제 26개 · 전체: PASS · 최대 61B · 최단 8B
```

새로 추가한 4줄(`M,60,4B` / `M,65535,7D` / `A,60,A3,0,05` / `A,60,??,5,72`)의 체크섬은
계산해서 넣었고 §2.5 에 검증 결과를 붙였다.

### REQ-0044 정리도 같이 했다

철회된 §12A.8 과 §12A.2 참조 줄을 **제거**했고, §13 개정 5 에 **"이 개정에서 한 번 뒤집힌 것"**
으로 경위를 남겼다. **자유 실행이 왜 없어졌는지 모르면 누군가 "주차장처럼 보이게" 다시 넣는다** —
그러면 이 문제가 통째로 돌아온다.
