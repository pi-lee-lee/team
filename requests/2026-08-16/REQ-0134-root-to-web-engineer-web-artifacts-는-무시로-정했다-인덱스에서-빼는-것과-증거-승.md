# REQ-0134 · web/artifacts 는 무시로 정했다 — 인덱스에서 빼는 것과 증거 승격은 네가

**요청자** `root` → **담당** `web-engineer`

## 요청 내용

# 판단 회신 — `web/artifacts/**` 는 **무시한다.** 인덱스에서 빼는 것은 네가 해라

네가 올린 판단 요청에 답한다. **무시로 정했다.**

## 근거 — 기준은 하나, "원본에서 다시 만들 수 있는가"

이 저장소는 그 기준 하나로 `.gitignore` 를 운영한다(`monitor/out/` 결정과 같은 규칙).
`web/artifacts/**` 는 **한 번에 약 670KB 이고 `e2e.mjs` 를 돌릴 때마다 전량이 새
바이너리로 바뀐다.** 추적하면 실행 횟수만큼 저장소가 부풀고 diff 는 읽을 수 없다.

**규칙은 루트가 넣었다** — `.gitignore` 에 `web/artifacts/` 와 함께 사유 주석까지
커밋했다(`98262a3`). `.gitignore` 는 루트 소유라 내가 했다.

## 🔴 그런데 무시만으로는 추적이 안 끊긴다 — 이 부분이 네 일이다

앞선 커밋(`45b2ee7`)에서 이미 추적에 들어갔다. **무시 규칙은 추적되지 않는 파일에만
적용되므로**, 지금 상태로는 규칙이 있어도 계속 커밋된다.

내가 `git rm -r --cached web/artifacts/` 를 치려다 **소유권 훅에 막혔다**(정당한 판정이다 —
`web/**` 는 네 영역이다). 그래서 너에게 넘긴다.

```
git rm -r --cached web/artifacts/
```

⚠ **`--cached` 를 빼지 마라.** 인덱스에서만 빼는 것이고 **작업트리 파일은 그대로 남는다.**
빼먹으면 실제로 지워진다. 실행 후 `ls web/artifacts/ | wc -l` 로 파일이 남아 있는지
확인하고 커밋해라.

## ⚠ 그리고 이것이 이 결정의 진짜 조건이다 — **"재생성 가능"은 지금 조건에서만 참이다**

네가 "지우면 `e2e.mjs` 재실행으로 다시 만든다"고 했는데, 그 말은 **오늘 밤의 서버와
오늘 밤의 화면 코드**에서만 참이다. socket 이 REQ-0132 의 결함 셋(특히 `/?demo=1` 404,
`last_frame_ts` 부재)을 고치면 **같은 스크립트가 다른 그림을 낸다.**

즉 지금 `web/artifacts/` 안에 있는 것은 **"고치기 전 상태의 유일한 증거"** 이기도 하다.
그건 재생성 가능한 산출물이 아니라 **결론**이다.

이 저장소의 규약이 그 자리를 이미 다룬다:

> **결론이 될 만한 것을 `out/` 에 두지 마라. 날짜 붙은 파일로 승격시켜라.**

### 그래서 네가 할 일 둘

1. **측정값과 판독은 이미 승격돼 있다** — `docs/web/FINDING-browser-leg-2026-08-16.md`
   가 추적 중이다. 205ms, 2ms, 5개 사례, 33 pass / 1 fail 같은 숫자가 거기 있으면
   그림이 사라져도 결론은 안 사라진다. **빠진 숫자가 있으면 지금 채워 넣어라.**

2. **그림이 정말 필요한 것만 골라 승격해라** — `docs/web/evidence-2026-08-16/` 를 만들고
   **최대 3장**만 복사해라. 각 장에 한 줄 설명을 FINDING 문서에 달아라.
   - 고르는 기준: **고쳐지고 나면 다시 못 찍는 그림인가.**
   - 내 추천은 `3-reserved.png`(예약이 화면에 반영된 순간) · `6-ws-cut.png`(소켓이
     끊겼을 때 화면이 말하는 모습) 둘이다. 세 번째는 네가 판단해라.
   - **전부 올리지 마라.** 3장이면 약 120KB 이고, 한 번만 들어가고 다시는 안 바뀐다.

## 참고 — 이번 검증에 대해

브라우저 구간이 **진짜 크롬 + 진짜 마우스 이벤트**로 동작하는 것을 확인한 것,
시연 경로에서 유일하게 안 재본 구간이 이걸로 닫혔다.

특히 **"처음부터 WS 없음"과 "잘 되던 소켓이 끊김"을 다른 사건으로 나눠 잰 것** —
지시에 없던 구분이고, 네 말대로 **후자가 시연에서 무서운 쪽**이다. 안 나눴으면
"폴백 된다"로 뭉뚱그려 끝났을 자리다.

그리고 **내 전제를 고친 것**(`slots[]` 이 이미 `상태 미상 / 데이터 없음` 으로 갈리고
있었다)도 접수했다. 내가 인수인계 문서의 옛 문장을 확인 없이 지시로 옮겼다.
진짜 빈틈이 **"그 말이 칸 안에만 있다"** 였다는 것 — 10칸 중 3칸만 미상이면 화면
전체는 멀쩡해 보인다 — 는 내가 지시할 수 없었던 종류의 발견이다.

⚠ `205ms` 를 실물 ESP 기대값으로 옮겨 쓰지 말라는 경고, 그대로 유지해라.
로컬 `fake_arduino` 기준이라는 것을 숫자 옆에 항상 붙여라.

## 왜 필요한가

무시 규칙만 넣으면 이미 추적 중인 파일은 계속 커밋된다. 그리고 지금 산출물은 서버 결함이 고쳐지기 전 상태의 유일한 증거이기도 해서, 그냥 버리면 오늘 밤 검증을 재현할 수 없다.
