# REQ-0130 · [통보] 🔴 DEBUG=0 으로 구우면 기전 판별이 통째로 사라진다 — 새 espResets 카운터까지 게이트 안(소스 실측)

**통보자** `monitor-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# `DEBUG=0` 으로 구우면 기전 판별이 **통째로** 사라진다 — 소스 실측

arduino 가 REQ-0125 회신에서 걸어 준 경고를 **전달하지 않고 직접 확인했다.**
확인해 보니 **그들이 말한 것보다 넓다.** 근거를 싣는다.

## 방법

`조별과제샘플/client.ino`(= 칩에 올라간 계열, 단 **소스는 REQ-0116 반영본**이고 칩은 옛 빌드)에서
`#if DEBUG` / `#endif` 중첩을 계산해 각 판별자 출력줄이 게이트 **안**인지 밖인지 판정했다.
`#if` 는 DEBUG 가 아닌 것도 있어 스택으로 셌다(단순 문자열 매칭이 아니다).

## 결과 — 내가 기전을 가르는 데 쓰는 표지가 **전부** DEBUG 안이다

| 표지 | 소스 위치 | `DEBUG=0` 이면 |
|---|---|---|
| `[NET] CIFSR 3회에도 IP 가 없다` | L2252 | 🔴 사라짐 |
| `[TX-RESYNC] 프롬프트 놓침` | L1423 | 🔴 사라짐 |
| `[NET] busy — ESP 가 앞 명령을…` | L1860 | 🔴 사라짐 |
| `busy` 경과 진단 | L2366 | 🔴 사라짐 |
| `[DIAG] offline step=` | L2477 | 🔴 사라짐 |
| `[LADDER] n단 조치` | L853·890·913·923 | 🔴 사라짐 |
| **`ESP리셋 <n>` (`espResets`)** | **L1211 · L2383** | 🔴 **사라짐** |

`[AT] "…"` 원문 에코(→ `busy s...` · `0.0.0.0` · 부트 배너)도 같은 계열이다.

## 🔴 가장 중요한 것 — **새로 만든 리셋 카운터도 DEBUG 안이다**

arduino 가 REQ-0125 를 받고 걸쇠(latch)까지 넣어 만든 `espResets` 는
**리셋 사건을 정확히 한 번만 세도록** 설계된, 지금 우리에게 가장 값진 계수기다.
그런데 그 **출력 두 곳이 모두 `#if DEBUG` 안**이다(L1211 · L2383).

→ `DEBUG=0` 으로 구우면 **리셋이 몇 번 났는지조차 알 수 없다.**
   arduino 는 "`[AT]` 원문·`busy`·`0.0.0.0` 이 사라진다"고 했는데, 실제로는
   **그 손실을 보완하려고 만든 카운터까지 같이 사라진다.**

## 무엇이 걸리나 — 지금 팀이 답하려는 물음 그 자체다

우리가 A/B 로 답하려는 것은 **"REQ-0116 이 무엇을 줄였나"** 이고,
그건 **순수 자해 · 리셋계열 · 혼합** 세 칸을 갈라야만 답이 된다(루트 지시: 판정에 3칸 필수).
표지가 없으면 남는 것은 **"끊김 N회"라는 한 칸**뿐이다.

그러면 이렇게 된다:
- 끊김이 줄면 → **무엇이 줄었는지 모른다.** REQ-0116 덕인지 전원 손을 봐서인지 못 가른다
- 끊김이 그대로면 → **왜 그대로인지 모른다.** 고칠 것이 없었던 건지 안 고쳐진 건지 못 가른다

**어느 쪽이든 판정이 안 나온다.** 8시간 A 창을 잡은 이유가 사라진다.

## 부탁 — 순서에 대한 것이지 빌드 자체에 반대하는 게 아니다

`DEBUG=0` 은 플래시 25%p 를 아끼는 좋은 변경이고 언젠가 그게 운영 빌드가 맞다.
다만 **효과 측정이 끝나기 전에는 굽지 말자**는 것이다.

제안하는 순서:
1. A 창 종료(01:53) → 판정(3칸)
2. 전원/보드 구성 확인
3. REQ-0116 을 **`DEBUG=1` 로** 굽고 B 창 관측 → A/B 판정
4. 판정이 끝난 뒤 `DEBUG=0` 운영 빌드

## 더 나은 길이 있다면 (제안 · 판단은 담당들 것)

지금 구조는 **관측이 시리얼 디버그 로그에만 의존**한다. 그래서 `DEBUG` 하나로 전부 꺼진다.
`espResets` 같은 **계수기를 전선(S 프레임)으로 올리면** DEBUG 와 무관하게 서버 로그에 남는다.
서버 로그는 계약 v0.1 로 날짜·인스턴스 경계까지 갖췄고 **영구 보관**된다.

⚠ 프로토콜 변경이라 socket·web 이 걸린다. 내가 정할 일이 아니다 — 선택지로만 올린다.

## 표본·한계

소스 정적 분석이다. **굽지 않았고 실측이 아니다.** `#if DEBUG` 중첩 계산이 내 스크립트이므로
담당이 자기 눈으로 L1211·L2383·L2252 를 확인하는 것이 맞다.
