## 1. 실물에 가까운 조작 — 프로세스 기동

### 크롬을 여러 번 띄웠다 (헤드리스)

- `--headless=new` · **매번 새 임시 `--user-data-dir`** (사용자 프로필 미사용·미변경)
- 종료 시 프로필 디렉터리까지 지운다. 남는 것 없음
- 붙은 대상은 **시험 인스턴스(:10000) 뿐**이다. 스크립트가 9900·9991·5500 을 인자로 받으면
  **실행을 거부**하도록 박아 뒀다
- 사용자의 크롬 창·프로필·로그인 상태는 건드리지 않았다

### 시험 인스턴스에 예약/취소를 **여러 번** 걸었다

`A1` 을 예약했다가 취소하는 왕복을 3회 돌렸다(시험 3회 실행). **매번 취소까지 돌려놨고
지금 10칸 전부 비어 있다.** 시험 로그에 전부 남아 있다.
→ 운영 서버·실물 보드에는 **아무것도 보내지 않았다.**

### 내가 하지 않은 것

- 시험 인스턴스를 **내가 내리지 않는다** — socket 이 띄웠으니 socket 이 내린다
- 운영 프로세스·포트·시리얼 미접촉

## 2. 요청 범위를 넘어 고친 것

### (가) `index.html` 의 WS 포트 결함 — 별도 통보 REQ-0129

브라우저를 열기 전에 반드시 고쳐야 했던 것이다. 자세한 것은 그쪽에.

### (나) `slots[]` 결손 집계 배너 추가 — `#slots-banner`

루트가 준 숙제인데, **전제가 실측과 달랐다.**

- "조용히 10칸이 비어 보인다" → **아니다.** 결손 칸은 이미 `상태 미상 / 데이터 없음` 이다
  (측정 5개 사례, `web/artifacts/probe-slots.json`)
- 진짜 빈틈은 **그 말이 칸 안에만 있다**는 것이었다. 3칸만 미상이면 화면 전체는 멀쩡해 보인다
- 그래서 칸 문구는 그대로 두고 **격자 위에 집계 배너**를 더했다

정상 운영에서는 **뜨지 않는다**(실측으로 확인). 늘 떠 있는 경고는 아무도 안 읽는다.

## 3. 새로 만든 도구 — `web/` 트리를 처음 만들었다

| 파일 | 용도 |
|---|---|
| `web/tools/cdp.mjs` | 최소 CDP 클라이언트 |
| `web/tools/e2e.mjs` | 종단 시험 9단계 |
| `web/tools/probe-slots.mjs` | `slots[]` 결손 측정 |
| `web/tools/check-index.mjs` | 브라우저 없이 도는 정적 회귀 |
| `web/artifacts/**` | 스크린샷·WS 프레임 원문·결과 JSON |

**npm 의존성 0개.** node 22 내장 `WebSocket`·`fetch` 만 썼다. "간단한 웹"이라는 기준을
검증 도구에도 그대로 적용한 것이고, 그러려고 puppeteer 를 안 들였다.

⚠ `web/artifacts/` 는 스크린샷이라 **커밋 대상인지 루트가 정해 달라.**
지금은 그냥 두었다. 지워도 `e2e.mjs` 를 다시 돌리면 재생성된다.

## 4. 앞선 내 판단 중 **틀린 것 하나를 정정한다**

REQ-0128 본문에서 나는 `조별과제샘플/data_log.json` 을 **"git 이 추적하는 파일"** 이라 적고
"시험 뒤 `git checkout` 으로 되돌려야 한다"고 했다. **틀렸다.**

- 그 파일은 `.gitignore:53` 에 있어 **추적되지 않는다**(socket-engineer 가 `git ls-files` 로 정정)
- 원인: 내가 파일 수정시각만 보고 추적 여부를 **확인하지 않은 채** 단정했다
- 원장 §4.3 에 취소선과 사유를 남겼다

같은 맥락으로, socket 이 `fake_arduino.py` 의 `--arrive-sec` 도움말이 낡았다는 것을 알려 왔다.
**내가 도움말만 보고 고른 `--arrive-sec 3600` 은 내 목적과 정반대**였고(3시간 창 한가운데서
예약 은퇴가 터진다), 물어본 덕분에 막혔다. **도구 도움말도 실측 대상이다.**
