# REQ-0121 · 도메인 원장 개설 — 오늘 확정된 것을 monitor/LEDGER.md 에 심어라

**요청자** `root` → **담당** `monitor-engineer`

## 요청 내용

네 정의에 **도메인 원장**(`monitor/LEDGER.md`) 절이 새로 들어갔다. 먼저 읽어라.

요지: 세션은 죽지만 원장은 남는다. 오늘 세 에이전트가 재기동으로 문맥을 통째로 잃었고,
살아남은 것은 파일로 적어 둔 것뿐이었다.

## 이 요청 — 오늘 나온 것을 원장에 심어라

오늘 하루에 뒤집히고 확정된 것이 많은데 **대부분 요청 파일과 판정문에 흩어져 있다.**
그건 사건 기록이지 지식이 아니다. 다음 사람은 REQ 를 처음부터 읽지 않는다.

**"이 도메인에서 시간이 지나도 참인 것"만 골라 옮겨라.** 그날 상태·진행·인수인계는 빼라.
근거(실측인지 추정인지)를 문장에 드러내고, 조건이 붙는 사실은 조건을 같이 적어라.

### 심을 것 — 최소한 이것들 (더 있으면 네가 판단해서 추가해라)

- **`0` 을 만나면 셋을 갈라라: 건강인가 · 미실행인가 · 못 센 것인가.** 2026-08-16 에 셋 다 겪었다.
  하행 0건(=미실행) · 서버 버린줄 0(=못 셈) · `[LINK] closed` 0(=없는 문자열).
- **진행 중인 창의 끝을 미래로 잡지 마라.** 분모에 안 온 시간이 들어가 시간당 값이 희석된다.
  실측 78배. 그리고 **"좋아 보이는" 쪽으로 틀려서 아무도 이의를 제기하지 않는다.**
- **P 값은 방향의 증거로만 읽는다.** 단측 포아송은 사건 독립을 가정하는데, 링크가 나빠지면
  세션종료와 오프라인이 함께 몰려 난다. 군집이 있으면 실제보다 작은 P 가 나온다.
- **표본 수를 항상 같이 적어라.** n=7 중앙값으로 "악화"를 단정하지 않는다.
  같은 자료에서 최댓값은 787.6s → 49.0s 로 좋아졌다.
- **λ 를 모르면 실험을 설계할 수 없다.** 검정력은 `monitor/power_plan.py`.
  λ=2.59/h 면 팔당 8시간에 3배 차이를 80% 로 잡지만, λ=0.5/h 면 24시간에도 56% 다.
  **λ 추정에 다른 구성의 옛 값을 쓰지 마라** — 계획 단계로 들어온 오염이다.
- **비교할 두 구간의 변수를 세라.** 하나가 아니면 그 비교는 **순위를 바꿀 뿐 원인을 지목하지 못한다.**
  (2026-08-16 사례: 펌웨어 계열·프롬프트 제한·DEBUG·캐패시터 넷이 달랐다)
- **집계 출력은 출처를 달고 나가야 한다.** 합성 픽스처는 출력 자체에 인용 금지 표시가 찍히게 한다 —
  사람이 붙일 때 기억하는 것에 의존하면 픽스처가 실물로 읽힌다(실제로 났다).
- **제외한 자료는 건수와 시각을 보여라.** 규칙상 뺀 것도 소리 없이 사라지면 안 된다.
- **도구가 관측 대상을 바꾼다.** `serial_tap` 이 오류마다 3초 간격 무한 재시도라
  사람이 포트를 열면 3초 안에 도로 뺏어 갔다. **포트는 사람이 우선이다.**
- **원시 캡처(`.raw`)는 줄바꿈 정규화에서 빼야 한다**(`.gitattributes -text`).
  커밋에서 CR 661개가 조용히 벗겨진 적이 있다 — 바이트가 증거인 파일이 이름표만 남는다.
- **판정 구간(오염 경계 2026-08-16 15:26 이전)**: 08-15 20:32 → 08-16 10:27 (13.92h),
  08-16 11:27 → 15:26 (3.98h). 13.92h 구간은 **빌드 특정 불가**(계열은 client 로 확정).

### 형식 규칙

- **근거 없이 적지 마라.** 실측이면 수치와 언제·어디서 잰 것인지.
- **조건부 사실은 조건을 적어라.** 조건 없이 단정하면 그게 다음 사람의 함정이 된다.
- **틀린 것으로 밝혀진 통념도 적어라** — 왜 틀렸는지와 함께. 결론만 고치면 다시 그 길로 간다.
- 오늘 철회된 것이 있으면 **취소선과 사유**로 남겨라. 지우지 마라.

## 완료 후

`req.sh done` 하고 루트에 포인터. 앞으로는 발견할 때마다 네가 알아서 append 하고,
갱신했으면 `req.sh notice` 로 알려라.
