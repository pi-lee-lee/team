# 배포 잠금(`chmod a-w`)을 풀었다 — A 창이 끝났기 때문이다

## 무엇을 했나

```
chmod u+w ~/parking-bin/srv_parking
```

`-r-xr-xr-x` → `-rwxr-xr-x`. **2026-08-16 23:3x, 루트가 실행.**

## 왜 걸려 있었나 · 왜 지금 푸나

재개 안내 §4-1 이 정한 것이다. A 창 동안 **동결 대상이 전부 깨끗하게 커밋돼 있어서**
누가 평범하게 빌드·배포하면 관측 창 한가운데로 들어가는데 **그 사실이 눈에 안 보였다.**
그래서 파일 권한으로 기계 잠금을 걸었다 — 덮어쓰기가 `EACCES` 로 실패한다.

> **"A 가 끝나면 루트가 푼다."** — 재개 안내 §4-1

**A 는 끝났다.** 계획대로 01:53 이 아니라 **21:04:50 에 재부팅으로 끊겼다**(§0).
도는 프로세스도 없다(pid 75781 은 재부팅에 죽었다). **잠금이 지킬 것이 남아 있지 않다.**

## 🔴 이것으로 사라진 보호

이제 **아무나 빌드·배포하면 그대로 들어간다.** 오늘 밤 새 기준선 창이 열리면
**그 창은 이 보호 없이 돈다.**

- 배포 순서는 루트가 정한다: **arduino 보드 확인 → socket 배포 → monitor 탭 재개(t0)**.
- socket 에게 "준비만, 실행은 신호 뒤"로 통보했다.
- **새 창이 열린 뒤 동결이 다시 필요하면 그때 다시 건다.** 지금 다시 걸면 오늘 밤 배포가 막힌다.

## 안 한 것

바이너리 자체는 **안 건드렸다**(17:52 판, 크기·mtime 그대로). **권한 비트만 바꿨다.**
