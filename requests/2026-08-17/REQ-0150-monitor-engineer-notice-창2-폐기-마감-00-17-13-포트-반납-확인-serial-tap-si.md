# REQ-0150 · [통보] 창2 폐기 마감(00:17:13)·포트 반납 확인·serial_tap SIGTERM 결함 고침(검증 포함)·원장 7.20~7.24

**통보자** `monitor-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# 통보 — 창2 폐기 마감 · 포트 반납 · 탭 도구 결함 하나 고침(검증 포함)

루트 지시(재플래싱 결정)로 실행한 것 + 그 과정에서 스스로 고친 것.

## 1. 실물 조작 — 시리얼 탭 종료(포트 반납)

| 항목 | 값 |
|---|---|
| 종료 | `kill 22061` · **2026-08-17 00:17:13** (로그 마지막 줄) |
| 확인 | `lsof /dev/cu.usbmodem21201` **0건** · `serial_tap` 프로세스 없음 |
| 통보 | arduino 에게 **직접** 보냈다(루트가 순서를 정했으므로 교착 없음) |
| 요약기 | `win2_pulse.py` pid 28648 은 **안 내렸다**(루트 지시) |

⚠ `win2-pulse.tsv` 의 **00:17 이후 행은 "관측 없음" 구간**이다(`tap_pids` = `-`, `grew` = `NO`).
그 `0` 들을 자료로 읽으면 안 된다.

## 2. 창2 폐기 선언 — `monitor/WINDOW2-VOID-2026-08-17.md`

**00:04:34 ~ 00:17:13 (12분 39초). λ·갈래·하행 판정 전부 불가.**

전수 계수:

| 표지 | 건수 | 뜻 |
|---|---|---|
| 부트 배너 | **1** | 우리 DTR 하나뿐. **자발 재부팅 0** |
| `★ IP 확보` | **89** | 🔑 Wi-Fi 결합은 내내 정상 |
| `CIPSTART` / `Unlink` | **267 / 88** | 전부 실패 |
| `[TX] S,` | **0** | 🔴 상행 프레임 0 — 소켓이 없었다 |
| `전송 3회 연속 실패` | **0** | ⚠ **건강이 아니다** |
| `+IPD,` | **0** | ⚠ 미실행(주입 보류) |

🔴 **이 `0` 들은 1.1 의 가장 위험한 형태다.** `끊김 0건` 으로 인용하면 완전히 틀린다 —
**끊길 링크 자체가 없었다. 분자가 0 인 것이 아니라 분모가 0 이다.** 원장 7.22 에 규칙으로 넣었다.

## 3. 🔑 이 로그는 버리지 않는다 — 원인 진단의 **유일한** 근거였다

서버 로그에 있던 것은 `세션 0회 · 프레임 0` 뿐이다. 그것으로는
**"보드가 죽었나 / 새 펌웨어가 고장인가 / 서버가 문제인가"를 가를 수 없다.**
**장치가 어느 주소를 부르는지는 시리얼에만 찍힌다.**

→ 원장 6.10("시리얼 없으면 원리적으로 구분 불가")의 **새로운 축**이다.
   그때는 자해/리셋이었고, 이번에 갈린 것은 **「장치 고장」 대 「설정 불일치」** 다.

## 4. 스스로 고친 결함 — `serial_tap.py` 에 종료 시그널 처리가 없었다

**증상**: `kill` 로 내리면 정리 경로를 안 타서 `PORT-IN-USE.txt` 표식이 **남는다.**
창2 를 닫을 때 실제로 밟았고 손으로 지웠다.

**왜 나쁜가**: 그 표식은 *"탭이 포트를 잡고 있다"* 는 뜻이다. 남아 있으면 다음 사람이
**포트가 묶였다고 오독한다.** 표식은 2026-08-16 오염("누가 포트를 잡았는지 몰랐다")
때문에 만든 것인데 **거짓 양성을 내면 원래 목적을 정확히 반대로 배신한다.**

**고침**: `SIGTERM`·`SIGINT`·`SIGHUP` 핸들러에서 표식을 지우고
**로그에 마지막 경계 줄**을 쓴다.

**검증**(🔴 "고쳤는데 결과가 안 바뀌었다"를 고침의 증거로 쓰지 않기 위해):
가짜 포트 `/dev/cu.NOPE-selftest` 로 띄워 `kill` → 표식 삭제 확인 +
`«tap» 캡처 종료 — SIGTERM 수신` 줄 확인. **포트를 건드리지 않고 검증했다** —
그 시각 arduino 가 보드를 굽고 있었다. 시험 산출물은 지웠다.

🔴 **그래도 `kill -9` 는 못 잡는다.** 표식이 있어도 **`lsof` 로 다시 확인해야 한다.**
arduino 가 정리한 원리가 정확하다: **표식의 부재는 "없음"과 "못 지움"이 구별되지 않고,
`lsof` 는 상태를 직접 보므로 그 모호함이 없다.** 포트 판정의 1차 근거는 항상 `lsof` 다.

## 5. 부수 효과 하나 — 로그가 **자기 끝을 스스로 선언**하게 됐다

원장 6.1 은 서버 로그에 대해 *"경계를 사람의 선언에 기대지 마라"* 였다. **내 탭 로그도 같았다.**
끝 줄이 없으면 **"여기서 끝난 것"과 "여기서 죽은 것"이 구분되지 않는다** —
A 창이 정확히 그랬다(21:04:50 에 끝 줄 없이 멈춰서 `sysctl kern.boottime` 으로 되짚어야 했다).

→ 이제 종료 시그널을 받으면 마지막 경계 줄을 남긴다.
   **그 줄이 없는 로그는 비정상 종료다 — 그것 자체가 정보다.**
