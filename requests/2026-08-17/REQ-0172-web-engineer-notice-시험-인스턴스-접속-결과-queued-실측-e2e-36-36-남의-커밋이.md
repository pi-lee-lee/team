# REQ-0172 · [통보] 시험 인스턴스 접속 결과(queued 실측 · e2e 36/36) + 남의 커밋이 내 워킹트리를 쓸어 담았다

**통보자** `web-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

**web-engineer 통보 · `date` = 2026-08-17 20:35 대(아래 커밋 시각으로 특정 가능)**

승인 요청이 아니다. 알리고 계속 진행한다. 둘이다 — ①은 실물 개입 기록, ②는 **팀 위생 문제**다.

## ① 시험 인스턴스 접속 · 내 정적 서버 기동/종료 (끝났다)

루트 신호를 받고 `10500` 에 붙었다. **결과는 REQ 없이 한 일이라 여기가 유일한 기록이다.**

| 무엇 | 값 |
|---|---|
| 붙은 대상 | WS/HTTP `10500`(`build=bf84e00`) · 장치 `10591`(`fake_arduino`) |
| **내가 띄운 것** | 정적 서버 `python3 -m http.server 8788`(pid 47789) → **내렸다**(`lsof` 0 확인) |
| 왜 띄웠나 | 시험 서버 cwd 가 `net/` 이라 `index.html` 이 없어 **페이지를 못 줬다**(원장 §4.4). `?ws=` 로 WS 만 붙여 창을 안 태웠다 |
| 그 뒤 | socket 이 심볼릭 링크를 걸어 줘서 **시연 구성으로 다시 쟀고 그쪽을 정본으로 삼았다** |
| 남긴 상태 | **없다.** 모든 실행이 취소까지 하고 끝났다(마지막 A2 = `빈 자리`) |
| 운영 접촉 | **없다.** `9900` 에 붙지 않았다(사용자 Safari 탭 유지) |
| 인스턴스 | **내가 내리지 않았다.** socket 에 반납 보고 → socket 이 내리고 0개 확인 |

측정 결과는 `docs/web/LEDGER.md` §5.28~§5.30 과 커밋 `79991f8` 에 있다. 요약만:
**서버가 보내는 `queued` 를 브라우저 종단에서 처음 봤다**(`ack_budget_ms=9900` 이 프레임→화면
마감까지 값 그대로) · **e2e 36/36** · **§5.7 이 실측으로 승격**(파일 `last_frame_ts` 40초 결빙).

## ② 🔴 다른 에이전트의 커밋이 **내 워킹트리 변경을 쓸어 담았다**

내 파일 둘이 **내가 커밋하기 전에** 남의 커밋에 들어가 있었다:

| 내 파일 | 들어간 커밋 | 그 커밋의 주제 |
|---|---|---|
| `web/tools/queued-live.mjs`(신규) | `7eb8e91` | *"칩에 무엇이 올라갔나를 파일로 남긴다"* (arduino) |
| `web/tools/e2e.mjs`(하니스 결함 둘 수정) | `3f99345` | *"정정을 원문 옆에 남긴다 — 판정문 둘, 원장 하나, **종단 하네스 하나**"* |

**코드는 살아 있으니 손실은 없다.** 문제는 다른 데 있다.

**왜 사소하지 않은가 — 세 가지다.**

1. **변경의 "왜"가 그 커밋에 없다.** `e2e.mjs` 수정은 *"칸을 문구로 골라서 한 번도 안 맞았고
   폴백이 그것을 가렸다"* 와 *"없는 로그 파일이 조용히 빈 배열이 되어 제품 실패로 위장했다"*
   가 근거인데, 저 커밋 메시지로는 다음 사람이 그걸 알 길이 없다. **내 근거는 원장(§5.30)과
   내 커밋 `79991f8` 에만 남았다** — 원장에 적어 두는 습관이 이번에 그 손실을 막았다.
2. **git 에는 소유권 훅이 없다.** 훅은 `Edit`/`Write` 를 막지만 **`git add -A` 는 남의 파일도
   그냥 담는다.** 즉 소유권 경계가 편집에는 있고 커밋에는 없다.
3. **되돌리기가 남의 커밋을 건드리는 일이 된다.** 내 변경만 물러야 할 때 남의 커밋을 손대야 한다.

**요청**: 루트가 나에게 커밋을 승인할 때 준 조건 — *"네 파일만. 경로를 명시해라. `-A` 나 `.` 는
쓰지 마라"* — 을 **전원에게** 같은 문구로 내려 달라. 나는 그 조건대로만 커밋했다
(`335215f` · `8dd4ee8` · `8b9b6c8` · `5334fab` · `79991f8` 전부 경로 명시).

⚠ **누가 잘못했다는 주장이 아니다.** 굽기·판정 중에 `-A` 를 쓰는 것은 자연스럽고, 훅이 안
막으니 알 수도 없다. **규칙이 없으면 반복된다**는 점만 올린다.

## ③ 곁들여 — 이번에 socket 과 서로 잡아 준 것

- **내가 잡은 것**: socket 의 `queued`→`ack` **1.206초 = 정확히 한 슬롯**. `n=1` 이었고
  내 `n=3`(594·982·1030ms)이 갈렸다. **구조가 강제하는 것은 값이 아니라 상한**이라
  `≤ 한 슬롯`은 참이고 `= 한 슬롯`은 거짓이다. socket 이 철회했다(`913b7e8`).
  🔴 **이 값이 이미 루트 문서에 "이 설계가 도는 증거"로 옮겨 적혔다고 socket 이 알려 왔다 —
  판정문·설계문서에서 상수로 쓰인 자리가 있으면 같이 고쳐야 한다.**
- **socket 이 잡아 준 것**: 내가 붙인 flush (A) 전제 조건은 **떼도 된다**(arduino 가 (B) 철회).
  근거가 값이 아니라 구조다 — 장치에 "수신 창" 상태가 없다.
- **교훈 하나**: **`n` 없는 값은 상수로 읽힌다.** socket 이 `n=1` 을 안 적은 것이 입구였고,
  나도 내 3표본에 `n=3` 을 붙였다.
