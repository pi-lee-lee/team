# REQ-0176 · 3차 재실행 ① (inj4) — 계측기 수정 후 같은 조건 · 사용자 지시 '3차 진행'

**요청자** `root` → **담당** `socket-engineer`

## 요청 내용

**사용자 지시 2026-08-17: "3차 진행."** 전제가 다 갖춰졌다. 지금 돌린다.

```

✅ 중단 조건 자동 판정 (커밋 8a7b5c3) — 장치 없는 서버에 50건 걸어 정확히 5건 정지 실측
```

## 할 것 — 런북 명령 그대로

`docs/net/RUNBOOK-winB-2026-08-17.md` 에 네가 박아 둔 것:

```
--interval 1.15 --count 300 --slot A1 --ack-timeout 10 --start-delay 0 --rid-prefix inj4
```

🔴 **한 글자도 바꾸지 마라.** 창 A 3차와 **계측기만 다른 상태**여야 대조가 성립한다.
주기·건수·자리·타임아웃·시작지연 전부 동일. 바뀌는 것은 `--rid-prefix` 뿐이다.

## 보고할 것

1. **시작·끝 시각을 monitor 에게 직접** 통보 — 그것이 monitor 의 구간 정의가 된다.
2. **`계획대로 끝났다` / `중단으로 끝났다`** 를 루트에 보고. 요약에 찍게 해 뒀다고 했다.
3. 중단이면 **어느 조건이 발동했는지와 시도 수.**

## ⚠ 자동 정지가 발동할 가능성이 높다 — 그건 실패가 아니다

창 A 3차에서 **링크가 실제로 깨졌다**(오프라인 5회 · 세션 종료 `errno=54` · 상행 공백 10초 ·
`[TX-WAIT] 44%`). **큐는 아직 없다.** 같은 조건이므로 같은 고장이 예상된다.

> **이 회차의 목적은 고장이 안 나는 것이 아니다. `slot3` 계측기로 같은 고장을 다시 보는 것이다.**
> 창 B 에서 큐가 그것을 막는지가 대조 대상이고, **이 회차가 그 대조의 기준선**이다.

**표본이 300 미만으로 끝나면 그 시도 수 자체가 창 B 의 대조값이다.**

## 🔴 대조 가능한 칸 / 불가능한 칸

| ✅ 대조 가능 | `재전송` · `CKSUM NG` · `due` · `smiss` · `skip` |
| 🔴 **대조 불가** | **`oow`** — 정의가 바뀌었다 |

```
slot2 까지 : oow = **처리** 시각이 송신 창 안   ← 위험 구간 도착을 놓친다
slot3 부터 : oow = **도착** 시각이 송신 창 안   ← 처음으로 위험 구간을 본다
```

**`oow` 가 오르는 것은 새 고장이 아니라 보이기 시작하는 것이다. 악화로 읽지 마라.**
monitor 가 창 A 판정문의 `oow 693` 에 폐기 표시를 했고, 이 회차가 `oow` 의 **새 기준선**이다.

🔑 **네 `재전송` 은 계측기 변경과 무관하다**(서버 쪽 계수) — **`slot2`↔`slot3` 을 잇는 유일한 다리**다.
네가 그것을 짚은 것이 맞고, 대조의 중심으로 써라.

## 이 회차가 처음 답하는 것

**`[SLOT-OOW]` 가 도착 시각을 찍는 것은 이번이 처음이다.** 그러므로:

- **위험 구간의 폭이 처음 실측된다.** 폐기된 `[116,171)ms` 를 대체하는 값이 여기서 나온다.
- **진짜 분모**(위험 위상에 착지한 도착 수)가 처음 세어진다 — 창 A 에서는 파괴된 것이 `+IPD` 에
  안 남아 직접 셀 수 없었다.

**그 값이 arduino 의 창 넘침 가드와 네 `cap` 계산의 근거를 교체한다.**

## 배포는 이 회차 판정 뒤다

네 배포 명령을 검증했다 — `server.cpp` 마지막 커밋 `abd3026` · **워킹트리 깨끗** · HEAD `70115bc`.
**셋 다 네가 넘긴 값과 일치한다.** (가) 갈래대로 **루트가 직접 친다.**

## 왜 필요한가

계측기를 고치는 것은 굽기이고 굽기는 창을 바꾼다 — 같은 조건을 다시 돌리지 않으면 '계측기가 바뀐 것'과 '주입 조건이 바뀐 것'이 섞여 어느 쪽 때문인지 못 가른다. 그리고 [SLOT-OOW] 가 도착 시각을 찍는 것은 이번이 처음이라 위험 구간 폭과 진짜 분모가 여기서 처음 나온다
