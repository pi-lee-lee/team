## 3. 🔴 아직 못 끝낸 검증 하나 — 실왕복 · **원인 규명됨: 배포 결함이 아니다**

> ### ✅ 00:1x 갱신 — 원인은 **주소 불일치**다. 서버도 펌웨어도 정상이다
>
> monitor 가 탭(t0 = **00:04:34**, DTR 리셋 · 첫 배너 00:04:36)을 열어 장치 로그를 잡았고,
> 루트가 확인했다:
>
> | 사실 | 값 |
> |---|---|
> | 이 머신 현재 IP | **192.168.35.81** (`ifconfig en0`) |
> | 펌웨어가 부르는 곳 | **192.168.35.21** (`client.ino:97` `#define SERVER_IP`) |
> | 장치 로그 | `AT+CIPSTART="TCP","192.168.35.21",9991` → `ERROR` → `Unlink` 반복 |
> | `.21` | **비어 있다**(ping 무응답) |
> | 내 서버 | **정상** — pid 18422 · `TCP *:9991 (LISTEN)` |
>
> **원인 추정**: 21:05 재부팅 뒤 DHCP 가 다른 주소를 줬다.
> (확정된 것은 "지금 .81 이고 장치는 .21 을 부른다"까지다)
>
> 🔴 **즉 배포 4항목 중 3개 통과이고, 나머지 하나는 배포와 무관한 외부 원인으로 막힌 것이다.**
> **이 배포를 "미검증"으로 읽지 마라.** 서버는 리슨·하트비트 모두 규약대로 돌고 있고,
> 장치의 TCP 가 **서버까지 오지도 않았다**(`+? 연결 수락` 0건).
>
> **처치**: 이 머신에 `.21` 을 **별칭으로 붙인다**(`sudo ifconfig en0 alias 192.168.35.21`, 사용자 실행).
> 펌웨어를 안 건드리므로 **t0 가 유지된다.** 다시 굽지 않는 이유가 하나 더 있다 —
> `.81` 로 구우면 **밤새 DHCP 가 또 바뀌는 순간 창이 조용히 죽는다.** 별칭은 그것과 무관하다.
>
> 🔑 **서버 재기동이 필요 없다는 것을 내가 확인했다**: 리슨이 **와일드카드(`*:9991`)** 라
> 특정 IP 바인드가 아니다. **별칭을 붙이면 이미 열려 있는 소켓이 그 주소를 자동으로 포함한다.**
> → 인스턴스 · pid 18422 · `build=` · t0 **전부 유지된다.**
>
> ⚠ **구간 경계**: `00:04:34 ~ 링크 성립` 은 λ 기준선에 못 넣는다. 다만 이 구간을
> **"서버 없는 재시도"로 적으면 틀린다** — 서버는 내내 정상이었다. 정확히는
> **"장치가 아무도 없는 주소를 부른 구간"** 이다. 그렇게 안 적으면 다음 사람이 서버 장애로 읽는다.

**보드가 아직 안 붙었다.** 00:04:45 기준 **세션 0회 · 프레임 0 · 링크없음 00:02:00.**

- 서버 수신 경로는 **규약대로 동작 중**이다(리슨·하트비트 정상).
- **`fake_arduino` 를 운영에 붙이지 않는다** — 가짜 자료가 운영 로그에 들어가면
  사후에 진짜와 구별되지 않는다(원장 §8.2). 도구가 이제 거부하기도 한다.
- 원인은 내 도메인이 아니다. **관측만 적는다.** 보드는 23:58:58 에 갓 구워졌고,
  서버는 21:04:50~00:02:44 동안 없었다.

→ **실왕복은 보드가 붙는 즉시 확인해서 따로 알린다.**
→ **하행 주입도 그때까지 시작하지 않는다**(아래 4).

## 4. 🔴 주입기에서 **없는 고장을 만들어 낼 뻔한 결함**을 잡았다 (배포 전 발견)

`downlink_inject.py` 가 **`type:"ack"` 만 보고 있었다.** 그런데 장치가 오프라인이면
서버는 ACK 가 아니라 **`{"type":"error","code":"device_offline"}`** 를 돌려주고
**전선에는 아무것도 안 내보낸다**(`server.cpp:1799·1810·1851` → `send_err`).

**고치기 전 동작**: 그 error 를 못 알아보고 흘림 → 30초 timeout → 기록에 "응답 없음"
→ **monitor 가 D1/D2(장치가 못 받았다)로 셈.**
🔴 **그러나 ①이 아예 없었다. 하행 경로를 시험한 적이 없다.**
**없는 하행 고장을 만들어 내는 자리였다** — 하필 지금처럼 **보드가 안 붙어 있을 때** 터진다.

**고친 뒤**(시험 인스턴스 실측, 00:04:59):
```
= 미주입 inj-1 — 장치 오프라인(서버가 전선에 안 내보냈다). 🔴 이것은 하행 실패가 아니다
▣ 시도 2 · ACK(result=4) 0 · 미주입(서버거절) 2 · 응답없음 0
```

→ **분모 규칙을 요약에 박았다: 분모는 `시도` 가 아니라 `시도 − 미주입` 이다.**

⚠ **monitor 는 이 구분을 알고 읽어야 한다.** `미주입` 은 D0~D3 어디도 아니다 —
**주입 자체가 없었던 것**이라 D3(미실행)에 가깝다.
