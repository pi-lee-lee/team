# REQ-0149 · [통보] 보드가 서버에 안 붙는 원인을 찾았다 — 맥 IP 가 .21 에서 .81 로 옮겨갔다(펌웨어·보드 문제 아님) · .81 판 빌드 대기

**통보자** `arduino-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# 보드가 서버에 안 붙는 원인을 찾았다 — **맥의 IP 가 옮겨갔다** (펌웨어·보드 문제 아님)

**지시받지 않고 한 조사다.** socket 이 관측을 넘겨줬고(명령 아님), 원인 규명이 내 도메인이라 바로 팠다.
**보드는 건드리지 않았다.**

## 무엇을 찾았나

```
펌웨어가 거는 곳 : 192.168.35.21:9991    strings arduino/.burn/out/client.ino.elf | grep CIPSTART
이 맥의 현재 IP  : 192.168.35.81         ipconfig getifaddr en0
이 맥이 .21 을 갖고 있나 : ❌ 없다        ifconfig 전수 (35.81 · 192.168.2.1 뿐)
```

**보드는 `.21` 로 SYN 을 쏘고 서버는 `.81` 에서 듣는다.** 서로 다른 주소다.

## 내 굽기가 원인이 아니라는 증거

직전 칩 `fa52a51` 도 **같은 `192.168.35.21:9991`** 이었다
(`git show fa52a51:조별과제샘플/client.ino` L90-91). **그 펌웨어로 A 창 3.2시간을 정상 통신했다.**

> **즉 펌웨어는 안 바뀌었고 주소가 옮겨갔다.** 21:05 재부팅에서 DHCP 임대가 `.21` → `.81` 로 바뀌었다.
> `539ac53` 은 송신 게이트만 건드렸고 IP·포트·접속 사다리는 안 건드렸다.

## 왜 진단이 오래 걸리는 부류인가 — **서버 로그가 완전히 빈다**

`+? 연결 수락` **0건**. 붙었다 끊기는 것이 아니라 **아예 안 온다.**
**서버측에서는 "보드가 죽었다"와 구별되지 않는다.** socket 이 그 상태에서 4분을 썼고,
모르면 다음엔 없는 보드 고장을 쫓게 된다.

⚠ 8/15 의 `DNS Fail`(`SERVER_IP` 앞 공백)과 **기전은 다른데 지문이 같다** — 둘 다 서버 로그가 빈다.
→ **로그가 비면 주소부터 대조하라.** 위 두 명령이면 끝난다.

## 🔴 묶어서 읽으면 안 되는 것

**IP 불일치 하나로 "연결 0건"이 전부 설명된다. 보드가 멀쩡해도 이 그림이 나온다.**

- **나는 보드가 정상 동작 중인지 모른다.** 굽고 나서 **일부러 포트를 안 열었다**(그 DTR 이 `t0` 를 둘로 만든다).
- 있는 증거는 23:59 덤프가 32768바이트를 정상으로 읽혔다는 것뿐 — **부트로더 응답이지 앱이 도는 증거가 아니다.**
- **주소를 맞춘 뒤에야 "보드가 사는가"를 물을 수 있다.**

## 권고 — 다시 굽지 말고 호스트 주소를 되돌려라 (조치는 내 도메인 밖)

| 선택지 | 대가 |
|---|---|
| **호스트를 `.21` 로 되돌린다(고정 IP·DHCP 예약)** | 보드 미접촉 · 리셋 0 · 즉시 확인 ✅ |
| 펌웨어에 `.81` 을 박아 다시 굽는다 | 리셋 1회 + 관측 경계 1개 + **다음 재부팅에 또 깨진다** ❌ |

### ❌ 내가 이 권고에 붙인 근거 하나는 틀렸다 — **정정한다**

*"`t0` 앞이라 지금이 공짜다"* 라고 썼다. **그 전제는 이미 죽어 있었다** —
monitor 가 **`00:04:34` 에 탭을 열었고 그것이 `t0`** 였다(첫 배너 `00:04:36`). 내가 모르는 사이였다.

> **결론은 안 바뀌지만 근거를 바꿔야 한다.**
> 이 조치가 싼 이유는 **"창 앞이라서"가 아니라 "관측 경계를 안 만들어서"** 다 —
> 보드를 안 건드리고 리셋이 없다. 그건 창 안이든 밖이든 참이다.
>
> ★ **개입의 값은 "언제 하는가"보다 "관측 경계를 만드는가"로 먼저 따져야 한다.**
> 앞의 것은 내가 판정할 수 있고, 뒤의 것은 남의 상태라 물어야 한다.
> **창이 열렸는지를 내가 안다고 가정한 것이 실수다.**

### ✅ 그리고 이 처치는 생각보다 더 싸다 (socket 확인)

**서버 재기동조차 필요 없다.** 서버가 **와일드카드로 리슨**한다(`TCP *:9991`).
특정 IP 바인드가 아니라서 **별칭을 붙이면 이미 열린 소켓이 그 주소를 자동으로 포함한다.**
→ 인스턴스·pid `18422`·`build=22f788d`·`t0` 가 **전부 유지된다.**
즉 **보드 미접촉 · 리셋 0 · 서버 재기동 0.**

🔑 **이 조치가 보드 생사 확인을 겸한다**: 서버가 없으면 이 펌웨어는 **백오프 없이 0.90초 주기로
재시도**하므로(원장 §1.5) **주소가 맞는 순간 1초 안에 붙는다.** 안 붙으면 그때 보드가 후보다.
**포트를 안 열고 얻는 판정이라 리셋을 아낀다.**

⚠ **호스트 네트워크 설정은 arduino 도메인이 아니다. 내가 손대지 않았다.** 발견만 하고 넘긴다.

## 대비책을 만들어 뒀다 — `.81` 판 **빌드까지만** (루트 지시)

사용자가 `sudo` 를 안 쓰겠다고 하면 굽는 갈래로 간다. 그때 즉시 굽도록 **빌드만** 해 뒀다.

```
arduino/.burn/alt81/client/client.ino   ← 소스 사본
arduino/.burn/alt81/out/                ← 빌드 산출물
확인: strings …/client.ino.elf | grep CIPSTART
      → AT+CIPSTART="TCP","192.168.35.81",9991   ✅
빌드: 21758B(67%) · RAM 1068B(52%)  — .21 판과 동일(문자열 길이가 같다)
```

🔑 **저장소의 `조별과제샘플/client.ino` 는 건드리지 않았다.** 사본에서만 바꿨다 —
지금 **칩과 저장소 소스가 일치**하는 상태이고(REQ-0144), 저장소를 고치면 그 보증이 깨진다.

⚠ **`diff` 로 한 줄만 바뀐 것을 확인했다.** 처음 `sed` 가 **8/15 `DNS Fail` 사고를 인용한 주석
두 줄까지 바꿨다** — 그건 그때 실제로 관측된 문자열(`" 192.168.35.21"`, 앞 공백)이라
**고치면 기록이 위조된다.** 정의 줄만 바꾸도록 다시 만들었다.

> 🔴 **굽는 결정이 나면 먼저 커밋해야 한다.** `BURN-CHECKLIST` 0단계:
> **커밋되지 않은 변경을 구우면 그 뒤 관측을 어느 소스에도 귀속할 수 없다.**
> 사본 빌드를 그대로 올리면 정확히 그 상태가 된다. **굽기 전에 저장소에 반영 → 커밋 → 그 해시로 굽는다.**

⚠ **포트를 열지 않았다.** 지금 탭이 열려 있어 충돌한다. 굽는다면 monitor 의 탭 내리기 순서를
루트가 잡은 뒤에만 한다.
