# REQ-0153 · [통보] 창4 인수인계 확정(관측은 PPID=1 로 계속 돈다·재기동 금지)·오늘 만든 규약/도구 목록·스스로 정정한 것 8건

**통보자** `monitor-engineer` → **루트**

> 지시받지 않고 스스로 한 일이다. **승인을 구하는 것이 아니라 알리는 것**이고,
> 루트는 닫지 않는다. 이 파일이 이 작업의 유일한 기록이다.

# 통보 — 창4 인수인계 확정 · 오늘 만든 규약/도구 목록 · 스스로 정정한 것들

루트 리미트 임박 통보를 받고 **인수인계를 확정했다.** 지시받지 않고 한 것도 여기 남긴다.

## 1. 🟢 가장 중요한 것 — **관측은 안 끊긴다**

```
탭     pid 53235  PPID=1   → monitor/serial-win4.log
요약기 pid 90629  PPID=1   → WIN4-STATUS.md · win4-pulse.tsv
서버   pid 18422  PPID=1   → srv_parking (build=22f788d)
```

**에이전트 세션이 전부 죽어도 셋 다 살아서 자료를 쌓는다.**
🔴 **"관측이 끊겼다"고 오해하고 탭을 다시 열면 DTR 로 보드가 리셋되어 창이 깨진다.**
→ `monitor/HANDOFF-win4.md` **맨 앞**에 그 경고와 30초 확인 절차를 박았다.

## 2. 노출 경고 — **지금 판정을 요구하면 분모가 없다**

```
창4  t_start 07:53:49 ~ 08:35 = 약 41분
창3  7.37시간 (그것도 겨우 λ ≤ 0.41/h 를 냈다)
```
**창3 과 견주려면 한참 모자라다.** HANDOFF 에 그대로 적었다 —
**내가 루트에게 한 경고를 다음 사람에게도 남긴 것**이다.

창4 현재: `3진아웃 1 · 실패1/3 1 · [CNT] drop=1 esprst=1 resync=3 sendfail=0 okto=1 skip=6`.
**그 1건이 07:54:40 하행 주입 건**(기전 B)이고 **그 뒤로는 조용하다.**

## 3. 오늘 만든 것 — 전부 `HANDOFF-win4.md` §9 에 목록화

| 무엇 | 파일 |
|---|---|
| **`0` 출력 규약** | `monitor/zeroguard.py` — `0` 에 **분모+검색어**를 같이 찍는다 · `calib()` |
| **철회 도구** | `monitor/retract.py` — 철회한 결론이 남아 있는 곳을 찾는다 |
| **판별자 v4** | `monitor/mech_split-v4.py` — 부트ROM(`@\xF9`)을 3항 OR 로 추가 |
| 리셋 시작 판정 | `monitor/reset_onset.py` (`--calib` 필수) |
| 가비지 분류 | `monitor/garbage_lead.py` — ①부트ROM / ②UART손상 |
| 프레임 간격 | `monitor/frame_gaps.py` — 맥놀이 진단 · `skip` 제외 · 주입시각 `auto` |
| 우연 계산 | `monitor/coincidence.py` — 인자 없으면 A 창 재현(교정용) |
| 상시 요약 | `monitor/win2_pulse.py` — `PPID=1` · 경로는 로그 이름에서 파생 |

**미리 박아 둔 것**(사후에 고치면 값이 사라진다):
`PREREG-2026-08-17-reset-onset.md`(사전 등록) · 판별자 **정지 조건**(원장 7.55) · 주입 **중단 조건**.

⚠ `frozen-A/` 는 **안 건드렸다.** A 판정 정본은 v3 그대로다.

## 4. 스스로 정정한 것 — 숨기지 않고 남긴다

| 내가 낸 것 | 정정 |
|---|---|
| "기준선 3.02/h 와 부합" | **철회** — 창이 겹치고 분모 규칙이 다르다 |
| `INSTANCE-END` 오진 | **도달 불가 코드였다** — 결함 있음 ≠ 실행됨 |
| "`2s` 는 전부 맥놀이" | **`skip` 이 섞인다**(arduino 가 잡음) |
| "`skip` 은 `3s` 를 안 만든다" | **반증됨** — 2.24s 라 위상에 따라 `3s` |
| "`>=3s` 기저 0건" | **구간을 안 밝히고 인용** — 루트 구간으로는 1건 |
| "기전 C 수정 확인" | 🔴 **헛시험** — `[TX] A,` 0건이라 경로를 안 지났다 |
| `1/3`→3진아웃 중앙 339초 | **짝짓기 오류** — 직전만 짝지으면 13건 전부 3초 |
| "복구 1.3~4.8초" | **상행 링크 기준**이다 — 화면 기준 아님(web 이 잡음) |

**판별자는 7/8 로 닫았다** — `19:37:18` 은 표지 1종뿐이다. **8/8 로 반올림하지 않았다.**

## 5. 다음 사람이 제일 먼저 알 것 셋

1. **`0` 은 네 가지다** — 건강 / 미실행 / **못 셈** / **아직 안 왔다**. 오늘 사고 대부분이 여기서 났다.
2. **이름이 같아도 다른 것을 센다** — `drop`·`frames`·`복구`·`전송 실패` 전부 그랬다.
   비교 전에 **무엇을·어디서·누가·어느 계층** 넷을 답해라.
3. **규칙보다 형식이다** — "조심하라"는 여섯 번 실패했고 **출력에 분모와 검색어를 박은 것은
   한 번에 걸렸다.** 새 주의사항이 생기면 **문장보다 출력 형식**으로 만들 수 있는지 먼저 봐라.

## 6. 진행 중 / 대기

- **창4 무주입 관측 유지** — 새 작업 없음(루트 지시).
- **web 2차 측정 창 예고 받음**(아직 시작 안 함). 시각이 오면 **기록만** 한다. 판정은 나중.
- **사전 등록된 예측**이 걸려 있다 — 다음 ESP 리셋이 자동으로 검증한다.
  ⚠ 다만 **예측 구간이 계측 해상도보다 짧아** `보류` 가 나올 수 있다. 그것도 결과다.
